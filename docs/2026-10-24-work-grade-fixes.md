## 范围与验收

1. AES 页面：输入、密钥、参数、文件变化或 Ctrl/⌘+L 清空后，正在等待的旧任务不得写回文本、下载、状态或使用事件。每次操作使用开始时的输入和文件名；旧任务结束不得解除新任务的忙碌状态。只改页面交互，保留受保护引擎逐字不变。用完整页面脚本、真实 Web Crypto 与可控制的异步完成边界做回归，并重跑原浏览器复现。
2. 工具搜索：让 `json 포맷` 与常见韩文词形找到 JSON Formatter，空格和拉丁/韩文连写都适用。别名须明确限定用途；保留每个查询词都要命中、精确名称/slug 优先及已有查询的完整排序。验证首页和工具目录的四语入口。
3. 移动端 LCP：用修复前五页的远程 PSI 数据定位共同瓶颈，再对单一变量做对照。变更须保持广告、统计与敏感页策略，CSS 隔离和顺序仍通过构建门禁。将有效的前后测量与排除的样本分开记录；本机负载门槛仍为前/中/后小于 10，缺少字段数据时不宣称 INP 达标。

## 首屏加载方案

同一时段的远程 PSI：AES 敏感页 LCP 1.7 秒，普通 GIF 页 5.6 秒、首页 5.3 秒；普通页仍有约 177–182 KiB 未使用 JavaScript，CSS 估算收益 0.15–0.51 秒。先调整广告加载时机，再由远程前后测量验证收益；这些跨页面对照尚不能独立区分全部第三方影响。

非文章页的 AdSense 在 DOM 就绪、正文获得绘制机会后，于浏览器空闲时追加原有 async / anonymous 脚本。手动广告位继续使用原队列。隐藏页等可见后启动，重复初始化只追加一次。博客文章上方有广告位，保留其加载时机。敏感页继续不输出 AdSense 或 GA 引导，GA 统计机制不变。CSS 合并只作为未采用的诊断变量。
