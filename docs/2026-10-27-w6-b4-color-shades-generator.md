## Reviewed, no change

- **50–950 scale and OKLCH model** (en:29-34, zh:29-34, ja:29-34, ko:29-34): 11 steps; lightness from the two surrounding 500 hues of Tailwind v4's 17 chromatic palettes; median of the 9 neutral palettes for grays (`component:307-317`); chroma curve; constant hue; CSS Color 4 §14.1.3 chroma reduction. CSS Color 4 is a CRD dated 27 October 2026, where §9.2 is Oklab / OkLCh and §14 is Gamut Mapping / §14.1.3 Chroma Reduction — both links and section numbers are current.
- **Worked examples** (en:38-98, zh:38-96, ja:38-84, ko:38-91): `#3b82f6` at 500 (base OKLCH L 62.308% vs Tailwind v4 blue-500 62.3%), `#1677ff` at 500, `#4979f5` at 500, `#256ef4` at 600; the `@theme`, SCSS, CSS and v3 exports; `#facc15` with −35° at 950 and `#5d4b0a` at 900 without the shift. Regenerated by the test, not hand-copied.
- **Contrast tables and labels** (en:104-110, zh:102-108, ja:90-96, ko:97-103): the tool floors ratios to 2 decimals (`component:712-717`), so 4.499 never displays as 4.50. The grade labels are AAA ≥ 7, AA ≥ 4.5, "AA Large" ≥ 3 (`component:714`, `815`); WCAG 2.2 asks 4.5:1 body / 3:1 large.
- **Tailwind v4 reference**: Tailwind's docs confirm 11 steps per color and 26 palettes (17 chromatic + 9 neutral, including taupe / mauve / mist / olive). Yellow-50 hue 102.212, yellow-950 53.813 → 48.4° hand-tuned shift, matching "about 50 degrees" in the en FAQ. The v4 blue-500 value is `oklch(62.3% 0.214 259.815)`.
- **"Many v4 colors are outside sRGB"** (en:15): using the engine's gamut test on `theme.css`, 82 of 286 palette values and 14 of 26 500 steps are outside sRGB, so the statement and the P3 note at en:124 hold. (The `#3b82f6` example is the v3 blue; v4's blue-500 maps to `#3180ff` in sRGB.)
- **Ant Design** (zh:15, zh:58-60): the official page confirms the HSB model, the 10-color generated palette, the sixth-color recommendation and `#1677FF`; the published `blue` array is `#E6F4FF … #001D66`. The tool's engine gives OKLCH hues 241.3° → 262.6° (21.3°) for that array, and 258.4–259.4° for its own scale except step 50 (254.6°, chroma 0.0142) — the numbers in zh:60 reproduce.
- **DADS** (ja:58-60): the color page states the 4.5:1 primary-color requirement; the palette page says Blue has 13 tones, Gray-420 is the 3:1 boundary and Gray-536 the 4.5:1 boundary against white. `#949494` = 3.03:1 and `#767676` = 4.54:1 with the tool's floor rule; `#3460fb` = 4.98:1 (4.986 floored). The DADS pages do not print those hex strings, so the hex values themselves are the earlier audit's tokens (see Unverified).
- **KRDS** (ko:40-58): magic numbers 40 / 50 / 70 / 90 = 3:1 / 4.5:1 / 7:1 / 15:1 and the 13-step (gray) / 11-step (other hues 5–95) rule match the fetched page. The tool's 600 = `#256ef4` and the KRDS column ratios (1.12 … 19.08) recompute with the floor rule from the printed hex values; `#020f27` white-text is 19.09 rounded, 19.08 floored.
- **Limits** (en:124-130, zh:120-127, ja:108-115, ko:115-122): sRGB-only output; ±180° linear hue shift; 11 fixed steps; input formats 3/4/6/8-digit hex + `rgb()` / `hsl()` / `oklch()`, alpha ignored, named colors / `lab()` / `lch()` / `color()` rejected (`component:488-545`); contrast against pure white and black only, no APCA, no shade-to-shade test.
- **Privacy / storage / analytics** (FAQ, all four languages): the component has no `localStorage`, `sessionStorage`, `ztPersist`, `fetch`, XHR or `sendBeacon` call (test asserts the script text); `persistence.ts:10-60` has no `color-shades-generator` key and `network.ts` has no entry. `update()` sends nothing; `trackTool` fires `generate` on `change` of the text / picker / hue / name / select fields (`component:889-901`), `copy_all` / `copy_shade` / `download` on the three exits (`827`, `908`, `922`). `?color=` is read on load only when it parses (`929-933`) and `ImageColorPaletteTool.astro:898-900` is the writer; the color therefore is part of the page address and the page-view note is correct.
- **Component strings** (10 groups): the seven tips, five export names, four value names, the mapped / collapsed / alpha / gamut / v3 / name notes, five parse errors, card aria labels, status auto / locked and `copyFailed` all match their handlers (`component:14`, `44-56`, `637-675`, `712-819`, `871-886`). The STRINGS key and placeholder parity is asserted by the test for all four languages.
