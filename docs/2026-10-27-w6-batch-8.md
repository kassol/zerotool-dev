## 修正要点

- **json-formatter**：`JSON.parse` 等价性排除开头的 BOM；与 `python3 -m json.tool` 的字节一致加上「Sort keys」并排除末尾换行；`ensure_ascii` 的范围改为可打印 ASCII（DEL 也转义）；zh / ja / ko 的 UTF-8 错误列号去掉「从 0 计」；zh / ko 的 `--sort-keys` 命令补全；JSON5 说明改用实际的 `", "` 连接。
- **openapi-validator**：隐私题补上 Web Worker 无法创建时的主线程回退；大文件窗口补 49,152 字符上限；URL 引用始终只记为提示，只有本地缺失文件才能添加；表格改为「本地 `$ref`」；2 MB / 50 MB 改为 2,097,152 字符 / 50 MiB；ja 补 `nullable` 警告行、draft-04 引文与「基于 2020-12 的方言」。
- **jq-playground**：ja 的「jq 1.7.1 从不打印列号」改为「解析错误打印、编译错误不打印」；空输入的末尾换行说明；Ctrl/⌘+L 只在焦点位于工具内时清存储；`copy` / `share` 事件范围；`$ENV` / `env` 与 `localtime` 说明；`--indent -1` 为 jq 合法而本页不支持；zh 退出码位置改为状态行。
- **sprite-sheet-generator**：Web3D Survey 的 Android 8192 px 支持率 77% → 75%；GIF 预算按「画布面积 × 帧数」；Unity 不再推荐无 Unity 导出的 free-tex-packer；en PixiJS 示例补构造参数；zh CSS 像素比建议补外边距。
- **glassmorphism-generator**：分析事件列表补上输出格式、预览背景与预览状态；删除未实测的「重载恢复默认」保证；ja 补 `prefers-reduced-transparency` 与 `forced-colors` 名称；ja / ko 的强制颜色说明补「滤镜也被禁用」；zh 的「扩散」改为「模糊」。

## 发现的问题

- **B 档（未改）**：json-formatter 的 50 MB / 2 MB / 1 MB 标签实际是 50 MiB / 2,000,000 code units / 1,000,000 characters；`steps` 仍写 2 MB。jq 的「1 s per MB」按 UTF-16 字符计，与页面提示的 MB 不一致。openapi 的「larger than 2^53」被测试逐字锁定。
