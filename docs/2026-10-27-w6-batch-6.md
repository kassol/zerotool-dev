## 修正要点

- **string-escape**：SQL 注入原因改为「方言与配置（如 `NO_BACKSLASH_ESCAPES`）+ 字符集」；CSV / Shell 反转义范围按引擎写；RFC 4180 的 requires 改为 may not；去掉 JS NUL 与 HTML emoji 的「唯一写法」绝对说法；补全角 `＝＋－＠`；36 万字符耗时改为约 1 秒。
- **htpasswd-generator**：255 字节上限是本工具的，不是 htpasswd 的（Apache 只在 Windows 截断 255 字符）；zh 示例 29 字符 / 87 字节；第三字段会让 Apache 登录失败，四语警告重写；CRYPT 截断 8 字节（非 8 字符）；文件上限 1 MiB。**主会话修复**：`htpw-check` 在匹配成功且该行有第三字段时追加四语 `checkExtraField`，不再暗示 Apache 也能登录；回归 1,578 项通过。
- **number-base**：按 BigInt / Python / 补码与页面示例复核 278 条；23 条未复核项（部分竞品与 Excel 数字）保留 unverified。
- **css-clip-path-generator**：几何气泡的滑块范围由 5–100% / 0–49% 改为实际的 0–100%；动画 FAQ 要求同一 reference box；MDN BCD 8.1.4 → 8.1.7，版本数字复核不变。
- **protobuf-to-json**：ja 示例 54 → 52 字节（protoc 36.2 重编码）；Duration 输出 `1.500s`；grpc-web-text 是一个 Base64 流；editions 没有 group / required；关闭枚举的未知值转入 unknown fields；Any 的回退是 `value` 里的 Base64；组件「其他解读」按 wire type 改写。

- **B 档（代码，未改）**：protobuf FieldMask 路径 `_x` 写出 `"X"`（Go protojson 拒绝）；edition 2026 报「不支持」但页面未说明；ko UTF-8 示例用 0 基字节偏移。属引擎或示例范围，留给后续批准。
