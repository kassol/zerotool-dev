## 修正要点

- **text-to-binary**：分组规则改为「超过 8 位的组必须是 8 的倍数；没有长组时 1–7 位组按前导零补成一个字节」；状态行的码点计数只在不同于字符数时显示；错误说明补短组与长组混排、字符位置；旧编码按 UTF-8 读取的实际后果与 UTF-16 反例；统计措辞与 BOM / 控制字符说明按代码收窄。
- **url-parser**：WPT 通过数由 888/896 改为 883/891（Node 24.14.0，891 例，8 个 `xn--` / IDNA 失败）；浏览器不把查询百分号转义按 UTF-8 解码，`URLSearchParams` 与本工具才这样；EN 的主机小写 / Punycode / 默认端口限定到特殊协议；补 fragment 不发送与 `fetch()` 拒绝带凭据 URL；RFC 3986 徽章改为「本检查没发现问题」；主机大小写编辑的 `ignored` 说明按实际行为改写。
- **markdown-table-generator**：统计去重键是「格式 + 输出」，换格式会再记一次；CJK 旁 `**` 的问题改为「closing `**` 在标点后不能闭合」；文件上限 10 MiB（10,485,760 字节）；旧编码通常是首个无效 UTF-8 字节被拒，合法 UTF-8 的旧编码会读成别的字符（GBK `模` C4 A3 → `ģ`，EUC-KR `홍` C8 AB → `ȫ`）。
- **image-color-palette**：CSS Color 4 链接改为 `#GM-chroma-local-MINDE`；导出说明改为「值列表 / JSON 不含分享注释」；「可见像素」改为「过滤后剩下的组」；P3 提示写「至少 0.1%」；GIF 不再承诺第 0 帧；ja 的「最常见的色调」按最重的 5 位组；隐私题补设置清除与统计动作。
- **svg-optimizer**：韩国国旗变大归因到 `convertPathData`（禁用后 581 B；禁用 `convertTransform` 仍 816 B）；删除「可拖入文件夹」与「可从 ZIP 排除变大文件」；10 MiB 比对上限补「结果超过」条件；ko 的 viewBox 说明改为「不随 CSS 缩放」；精度 0–1 位改为「可能被比对发现」；拆分 inlineStyles / minifyStyles；4.1.0 `foreignObject` 清理范围按 release notes 写明。

## 发现的问题

- **B 档（未改）**：text-to-binary 的 UTF-16 无 BOM 可能静默按 ASCII 通过（已写入限制，未加检测）；url-parser 的 RFC 3986 检查接受 `http://[:::]`（徽章已改为「没发现问题」）；markdown-table 的 10 MiB 读取仍可能在大文件上停顿。
- **C 档**：image-color-palette 的 Adobe `.ase` 应用列表与 HEIC 仅 Safari 未取得一手来源；svg-optimizer 的 KRDS 91 图标汇总与 0.57% 像素数未安装 `krds-uiux` 复核。
- **未核实**：各工具 2026-10-01/02 竞品与浏览器观察保留日期，未重跑。
