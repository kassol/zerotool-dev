<h2>使用方法</h2>
<ol>
  <li>将 JSON 粘贴或输入到左侧面板，工具会实时验证。</li>
  <li>可选设置<strong>根类名称</strong>（默认：<code>RootObject</code>）。</li>
  <li>选择注解模式：<strong>无注解</strong>、<strong>Jackson</strong>、<strong>Gson</strong> 或 <strong>Lombok (@Data)</strong>。</li>
  <li>点击<strong>生成 Java</strong>，或等待实时转换结果。</li>
  <li>点击<strong>复制</strong>将输出复制到剪贴板。</li>
</ol>

<h2>类型映射</h2>
<ul>
  <li><code>null</code> → <code>Object</code></li>
  <li>字符串 → <code>String</code></li>
  <li>整数 → <code>int</code>，超出 int 范围（±2,147,483,647 左右）时 → <code>long</code></li>
  <li>浮点数 → <code>double</code></li>
  <li>布尔值 → <code>boolean</code></li>
  <li>数组 → <code>List&lt;T&gt;</code></li>
  <li>嵌套对象 → 独立 <code>public class</code></li>
</ul>

<h2>示例</h2>
<p>给定如下 JSON：</p>
<pre><code>{`{"user": {"first_name": "Alice", "age": 30}, "tags": ["admin"]}`}</code></pre>
<p>Lombok 模式下生成：</p>
<pre><code>{`import java.util.List;\nimport lombok.Data;\n\n@Data\npublic class RootObject {\n    private User user;\n    private List<String> tags;\n}\n\n@Data\npublic class User {\n    private String firstName;\n    private int age;\n}`}</code></pre>

<h2>示例：带嵌套明细的订单（Jackson 模式）</h2>

<p>输入：</p>

<pre><code>{`{"order_id": 9007, "customer": {"name": "Alice", "vip": true}, "items": [{"sku": "A-1", "qty": 2, "price": 9.5}, {"sku": "B-2", "qty": 1, "price": 20}], "note": null}`}</code></pre>

<p>输出（省略了 getter / setter）：</p>

<pre><code>{`import java.util.List;
import com.fasterxml.jackson.annotation.JsonProperty;

public class RootObject {
    @JsonProperty("order_id")
    private int orderId;
    private Customer customer;
    private List<ItemsItem> items;
    private Object note;
    // getters and setters omitted here
}

public class Customer {
    private String name;
    private boolean vip;
    // ...
}

public class ItemsItem {
    private String sku;
    private int qty;
    private double price;
    // ...
}`}</code></pre>

<p>这段输出不能整体存成一个文件编译：每个 <code>{"public class"}</code> 必须放在同名文件里。拆成 <code>{"RootObject.java"}</code>、<code>{"Customer.java"}</code>、<code>{"ItemsItem.java"}</code> 三个文件后，「无注解」模式的输出可以直接用 javac 21 编译。</p>

<h2>生成后要检查的地方</h2>

<ul>
  <li><code>{"price"}</code> 是 <code>{"double"}</code>：第一个元素是 <code>{"9.5"}</code>、第二个是 <code>{"20"}</code>，工具把 <code>{"int"}</code> 和 <code>{"double"}</code> 合并成更宽的 <code>{"double"}</code>。金额建议改用 <code>{"BigDecimal"}</code>。</li>
  <li>样例里的 <code>{"null"}</code> 会变成 <code>{"Object"}</code>，请换成真实类型。</li>
  <li>样例里超出 int 范围的整数（如毫秒时间戳 <code>{"1730000000000"}</code>）会生成 <code>{"long"}</code>；样例值小、实际可能变大的 ID 请自己改成 <code>{"long"}</code>。</li>
  <li>Lombok 模式不会加 <code>{"@JsonProperty"}</code>，<code>{"order_id"}</code> 不再映射到 <code>{"orderId"}</code>：</li>
</ul>

<pre><code>{`import java.util.List;
import lombok.Data;

@Data
public class RootObject {
    private int orderId;
    private Customer customer;
    private List<ItemsItem> items;
    private Object note;
}`}</code></pre>

<p>Lombok 模式下请自己补 <code>{"@JsonProperty"}</code>，或给 Jackson 配置 <code>{"PropertyNamingStrategies.SNAKE_CASE"}</code>。Gson 模式用 <code>{"@SerializedName"}</code> 做同样的映射。</p>

<p>用 Jackson 读取 JSON：</p>

<pre><code>{`ObjectMapper mapper = new ObjectMapper();
RootObject order = mapper.readValue(json, RootObject.class);`}</code></pre>

<p>Java 16 及以上，简单的不可变模型可以改用 record，Jackson 2.12 起支持读取 record：</p>

<pre><code>{`public record Customer(String name, boolean vip) {}`}</code></pre>
