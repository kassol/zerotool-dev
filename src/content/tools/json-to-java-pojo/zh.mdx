<h2>类型映射</h2>
<ul>
  <li><code>null</code> → <code>Object</code></li>
  <li>字符串 → <code>String</code></li>
  <li>整数 → <code>int</code>，超出 int 范围（±2,147,483,647 左右）时 → <code>long</code></li>
  <li>浮点数 → <code>double</code></li>
  <li>布尔值 → <code>boolean</code></li>
  <li>数组 → <code>List&lt;T&gt;</code></li>
  <li>嵌套对象 → 独立 <code>public class</code></li>
</ul>

<h2>示例</h2>
<p>给定如下 JSON：</p>
<pre><code>{`{"user": {"first_name": "Alice", "age": 30}, "tags": ["admin"]}`}</code></pre>
<p>Lombok 模式下生成：</p>
<pre><code>{`import java.util.List;\nimport lombok.Data;\n\n@Data\npublic class RootObject {\n    private User user;\n    private List<String> tags;\n}\n\n@Data\npublic class User {\n    private String firstName;\n    private int age;\n}`}</code></pre>

<h2>示例：带嵌套明细的订单（Jackson 模式）</h2>

<p>输入：</p>

<pre><code>{`{"order_id": 9007, "customer": {"name": "Alice", "vip": true}, "items": [{"sku": "A-1", "qty": 2, "price": 9.5}, {"sku": "B-2", "qty": 1, "price": 20}], "note": null}`}</code></pre>

<p>输出（省略了 getter / setter）：</p>

<pre><code>{`import java.util.List;
import com.fasterxml.jackson.annotation.JsonProperty;

public class RootObject {
    @JsonProperty("order_id")
    private int orderId;
    private Customer customer;
    private List<ItemsItem> items;
    private Object note;
    // getters and setters omitted here
}

public class Customer {
    private String name;
    private boolean vip;
    // ...
}

public class ItemsItem {
    private String sku;
    private int qty;
    private double price;
    // ...
}`}</code></pre>

<p>这段输出不能整体存成一个文件编译：每个 <code>{"public class"}</code> 必须放在同名文件里。拆成 <code>{"RootObject.java"}</code>、<code>{"Customer.java"}</code>、<code>{"ItemsItem.java"}</code> 三个文件后，「无注解」模式的输出可以直接用 javac 21 编译。</p>

<h2>生成后要检查的地方</h2>

<ul>
  <li><code>{"price"}</code> 是 <code>{"double"}</code>：第一个元素是 <code>{"9.5"}</code>、第二个是 <code>{"20"}</code>，工具把 <code>{"int"}</code> 和 <code>{"double"}</code> 合并成更宽的 <code>{"double"}</code>。金额建议改用 <code>{"BigDecimal"}</code>。</li>
  <li>样例里的 <code>{"null"}</code> 会变成 <code>{"Object"}</code>，请换成真实类型。</li>
  <li>样例里超出 int 范围的整数（如毫秒时间戳 <code>{"1730000000000"}</code>）会生成 <code>{"long"}</code>；样例值小、实际可能变大的 ID 请自己改成 <code>{"long"}</code>。</li>
  <li>Lombok 模式不会加 <code>{"@JsonProperty"}</code>，<code>{"order_id"}</code> 不再映射到 <code>{"orderId"}</code>：</li>
</ul>

<pre><code>{`import java.util.List;
import lombok.Data;

@Data
public class RootObject {
    private int orderId;
    private Customer customer;
    private List<ItemsItem> items;
    private Object note;
}`}</code></pre>

<p>Lombok 模式下请自己补 <code>{"@JsonProperty"}</code>，或给 Jackson 配置 <code>{"PropertyNamingStrategies.SNAKE_CASE"}</code>。Gson 模式用 <code>{"@SerializedName"}</code> 做同样的映射。</p>

<p>用 Jackson 读取 JSON：</p>

<pre><code>{`ObjectMapper mapper = new ObjectMapper();
RootObject order = mapper.readValue(json, RootObject.class);`}</code></pre>

<p>Java 16 及以上，简单的不可变模型可以改用 record，Jackson 2.12 起支持读取 record：</p>

<pre><code>{`public record Customer(String name, boolean vip) {}`}</code></pre>

<h2>示例：同名 key 结构不同、key 不是合法 Java 名（Jackson 模式）</h2>

{/* jjp-check: {"json":"{\"billing\":{\"address\":{\"city\":\"Paris\"}},\"shipping\":{\"address\":{\"line1\":\"1 Main St\"}},\"class\":\"A\",\"2fa\":true,\"URL\":\"https://example.com\"}","mode":"jackson"} */}

<pre><code>{`{"billing": {"address": {"city": "Paris"}}, "shipping": {"address": {"line1": "1 Main St"}}, "class": "A", "2fa": true, "URL": "https://example.com"}`}</code></pre>

<p>输出（省略了大部分 getter / setter）：</p>

<pre><code>{`import com.fasterxml.jackson.annotation.JsonProperty;

public class RootObject {
    private Billing billing;
    private Shipping shipping;
    @JsonProperty("class")
    private String classValue;
    @JsonProperty("2fa")
    private boolean t2fa;
    @JsonProperty("URL")
    private String uRL;

    @JsonProperty("URL")
    public String getURL() {
    // 其余 getter / setter 省略
}

public class Address {
    private String city;
    // ...
}

public class ShippingAddress {
    private String line1;
    // ...
}`}</code></pre>

<ul>
  <li>两个 <code>{"address"}</code> 字段不同，第二个用父级名作前缀（<code>{"ShippingAddress"}</code>）。字段和类型都相同的对象共用一个类；加前缀后仍重名时再加数字。</li>
  <li>Java 关键字和字面量加 <code>{"Value"}</code>（<code>{"class"}</code> → <code>{"classValue"}</code>），会以数字开头的名字加 <code>{"T"}</code>（<code>{"2fa"}</code> → <code>{"t2fa"}</code>），变成同一个名字的 key 依次加数字（<code>{"first-name"}</code> 和 <code>{"first_name"}</code> → <code>{"firstName"}</code> 和 <code>{"firstName2"}</code>）。注解保留原 key。</li>
  <li>Jackson 把 <code>{"getURL()"}</code> 读作 <code>{"url"}</code>，不是 <code>{"uRL"}</code>。getter 和 setter 不加注解时，Jackson 会多出一个属性，读到 <code>{"URL"}</code> 时报错。Gson 只读字段，不需要这条注解。</li>
</ul>

<p>工具的测试用 javac 21、Jackson 2.17.2 和 Gson 2.11.0 编译每段 Jackson / Gson 输出，读入样例再写回，结果与原 JSON 相同；每段 Lombok 1.18.34 输出都能编译。</p>

<h2>限制</h2>
<ul>
  <li><strong>无注解与 Lombok 模式只有 Java 名。</strong>这两种模式下 <code>{"classValue"}</code>、<code>{"t2fa"}</code> 对应不到 <code>{"class"}</code>、<code>{"2fa"}</code>。key 不是合法 Java 名时请用 Jackson 或 Gson 模式。</li>
  <li><strong>Jackson 写不出空 key。</strong><code>{'@JsonProperty("")'}</code> 表示「用默认名」，所以对 key <code>{'""'}</code> 工具写 <code>{'@JsonAlias("")'}</code> 加一行注释：Jackson 能读 <code>{'{"": 4}'}</code>，写回时是 <code>{'{"t": 4}'}</code>。Gson 模式写 <code>{'@SerializedName("")'}</code>，保留空 key。</li>
</ul>
