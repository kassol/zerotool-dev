<h2>使い方</h2>
<ol>
  <li>左パネルにJSONを貼り付けるか入力します。リアルタイムで検証されます。</li>
  <li>必要に応じて<strong>ルートクラス名</strong>を設定します（デフォルト：<code>RootObject</code>）。</li>
  <li>アノテーションモードを選択します：<strong>なし</strong>、<strong>Jackson</strong>、<strong>Gson</strong>、または<strong>Lombok (@Data)</strong>。</li>
  <li><strong>Javaを生成</strong>をクリックするか、リアルタイム変換を待ちます。</li>
  <li><strong>コピー</strong>をクリックして出力をクリップボードにコピーします。</li>
</ol>

<h2>型マッピング</h2>
<ul>
  <li><code>null</code> → <code>Object</code></li>
  <li>文字列 → <code>String</code></li>
  <li>整数 → <code>int</code>（int の範囲を超える値は <code>long</code>）</li>
  <li>浮動小数点数 → <code>double</code></li>
  <li>真偽値 → <code>boolean</code></li>
  <li>配列 → <code>List&lt;T&gt;</code></li>
  <li>ネストオブジェクト → 独立した <code>public class</code></li>
</ul>

<h2>例</h2>
<p>以下のJSONを入力した場合：</p>
<pre><code>{`{"user": {"first_name": "Alice", "age": 30}, "tags": ["admin"]}`}</code></pre>
<p>Lombokモードで生成される出力：</p>
<pre><code>{`import java.util.List;\nimport lombok.Data;\n\n@Data\npublic class RootObject {\n    private User user;\n    private List<String> tags;\n}\n\n@Data\npublic class User {\n    private String firstName;\n    private int age;\n}`}</code></pre>

<h2>例：明細を含む注文（Jackson モード）</h2>

<p>入力：</p>

<pre><code>{`{"order_id": 9007, "customer": {"name": "Alice", "vip": true}, "items": [{"sku": "A-1", "qty": 2, "price": 9.5}, {"sku": "B-2", "qty": 1, "price": 20}], "note": null}`}</code></pre>

<p>出力（getter / setter は省略）：</p>

<pre><code>{`import java.util.List;
import com.fasterxml.jackson.annotation.JsonProperty;

public class RootObject {
    @JsonProperty("order_id")
    private int orderId;
    private Customer customer;
    private List<ItemsItem> items;
    private Object note;
    // getters and setters omitted here
}

public class Customer {
    private String name;
    private boolean vip;
    // ...
}

public class ItemsItem {
    private String sku;
    private int qty;
    private double price;
    // ...
}`}</code></pre>

<p>この出力は 1 ファイルのままではコンパイルできません。<code>{"public class"}</code> は同名のファイルに置く必要があるため、<code>{"RootObject.java"}</code>・<code>{"Customer.java"}</code>・<code>{"ItemsItem.java"}</code> に分けます。分けると「アノテーションなし」モードの出力は javac 21 でそのままコンパイルできます。</p>

<h2>生成後に確認すること</h2>

<ul>
  <li><code>{"price"}</code> は <code>{"double"}</code> です。1 件目は <code>{"9.5"}</code>、2 件目は <code>{"20"}</code> で、ツールは <code>{"int"}</code> と <code>{"double"}</code> を広い方の <code>{"double"}</code> にまとめます。金額なら <code>{"BigDecimal"}</code> に直してください。</li>
  <li>サンプル中の <code>{"null"}</code> は <code>{"Object"}</code> になります。実際の型に置き換えます。</li>
  <li>int の範囲を超える整数（ミリ秒のタイムスタンプ <code>{"1730000000000"}</code> など）は <code>{"long"}</code> になります。サンプルの値が小さくても将来大きくなる ID は、自分で <code>{"long"}</code> にします。</li>
  <li>Lombok モードは <code>{"@JsonProperty"}</code> を付けないため、<code>{"order_id"}</code> が <code>{"orderId"}</code> に対応しなくなります：</li>
</ul>

<pre><code>{`import java.util.List;
import lombok.Data;

@Data
public class RootObject {
    private int orderId;
    private Customer customer;
    private List<ItemsItem> items;
    private Object note;
}`}</code></pre>

<p>Lombok モードでは <code>{"@JsonProperty"}</code> を自分で付けるか、Jackson に <code>{"PropertyNamingStrategies.SNAKE_CASE"}</code> を設定します。Gson モードは同じ目的で <code>{"@SerializedName"}</code> を使います。</p>

<p>Jackson での読み込み：</p>

<pre><code>{`ObjectMapper mapper = new ObjectMapper();
RootObject order = mapper.readValue(json, RootObject.class);`}</code></pre>

<p>Java 16 以降なら、小さな不変モデルはクラスの代わりに record にできます。Jackson は 2.12 から record を読めます：</p>

<pre><code>{`public record Customer(String name, boolean vip) {}`}</code></pre>

<h2>例：同じキーで構造が違う場合と、Java の名前にできないキー（Jackson モード）</h2>

{/* jjp-check: {"json":"{\"billing\":{\"address\":{\"city\":\"Paris\"}},\"shipping\":{\"address\":{\"line1\":\"1 Main St\"}},\"class\":\"A\",\"2fa\":true,\"URL\":\"https://example.com\"}","mode":"jackson"} */}

<pre><code>{`{"billing": {"address": {"city": "Paris"}}, "shipping": {"address": {"line1": "1 Main St"}}, "class": "A", "2fa": true, "URL": "https://example.com"}`}</code></pre>

<p>出力（getter / setter の大部分は省略）：</p>

<pre><code>{`import com.fasterxml.jackson.annotation.JsonProperty;

public class RootObject {
    private Billing billing;
    private Shipping shipping;
    @JsonProperty("class")
    private String classValue;
    @JsonProperty("2fa")
    private boolean t2fa;
    @JsonProperty("URL")
    private String uRL;

    @JsonProperty("URL")
    public String getURL() {
    // 残りの getter / setter は省略
}

public class Address {
    private String city;
    // ...
}

public class ShippingAddress {
    private String line1;
    // ...
}`}</code></pre>

<ul>
  <li>2 つの <code>{"address"}</code> はフィールドが違うので、2 つ目は親の名前を前に付けます（<code>{"ShippingAddress"}</code>）。フィールドと型が同じオブジェクトは 1 つのクラスを共有します。前置きしても名前が重なるときは番号を付けます。</li>
  <li>Java のキーワードとリテラルには <code>{"Value"}</code> を付け（<code>{"class"}</code> → <code>{"classValue"}</code>）、数字で始まる名前には <code>{"T"}</code> を付け（<code>{"2fa"}</code> → <code>{"t2fa"}</code>）、同じ名前になるキーには番号を付けます（<code>{"first-name"}</code> と <code>{"first_name"}</code> → <code>{"firstName"}</code> と <code>{"firstName2"}</code>）。元のキーはアノテーションに残ります。</li>
  <li>Jackson は <code>{"getURL()"}</code> を <code>{"uRL"}</code> ではなく <code>{"url"}</code> と読みます。getter と setter にアノテーションがないと別のプロパティができ、<code>{"URL"}</code> を読むときにエラーになります。Gson はフィールドだけを読むので不要です。</li>
</ul>

<p>ツールのテストでは javac 21、Jackson 2.17.2、Gson 2.11.0 で Jackson / Gson の各出力をコンパイルし、サンプルを読み込んで書き戻すと元の JSON と一致します。Lombok 1.18.34 の各出力もコンパイルできます。</p>

<h2>制限</h2>
<ul>
  <li><strong>なし・Lombok モードは Java の名前しか持ちません。</strong>この 2 つでは <code>{"classValue"}</code>・<code>{"t2fa"}</code> は <code>{"class"}</code>・<code>{"2fa"}</code> に対応しません。キーが Java の名前として使えないときは Jackson か Gson モードを使ってください。</li>
  <li><strong>Jackson は空のキーを書き出せません。</strong><code>{'@JsonProperty("")'}</code> は「既定の名前を使う」という意味なので、キー <code>{'""'}</code> には <code>{'@JsonAlias("")'}</code> とコメントを出力します。Jackson は <code>{'{"": 4}'}</code> を読めますが、書き戻すと <code>{'{"t": 4}'}</code> になります。Gson モードは <code>{'@SerializedName("")'}</code> で空のキーを保ちます。</li>
</ul>
