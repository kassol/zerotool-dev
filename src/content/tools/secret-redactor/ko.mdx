<h2>사용 방법</h2>

<ol>
  <li>도움을 받고 싶은 로그, 스택 트레이스, <code>.env</code>, 설정 파일을 ① 칸에 붙여넣습니다. 입력하는 동안 감지가 진행됩니다.</li>
  <li>카테고리 토글의 개수를 확인하고 <strong>감지 목록</strong>을 펼쳐 일치한 항목을 봅니다. 시크릿이 아닌 것을 잡는 카테고리는 끕니다.</li>
  <li>② 칸의 마스킹된 텍스트를 복사해 ChatGPT, Claude 등 AI 어시스턴트에 붙여넣습니다.</li>
  <li>돌아온 답변을 ③ 칸에 붙여넣으면 남아 있던 플레이스홀더가 실제 값으로 바뀌어, 터미널이나 에디터에 바로 복사할 수 있습니다.</li>
</ol>

<p>복원을 마칠 때까지 ① 칸을 바꾸지 마세요. 플레이스홀더와 값의 매핑은 이 텍스트가 바뀔 때마다 새로 만들어지며 다른 곳에는 기록되지 않습니다.</p>

<p>변수명으로 판단하는 규칙은 이름이 키워드로 <em>끝날</em> 때만 일치합니다. 그래서 <code>max_tokens: 1024</code>나 <code>token_count=12</code>는 치환되지 않습니다. <code>$&#123;DB_PASS&#125;</code> 같은 환경 변수 참조, <code>&lt;your-key&gt;</code> 같은 템플릿, <code>****</code> 같은 가려진 값, <code>true</code>·<code>null</code> 같은 리터럴도 건너뜁니다.</p>

<h2>고엔트로피 검사 방식</h2>

<p>base64 / base64url 문자가 32자 이상 이어진 부분이 후보가 됩니다. 대문자, 소문자, 숫자를 모두 포함하고 섀넌 엔트로피가 문자당 4.2비트 이상일 때만 치환합니다. 같은 길이의 무작위 base64는 평균 약 4.56비트입니다.</p>

<p>대소문자와 숫자가 섞여야 한다는 조건 덕분에 CI 로그가 읽기 좋게 유지됩니다. git 커밋 SHA, MD5·SHA-256 다이제스트, Docker 이미지 다이제스트, UUID는 모두 16진수이거나 한 가지 대소문자만 쓰므로 해당하지 않습니다. lockfile의 <code>sha512-…</code> 무결성 해시, <code>data:</code> URI, 파일 경로, 인증서와 공개 키 본문은 원래 공개 정보라서 명시적으로 제외합니다.</p>

<p>의도된 절충입니다. 옆에 변수명이 없는 32자 16진수 토큰은 이 검사로 잡히지 않습니다. <code>TWILIO_AUTH_TOKEN=…</code>처럼 이름이 붙어 있으면 비밀번호 규칙이 잡아냅니다.</p>

<h2>플레이스홀더 규칙</h2>

<ul>
  <li>형식은 <code>[종류_번호]</code>입니다(<code>[OPENAI_KEY_1]</code>, <code>[URL_PASSWORD_1]</code>, <code>[SECRET_2]</code>). 종류 이름 덕분에 AI는 값을 보지 않고도 무엇인지 알 수 있어 "<code>[AWS_ACCESS_KEY_1]</code>을 교체하세요" 같은 답변이 의미를 가집니다.</li>
  <li>같은 값은 항상 같은 플레이스홀더를 받습니다. 스무 번 나오든 두 규칙에 동시에 걸리든 같습니다.</li>
  <li>번호는 종류별로 매기며, 원문에 이미 있는 플레이스홀더 번호는 건너뜁니다. 붙여넣은 <code>[SECRET_1]</code>이 생성된 것과 겹치지 않습니다.</li>
  <li>이미 마스킹된 텍스트를 다시 처리해도 결과는 같습니다.</li>
  <li>복원은 <code>[OPENAI_KEY_1]</code>, <code>&#92;[OPENAI_KEY_1&#92;]</code>, <code>[openai_key_1]</code>, <code>[ OPENAI_KEY_1 ]</code>, 인라인 코드 안의 플레이스홀더를 받아들입니다. 대괄호 없는 <code>OPENAI_KEY_1</code>은 환경 변수 이름과 구별할 수 없어 대상이 아닙니다.</li>
  <li>답변에 있지만 매핑에 없는 플레이스홀더(AI가 지어낸 것 등)는 그대로 두고 복원 칸 아래에 목록으로 보여 줍니다.</li>
</ul>
