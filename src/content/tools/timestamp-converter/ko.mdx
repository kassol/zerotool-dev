<h2>Unix 타임스탬프에 대하여</h2>
<p>Unix 타임스탬프는 프로그래밍·데이터베이스·API에서 시각을 다루는 표준적인 방법입니다. 타임존을 신경 쓰지 않고 절대 시각을 표현할 수 있으며, 날짜·시각 계산과 비교가 간단합니다.</p>
<p>로그 분석, API 응답 디버깅, 데이터베이스 타임스탬프 확인 등에 편리합니다.</p>

## 변환 예시

단위가 '단위 자동 판단'이면 소수점 앞 자릿수로 판단합니다. 12자리 이하는 초, 13–15자리는 밀리초, 16–18자리는 마이크로초, 19자리 이상은 나노초입니다. 현재 시각이라면 각각 10, 13, 16, 19자리입니다. 어떤 단위로 읽었는지 상태 줄에 표시되며, 틀리면 목록에서 단위를 고를 수 있습니다.

| 입력 | 판단 | ISO 8601(UTC) |
|---|---|---|
| `1700000000` | 초 | `2023-11-14T22:13:20.000Z` |
| `1700000000123` | 밀리초 | `2023-11-14T22:13:20.123Z` |
| `2147483647` | 초 | `2038-01-19T03:14:07.000Z` |
| `1700000000123456` | 마이크로초 | `2023-11-14T22:13:20.123Z` |
| `1700000000123456789` | 나노초 | `2023-11-14T22:13:20.123Z` |

`2147483647`은 부호 있는 32비트 정수의 최댓값이며, 2038년 문제는 이 시점에 시작됩니다. 마지막 두 행은 마이크로초(Python `time.time_ns() // 1000` 등)와 나노초(Go `time.Now().UnixNano()`, `date +%s%N`) 타임스탬프입니다. JavaScript 날짜는 밀리초 단위이므로 밀리초 미만 자릿수는 버립니다. 나노초 값은 2<sup>53</sup>을 넘기 때문에 큰 정수로 읽어 정밀도를 잃지 않습니다.

## 코드로 변환하기

```bash
date +%s                      # current timestamp (Linux, macOS)
date -u -d @1700000000        # GNU date (Linux)
date -u -r 1700000000         # BSD date (macOS)
```

```javascript
Math.floor(Date.now() / 1000)          // current timestamp in seconds
new Date(1700000000 * 1000).toISOString()  // "2023-11-14T22:13:20.000Z"
```

```python
import time, datetime
int(time.time())                                                  # current timestamp
datetime.datetime.fromtimestamp(1700000000, datetime.timezone.utc)  # 2023-11-14 22:13:20+00:00
```

## 제한 사항

- **자동 판단은 자릿수만 봅니다.** 2001-09-09 이전의 밀리초 값은 12자리라 초로, 13자리 이상의 초 값(서기 33658년 이후)은 밀리초로 읽습니다. 이럴 때는 단위를 고르세요.
- **숫자만 받습니다.** 지수(`1e10`), 16진수, 천 단위 구분 기호는 오류가 나며 소수 부분은 입력할 수 있습니다.
- **'날짜 → 타임스탬프'는 로컬 타임존을 씁니다.** 날짜 선택기 값은 브라우저의 타임존으로 해석되므로, 같은 값이라도 타임존 설정이 다른 컴퓨터에서는 다른 타임스탬프가 나옵니다.
- **윤초를 세지 않습니다.** Unix 시간은 윤초를 무시하며 JavaScript의 `Date`도 마찬가지입니다.
