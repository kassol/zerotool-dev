<h2>使用方法</h2>
<ol>
  <li>点击<strong>打开图片</strong>，或把图片拖到工具区任意位置，也可以用 Ctrl+V / ⌘V 粘贴截图，Ctrl+L / ⌘L 清除图片与色板。<strong>用示例图</strong>会载入一张小插画。</li>
  <li>每张色卡显示一种颜色和它在图中的占比；色卡上方的条形图并排显示各颜色的占比，预览图上的编号圆点标出每种颜色出现的位置。</li>
  <li><strong>颜色数</strong>可设 2–16。排序可选占比、色相或明度。<strong>色块取值</strong>可选「最常见的色调」或「聚类平均色」。</li>
  <li>点击色块复制 HEX，点击下方各行复制 RGB、HSL 或 OKLCH。<strong>色阶</strong>和<strong>配色</strong>会把该颜色带到<a href="/zh/tools/color-shades-generator/">颜色色阶生成器</a>或<a href="/zh/tools/color-palette-generator/">配色生成器</a>。</li>
  <li>在<strong>导出</strong>里复制 CSS 变量、SCSS、Tailwind v4 / v3、JSON 或色值列表，也可以下载 .gpl、.ase 调色板文件。</li>
</ol>

<h2>计算方法</h2>
<ul>
  <li><strong>采样</strong>：不超过 262,144 像素的图片逐像素统计；更大的图缩小读取，且不做平滑，每个样本都是原图里的真实像素，边缘不会混出原图没有的颜色。</li>
  <li><strong>颜色组</strong>：按每通道 8 级分成 32,768 组，与 <a href="https://github.com/lokesh/color-thief" target="_blank" rel="noopener">Color Thief</a> 的中值切割相同精度。像素按不透明度计权。</li>
  <li><strong>聚类</strong>：在 <a href="https://bottosson.github.io/posts/oklab/" target="_blank" rel="noopener">OKLab</a> 中做加权 k-means，直线距离对应看上去的色差。种子按固定顺序选取，没有随机步骤。开启「突出鲜艳的点缀色」时，色相与彩度的差按两倍计算，小面积的饱和色能单独成组。</li>
  <li><strong>合并</strong>：相距小于 0.02 的聚类合并，0.02 是 <a href="https://drafts.csswg.org/css-color-4/#binsearch" target="_blank" rel="noopener">CSS Color 4</a> 色域映射采用的最小可察觉差。</li>
</ul>

<h2>导出与调色板文件</h2>
<p>代码导出按屏幕顺序把颜色命名为 <code>palette-1</code> 到 <code>palette-n</code>，并把占比写在注释里。色值可选 HEX、<code>rgb()</code>、<code>hsl()</code>、<code>oklch()</code>，小数位刚好能换算回同一个 8 位颜色。上面的局部图导出为 CSS 变量：</p>
<pre><code>{`:root {
  --palette-1: #645736; /* 26.0% */
  --palette-2: #8A7543; /* 23.2% */
  --palette-3: #73663D; /* 17.6% */
  --palette-4: #74744D; /* 17.3% */
  --palette-5: #48432B; /* 8.5% */
  --palette-6: #4E6769; /* 7.0% */
}`}</code></pre>
<p>.gpl 文件可在 GIMP、<a href="https://inkscape-manuals.readthedocs.io/en/latest/palette.html" target="_blank" rel="noopener">Inkscape</a>（放进调色板目录）与 <a href="https://docs.krita.org/zh_CN/reference_manual/dockers/palette_docker.html" target="_blank" rel="noopener">Krita</a> 中使用；.ase 文件可载入 <a href="https://helpx.adobe.com/illustrator/desktop/manage-colors/use-swatches/share-swatches-between-applications.html" target="_blank" rel="noopener">Illustrator、Photoshop 与 InDesign</a> 的色板。</p>

<p>2026 年 10 月 2 日实测：</p>
<ul>
  <li><strong>256-tools 的图片配色提取</strong>同样显示占比，同一张图两次结果相同。但它读取的是缩小并平滑过的图：一张由 <code>#1E3A8A</code>、<code>#F8FAFC</code>、<code>#F97316</code> 三色组成的横幅（面积 72% / 25% / 3%），给出 71.2% / 24.2% / 3%，另加两个原图中没有的混合色 <code>#475E9F</code> 与 <code>#CFD6E7</code>（各 0.8%）。本工具对<a href="/images/icp-banner.png">同一张图</a>给出准确的三色与 72.0% / 25.0% / 3.0%。</li>

<h2>限制</h2>
<ul>
  <li>超过 262,144 像素的图片会抽样，只有几个像素大的细节可能漏掉。</li>
  <li>「最常见的色调」只有在一种颜色占其颜色组一半以上时才是精确原色，否则是该组的平均色。</li>
  <li>超出 sRGB 的颜色（如 Display P3 照片）按 sRGB 截取。色板显示后，工具会以 Display P3 再读一遍同样的采样像素，状态栏给出完全不透明像素中超出 sRGB 的比例。浏览器支持 OffscreenCanvas 时，打开的文件在后台 Worker 中解码和检查，大照片转换到 Display P3 的工作不在页面线程上进行（提示可能比色板晚几秒出现）；示例插画和 SVG 文件在页面中按每次 16 行分段读取。浏览器不能按 Display P3 绘制时，状态栏会说明无法检查。</li>
  <li>动图 GIF 只取第一帧。HEIC 只有 Safari 能打开，相机 RAW 需先转换。</li>
</ul>
<p>只想取某一个像素的颜色，请用<a href="/zh/tools/eyedropper-color-picker/">取色器</a>；想看配色在色觉障碍者眼中的样子，可放进<a href="/zh/tools/color-blindness-simulator/">色盲模拟器</a>，文字可读性用<a href="/zh/tools/color-contrast-checker/">颜色对比度检测器</a>。</p>
