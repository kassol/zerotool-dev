<h2>使い方</h2>
<ol>
  <li><strong>画像を開く</strong>を押すか、ツールの上に画像をドロップします。Ctrl+V / ⌘V でスクリーンショットを貼り付けることもできます。Ctrl+L / ⌘L で画像とパレットを消去します。<strong>サンプルで試す</strong>を押すと小さなイラストを読み込みます。</li>
  <li>カードには色と、その色が画像に占める割合が表示されます。カードの上の帯グラフは割合を横に並べたもの、プレビュー上の番号付きの点はその色が現れる位置です。</li>
  <li><strong>色数</strong>は 2〜16。並べ替えは割合・色相・明度から選べます。<strong>スウォッチの色</strong>は「最も多い色合い」と「クラスタの平均色」を切り替えられます。</li>
  <li>スウォッチを押すと HEX、下の行を押すと RGB・HSL・OKLCH をコピーします。<strong>濃淡</strong>と<strong>配色</strong>は、その色を<a href="/ja/tools/color-shades-generator/">カラーシェード生成器</a>や<a href="/ja/tools/color-palette-generator/">カラーパレット作成・配色ツール</a>で開きます。</li>
  <li><strong>書き出し</strong>では CSS 変数・SCSS・Tailwind v4 / v3・JSON・値の一覧をコピーでき、.gpl と .ase のパレットファイルもダウンロードできます。</li>
</ol>

<h2>例：葛飾北斎「神奈川沖浪裏」</h2>
<p><img src="/images/icp-great-wave.jpg" alt="葛飾北斎「富嶽三十六景 神奈川沖浪裏」" width="512" height="344" loading="lazy" style={{ maxWidth: '100%', height: 'auto' }} /></p>
<p><a href="https://www.metmuseum.org/art/collection/search/45434" target="_blank" rel="noopener">メトロポリタン美術館</a>の解説によると、「富嶽三十六景 神奈川沖浪裏」（1830〜32 年頃）を含む北斎の風景版画は、藍と輸入されたプルシアンブルーの配色で知られています。上の画像は同館所蔵品を撮影したパブリックドメイン画像（Wikimedia Commons）を幅 512 画素に縮小したものです。色数 5、最も多い色合いで抽出すると次のようになります。</p>

<ul>

  <li><code>#F5E5C2</code> 24.9%（黄ばんだ紙）</li>

<p>画面の 6 割以上は紙の色です。<strong>白に近い色を除外</strong>をオンにすると画像の 20.1% が外れ、空いた枠に水色がかった <code>#C4D4CB</code> 7.9% が入ります。割合は画像全体に対する値のままなので、<code>#244363</code> は 16.7% です。</p>

<p>和風の配色を Web サイトに使うなら、<strong>書き出し</strong>で Tailwind v4 を選びます。最初の結果は次の <code>@theme</code> ブロックになり、<code>bg-palette-3</code> で藍色の背景が使えます。</p>
<pre><code>{`@theme {
  --color-palette-1: #F4EAD4; /* 37.6% */
  --color-palette-2: #F5E5C2; /* 24.9% */

<h2>例：バナー画像の色を正確に取る</h2>
<p><a href="/images/icp-banner.png">この 400 × 300 の PNG</a> は、紺 <code>#1E3A8A</code> の背景、下 4 分の 1 の白っぽい帯 <code>#F8FAFC</code>、60 × 60 のオレンジの四角 <code>#F97316</code> だけでできています。色数 6 のまま抽出すると <code>#1E3A8A</code> 72.0%、<code>#F8FAFC</code> 25.0%、<code>#F97316</code> 3.0% で、元の色と面積がそのまま出ます。見えている画素が 3 つの色グループにしかないため、6 色ではなく 3 色を表示した、とステータス行に出ます。</p>

<h2>計算のしくみ</h2>
<ul>
  <li><strong>サンプリング</strong>：262,144 画素以下の画像はすべての画素を数えます。それより大きい画像は縮小して読みますが、平滑化はしないので、どのサンプルも元画像の実際の画素です。境目に元画像にない中間色が生まれません。</li>
  <li><strong>色グループ</strong>：各チャンネル 8 段階ずつ、32,768 グループで数えます。<a href="https://github.com/lokesh/color-thief" target="_blank" rel="noopener">Color Thief</a> のメディアンカットと同じ 5 ビット精度です。画素は不透明度で重み付けします。</li>
  <li><strong>クラスタリング</strong>：<a href="https://bottosson.github.io/posts/oklab/" target="_blank" rel="noopener">OKLab</a> で重み付き k-means を行います。OKLab の直線距離は見た目の色差に近い値です。初期値は決まった順番で選び、乱数は使いません。「鮮やかなアクセントを優先」がオンのときは色相と彩度の差を 2 倍に数え、面積の小さい鮮やかな色も 1 色として残します。</li>
  <li><strong>統合</strong>：0.02 未満しか離れていないクラスタはまとめます。0.02 は <a href="https://drafts.csswg.org/css-color-4/#binsearch" target="_blank" rel="noopener">CSS Color 4</a> の色域マッピングが使う「見分けられる最小の差」です。</li>
</ul>
<p>.gpl は GIMP、<a href="https://inkscape-manuals.readthedocs.io/en/latest/palette.html" target="_blank" rel="noopener">Inkscape</a>（パレットフォルダーに置く）、<a href="https://docs.krita.org/ja/reference_manual/dockers/palette_docker.html" target="_blank" rel="noopener">Krita</a> で、.ase は <a href="https://helpx.adobe.com/jp/illustrator/desktop/manage-colors/use-swatches/share-swatches-between-applications.html" target="_blank" rel="noopener">Illustrator・Photoshop・InDesign</a> のスウォッチとして使えます。</p>

<h2>ほかの抽出ツールとの違い</h2>
<p>2026 年 10 月 2 日に、上のバナーとゴッホ「星月夜」の画像で確認しました。</p>
<ul>
  <li><strong>patto-tool.com の「画像からカラーパレット抽出」</strong>は、ページの説明によると画像を最大 10,000 画素に縮小し、k-means++ で色を選びます。バナーからは元画像にない紺と白の中間色 <code>#8B9AC3</code> を返し、割合は表示しません。同じ「星月夜」を 2 回読み込むと、灰緑の色が <code>#9AA795</code> と <code>#A0AB93</code> で変わりました。</li>
  <li><strong>imageonline.io（日本語版）</strong>はバナーの 3 色を正確に返しますが、割合は表示しません。</li>
  <li>ライブラリの <strong>node-vibrant 4.0.4</strong> は「Vibrant」「Muted」など 6 つの役割で色を選び、5 ビットのグループから色を作り直すため、バナーの紺は <code>#1C3C8C</code> になります。</li>
</ul>
<p>どのページも、画像を開いたあとに画像を送るネットワーク要求は出しませんでした（ブラウザのリソースタイミングで確認）。</p>

<h2>制限</h2>
<ul>
  <li>262,144 画素を超える画像は間引いて数えるため、数画素ほどの細部は拾えないことがあります。</li>
  <li>「最も多い色合い」が元の色と完全に一致するのは、1 つの色がその色グループの半分以上を占めるときです。そうでなければグループの平均色です。</li>
  <li>sRGB の外にある色（Display P3 の写真など）は sRGB に切り詰めます。パレットの表示後、同じサンプル画素を Display P3 で読み直し、完全に不透明な画素のうち sRGB の外にある割合をステータス行に表示します。ブラウザが OffscreenCanvas に対応していれば、開いたファイルはバックグラウンドの Worker でデコードして調べるため、大きな写真の Display P3 への変換はページのスレッドで行いません（表示はパレットより数秒遅れることがあります）。サンプルのイラストと SVG ファイルはページ内で 16 行ずつ読みます。ブラウザが Display P3 で描画できない場合は、チェックできない旨をステータス行に表示します。</li>
  <li>アニメーション GIF は最初のフレームだけを使います。HEIC は Safari でのみ開け、カメラの RAW は変換が必要です。</li>
</ul>
