<h2>このツールの役割</h2>

<p>UI モックアップ、ブランド素材、商品写真、ストック画像 — 任意の画像をドロップすると、CSS、デザイントークン、Tailwind テーマにそのまま貼り付けられるパレットが返ります。可視ピクセルを k-means でクラスタリングし、各クラスタを 1 枚のスウォッチとして提示。占有率、HEX、RGB、HSL、そして OKLCH の 5 つの読み出しが揃います。</p>

<h2>使い方</h2>

<ol>
  <li>アップロードカードに画像をドロップする、カードをクリックして選択する、もしくは画像をコピーした状態で `Ctrl + V` を押してペーストします。</li>
  <li>コントロールを調整：抽出する色数 (3〜16)、ソート (頻度 / 色相 / 明度)、フィルター (透明ピクセルを除外 / 白に近い色を除外)。</li>
  <li>スウォッチ上部をクリックすると HEX をコピー。下の RGB / HSL / OKLCH 行をクリックすればその表記をコピー。</li>
  <li>一括コピー：<strong>CSS 変数をコピー</strong> で `:root { --color-1: …; }` ブロック、<strong>JSON をコピー</strong> で `{hex, rgb, weight}` 配列、<strong>Tailwind をコピー</strong> で `theme.extend.colors.palette` スニペットが取得できます。</li>
</ol>

<h2>アルゴリズム</h2>

<p>k-means はシンプルですがデザイナー向けパレットを生成するのに十分な手法です。画像は最長辺 200 ピクセルにダウンサンプリング。3840×2160 の写真なら 200×113、約 2 万 2600 サンプルピクセルになります。各ピクセルは二乗 RGB 距離が最小のセントロイドに割り当てられ、セントロイドはクラスタの平均で更新、24 回反復するか移動量が閾値を下回るまで繰り返します。</p>

<p>2 つの実用的な調整を加えています。1) ΔRGB &lt; 6 のクラスタ同士は統合し、見た目が同じスウォッチが並ばないようにする。2) オプションのプリフィルタで透明ピクセルや白に近いピクセル (輝度 &gt; 0.95) を除外し、被写体ではなく余白に引っ張られないようにする。</p>

<h2>例：小さなロゴ入りのバナー</h2>

<p>400×300 の PNG です。紺色 <code>#1E3A8A</code> の背景、下 4 分の 1 にほぼ白の <code>#F8FAFC</code> の帯、60×60 のオレンジ <code>#F97316</code> の正方形（面積の 3%）があります。<strong>色数</strong>を 3、頻度順にした結果です。</p>

<ul>
  <li>1 回目：<code>#1F3B8B</code> 72.3%、<code>#F8FAFC</code> 24.7%、<code>#F97316</code> 3.0%。</li>
  <li>2 回目（再抽出）：<code>#1E3A8A</code> 71.7%、<code>#F5F7FB</code> 25.3%、<code>#F97316</code> 3.0%。</li>
  <li><strong>白に近い色を除外</strong>をオン：<code>#1E3A8A</code> 95.1%、<code>#F97316</code> 4.0%、<code>#8B9AC3</code> 0.9%。</li>
  <li>色数を 8 にした場合：色見本は 4 つだけで、元の 3 色と <code>#8B9AC3</code> 0.7% です。</li>
</ul>

<p>2 回の結果が違うのは、初期セントロイドをランダムに選ぶためです。セントロイドが色の境目の混ざったピクセルを取り込むと、16 進値が 1〜2 段ずれます。<code>#8B9AC3</code> がその混色で、200×150 に縮小したときに紺とほぼ白の境界の行が混ざって生まれました。8 色を指定して 4 色しか出ないのは、空のクラスタを捨て、差（RGB 差の合計）が 6 未満のセントロイドを統合するためです。白に近い色を除外すると、割合は画像全体ではなく残ったピクセルに対する値になります。</p>

<h2>制限</h2>

<ul>
  <li>実行するたびに結果が変わることがあります。気に入ったパレットは再抽出の前にコピーしてください。</li>
  <li>小さなアクセントカラーは、近い色の大きなクラスタに吸収されることがあり、色数を増やすまで出てこない場合があります。</li>
  <li>色は sRGB で平均するため、セントロイドは元画像にある色そのものではなく、少しくすんだ混色になることがあります。</li>
  <li>「白に近い色を除外」は輝度（ガンマ補正済みの RGB 値で計算）が 0.95 を超えるピクセルを除き、「透明ピクセルを除外」はアルファが 128 未満のピクセルを除きます。</li>
</ul>

<h2>出力フォーマット</h2>

<ul>
  <li><strong>HEX</strong> — 汎用フォーマット。スウォッチ上部をクリックでコピー。</li>
  <li><strong>RGB</strong> — モダンなスペース区切り構文 `rgb(160 90 44)`。すべての現行ブラウザに対応。</li>
  <li><strong>HSL</strong> — 色相 / 彩度 / 明度を素早く微調整したいときに便利。</li>
  <li><strong>OKLCH</strong> — 知覚均等で、デザイントークンや色相を回転させるカラーパイプライン向け。HSL のような明度ジャンプが起きにくい。</li>
  <li><strong>占有率</strong> — 各クラスタが原画像で占めるピクセルの割合。最大値はブランドのアクセント、それ以外は補助色として扱うのがおすすめ。</li>
</ul>

<h2>想定シナリオ</h2>

<ul>
  <li>クライアントから受け取った既存ブランド素材から主要色を逆算してデザインシステムを再構築する。</li>
  <li>写真作品集や EC 商品ページで、メインビジュアルから派生した CSS トークンを生成する。</li>
  <li>競合分析時、自社プロダクトと競合の LP の色構成比を並べて違いを把握する。</li>
  <li>記事のアイキャッチを決めた後、見出し・引用ブロックの色を画像のパレットに合わせて選ぶ。</li>
</ul>

<h2>プライバシー</h2>

<p>すべての処理はクライアント側で行われます。画像は HTMLImageElement にデコードされ、隠し Canvas に縮小描画され、JavaScript で k-means が走るのみ。サーバーに送信されるバイトは一切ありません。確認したい場合はネットワークパネルを開いてください。新しい画像をロードするたびに、クリーンなログが表示されるはずです。</p>
