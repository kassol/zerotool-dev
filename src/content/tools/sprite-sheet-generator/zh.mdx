## 实测：H5 页面的 2 倍图标

{/* ssg-check: {"items":[["home.png",48,48],["search.png",48,48],["user.png",48,48],["cart.png",44,40]],"opts":{"trim":false},"format":"css","ratio":2,"image":"icons.png","expect":{"size":[98,98],"unique":4},"text":["background-size: 49px 49px;","background-position: -25px -25px;"],"notes":[]} */}

活动页上的图标通常按 2 倍尺寸切图，再用 CSS 缩小一半显示，高分屏上才清晰。准备 3 个 48 × 48 的图标和一个 44 × 40 的购物车图标，关闭「裁剪透明边」（CSS 按裁剪后的尺寸输出，图标会丢掉四周留白），间距保持 2，数据格式选 CSS、像素比选 2×、图集文件名填 `icons`。雪碧图为 **98 × 98 px**，CSS 中的关键几行：

```css
.icons {
  background-image: url("icons.png");
  background-size: 49px 49px;
}
.icons-cart {
  width: 22px;
  height: 20px;
  background-position: -25px -25px;
}
```

把间距改成 1，雪碧图变成 97 × 97，位置变成 `background-position: -24.5px 0;`，工具会提示「有尺寸或位置不是整数 CSS 像素」。半像素位置在不同浏览器里取整方式不一样，图标边缘可能露出相邻图标的一条细线，所以 2× 时尺寸和间距都用偶数。

## 游戏图集：Phaser 与 PixiJS 怎么读

数据格式选 JSON Hash，PNG 与 JSON 放在同一目录：Phaser 3 / 4 用 `this.load.atlas(key, png, json)`，PixiJS 8 用 `await Assets.load('xxx.json')`。帧名只差末尾数字时（`walk_01.png`、`walk_02.png`），JSON Hash 会多出 `animations` 字段，PixiJS 用 `new AnimatedSprite(sheet.animations.walk)` 即可播放。

导出结果用引擎自带的解析器逐项核对过（Phaser 3.90.0 / 4.2.1、PixiJS 8.22.0），有两点要注意：

- PixiJS 读取 JSON Array 时纹理按 `"0"`、`"1"` 编号，不能按文件名取，所以 PixiJS 请用 JSON Hash。
- Phaser 3.90 及更早版本读取 XML 中裁剪过的帧时，把裁剪后的宽度当成原图宽度（[Phaser issue #7245](https://github.com/phaserjs/phaser/issues/7245)，4.0.0 已修复），设置了非默认原点的精灵会错位。选 XML 且有裁剪帧时工具会提示；用 Phaser 3 时请改用 JSON Hash，或关闭裁剪。

## GIF 动图转序列帧

表情、特效常以 GIF 形式拿到。拖入 GIF 后，工具用与 [GIF 拆帧工具](/zh/tools/gif-splitter/) 相同的解码器逐帧合成，再和其他图片一起裁剪、排布。位置不同但裁剪后像素完全相同的帧只放一次，各自保留偏移量，信息行会显示「其中 N 个不重复」。

## Cocos Creator 用户注意

[Cocos Creator 3.8 文档](https://docs.cocos.com/creator/3.8/manual/zh/asset/atlas.html)写明，图集资源由 plist 和 png 组成，需用 TexturePacker 生成 cocos2d-x 格式的 plist，并且不支持 TexturePacker 4.x 以下的格式。本工具不输出 plist，做 Cocos 项目请直接用 TexturePacker；免费方案可以用 free-tex-packer，它的导出格式里有 cocos2d。

## 防止渗色与纹理尺寸

精灵被缩放、旋转或画在非整数坐标上时，线性过滤会把相邻像素混进来，边缘出现别的颜色。**间距**（默认 2 px）在帧之间留透明像素；**边缘扩展**把每帧最外一圈像素向外复制 1–8 px，适合拼接的地图瓦片；**外边距**让帧离开图集边缘。像素风素材用最近邻过滤、按整数像素绘制时，三项都可以设为 0。

最大宽度不要贪大。[Web3D Survey](https://web3dsurvey.com/webgl2/parameters/MAX_TEXTURE_SIZE)（2026-10-02 查阅）中所有 Android 设备都支持每边 4096 px 的 WebGL2 纹理，但只有 77% 支持 8192 px；任一边超过 4096 px 时工具会提示。

## 与同类工具的差别

2026-10-02 用同一组文件（4 张 64 × 64 走路帧，其中一帧重复、一个 4 帧 GIF、一个 SVG）实测，两款工具都没有上传图片：

- **CodeAndWeb Free Sprite Sheet Packer**（TexturePacker 官方的在线版）：有 Phaser、PixiJS、CSS、LESS 数据，默认 1 px 间距；不裁剪透明边（页面标注为 TexturePacker Pro 功能），重复帧打包了两次，GIF 只取一帧，SVG 没有加入也没有提示。
- **free-tex-packer.org 0.6.7**（有简体中文界面）：支持裁剪、相同图片检测和多种格式（含 cocos2d），但默认允许旋转帧（CSS 无法显示旋转帧）、间距为 0，GIF 只取一帧，不接受 SVG 和 WebP，这组图片被排成 30 × 140 的单列。

## 限制

- 最多 1000 张图，单张每边不超过 8192 px；雪碧图每边不超过 16384 px，总像素不超过 16,777,216；WebP 每边不超过 16383 px。
- Chrome、Edge 把 WebP 编成无损格式；Safari 不能编码 WebP，该选项在 Safari 中不可选。
- 浏览器的 canvas 按预乘 alpha 存储像素：alpha 为 1、颜色 `rgb(200, 100, 50)` 的像素，从 Chrome 152 导出后变成 `rgb(255, 0, 0)`；alpha 128 时为 `rgb(199, 100, 50)`。完全不透明的像素不变。
- 动态 WebP、APNG 只取第一帧。不旋转帧，不分页，不输出 plist 和 Unity、Godot 图集文件。
