<h2>使用方法</h2>
<ol>
  <li><strong>TOML → JSON</strong>：将 TOML 粘贴到左侧面板，点击 <strong>TOML → JSON</strong> 按钮。</li>
  <li><strong>JSON → TOML</strong>：将 JSON 粘贴到右侧面板，点击 <strong>JSON → TOML</strong> 按钮。</li>
  <li>可使用 <strong>Ctrl+Enter</strong>（Mac 上为 <strong>Cmd+Enter</strong>）快捷键直接转换当前编辑面板的内容。</li>
  <li>点击面板上的 <strong>Copy</strong> 按钮，将结果复制到剪贴板。</li>
</ol>

<h2>转换示例</h2>

<h3>简单表格</h3>
<p>输入 TOML：</p>
<pre><code>[database]
host = "localhost"
port = 5432
enabled = true</code></pre>
<p>输出 JSON 包含嵌套的 database 对象，含 host、port 和 enabled 字段。</p>

<h3>表格数组</h3>
<p>TOML 表格数组（使用双方括号 <code>[[table]]</code> 语法）会转换为 JSON 对象数组。例如，两个 <code>[[fruits]]</code> 表格块转换后得到包含两个对象的 fruits 数组。</p>

<h2>TOML 与 JSON 对比</h2>
<p>
  <strong>TOML</strong>（Tom's Obvious Minimal Language）是一种以语义明确、易于阅读著称的配置文件格式，广泛用于 Rust 项目（<code>Cargo.toml</code>）、Hugo 等工具。
  <strong>JSON</strong> 是 API 和 Web 服务中最常用的数据交换格式。
  本工具在两者之间转换，两种类型系统的差异见下文「转换时会变的地方」。
</p>

## 转换时会变的地方

TOML 有 JSON 没有的类型，反过来也一样。下面的输入：

```toml
# build settings
title = "x"
created = 2026-09-29T10:00:00Z
day = 2026-09-29
ratio = inf

[server]
port = 8080
```

转换结果是：

```json
{
  "title": "x",
  "created": "2026-09-29T10:00:00.000Z",
  "day": "2026-09-29",
  "ratio": null,
  "server": {
    "port": 8080
  }
}
```

- **注释会丢失。** JSON 没有注释。
- **日期时间变成字符串。** 带时区偏移的日期时间会补上毫秒（`.000Z`）。再转回 TOML 时得到的是带引号的字符串，不再是 TOML 日期。
- **`inf` 和 `nan` 变成 `null`。** JSON 没有无穷大和 NaN。
- **超过 2^53 − 1 的整数会报错。** [TOML 1.0](https://toml.io/en/v1.0.0) 允许 64 位整数，但解析器不会四舍五入，而是报错 `integer value cannot be represented losslessly`。
- **转 TOML 时 JSON 的 `null` 会被丢弃。** TOML 没有 null，`{"a": null}` 会得到空文档，不报错。请先替换 null 值。
