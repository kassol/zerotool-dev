## How Big the Code Gets

The generator picks the smallest QR version that fits your text at the chosen error correction level. Measured with the page's QR library (node-qrcode):

| Content | Level | Version | Modules per side |
|---|---|---|---|
| `https://zerotool.dev` | M | 2 | 25 |
| `https://zerotool.dev` | H | 3 | 29 |
| `WIFI:T:WPA;S:Office Guest;P:correct-horse-battery;;` | M | 4 | 33 |
| `https://example.com/landing?utm_source=print&utm_medium=flyer&utm_campaign=spring` | M | 5 | 37 |
| `你好，世界` | M | 2 | 25 |

Fewer modules means larger squares at the same print size, which scans more easily from a distance. Shorten long tracking URLs before generating.

Maximum lengths for lowercase text (byte mode) at version 40: 2,953 bytes at L, 2,331 at M, 1,663 at Q, and 1,273 at H. Beyond that the status shows "The amount of data is too big to be stored in a QR Code". Chinese, Japanese, and Korean characters are stored as UTF-8 and take 3 bytes each.

## Error Correction Levels

| Level | Recoverable damage (ISO/IEC 18004) | Use |
|---|---|---|
| L | about 7% | Screens and clean prints where size matters |
| M (default) | about 15% | Most printed material |
| Q | about 25% | Surfaces that get scuffed |
| H | about 30% | A logo placed over the center, harsh environments |

A higher level adds modules, so do not raise it without a reason.

## Content Formats Phones Recognize

| Content | Format |
|---|---|
| Web page | `https://example.com` |
| Wi-Fi | `WIFI:T:WPA;S:NetworkName;P:password;;` (escape `;`, `,`, `:`, `"`, and `\` with a backslash). The [WiFi QR Code Generator](/tools/wifi-qr-code-generator/) builds this for you |
| Email | `mailto:user@example.com?subject=Hello` |
| Phone | `tel:+15551234567` |
| SMS | `sms:+15551234567` or `SMSTO:+15551234567:Message` |
| Contact | vCard text from `BEGIN:VCARD` to `END:VCARD` |
| Location | `geo:37.7749,-122.4194` |

## Before You Print

- The codes are static: the content is in the pattern, so a printed code cannot be redirected later. If the destination may change, point the code at a URL you control.
- Scan the downloaded PNG with two phones and with the [QR Code Decoder](/tools/qr-code-decoder/), then confirm that the link opens or the Wi-Fi joins.
- Keep dark modules on a light background with strong contrast. Light-on-dark codes fail in some scanners.
- The image has a 2-module white border. ISO/IEC 18004 asks for 4 modules of quiet zone, so leave extra white space around the code in your layout.

## Limits

- PNG download only, 128 to 512 pixels. For large prints, export at 512 px and scale with nearest-neighbor resampling, or place the code in a vector layout tool.
- Leading and trailing spaces in the content are removed before encoding.
- Kanji mode is not used; Japanese text is stored as UTF-8 bytes, which phone cameras read correctly.
