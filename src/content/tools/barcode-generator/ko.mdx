<p>소매 상품이라면 번호 체계가 심볼로지를 결정합니다. GTIN-13은 EAN-13, GTIN-12는 UPC-A로 만들어야 합니다. 국내 상품에 부여되는 KAN은 앞 세 자리가 국가코드 880일 뿐 규격 자체는 EAN-13과 동일하므로, 880으로 시작하는 12자리를 그대로 EAN-13에 입력하면 됩니다. 사내 관리용이라면 문자·숫자·기호를 한 심볼에 압축해 담는 Code 128이 무난한 기본값입니다.</p>

<p>Code 128은 입력에 따라 서브셋 A·B·C를 자동으로 전환하므로 숫자가 길게 이어질수록 심볼이 짧아집니다. Code 39는 소문자를 입력하면 규격에 맞게 대문자로 변환합니다. Codabar는 A·B·C·D 시작·종료 문자로 데이터를 감싸는 규격이며, 이를 빼고 입력하면 앞뒤에 <code>A</code>와 <code>B</code>를 붙여 완성합니다.</p>

<h2>체크 디지트 계산</h2>

<p>EAN-13, EAN-8, UPC-A, ITF-14는 같은 계산식을 씁니다. 데이터의 맨 오른쪽 자리부터 왼쪽으로 3, 1, 3, 1 순서의 가중치를 곱해 더한 뒤, 그 합을 다음 10의 배수까지 채우는 값이 체크 디지트입니다.</p>

<pre><code>체크 디지트 = (10 - (가중합 mod 10)) mod 10</code></pre>

<p>데이터가 <code>590123412345</code>이면 가중합이 83이므로 체크 디지트는 7이고 완성된 EAN-13은 <code>5901234123457</code>입니다. 같은 방식으로 KAN 데이터 <code>880123456789</code>는 가중합이 127이 되어 체크 디지트 3이 붙고 <code>8801234567893</code>이 됩니다.</p>

<p>Code 128은 자체 모듈로 103 체크 심볼을 쓰며, 이 값은 자동으로 계산되어 코드에 포함되고 판독용 텍스트에는 나타나지 않습니다. Code 39에는 선택적인 모듈로 43 검사 문자가 있어 일부 폐쇄형 시스템에서 요구합니다. 받는 쪽 시스템이 요구할 때만 켜세요. 검사 문자를 예상하지 않는 스캐너는 이 문자를 데이터의 일부로 읽어 버립니다.</p>

<h2>인쇄와 스캔 성공률</h2>

<p>인쇄한 바코드가 실제 스캐너에서 읽히는지는 두 가지 설정이 좌우합니다. 첫째는 바 너비입니다. 가장 좁은 바가 프린터 해상도보다 가늘면 판독이 실패하므로, 감열 라벨이라면 내보낼 크기 기준으로 모듈당 최소 2px를 확보하세요. 둘째는 여백(quiet zone)입니다. 코드 좌우의 빈 공간을 말하며, 이 도구는 여백을 포함한 상태로 이미지를 내보냅니다. 여백을 잘라내지 말고, 상자 모서리나 다른 인쇄물에 바짝 붙이지 마세요.</p>

<p>바 높이는 판독 자체보다 각도에 영향을 줍니다. 심볼이 높을수록 비스듬히 읽어도 성공률이 올라갑니다. 라벨이 훼손됐을 때 사람이 번호를 직접 입력해야 하는 용도라면 판독용 텍스트 표시를 켜 두세요. ITF-14는 규격대로 심볼 위아래에 베어러 바를 함께 그려 인쇄 번짐으로 인한 부분 판독을 막습니다.</p>

<p>세 번째 제약은 길이이며, 가변 길이 심볼로지에만 해당합니다. 휴대용 스캐너는 시야에 들어온 만큼만 읽기 때문에, 데이터가 너무 길면 규격상 아무 문제 없는 심볼이라도 한 번에 읽히지 않습니다. Code 128이 48자, Code 39와 Codabar가 43자를 넘으면 상태 표시줄이 이를 알려 줍니다. 바코드는 그대로 생성되며, 이 안내는 시야가 더 넓은 스캐너를 쓰거나 데이터를 줄여야 한다는 신호입니다.</p>

<h2>지원 범위의 경계</h2>

<p>이 도구가 인코딩하는 것은 위 일곱 가지 심볼로지입니다. UPC-E는 여기에 포함되지 않습니다. UPC-A에서 0을 압축한 인쇄용 변형이고 스캐너가 읽으면 같은 12자리 숫자로 되돌아가므로, UPC-A로 생성하면 됩니다. 잡지 호수나 도서 가격을 담는 EAN 2자리·5자리 부가기호는 별도의 보조 심볼이라 범위 밖입니다. Code 128은 입력을 문자 그대로 인코딩합니다. 괄호로 표기한 GS1-128 애플리케이션 식별자는 해석 대상이 아닌 일반 문자로 처리되며 FNC1 구분자도 삽입되지 않습니다. 목록을 한꺼번에 처리해야 한다면 로컬 스크립트에서 바코드 라이브러리를 돌리세요.</p>
