<h2>사용 방법</h2>
<ol>
  <li>왼쪽 패널에 JSON을 붙여넣거나 입력합니다. 실시간으로 유효성이 검사됩니다.</li>
  <li><strong>모델 이름</strong>을 설정합니다(기본값: <code>User</code>). 스키마 변수와 Mongoose 모델 이름으로 사용됩니다.</li>
  <li><strong>JavaScript</strong> 또는 <strong>TypeScript</strong> 출력 모드를 선택합니다.</li>
  <li><strong>timestamps</strong>를 켜거나 끕니다.</li>
  <li><strong>스키마 생성</strong>을 클릭하거나 실시간 변환 결과를 기다립니다.</li>
  <li><strong>복사</strong>를 클릭하여 출력을 클립보드에 복사합니다.</li>
</ol>

<h2>타입 매핑</h2>
<ul>
  <li><code>null</code>은 어떤 타입에도 들어가므로 추론에서 건너뜁니다. 모든 샘플에서 <code>null</code>인 필드 → <code>mongoose.Schema.Types.Mixed</code></li>
  <li>샘플마다 타입이 다른 필드(숫자와 문자열, 객체와 문자열) → <code>mongoose.Schema.Types.Mixed</code>. ISO 날짜·시간과 다른 문자열이 섞이면 → <code>String</code></li>
  <li>문자열 → <code>String</code></li>
  <li>숫자 → <code>Number</code></li>
  <li>불리언 → <code>Boolean</code></li>
  <li>기본 타입 배열 → <code>[String]</code> / <code>[Number]</code> / <code>[Boolean]</code></li>
  <li>객체 배열 → <code>[subSchema]</code>(별도 서브스키마 생성)</li>
  <li>중첩 객체 → 별도 스키마 변수를 인라인으로 참조</li>
</ul>

<h2>예시</h2>
<p>모델 이름 <code>User</code>, 다음 JSON 입력 시:</p>
<pre><code>{`{"username": "alice", "age": 28, "tags": ["admin"], "address": {"city": "London"}}`}</code></pre>
<p>JavaScript 출력(timestamps 켜짐):</p>
<pre><code>{`const mongoose = require('mongoose');\nconst { Schema } = mongoose;\n\nconst addressSchema = new Schema({\n  city: { type: String },\n});\n\nconst userSchema = new Schema({\n  username: { type: String },\n  age: { type: Number },\n  tags: [String],\n  address: addressSchema,\n}, { timestamps: true });\n\nmodule.exports = mongoose.model('User', userSchema);`}</code></pre>

<h2>예시: 모든 샘플로 타입 결정</h2>

{/* jtm-check: {"json":"[{\"code\":1,\"note\":null,\"seller\":{\"meta\":{\"x\":1}},\"buyer\":{\"meta\":{\"y\":\"2\"}}},{\"code\":\"A-2\",\"note\":\"gift\",\"tags\":[\"a\",1]}]","model":"Order","mode":"javascript","timestamps":false,"required":false} */}

<p>주문 2건의 루트 배열, 모델 이름 <code>Order</code>, JavaScript, timestamps 끔:</p>
<pre><code>{`[{"code":1,"note":null,"seller":{"meta":{"x":1}},"buyer":{"meta":{"y":"2"}}},{"code":"A-2","note":"gift","tags":["a",1]}]`}</code></pre>

<p>출력:</p>
<pre><code>{`const mongoose = require('mongoose');
const { Schema } = mongoose;

const metaSchema = new Schema({
  x: { type: Number },
});

const sellerSchema = new Schema({
  meta: metaSchema,
});

const buyerMetaSchema = new Schema({
  y: { type: String },
});

const buyerSchema = new Schema({
  meta: buyerMetaSchema,
});

const orderSchema = new Schema({
  code: { type: mongoose.Schema.Types.Mixed },
  note: { type: String },
  seller: sellerSchema,
  buyer: buyerSchema,
  tags: [mongoose.Schema.Types.Mixed],
}, { timestamps: false });

module.exports = mongoose.model('Order', orderSchema);`}</code></pre>
<ul>
  <li><code>code</code>는 한 건이 <code>1</code>, 다른 건이 <code>"A-2"</code>라서 <code>Mixed</code>입니다. <code>Number</code>면 <code>"A-2"</code>를 거부합니다. <code>note</code>는 <code>null</code>과 <code>"gift"</code>라서 <code>String</code>입니다. <code>tags</code>는 문자열과 숫자가 섞여 요소가 <code>Mixed</code>입니다.</li>
  <li>두 <code>meta</code>는 필드가 달라서 두 번째에 부모 키를 앞에 붙입니다(<code>buyerMetaSchema</code>). 같은 키에서 필드와 타입이 같은 객체는 스키마 하나를 함께 씁니다. 앞에 붙여도 이름이 겹치면 번호를 붙입니다.</li>
  <li><code>Mixed</code> 필드는 타입 변환과 검증을 하지 않고, 내부를 바꾸면 <code>markModified()</code>를 호출해야 Mongoose가 저장합니다. 데이터가 허용하면 한 타입으로 바꾸세요.</li>
</ul>
<p>도구 테스트는 생성된 JavaScript를 Mongoose 9.10.3으로 실행해 샘플마다 문서를 만들고, <code>validateSync()</code>가 통과하는지와 모든 필드·값이 남는지 확인합니다(ISO 날짜·시간은 <code>Date</code>가 되어 <code>toISOString()</code> 형태로 비교. 샘플에 없는 배열 필드는 Mongoose 기본값 <code>[]</code>가 됩니다).</p>
