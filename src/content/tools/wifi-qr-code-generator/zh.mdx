<h2>使用方法</h2>
<ol>
  <li>填入网络名称（<strong>SSID</strong>）—— 和路由器中显示完全一致，包括大小写与空格。</li>
  <li>填入 <strong>密码</strong>，点眼睛图标可临时显示密码核对。</li>
  <li>选择路由器使用的 <strong>加密方式</strong>（WPA 选项覆盖 WPA / WPA2 / WPA3）。</li>
  <li>如果 SSID 不广播，请勾选 <strong>隐藏网络</strong>。</li>
  <li>点击 <strong>生成二维码</strong>，用任意手机摄像头扫一下试试。</li>
  <li>点击 <strong>下载 PNG</strong>，保存图片用于打印或分享。</li>
</ol>

<h2>Wi-Fi 二维码字符串格式</h2>

<p>Wi-Fi 二维码遵循一种纯文本标准格式，手机摄像头能原生解析：</p>

<pre><code>WIFI:T:WPA;S:&lt;ssid&gt;;P:&lt;password&gt;;;</code></pre>

<ul>
  <li><code>T</code> — 加密类型（<code>WPA</code> / <code>WEP</code> / <code>nopass</code>）</li>
  <li><code>S</code> — SSID（网络名称）</li>
  <li><code>P</code> — 密码（<code>T</code> 为 <code>nopass</code> 时省略）</li>
  <li><code>H:true</code> — 可选，标记隐藏网络</li>
  <li><code>;;</code> — 结尾终止符</li>
</ul>

<p>密码中如果包含 <code>{'\\'}</code>、<code>;</code>、<code>,</code>、<code>{'"'}</code>、<code>:</code> 等保留字符，会自动加反斜杠转义，含标点的密码也能正常工作。</p>

</ul>

<h2>示例：SSID 和密码里有特殊字符</h2>

<p>SSID 为 <code>{"Cafe;Guest"}</code>、密码为 <code>{"p@ss:\"word\",1"}</code>、WPA 加密时，工具生成：</p>

<pre><code>{`WIFI:T:WPA;S:Cafe\\;Guest;P:p@ss\\:\\"word\\"\\,1;;`}</code></pre>

<p>按 <a href="https://github.com/zxing/zxing/wiki/Barcode-Contents#wi-fi-network-config-android-ios-11" target="_blank" rel="noopener">ZXing Barcode Contents</a> 的规则，每个 <code>{";"}</code>、<code>{":"}</code>、<code>{"\""}</code>、<code>{","}</code>、<code>{"\\"}</code> 前都加了反斜杠。用本站的 <a href="/zh/tools/qr-code-decoder/">二维码扫描识别</a> 读回来，得到的是原始 SSID 和密码。</p>

<h2>打印之前</h2>

<ul>
  <li><strong>SSID 长度按字节算。</strong>IEEE 802.11 允许 32 字节，一个汉字在 UTF-8 下占 3 字节。工具按 UTF-8 字节计数，超过 32 字节就提醒：11 个汉字是 33 字节，会收到提醒，因为路由器无法广播这个名称。例如「咖啡店二楼的访客无线网络名称」14 个字、42 字节。</li>
  <li><strong>静区。</strong>PNG 四周留有 4 个模块宽的白边，即 ISO/IEC 18004 要求的静区。裁图放到桌卡上时不要裁掉。</li>
  <li><strong>密码长度。</strong>WPA2 密码须为 8–63 个可打印 ASCII 字符，或 64 位十六进制密钥本身（IEEE 802.11 附录 J），超出范围时工具会提醒。仅 WPA3 的网络接受其他密码，所以仍会生成二维码。WEP 密钥为 5 或 13 个字符，或 10 或 26 位十六进制。</li>
  <li><strong>隐藏网络</strong>会加上 <code>{"H:true"}</code>，让手机也去连接不广播名称的网络。</li>
  <li><strong>密码以明文写在二维码里。</strong>任何人拍下桌卡都能用二维码软件读出来。请为访客网络打印，不要用自己设备连接的那个网络。</li>
</ul>
