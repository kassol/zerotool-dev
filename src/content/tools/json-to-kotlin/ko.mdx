<h2>사용 방법</h2>
<ol>
  <li>왼쪽에 JSON을 붙여 넣거나 입력합니다. 실시간으로 검증합니다.</li>
  <li>필요하면 <strong>루트 클래스 이름</strong>을 정합니다(기본값 <code>RootObject</code>). 공백과 기호는 제거되고 PascalCase로 바뀝니다.</li>
  <li><strong>Kotlin 생성</strong>을 누르거나 실시간 변환을 기다립니다.</li>
  <li><strong>복사</strong>로 import를 포함한 출력을 복사해 <code>.kt</code> 파일에 붙여 넣습니다.</li>
</ol>

<h2>타입 매핑</h2>
<ul>
  <li>문자열 → <code>String</code>, 불리언 → <code>Boolean</code></li>
  <li>−2,147,483,648~2,147,483,647 정수 → <code>Int</code>, 더 크면 → <code>Long</code>, <code>Long</code> 범위 밖 → <code>Double</code></li>
  <li>소수점이나 지수가 있는 숫자(<code>9.5</code>, <code>19.0</code>, <code>1e3</code>) → <code>Double</code></li>
  <li>배열 → <code>List&lt;T&gt;</code>. <code>Int</code>·<code>Long</code>·<code>Double</code>이 섞이면 가장 넓은 타입, 그 밖의 혼합과 빈 배열은 <code>List&lt;JsonElement&gt;</code></li>
  <li><code>null</code> → nullable 타입, 항상 <code>null</code>인 필드 → <code>JsonElement?</code></li>
  <li>중첩 객체 → 별도 <code>data class</code>, 빈 객체 <code>{"{}"}</code> → <code>class Name</code>(data class는 속성이 하나 이상 필요)</li>
</ul>

<h2>예시: snake_case API 응답</h2>

<p>snake_case 키, null 필드, <code>Int.MAX_VALUE</code>를 넘는 카운터, <code>4.0</code>으로 쓴 평점이 있는 입력:</p>

{/* kt: {"roundTrip": true} */}

<pre><code>{`{"user_id": 1024, "display_name": "Alice", "is_active": true, "last_login": null, "follower_count": 3000000000, "rating": 4.0, "tags": ["admin", "editor"], "address": {"city": "Tokyo", "zip_code": "100-0001"}}`}</code></pre>

<p>출력:</p>

<pre><code>{`import kotlinx.serialization.SerialName
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.JsonElement

@Serializable
data class RootObject(
    @SerialName("user_id")
    val userId: Int = 0,
    @SerialName("display_name")
    val displayName: String = "",
    @SerialName("is_active")
    val isActive: Boolean = false,
    @SerialName("last_login")
    val lastLogin: JsonElement? = null,
    @SerialName("follower_count")
    val followerCount: Long = 0L,
    val rating: Double = 0.0,
    val tags: List<String> = emptyList(),
    val address: Address = Address()
)

@Serializable
data class Address(
    val city: String = "",
    @SerialName("zip_code")
    val zipCode: String = ""
)`}</code></pre>

<p>camelCase 이름이 JSON 키와 다른 필드는 <code>{"@SerialName"}</code>으로 원래 키를 유지합니다. 키로 쓰인 Kotlin 키워드(<code>class</code>, <code>in</code>, <code>fun</code>)는 백틱으로 감쌉니다. <code>last_login</code>은 샘플에서 <code>null</code>뿐이라 <code>JsonElement?</code>가 됩니다. 타임스탬프임을 알면 <code>String?</code>으로 바꾸세요.</p>

<h2>예시: 객체 배열</h2>

<p>루트가 배열이면 모든 객체를 하나의 클래스로 합칩니다. <code>price</code>가 <code>2</code>와 <code>1.5</code>이므로 <code>Double</code>이 됩니다. 일부 요소에만 있는 키는 nullable이며 기본값은 <code>{"null"}</code>입니다.</p>

{/* kt: {} */}

<pre><code>{`[{"id": 1, "name": "Pen", "price": 2}, {"id": 2, "name": "Ink", "price": 1.5, "discount": 0.1}]`}</code></pre>

<pre><code>{`import kotlinx.serialization.Serializable

@Serializable
data class RootObject(
    val id: Int = 0,
    val name: String = "",
    val price: Double = 0.0,
    val discount: Double? = null
)`}</code></pre>

<p>상태 표시줄에 <code>{"List<RootObject>"}</code>로 디코딩하라는 안내가 나옵니다.</p>

<h2>예시: 같은 이름의 키, 다른 객체</h2>

<p>필드가 다른 <code>meta</code> 객체가 두 개 있으면 클래스도 두 개가 생성되고, 두 번째에는 부모 이름이 앞에 붙습니다.</p>

{/* kt: {"roundTrip": true} */}

<pre><code>{`{"order": {"id": 7, "meta": {"source": "web"}}, "payment": {"meta": {"method": "card", "last4": "4242"}}}`}</code></pre>

<pre><code>{`import kotlinx.serialization.Serializable

@Serializable
data class RootObject(
    val order: Order = Order(),
    val payment: Payment = Payment()
)

@Serializable
data class Order(
    val id: Int = 0,
    val meta: Meta = Meta()
)

@Serializable
data class Meta(
    val source: String = ""
)

@Serializable
data class Payment(
    val meta: PaymentMeta = PaymentMeta()
)

@Serializable
data class PaymentMeta(
    val method: String = "",
    val last4: String = ""
)`}</code></pre>

<h2>디코딩</h2>

<p>빌드 설정에 직렬화 플러그인과 JSON 라이브러리를 추가하고(<a href="https://kotlinlang.org/docs/serialization.html" target="_blank" rel="noopener">Kotlin 직렬화 가이드</a> 참고) 다음처럼 디코딩합니다.</p>

<pre><code>{`import kotlinx.serialization.json.Json

val user = Json.decodeFromString<RootObject>(body)
val items = Json.decodeFromString<List<RootObject>>(arrayBody)

// 샘플에 없던 키 허용
val lenient = Json { ignoreUnknownKeys = true }`}</code></pre>

<p>기본 <code>Json</code>은 클래스에 없는 키를 오류로 처리합니다. 이 페이지의 예시는 모두 Kotlin 2.4.20과 kotlinx.serialization 1.11.0으로 컴파일하고 기본 설정으로 디코딩되는 것을 확인했습니다.</p>

<h2>제한 사항</h2>
<ul>
  <li>타입은 샘플 하나로만 정합니다. 샘플의 ID가 작으면 <code>Int</code>가 되므로, 실제 ID가 2,147,483,647을 넘는다면 <code>Long</code>으로 바꾸세요.</li>
  <li>브라우저는 JSON 숫자를 64비트 부동소수점으로 읽기 때문에 9,007,199,254,740,991보다 큰 정수는 타입을 정하기 전에 자릿수를 잃습니다. 타입은 <code>Long</code>이지만 범위는 직접 확인하세요.</li>
  <li><code>19.0</code>을 소수로 판단하는 것은 <code>JSON.parse</code>에 원본 텍스트를 넘겨주는 브라우저(Chrome 114+, Firefox 135+, Safari 18.4+)뿐입니다. 오래된 브라우저에서는 <code>Int</code>가 됩니다.</li>
  <li><code>JsonElement</code> 필드는 <code>Json</code> 포맷에서만 동작하며 CBOR, ProtoBuf에서는 쓸 수 없습니다.</li>
  <li>날짜는 <code>String</code>으로 남습니다. JSON에는 날짜 타입이 없으므로 디코딩 후 파싱하거나 커스텀 시리얼라이저를 추가하세요.</li>
  <li>모든 속성에 기본값이 있어 키가 빠져도 조용히 기본값이 됩니다. 꼭 있어야 하는 키는 기본값을 지우세요.</li>
</ul>
