<h2>정확히 셀 수 있는 모델</h2>
<ul>
  <li><strong>o200k_base</strong>: GPT-5.x, GPT-4.1, GPT-4o, o1, o3, o4-mini. 근거는 OpenAI <a href="https://github.com/openai/tiktoken/blob/main/tiktoken/model.py">tiktoken의 모델 대응표</a>입니다.</li>
  <li><strong>cl100k_base</strong>: GPT-4, GPT-3.5 Turbo, 그리고 <a href="https://developers.openai.com/api/docs/guides/embeddings">임베딩 가이드</a>가 지정한 text-embedding-3. 임베딩 입력 한도 8,192 토큰을 확인할 때 씁니다.</li>
  <li><strong>DeepSeek V4</strong>: deepseek-flash, deepseek-v4-pro. DeepSeek <a href="https://api-docs.deepseek.com/quick_start/token_usage">오프라인 계산 패키지</a>의 tokenizer.json으로 만들었습니다.</li>
  <li><strong>Claude, Gemini, GPT-6</strong>: 로컬 토크나이저가 공개되지 않았습니다. Anthropic의 <a href="https://platform.claude.com/docs/en/build-with-claude/token-counting">토큰 계산 API</a>는 무료지만 문서 스스로 결과를 추정값이라고 하며, Claude 4.7 이후 모델은 같은 텍스트에서 이전 Claude보다 토큰이 약 30% 많다고 밝힙니다. Google <a href="https://ai.google.dev/gemini-api/docs/tokens">문서</a>는 「토큰 하나는 약 4자」라는 기준만 줍니다. 표에서는 이 모델들에 o200k_base 수를 참고값으로 쓰고 ≈를 붙입니다.</li>
</ul>

<h2>제한 사항</h2>
<p>문자 통계, 사전 분할, 토큰 계산은 Web Worker에서 실행합니다. 입력을 수정하거나 지우면 이전 계산을 종료합니다. 페이지에는 통계, 전체 개수, 처음 2,000개 토큰의 표시 데이터만 반환합니다. 큰 텍스트를 입력란에 표시하는 데는 여전히 시간이 걸릴 수 있습니다. 저희 테스트(Apple M1 Max, Chromium 152, 2026-10-03)에서 중국어와 영어가 섞인 100만 자를 입력란에 표시하는 데 1~2초, 이어서 o200k_base로 세는 데 약 1.1~1.9초가 걸렸습니다.</p>
<ul>
  <li>일반 텍스트만 셉니다. 메시지 형식, 시스템 프롬프트, 도구 정의, 이미지, PDF가 더하는 토큰은 각 회사 API만 알 수 있습니다.</li>
  <li><code>&lt;|endoftext|&gt;</code> 같은 OpenAI 특수 토큰은 일반 문자열로 셉니다(7 토큰). tiktoken의 <code>encode_ordinary</code>와 같습니다. DeepSeek의 <code>&lt;｜User｜&gt;</code> 같은 표시는 공식 tokenizer.json대로 1 토큰입니다.</li>
  <li>Claude, Gemini, GPT-6 행은 참고값입니다.</li>
  <li>DeepSeek 패키지의 예제는 transformers로 불러옵니다. transformers 5.18.0에서는 이 패키지로 중국어 텍스트를 넣으면 빈 목록이 나왔고, 4.57.6과 tokenizers 라이브러리는 이 페이지와 같은 결과를 냈습니다.</li>
  <li>가격은 2026년 10월 1일 기준이며 세금, 지역별 할증, 개별 계약 할인은 넣지 않았습니다.</li>
</ul>
