<h2>Worked Examples</h2>
<p>Each example shows the input and the numbers that the tool shows for it.</p>

<h3>Abbreviations and the sentence count</h3>
{/* wc-check: {"show":["words","sentences"]} */}

```text
Dr. Smith arrived at 3.30 p.m. He left early.
```

```text
Words: 9
Sentences: 3
```

<p>A human reader sees two sentences. The Unicode sentence rules also end one after <code>Dr.</code> because a capital letter follows it; the period inside <code>3.30</code> does not end a sentence. The three sentences are <code>Dr.</code>, <code>Smith arrived at 3.30 p.m.</code> and <code>He left early.</code> Read the sentence count as an estimate when the text has abbreviations.</p>

<h3>A short post with an emoji</h3>
{/* wc-check: {"show":["characters","charsNoSpaces","words"]} */}

```text
I love it 👨‍👩‍👧
```

```text
Characters: 18
Characters (no spaces): 15
Words: 4
```

<p>The family emoji is three person emoji joined by two zero-width joiners: 8 UTF-16 code units. The emoji also counts as one word because whitespace separates it. X counts this emoji as 2 (see Limits), so X would count this post as 12.</p>

<h3>Paragraphs and line breaks</h3>
{/* wc-check: {"show":["sentences","paragraphs"]} */}

```text
Release notes

Fixed the login bug.
Improved search speed.

Thanks to all testers!
```

```text
Sentences: 4
Paragraphs: 3
```

<p>The heading line counts as a sentence because a line break ends a sentence. The two lines in the middle are one paragraph: a single line break does not start a new paragraph, only a blank line does.</p>

<h2>Character Counting Standards</h2>
<p>Different platforms count characters differently. Some count Unicode code points, some count graphemes (what a reader sees as one character), and some weight characters. This tool counts JavaScript string length, which is UTF-16 code units. Most Latin, Cyrillic, Chinese, Japanese and Korean characters count as 1. Emoji, rare CJK characters outside the Basic Multilingual Plane (for example 𠮷) and letters written with a separate combining accent count as 2 or more.</p>

## How Each Number Is Counted

| Stat | Rule in this tool | Example |
|---|---|---|
| Words | Text split on spaces, tabs, and line breaks | `well-being`, `3.14`, and `https://example.com/a` are 1 word each; `**bold**` is 1 word with the asterisks |
| Characters | JavaScript string length (UTF-16 code units), including spaces and line breaks | `👍` counts as 2 |
| Characters (no spaces) | The same, with all whitespace removed | — |
| Sentences | Unicode sentence boundaries ([UAX #29](https://www.unicode.org/reports/tr29/#Sentence_Boundaries)), computed by the browser's `Intl.Segmenter`. Sentence-ending marks include `.` `!` `?` and the full-width `。` `！` `？`; a period before a lowercase word or inside a number does not end a sentence, and each line break ends one | `Dr. Smith agreed.` counts 2; `The value is 3.14. Next line.` counts 2; `今日は晴れです。明日は雨です！` counts 2 |
| Paragraphs | Blocks separated by a blank line; a line that has only spaces also counts as blank | — |
| Reading / speaking time | Words ÷ 200 and words ÷ 130 per minute, rounded up to whole minutes; under 1 minute shows `< 1 min` | 1,000 words → 5 min reading, 8 min speaking |

Other counters can give different numbers for the same text. Microsoft Word, Google Docs, and web counters do not all treat hyphenated words, URLs, Markdown symbols, and code in the same way. When you must stay under a limit, measure with the tool that the reviewer uses.

## Limits

- **Abbreviations and lowercase starts affect the sentence count.** `Dr.` before a capital letter counts as a sentence end. A sentence that starts with a lowercase letter or a digit after a period is not counted as a new sentence. `…` alone does not end a sentence.
- **Line breaks end sentences.** A heading or list item on its own line counts as a sentence, and text with hard line breaks inside sentences (for example, copied from a PDF) shows more sentences than it has.
- **Chinese and Japanese text.** These languages do not put spaces between words, so a whole paragraph counts as 1 word, and reading time is not useful. Sentence counts work (`。` `！` `？` end a sentence). Use the character counts for length.
- **Characters are code units, not what you see.** A thumbs-up with a skin tone (👍🏽) counts as 4, a family of four (👨‍👩‍👧‍👦) as 11, and an accent typed as a separate combining mark adds 1.
- **Time units are always written in English** (`min`, `hr`) on every language version of the page.
- **Posts on X.** X counts each URL as 23 characters and most CJK characters and emoji as 2 ([counting characters](https://docs.x.com/fundamentals/counting-characters)), so the X count can differ from the Characters stat here.
