<h2>チェック内容</h2>
<p>
  <a href="https://github.com/DavidAnson/markdownlint/blob/main/doc/Rules.md" target="_blank" rel="noopener">markdownlintの全ルール</a>を適用します。主な内容：
</p>
<ul>
  <li><strong>MD001</strong> — 見出しレベルは一度に1段階だけ増やす</li>
  <li><strong>MD009</strong> — 行末にスペースを置かない</li>
  <li><strong>MD010</strong> — ハードタブを使わない（スペースを使用）</li>
  <li><strong>MD012</strong> — 連続する空行を複数置かない</li>
  <li><strong>MD022</strong> — 見出しの前後には空行を入れる</li>
  <li><strong>MD025</strong> — ドキュメント内のH1は1つだけ</li>
  <li><strong>MD031</strong> — コードフェンスの前後には空行を入れる</li>
  <li><strong>MD034</strong> — 裸のURLは使わず、リンク記法を使う</li>
  <li><strong>MD041</strong> — 最初の行はトップレベルの見出し</li>
</ul>

<h2>プライバシー</h2>
<p>処理はすべてクライアント側で行われます。Markdownはアップロードも保存もされません。</p>

<h2>例：CHANGELOG</h2>

<p>入力：</p>

<pre><code>{`# Changelog

## 1.2.0

### Added

- Export button

## 1.1.0

### Added

* Dark mode

See https://example.com/releases`}</code></pre>

<p>結果（markdownlint 0.40、既定のルール）：</p>

<pre><code>{`L13  MD004 / ul-style            Unordered list style — Expected: dash; Actual: asterisk
L11  MD024 / no-duplicate-heading Multiple headings with the same content
L15  MD034 / no-bare-urls         Bare URL used`}</code></pre>

<ul>
  <li>どちらのバージョンにも「Added」見出しがあるため MD024 が出ます。Keep a Changelog の標準的な書き方なので、自分の設定では <code>{"\"MD024\": { \"siblings_only\": true }"}</code> として親が異なる同名見出しを許可します。</li>
  <li>MD004 は文書内でリスト記号を 1 種類にそろえるよう求めます。最初のリストが <code>{"-"}</code> なので <code>{"*"}</code> が指摘されます。</li>
  <li>MD034 は裸の URL を <code>{"<https://example.com/releases>"}</code> か Markdown のリンクにするよう求めます。</li>
</ul>

<h2>ここでは変えられない既定値</h2>

<p>ツールは markdownlint が既定で有効にしているルールをすべて、既定の設定で実行します（<a href="https://github.com/DavidAnson/markdownlint/blob/main/doc/Rules.md" target="_blank" rel="noopener">markdownlint rules</a> を参照）。設定画面はないため、次の 2 つがよく余計な指摘になります：</p>

<ul>
  <li><strong>MD013 行の長さ</strong>は 80 文字です。104 文字の英文の行は <code>{"Expected: 80; Actual: 104"}</code> と報告されます。80 桁目以降に空白のない長い行は報告されないので、空白を含まない日本語の長い行はたいてい通ります。</li>
  <li><strong>MD024</strong> は文書内で同じ見出しの文字列が繰り返されると指摘します。上の CHANGELOG がその例です。</li>
</ul>

<p>自分の設定で検査するなら <code>{".markdownlint.json"}</code> に書き、ローカルや CI で <a href="https://github.com/DavidAnson/markdownlint-cli2" target="_blank" rel="noopener">markdownlint-cli2</a> を実行します：</p>

<pre><code>{`{
  "MD013": { "line_length": 120 },
  "MD024": { "siblings_only": true }
}`}</code></pre>

<p>markdownlint はファイル先頭の YAML Front Matter を読み飛ばし、その中の <code>{"title"}</code> は MD041 ではトップレベルの見出しとして扱われます。</p>
