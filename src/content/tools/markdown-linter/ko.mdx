<h2>사용 방법</h2>
<ol>
  <li>왼쪽 패널에 Markdown을 붙여넣거나 입력합니다.</li>
  <li>버튼을 누르지 않아도 오른쪽에 실시간으로 Lint 결과가 표시됩니다.</li>
  <li>결과를 클릭하면 에디터의 해당 줄로 이동합니다.</li>
  <li>문제를 수정하면 결과가 즉시 업데이트됩니다.</li>
</ol>

<h2>검사 내용</h2>
<p>
  <a href="https://github.com/DavidAnson/markdownlint/blob/main/doc/Rules.md" target="_blank" rel="noopener">markdownlint 전체 규칙</a>을 적용합니다. 주요 내용:
</p>
<ul>
  <li><strong>MD001</strong> — 제목 레벨은 한 번에 1단계씩만 증가</li>
  <li><strong>MD009</strong> — 줄 끝에 공백을 두지 않음</li>
  <li><strong>MD010</strong> — 하드 탭 사용 금지 (공백 사용)</li>
  <li><strong>MD012</strong> — 연속 빈 줄을 여러 개 두지 않음</li>
  <li><strong>MD022</strong> — 제목 앞뒤에 빈 줄 삽입</li>
  <li><strong>MD025</strong> — 문서 내 최상위 제목은 하나만</li>
  <li><strong>MD031</strong> — 코드 펜스 앞뒤에 빈 줄 삽입</li>
  <li><strong>MD034</strong> — 노출된 URL 사용 금지, 링크 문법 사용</li>
  <li><strong>MD041</strong> — 첫 줄은 최상위 제목이어야 함</li>
</ul>

<h2>개인정보</h2>
<p>모든 처리는 클라이언트에서 이루어집니다. Markdown 내용은 업로드되거나 저장되지 않습니다.</p>

<h2>예시: CHANGELOG</h2>

<p>입력:</p>

<pre><code>{`# Changelog

## 1.2.0

### Added

- Export button

## 1.1.0

### Added

* Dark mode

See https://example.com/releases`}</code></pre>

<p>결과(markdownlint 0.40, 기본 규칙):</p>

<pre><code>{`L13  MD004 / ul-style            Unordered list style — Expected: dash; Actual: asterisk
L11  MD024 / no-duplicate-heading Multiple headings with the same content
L15  MD034 / no-bare-urls         Bare URL used`}</code></pre>

<ul>
  <li>두 버전 모두에 「Added」 제목이 있어 MD024가 발생합니다. Keep a Changelog의 표준 형식이므로, 자신의 설정에서는 <code>{"\"MD024\": { \"siblings_only\": true }"}</code>로 부모가 다른 같은 제목을 허용합니다.</li>
  <li>MD004는 문서 안에서 목록 기호를 하나로 통일하라고 요구합니다. 첫 목록이 <code>{"-"}</code>를 썼으므로 <code>{"*"}</code>가 지적됩니다.</li>
  <li>MD034는 맨 URL을 <code>{"<https://example.com/releases>"}</code>나 Markdown 링크로 쓰라고 요구합니다.</li>
</ul>

<h2>여기서 바꿀 수 없는 기본값</h2>

<p>도구는 markdownlint가 기본으로 켜 둔 모든 규칙을 기본 설정으로 실행합니다(<a href="https://github.com/DavidAnson/markdownlint/blob/main/doc/Rules.md" target="_blank" rel="noopener">markdownlint rules</a> 참고). 설정 화면이 없어서 다음 두 가지가 자주 불필요한 지적이 됩니다:</p>

<ul>
  <li><strong>MD013 줄 길이</strong>는 80자입니다. 104자짜리 영어 문장 줄은 <code>{"Expected: 80; Actual: 104"}</code>로 보고됩니다. 80열 이후에 공백이 없는 긴 줄은 보고되지 않지만, 한국어는 띄어쓰기를 하므로 긴 한국어 줄은 보통 보고됩니다.</li>
  <li><strong>MD024</strong>는 문서에서 같은 제목 문자열이 반복되면 지적합니다. 위의 CHANGELOG가 그 예입니다.</li>
</ul>

<p>자신의 설정으로 검사하려면 <code>{".markdownlint.json"}</code>에 쓰고 로컬이나 CI에서 <a href="https://github.com/DavidAnson/markdownlint-cli2" target="_blank" rel="noopener">markdownlint-cli2</a>를 실행하세요:</p>

<pre><code>{`{
  "MD013": { "line_length": 120 },
  "MD024": { "siblings_only": true }
}`}</code></pre>

<p>markdownlint는 파일 맨 앞의 YAML front matter를 건너뛰며, 그 안의 <code>{"title"}</code>은 MD041에서 최상위 제목으로 취급됩니다.</p>
