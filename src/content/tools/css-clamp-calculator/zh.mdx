<h2>默认示例</h2>

<p>默认设置为 320px 到 1440px、16px 到 32px，生成结果如下：</p>

{/* ccc-check: {"min":320,"max":1440,"start":16,"end":32,"at":[880],"zoom":false} */}

<pre><code>font-size: clamp(1rem, 0.7143rem + 1.4286vw, 2rem);</code></pre>

<p>预览滑块初始停在两端中间的 880px，此时数值是 24px（1.5rem）。</p>

<h2>生成表达式的含义</h2>

<p><code>clamp(最小值, 首选值, 最大值)</code> 会尽量采用首选值，同时确保结果不越过上下限。工具依据两个“视口宽度—属性值”端点计算直线：</p>

<pre><code>斜率 = (结束值 - 起始值) / (最大视口 - 最小视口)
截距 = 起始值 - 斜率 × 最小视口
首选值 = 截距 + (斜率 × 100)vw</code></pre>

<p>视口小于起点时，属性停在对应端点；位于两个端点之间时，数值线性变化；超过终点后，另一侧边界接管。断点切换会造成明显跳变的地方最适合用它，例如标题字号、区块内边距、网格间距和内容宽度；1px 边框这类必须固定的尺寸没有必要用 clamp。</p>

<h2>示例：手机到 PC 的活动页标题</h2>

<p>假设一个活动页的主标题在 375px 宽的手机上是 20px，在 1200px 宽的 PC 版心里是 32px。属性选“字号”，输出单位选 px，视口填 375 和 1200，数值填 20 和 32：</p>

{/* ccc-check: {"unit":"px","min":375,"max":1200,"start":20,"end":32,"at":[375,768,1200],"zoom":true} */}

<pre><code>font-size: clamp(20px, 14.5455px + 1.4545vw, 32px);</code></pre>

<p>把预览滑块拖到 768px，标题是 25.7164px；375px 时正好是 20px，1200px 时到达 32px 的上限，再宽也不会变大。32 不到 20 的两倍，所以状态栏会出现缩放提示：浏览器放大到 200% 时，vw 部分按缩小后的 CSS 视口计算，这个标题放大不到两倍。要消除提示，可以把最大值改到 40px 以上，或者接受这个范围、在 200% 缩放下实际检查一遍。</p>

<h2>用了 lib-flexible 的页面不要选 rem</h2>

<p>不少国内移动端项目用过阿里巴巴 amfe 团队的 lib-flexible。它的脚本里写着 <code>set 1rem = viewWidth / 10</code>，也就是在每次窗口变化时把根字号改成屏幕宽度的十分之一：375px 宽时根字号是 37.5px，1200px 宽时是 120px。它的 <a href="https://github.com/amfe/lib-flexible">README</a> 也已写明这个过渡方案可以放弃，建议改用 viewport 单位。</p>

<p>本工具换算 rem 时假定根字号固定不变。在上面的标题例子里把输出单位改成 rem、根字号填 37.5，得到的是：</p>

{/* ccc-check: {"unit":"rem","root":37.5,"min":375,"max":1200,"start":20,"end":32,"zoom":true} */}

<pre><code>font-size: clamp(0.5333rem, 0.3879rem + 1.4545vw, 0.8533rem);</code></pre>

<p>在 375px 的屏幕上它确实是 20px，但到了 1200px，lib-flexible 已经把根字号改成 120px，上限 <code>0.8533rem</code> 变成约 102px，标题比设计稿大了三倍多。这类页面请选 px 输出，或者先去掉 lib-flexible，再用固定的根字号换算。</p>

<h2>反向范围与固定值</h2>

<p>结束值可以小于起始值。此时首选表达式会包含负的 vw 项，使属性随视口变宽而减小。工具只会将 <code>clamp()</code> 的上下边界按正确顺序排列，不会改变直线方向。</p>

<p>如果两个端点相同，就不需要流体计算，输出会简化为 <code>1rem</code> 这样的固定长度。负值仅对 <code>margin</code> 和自定义属性开放，其他预设属性填负数时不生成结果，状态栏显示：仅外边距和自定义属性允许负值。</p>

<h2>限制</h2>

<ul>
  <li><strong>缩放。</strong>MDN 对 <code>clamp()</code> 的<a href="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/clamp#accessibility">无障碍说明</a>建议，用于字号时最大值至少是最小值的两倍，文字才能放大到 200%（WCAG 1.4.4）。工具只在“字号”属性、最大值小于最小值两倍时提示，这只是提醒，不是合规判断。</li>
  <li><strong>vw 包含滚动条。</strong>桌面浏览器显示常规滚动条时，100vw 是含竖向滚动条的窗口宽度，内容区比用来算直线的宽度略窄。</li>
  <li><strong>只用视口单位。</strong>首选值永远写成 <code>vw</code>。组件需要随容器而不是随窗口变化时，要手动把 <code>vw</code> 换成 <code>cqi</code>，并给容器加 <code>container-type: inline-size</code>。</li>
  <li><strong>四位小数。</strong>数值最多保留四位小数，在常见宽度下误差不到百分之一像素。</li>
  <li><strong>输入都是像素。</strong>视口和端点值都以 px 填写，只能输出 rem 或 px，不能输出 em、ch 或百分比。</li>
  <li><code>clamp()</code> 从 Chrome 79、Firefox 75、Safari 13.1 起可用（MDN 浏览器兼容数据）。</li>
</ul>
