<h2>기본값 예제</h2>

<p>기본값인 320px~1440px, 16px~32px에서는 다음 결과가 생성됩니다.</p>

{/* ccc-check: {"min":320,"max":1440,"start":16,"end":32,"at":[880],"zoom":false} */}

<pre><code>font-size: clamp(1rem, 0.7143rem + 1.4286vw, 2rem);</code></pre>

<p>미리보기 슬라이더는 두 끝점의 가운데인 880px에서 시작하며, 이때 값은 24px(1.5rem)입니다.</p>

<h2>생성된 표현식의 의미</h2>

<p><code>clamp(최솟값, 선호 값, 최댓값)</code>은 선호 값을 사용하되 두 경계를 벗어나지 않게 합니다. 이 도구는 두 개의 “뷰포트 너비—속성 값” 점을 지나는 직선을 계산합니다.</p>

<pre><code>기울기 = (끝 값 - 시작 값) / (최대 뷰포트 - 최소 뷰포트)
절편 = 시작 값 - 기울기 × 최소 뷰포트
선호 값 = 절편 + (기울기 × 100)vw</code></pre>

<p>시작 뷰포트보다 좁으면 한쪽 끝점 값을 유지하고, 두 끝점 사이에서는 선형으로 변하며, 종료 뷰포트보다 넓으면 반대쪽 끝점 값을 유지합니다. 브레이크포인트에서 값이 갑자기 바뀌는 제목 글꼴 크기, 섹션 패딩, 그리드 간격, 콘텐츠 너비에 유용하고, 1px 테두리처럼 고정해야 하는 값에는 대개 필요하지 않습니다.</p>

<h2>예시: KRDS처럼 루트 글꼴 크기를 10px로 쓰는 프로젝트</h2>

<p>대한민국 정부 디자인 시스템 KRDS의 npm 패키지 <code>krds-uiux</code> 1.1.0은 <code>common.css</code>에서 <code>--krds-font-size-base: 62.5%;</code>를 정의하고 이를 <code>html</code>의 글꼴 크기로 씁니다. 브라우저 기본값이 16px일 때 루트는 10px로 계산됩니다. 같은 패키지의 <a href="https://unpkg.com/krds-uiux@1.1.0/resources/css/token/krds_tokens.css"><code>krds_tokens.css</code></a>에는 큰 제목 크기가 모바일 <code>--krds-mobile-font-size-heading-large: 2.4rem;</code>, PC <code>--krds-pc-font-size-heading-large: 3.2rem;</code>로 들어 있으므로 각각 24px, 32px입니다.</p>

<p>이 두 값을 한 줄로 잇고 싶다면 루트 글꼴 크기를 10으로 바꾸고, 뷰포트 360과 1280, 값 24와 32를 입력합니다(양 끝 너비는 이 예시의 가정이며 KRDS가 정한 값이 아닙니다).</p>

{/* ccc-check: {"root":10,"min":360,"max":1280,"start":24,"end":32,"at":[768],"zoom":true} */}

<pre><code>font-size: clamp(2.4rem, 2.087rem + 0.8696vw, 3.2rem);</code></pre>

<p>경계의 <code>2.4rem</code>과 <code>3.2rem</code>이 KRDS 토큰과 그대로 일치하고, 768px에서는 27.5478px입니다. 32가 24의 두 배에 못 미치므로 상태 줄에 확대 안내가 함께 나옵니다.</p>

<p>루트 글꼴 크기를 기본값 16으로 둔 채 같은 값을 넣으면 다음과 같이 나옵니다.</p>

{/* ccc-check: {"min":360,"max":1280,"start":24,"end":32,"zoom":true} */}

<pre><code>font-size: clamp(1.5rem, 1.3043rem + 0.8696vw, 2rem);</code></pre>

<p>이 식을 KRDS를 쓰는 페이지에 붙이면 루트가 10px로 설정되어 있어서 <code>1.5rem</code>은 15px, <code>2rem</code>은 20px로 계산되고 제목이 설계보다 작아집니다. vw 항은 루트와 관계없으니 그대로이고, rem 부분만 어긋납니다. rem으로 출력할 때는 붙여 넣을 프로젝트의 루트 크기를 먼저 확인하세요.</p>

<h2>역방향 범위와 고정 값</h2>

<p>끝 값을 시작 값보다 작게 입력할 수도 있습니다. 이 경우 선호 표현식에 음의 vw 항이 들어가 뷰포트가 넓어질수록 값이 줄어듭니다. 도구는 <code>clamp()</code> 경계만 올바른 순서로 정렬하고 직선의 방향은 유지합니다.</p>

<p>두 끝점 값이 같으면 유동 계산이 필요하지 않으므로 <code>1rem</code> 같은 고정 길이를 출력합니다. 음수는 의미가 있을 수 있는 <code>margin</code>과 사용자 정의 속성에서만 허용합니다.</p>

<h2>제한 사항</h2>

<ul>
  <li><strong>확대.</strong> 페이지를 확대하면 CSS 픽셀 기준 뷰포트가 줄어 vw 부분이 rem 부분보다 덜 커집니다. MDN의 <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/clamp#accessibility"><code>clamp()</code> 접근성 항목</a>은 글꼴 크기에 쓸 때 최댓값을 최솟값의 두 배 이상으로 두라고 권합니다(WCAG 1.4.4의 200% 확대). 도구의 안내는 글꼴 크기에서 최댓값이 최솟값의 두 배보다 작을 때 나타납니다.</li>
  <li><strong>vw에는 스크롤바가 포함됩니다.</strong> 데스크톱 브라우저에 일반 스크롤바가 보이면 100vw는 세로 스크롤바까지 포함한 창 너비이므로 콘텐츠 영역은 계산에 쓴 너비보다 조금 좁습니다.</li>
  <li><strong>뷰포트 단위만 씁니다.</strong> 선호 값은 항상 <code>vw</code>입니다. 컨테이너 너비를 따라야 하는 컴포넌트라면 <code>vw</code>를 직접 <code>cqi</code>로 바꾸고 컨테이너에 <code>container-type: inline-size</code>를 지정하세요.</li>
  <li><strong>소수점 넷째 자리까지.</strong> 흔한 화면 너비에서는 0.01px보다 훨씬 작은 차이입니다.</li>
  <li><strong>입력은 픽셀입니다.</strong> 뷰포트와 끝점 값은 px로 넣고 출력은 rem 또는 px뿐이며 em, ch, %는 만들 수 없습니다.</li>
  <li><code>clamp()</code>는 Chrome 79, Firefox 75, Safari 13.1부터 지원됩니다(MDN 호환성 데이터).</li>
</ul>
