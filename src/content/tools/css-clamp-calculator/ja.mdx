<h2>初期値の例</h2>

<p>既定値の 320px〜1440px、16px〜32pxでは、次の結果になります。</p>

{/* ccc-check: {"min":320,"max":1440,"start":16,"end":32,"at":[880],"zoom":false} */}

<pre><code>font-size: clamp(1rem, 0.7143rem + 1.4286vw, 2rem);</code></pre>

<p>プレビューのスライダーは両端の中央、880px から始まり、そこでの値は 24px（1.5rem）です。</p>

<h2>生成される式の意味</h2>

<p><code>clamp(最小値, 推奨値, 最大値)</code> は、推奨値を上下限の間に収めて使います。このツールは二つの「ビューポート幅と値」の点を通る直線を求めます。</p>

<pre><code>傾き = (終了値 - 開始値) / (最大ビューポート - 最小ビューポート)
切片 = 開始値 - 傾き × 最小ビューポート
推奨値 = 切片 + (傾き × 100)vw</code></pre>

<p>開始ビューポートより狭い範囲では一方の端点値を保ち、二つの端点の間では線形に変化し、終了ビューポートより広い範囲ではもう一方の端点値を保ちます。ブレークポイントで急に値が変わるのを避けたい見出し、セクションのパディング、グリッドのギャップ、コンテンツ幅などに向いています。1px の境界線のように厳密な固定値が必要なものには通常不要です。</p>

<h2>例：見出しを DADS の 24px から 36px へ</h2>

<p>デジタル庁デザインシステムのデザイントークン（<code>@digital-go-jp/design-tokens</code> 2.0.1 の <a href="https://unpkg.com/@digital-go-jp/design-tokens@2.0.1/dist/tokens.css"><code>tokens.css</code></a>）には、<code>--font-size-24: 1.5rem;</code> や <code>--font-size-36: 2.25rem;</code> のように rem で書いた文字サイズが並んでいます。ルートが 16px ならそれぞれ 24px と 36px です。スマートフォンでは 24px、PC では 36px の見出しにしたいとして、ビューポートを 360 と 1280、値を 24 と 36 にします（どの幅を両端にするかはこの例の仮定で、DADS の規定ではありません）。</p>

{/* ccc-check: {"min":360,"max":1280,"start":24,"end":36,"at":[768],"zoom":true} */}

<pre><code>font-size: clamp(1.5rem, 1.2065rem + 1.3043vw, 2.25rem);</code></pre>

<p>上下限の <code>1.5rem</code> と <code>2.25rem</code> は、トークンの値とそのまま一致します。スライダーを 768px にすると 29.3217px です。ただし 36 は 24 の 2 倍に届かないため、ステータス欄にズームの通知が出ます。ページを 200% に拡大すると CSS 上のビューポートが半分になり、vw の部分が小さくなるので、この見出しは 2 倍まで大きくなりません。</p>

<h2>2 倍にするとズームの通知が消える</h2>

<p>MDN の <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/clamp#accessibility"><code>clamp()</code> のアクセシビリティの項</a>は、文字サイズに使う場合、最大値を最小値の 2 倍以上にするよう勧めています（WCAG 1.4.4 の 200% 拡大）。同じ条件で終了値だけを 48 にすると、上限は DADS の <code>--font-size-48: 3rem;</code> と同じになり、通知は表示されません。</p>

{/* ccc-check: {"min":360,"max":1280,"start":24,"end":48,"zoom":false} */}

<pre><code>font-size: clamp(1.5rem, 0.913rem + 2.6087vw, 3rem);</code></pre>

<p>見出しが大きすぎるなら、2 倍の幅を取らずに元の 24〜36px のまま使い、200% ズームで実際に読めるか確認する方法もあります。通知は目安であり、適合の判定ではありません。</p>

<h2>逆方向と固定範囲</h2>

<p>終了値を開始値より小さくすることもできます。その場合は負の vw 項を使い、画面が広がるほど値が小さくなります。ツールは <code>clamp()</code> の上下限だけを正しい順序にし、直線の方向は維持します。</p>

<p>両端の値が同じなら流体計算は不要で、<code>1rem</code> のような固定長を返します。負の値は、意味を持つ場合がある <code>margin</code> とカスタムプロパティでのみ利用できます。</p>

<h2>制限</h2>

<ul>
  <li><strong>vw はスクロールバーを含みます。</strong>デスクトップのブラウザーで通常のスクロールバーが出ていると、100vw は縦スクロールバーを含むウィンドウ幅です。コンテンツ領域は、直線を計算した幅より少し狭くなります。</li>
  <li><strong>ビューポート単位だけです。</strong>推奨値は常に <code>vw</code> で書きます。コンテナーの幅に合わせたい部品では、<code>vw</code> を手で <code>cqi</code> に置き換え、コンテナーに <code>container-type: inline-size</code> を指定してください。</li>
  <li><strong>小数は 4 桁まで。</strong>一般的な画面幅では 0.01px よりずっと小さい差です。</li>
  <li><strong>入力はピクセルです。</strong>ビューポートと端点値は px で入力し、出力は rem か px です。em、ch、% にはできません。</li>
  <li><strong>ルートフォントサイズは固定と仮定します。</strong>rem への換算には入力したルートサイズを使います。画面幅に応じてルートの文字サイズを書き換えるスクリプトを使うページでは、px 出力を選んでください。</li>
  <li><code>clamp()</code> は Chrome 79、Firefox 75、Safari 13.1 以降で使えます（MDN の互換性データ）。</li>
</ul>
