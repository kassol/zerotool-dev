## 使い方

1. 左のエディターに Markdown を貼り付けるか、**.md を開く** でファイルを読み込みます。右側にプレビューが表示されます。
2. ファイル名は最初の見出しが初期値です。別の名前にするときは入力します。
3. 用紙は A4 が初期値です。「和文フォント」は游明朝が初期値で、游ゴシックも選べます。
4. http(s) の画像をファイルに入れたいときは **ネット上の画像を埋め込む** をオンにします。既定はオフで、オフの間は書き出しで通信しません。
5. **.docx をダウンロード** を押します。埋め込んだ画像、リンクとして残したネット上の画像、読み込めなかった画像の数がステータス欄に出ます。

## 日本語の文書で起きやすい 2 つの問題

**太字が効かない。** `**太字。**の後` のように、閉じ側の `**` の直前が「。」「」」「：」などの約物で、直後が文字だと、[CommonMark 0.31.2 の規則](https://spec.commonmark.org/0.31.2/#right-flanking-delimiter-run)では強調が閉じず、アスタリスクが残ります。生成 AI の回答や議事録メモでよく見る書き方です。このツールは [markdown-cjk-friendly](https://github.com/tats-u/markdown-cjk-friendly) 拡張を使っているので、`**注意：**`、`**「引用」**` も太字になります。取り消し線 `~~…~~` も同じです。

**改行で余計な空白が入る。** 段落の途中の改行は Markdown ではソフト改行で、HTML では空白として表示されます。和文の途中で折り返して書いた原稿だと「日本語の文 です。」のように隙間ができます。このツールは漢字・かな・全角記号にはさまれた改行を詰め、英単語の間の改行は空白にします。pandoc にも同じ目的の拡張 [east_asian_line_breaks](https://pandoc.org/MANUAL.html#extension-east_asian_line_breaks) がありますが、gfm と commonmark 形式では既定で無効です。

## 実測：週報サンプルの中身

エディターに入っているサンプルは週報です。2026-09-30 に書き出し、`word/document.xml` を確認しました。

- 「今週やったこと」「来週の予定」は `<w:pStyle w:val="Heading2"/>`。ナビゲーション ウィンドウから移動できます。
- 番号付きの 2 項目は同じ `numId` の `<w:numPr>` を持ち、番号は Word が振ります。途中に項目を足すと後ろの番号が繰り下がります。
- 「3 回失敗したらデッドレターキューへ」は箇条書きの 2 段目です。
- チェックリストの 2 項目は `w14:checkbox` のコンテンツ コントロールで、Word 上でクリックしてオン・オフできます。
- 表の見出し行には `<w:tblHeader/>` が付き、ページをまたぐと各ページの先頭に繰り返されます。区切り行が `------:` の「移行前」「移行後」列は右揃えです。
- `[^1]` は `word/footnotes.xml` に入り、ページ下部の脚注になります。

## フォントと言語の設定

- 既定スタイルの東アジア文字フォントに、選んだフォントを書き込みます。游明朝なら `w:eastAsia="Yu Mincho"`、あわせて `w:lang w:eastAsia="ja-JP"` で文字の言語を日本語にします。英数字は Calibri です。
- 日本語を含む段落の文字には `w:hint="eastAsia"` を付けます。ECMA-376 の定義では、これで「“”」や「…」のように和欧どちらにも使う文字が和文フォントで表示されます。
- コードは英数字が Consolas、コメント中の日本語は選んだ和文フォントになります。
- 開いたパソコンに指定フォントがない場合は、そのパソコンにあるフォントで代わりに表示されます。

## 他のツールとの比較

2026-09-30 に同じテスト用ファイルを、Google で「markdown word 変換」の 1 位だった markdowntoword.io と、同じ検索結果に出た mdtoword.org から書き出し、`document.xml` を比べました。

| 項目 | このツール | markdowntoword.io | mdtoword.org |
|---|---|---|---|
| `**注意：**ここ` | 太字 | `**` が残る | `**` が残る |
| 番号付きリスト | Word の段落番号 | 「1.」という文字 | Word の段落番号 |
| チェックリスト | チェックボックス、状態を保持 | ふつうの箇条書き、状態が消える | ふつうの箇条書き、状態が消える |
| 表の列揃え | 保持 | すべて左揃え | 指定なし |
| 脚注 | Word の脚注 | ふつうの段落 | 「^1」だけ残り本文が消える |
| 見出しのアウトライン レベル | あり | なし | なし |
| 東アジア文字のフォントと言語 | 両方指定 | どちらもなし | フォントのみ（Microsoft YaHei） |

Qiita や Zenn でよく紹介される pandoc は、社内テンプレート（`--reference-doc`）や数式、一括変換が必要なときに向いています。インストールが必要で、アップロードはしません。

## 制限

- 目次は自動では入りません。Word の「参考資料 > 目次」で作成します（[Microsoft の説明](https://support.microsoft.com/ja-jp/office/882e8564-0edb-435e-84b5-1d8552ccf0c0)）。既定では見出し 1〜3 が対象です。
- LaTeX 数式、Mermaid、コードの色分け、ヘッダー・フッター、ページ番号には対応していません。
- HTML タグは描画しません。タグを取り除いて文字だけ残し、`<br>` は改行、`<script>`・`<style>`・コメントは出力しません。
- ファイル先頭の `---` で囲んだ YAML は書き出しません。
- `data:` 形式の画像は常に埋め込みます。http(s) の画像は既定ではリンクになり、「ネット上の画像を埋め込む」をオンにした場合も、クロスオリジンの読み込みを許可している URL しか埋め込めません。`./img/a.png` のような相対パスは「[代替テキスト]」という文字になります。画像は本文の幅（A4 で約 16 cm）まで縮小し、SVG・WebP は PNG に描き直します（1 辺最大 4,096 px）。
- 用紙は A4 か Letter の縦向き、余白は上下左右 2.54 cm です。
- ファイル名からは `\ / : * ? " < > |` を取り除き、80 文字までにします。
- 12,000 行（167,559 文字）のテスト用ファイルは、Apple M1 Max で解析から書き出しまで約 1 秒でした。

書き出す前に表示を確かめるなら [Markdown プレビュー](/ja/tools/markdown-preview/)、Web ページの内容を Markdown にするなら [HTML → Markdown 変換](/ja/tools/html-to-markdown/) を使ってください。
