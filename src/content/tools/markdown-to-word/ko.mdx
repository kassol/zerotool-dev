## 한국어 문서에서 확인한 두 가지

**굵은 글씨.** `**주의:**여기`처럼 닫는 `**` 바로 앞이 문장 부호이고 바로 뒤에 한글이 붙으면, [CommonMark 0.31.2 규칙](https://spec.commonmark.org/0.31.2/#right-flanking-delimiter-run)상 강조가 닫히지 않아 별표가 문서에 그대로 남습니다. 생성형 AI 답변이나 회의록에서 흔한 표기입니다. 이 도구는 [markdown-cjk-friendly](https://github.com/tats-u/markdown-cjk-friendly) 확장으로 이런 경우에도 굵게 처리하고, 취소선 `~~…~~`도 같게 처리합니다.

**줄바꿈과 띄어쓰기.** 문단 안의 줄바꿈 하나는 마크다운에서 '소프트 줄바꿈'이고 HTML에서는 공백으로 보입니다. 중국어·일본어는 단어 사이를 띄우지 않으므로 이 도구는 한자·가나 사이의 줄바꿈을 붙여 씁니다. 한국어는 띄어쓰기를 하므로 한글 사이의 줄바꿈은 공백으로 남깁니다. 예를 들어 `한국어 문장` 다음 줄 `다음 줄`은 `한국어 문장 다음 줄`이 됩니다.

## 실측: 주간 보고 예시의 구조

편집기의 예시는 주간 보고입니다. 2026-09-30에 내보낸 뒤 `word/document.xml`을 확인했습니다.

- '이번 주 한 일', '다음 주 계획'은 `<w:pStyle w:val="Heading2"/>`이며 탐색 창에서 바로 이동할 수 있습니다.
- 번호 목록 두 항목은 같은 `numId`의 `<w:numPr>`를 가지며 번호는 Word가 매깁니다. 중간에 항목을 넣으면 뒤 번호가 자동으로 바뀝니다.
- '3회 실패하면 데드 레터 큐로 이동'은 글머리 기호 2단계입니다.
- 체크리스트 두 항목은 `w14:checkbox` 콘텐츠 컨트롤이라 Word에서 클릭으로 켜고 끌 수 있습니다.
- 표 머리글 행에는 `<w:tblHeader/>`가 있어 페이지가 넘어가면 다시 표시됩니다. 구분 행이 `-----:`인 '이전', '이후' 열은 오른쪽 정렬입니다.
- `[^1]`은 `word/footnotes.xml`에 들어가 페이지 아래쪽 각주가 됩니다.

## 글꼴과 언어

- 기본 스타일의 동아시아 문자 글꼴을 고른 글꼴로 지정합니다. 맑은 고딕이면 `w:eastAsia="Malgun Gothic"`, 그리고 `w:lang w:eastAsia="ko-KR"`로 문자의 언어를 한국어로 표시합니다. 영문과 숫자는 Calibri입니다.
- 한글이 들어간 문단의 글자에는 `w:hint="eastAsia"`를 붙입니다. ECMA-376 정의에 따라 '“”', '…'처럼 한글과 영문에 함께 쓰는 문자가 한글 글꼴로 표시됩니다.
- 코드의 영문은 Consolas, 주석의 한글은 고른 한글 글꼴입니다.
- 문서를 여는 컴퓨터에 해당 글꼴이 없으면 그 컴퓨터에 있는 글꼴로 대신 표시됩니다.

## 다른 도구와 비교

2026-09-30에 같은 테스트 파일을 Google에서 '마크다운 워드 변환' 1위였던 markdowntoword.io와 mdtoword.org로 내보내 `document.xml`을 비교했습니다.

| 항목 | 이 도구 | markdowntoword.io | mdtoword.org |
|---|---|---|---|
| `**注意：**这里`(중국어 예) | 굵게 | `**`가 남음 | `**`가 남음 |
| 번호 목록 | Word 번호 매기기 | '1.' 글자로 입력 | Word 번호 매기기 |
| 체크리스트 | 확인란, 상태 유지 | 일반 글머리 기호, 상태 사라짐 | 일반 글머리 기호, 상태 사라짐 |
| 표 열 정렬 | 유지 | 모두 왼쪽 | 지정 없음 |
| 각주 | Word 각주 | 일반 문단 | '^1'만 남고 내용 사라짐 |
| 제목 개요 수준 | 있음 | 없음 | 없음 |
| 링크 | 클릭 가능 | 클릭 불가 | 클릭 가능 |

회사 서식, 수식, 여러 파일 일괄 변환이 필요하면 [pandoc](https://pandoc.org/MANUAL.html#option--reference-doc)의 `--reference-doc`이 더 맞습니다. 설치가 필요하고, 업로드는 하지 않습니다.

## 제한 사항

- 목차는 자동으로 넣지 않습니다. Word의 '참조 > 목차'로 만듭니다([Microsoft 안내](https://support.microsoft.com/ko-kr/office/882e8564-0edb-435e-84b5-1d8552ccf0c0)). 기본값은 제목 1~3입니다.
- LaTeX 수식, Mermaid, 코드 색상, 머리글·바닥글, 쪽 번호는 지원하지 않습니다.
- HTML 태그는 렌더링하지 않습니다. 태그를 지우고 글자만 남기며, `<br>`은 줄바꿈, `<script>`·`<style>`·주석은 내보내지 않습니다.
- 파일 맨 앞 `---` 사이의 YAML은 내보내지 않습니다.
- `data:` 이미지는 항상 넣습니다. http(s) 이미지는 기본적으로 링크가 되고, '웹 이미지 포함'을 켜도 교차 출처 요청을 허용하는 주소만 넣을 수 있습니다. `./img/a.png` 같은 상대 경로는 '[대체 텍스트]' 글자가 됩니다. 이미지는 본문 폭(A4 기준 약 16cm)까지 줄이고, SVG·WebP는 PNG로 다시 그립니다(한 변 최대 4,096px).
- 용지는 A4 또는 Letter 세로 방향, 여백은 사방 2.54cm입니다.
- 파일 이름에서 `\ / : * ? " < > |`를 지우고 80자까지만 씁니다.
- 12,000줄(167,559자) 테스트 파일은 Apple M1 Max에서 파싱부터 파일 생성까지 약 1초 걸렸습니다.
