<h2>使い方</h2>
<ol>
  <li><code>.svg</code> ファイルを枠にドラッグ＆ドロップするか、クリックして選びます。複数まとめて選べます。コードを直接変換するときは「SVG コードを貼り付け」を開きます。クリップボードに SVG コードや SVG ファイルがあれば、ページのどこでも <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>V</kbd> で変換できます。</li>
  <li>変換結果がすぐに表示され、上にピクセルサイズとファイルサイズが出ます。</li>
  <li>「サイズ」で倍率（1x〜4x または任意の数値）、幅、高さ、「幅 × 高さ」のどれかを選びます。幅または高さだけを指定すると縦横比を保ちます。</li>
  <li>形式（PNG・JPEG・WebP）と背景（透過・白・任意の色）を選びます。設定を変えると結果もその場で更新されます。</li>
  <li>「PNG をダウンロード」を押します。複数ファイルのときは行ごとのボタンか「すべてダウンロード（.zip）」を使います。</li>
</ol>

<h2>出力サイズの決まり方</h2>
<p>等倍では、SVG のルート要素が宣言するサイズで出力します。単位は <a href="https://www.w3.org/TR/css-values-4/#absolute-lengths" target="_blank" rel="noopener">CSS の絶対長</a>で換算します（1in = 96px、1mm = 96/25.4px）。</p>
<ul>
  <li><code>width="50mm" height="25mm"</code> → 189×94。mm を px と取り違えると 50×25 になります。</li>
  <li><code>width="200"</code> と <code>viewBox="0 0 24 12"</code> → 高さは viewBox の比率から 100。</li>
  <li>viewBox だけ → viewBox の幅と高さ。<code>width="100%"</code> のような割合は置き場所のページで決まるため、viewBox を使います。</li>
  <li>どれもない → 300×150。</li>
</ul>
<p>描画の前に、出力サイズを SVG の <code>width</code> と <code>height</code> に書き込み、viewBox がなければ補います。小さな画像を引き伸ばすのではなく、最終解像度でベクターを描き直します。「幅 × 高さ」の比率が SVG と違うときは、SVG の <code>preserveAspectRatio</code> に従って配置されます（既定は中央）。</p>

<h2>自動で直すこと・知らせること</h2>
<ul>
  <li><strong><code>xmlns</code> の欠落</strong>：HTML に直接書いた <code>&lt;svg&gt;</code> には <code>xmlns</code> が要らないため、Web ページや React コンポーネントからコピーしたコードにはよくありません。そのまま保存した SVG は画像として開けないので、本ツールは <code>xmlns="http://www.w3.org/2000/svg"</code> を補って変換し、補ったことを表示します。</li>
  <li><strong>外部参照</strong>：<code>&lt;img&gt;</code> として描画される SVG は SVG Integration 仕様の <a href="https://www.w3.org/TR/svg-integration/#secure-animated-mode" target="_blank" rel="noopener">secure animated mode</a> で処理され、スクリプトも外部ファイルも使えません。Chrome では外部 <code>&lt;image&gt;</code> が「画像なし」アイコンとして描かれてしまうため、リンクを外して URL を一覧表示します。</li>
  <li><strong>XML エラー</strong>：たとえば本文に <code>&amp;nbsp;</code>（HTML の文字参照）があると、何行目かを示して <code>&amp;#160;</code> への書き換えを案内します。</li>
  <li><strong><code>&lt;foreignObject&gt;</code></strong>：Chrome は SVG 内の HTML を描いた canvas の書き出しを拒否します。空の画像を出さずに理由を表示します。</li>
</ul>
<p>変換の前にファイルを軽くするなら <a href="/ja/tools/svg-optimizer/">SVG オプティマイザー</a>、React で使うなら <a href="/ja/tools/svg-to-jsx/">SVG → JSX</a>、favicon 一式を作るなら <a href="/ja/tools/favicon-generator/">Favicon ジェネレーター</a>が使えます。</p>

<h2>制限</h2>
<ul>
  <li>描画はブラウザ自身の SVG エンジンで行うため、Chrome・Firefox・Safari で文字のアンチエイリアスやフィルターの結果が少し異なることがあります。</li>
  <li>文字はこの端末にインストールされたフォントで描かれます。別の PC ではフォントが変わることがあるので、固定したいときはフォントを data: URI で <code>@font-face</code> に埋め込んでください。</li>
  <li><code>&lt;foreignObject&gt;</code> を含む SVG は、Chrome（152 で確認）と同じエンジンの Edge では書き出せません。</li>
  <li>SMIL アニメーション付きの SVG は最初のフレームだけを保存します。</li>
  <li>canvas から WebP を書き出せないブラウザでは PNG が返されます。本ツールはその PNG を保存し、その旨を表示します。</li>
  <li><code>.svgz</code>（gzip 圧縮した SVG）には対応していません。展開してから読み込んでください。</li>
</ul>

<h2>コマンドラインでの一括変換</h2>

<p>ファイルが多い場合やビルド処理に組み込む場合は、librsvg で SVG を描画する Node.js ライブラリ <a href="https://sharp.pixelplumbing.com/">sharp</a> が使えます。sharp 0.34.5（librsvg 2.61.2）で viewBox だけを持つ 24 × 24 のアイコンを変換した結果：</p>

```javascript
import sharp from 'sharp'; // npm install sharp

await sharp('icon.svg').resize(512, 512).png().toFile('icon-512.png');   // 512 × 512
await sharp('icon.svg', { density: 288 }).png().toFile('icon@4x.png');   // 4 × the SVG size
```

<p><code>resize</code> も <code>density</code> も指定しないと、PNG は SVG 自体のサイズ（ここでは 24 × 24）になります。既定の密度は 72 なので、<code>density: 288</code> で 96 × 96 です。librsvg はブラウザとは別の描画エンジンで、Web フォントや CSS の <code>@import</code> に依存する文字は見た目が変わることがあります。フォルダごと変換する前に、1ファイルをこのページの結果と比べてください。</p>
