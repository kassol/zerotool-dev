<h2>输出尺寸怎么定</h2>
<p>1 倍时按 SVG 根元素声明的尺寸输出，单位按 <a href="https://www.w3.org/TR/css-values-4/#absolute-lengths" target="_blank" rel="noopener">CSS 绝对长度</a>换算（1in = 96px，1mm = 96/25.4px）：<code>width="50mm" height="25mm"</code> 得到 189×94；只写 <code>width="200"</code> 加 <code>viewBox="0 0 24 12"</code> 时，高度按 viewBox 比例算成 100；只有 viewBox 时用 viewBox 的宽高；<code>width="100%"</code> 这类百分比取决于所在页面，改用 viewBox。三者都没有时是 300×150。</p>
<p>绘制前，工具把目标尺寸写进 SVG 的 <code>width</code>、<code>height</code>，缺 viewBox 时补上，浏览器因此按最终分辨率重新渲染矢量，不会把小图拉伸放大。「宽 × 高」与原图比例不同时，图形按 SVG 的 <code>preserveAspectRatio</code> 放置（默认居中），其余部分是背景。</p>

<h2>从网页复制出来的 SVG</h2>
<p>SVG 直接写在 HTML 里时不需要 <code>xmlns</code>，所以从开发者工具或 React 组件里复制出来的代码常常没有它。这样的代码单独保存后，浏览器无法把它当成图像打开。实测一段 <code>&lt;svg viewBox="0 0 1024 1024" width="200" height="200"&gt;</code> 开头的图标代码：工具补上 <code>xmlns="http://www.w3.org/2000/svg"</code> 后输出 200×200、3,675 字节的 PNG，并在预览下方注明已补全。</p>
<p>另一种常见错误是文字里夹着 <code>&amp;nbsp;</code>。它是 HTML 实体，XML 里没有定义，工具会报「第 N 行」并建议改成 <code>&amp;#160;</code>。</p>
<p>转换前想先压缩 SVG，可以用 <a href="/zh/tools/svg-optimizer/">SVG 压缩优化</a>；要生成整套网站图标（ICO、apple-touch-icon）用 <a href="/zh/tools/favicon-generator/">Favicon 生成器</a>；要把 PNG 内嵌进 CSS 或 HTML，用<a href="/zh/tools/image-to-base64/">图片转 Base64</a>。</p>

<h2>限制</h2>
<ul>
  <li>渲染用的是浏览器自己的 SVG 引擎，Chrome、Firefox、Safari 的输出在文字抗锯齿和滤镜上可能略有差别。</li>
  <li>文字用本机字体，换一台电脑转换，字体可能不同；要固定字体，把字体以 data: URI 写进 <code>@font-face</code>。</li>
  <li>含 <code>&lt;foreignObject&gt;</code> 的 SVG 在 Chrome（实测 152 版）和同内核的 Edge 里无法导出。</li>
  <li>带 SMIL 动画的 SVG 只保存第一帧。</li>
  <li>浏览器不能从 canvas 编码 WebP 时会改为输出 PNG，工具按实际格式保存并提示。</li>
  <li>不支持 <code>.svgz</code>（gzip 压缩的 SVG），请先解压。</li>
</ul>

<h2>命令行批量转换</h2>

<p>文件多或要放进构建流程时，可以用 Node.js 库 <a href="https://sharp.pixelplumbing.com/">sharp</a>，它用 librsvg 渲染 SVG。用 sharp 0.34.5（librsvg 2.61.2）对一个只有 viewBox 的 24 × 24 图标实测：</p>

```javascript
import sharp from 'sharp'; // npm install sharp

await sharp('icon.svg').resize(512, 512).png().toFile('icon-512.png');   // 512 × 512
await sharp('icon.svg', { density: 288 }).png().toFile('icon@4x.png');   // 4 × the SVG size
```

<p>不写 <code>resize</code> 或 <code>density</code> 时，PNG 就是 SVG 自身的尺寸（这里是 24 × 24）。默认密度为 72，所以 <code>density: 288</code> 得到 96 × 96。librsvg 和浏览器是不同的渲染器，依赖网页字体或 CSS <code>@import</code> 的文字可能显示不同，整批转换前先拿一个文件和本页的结果对比。</p>
