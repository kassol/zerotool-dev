<h2>How to convert SVG to PNG</h2>
<ol>
  <li>Drop one or more <code>.svg</code> files on the box, click it to choose files, or open <strong>Paste SVG code</strong>. You can also press <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>V</kbd> anywhere on the page with SVG code or an SVG file on the clipboard.</li>
  <li>The PNG appears at once, with its pixel size and file size. Nothing is converted on a server.</li>
  <li>Change <strong>Size</strong>: a scale (1x–4x or any number), a width, a height, or an exact width × height. Width and height alone keep the aspect ratio.</li>
  <li>Pick <strong>Format</strong> (PNG, JPEG or WebP) and <strong>Background</strong> (transparent, white or any color). The result updates as you change a setting.</li>
  <li>Click <strong>Download PNG</strong>. With several files, each row has its own button and <strong>Download all (.zip)</strong> saves them together.</li>
</ol>

<h2>How the output size is worked out</h2>
<p>At 1x the PNG has the size the SVG declares on its root element. Units follow <a href="https://www.w3.org/TR/css-values-4/#absolute-lengths" target="_blank" rel="noopener">CSS absolute lengths</a> (1in = 96px, 1mm = 96/25.4px). The sizes below match what Chrome reports as the natural size of the same file in an <code>&lt;img&gt;</code>, except the viewBox-only row, where Chrome uses 300 × 150.</p>
<table>
  <thead><tr><th>Root element</th><th>PNG at 1x</th></tr></thead>
  <tbody>
    <tr><td><code>width="120" height="60"</code></td><td>120 × 60</td></tr>
    <tr><td><code>width="200" viewBox="0 0 24 12"</code></td><td>200 × 100 (height follows the viewBox ratio)</td></tr>
    <tr><td><code>viewBox="0 0 24 24"</code> only</td><td>24 × 24</td></tr>
    <tr><td><code>width="50mm" height="25mm"</code></td><td>189 × 94</td></tr>
    <tr><td><code>width="10em" height="5em"</code></td><td>160 × 80 (1em = 16px unless the root sets <code>font-size</code>)</td></tr>
    <tr><td><code>width="100%" viewBox="0 0 200 100"</code></td><td>200 × 100 (percentages depend on a page, so the viewBox is used)</td></tr>
    <tr><td>no width, height or viewBox</td><td>300 × 150</td></tr>
  </tbody>
</table>
<p>Before drawing, the tool writes the output size into the SVG's <code>width</code> and <code>height</code> and adds a viewBox if there is none, so the browser renders the vector at the final resolution instead of stretching a small bitmap. With <strong>Width × height</strong> and a different aspect ratio, the drawing is placed the way its <code>preserveAspectRatio</code> says (centered by default) and the rest stays background.</p>

<h2>What the tool fixes and what it reports</h2>
<ul>
  <li><strong>Missing <code>xmlns</code>.</strong> Inside HTML an <code>&lt;svg&gt;</code> needs no <code>xmlns</code>, so code copied from a web page or a React component often lacks <code>xmlns="http://www.w3.org/2000/svg"</code>. A standalone file without it does not open as an image; the tool adds it, and adds <code>xmlns:xlink</code> when <code>xlink:href</code> is used.</li>
  <li><strong>External references.</strong> An SVG drawn as an image runs in the <a href="https://www.w3.org/TR/svg-integration/#secure-animated-mode" target="_blank" rel="noopener">secure animated mode</a> of SVG Integration: no scripts and no external files. In Chrome an external <code>&lt;image&gt;</code> is then painted as a broken-image icon, so the tool removes those links and lists them. External <code>&lt;use&gt;</code> targets, CSS <code>@import</code> and web fonts are listed too.</li>
  <li><strong>XML errors.</strong> The message gives the line, for example when <code>&amp;nbsp;</code> (an HTML entity, not XML) appears in text.</li>
  <li><strong><code>&lt;foreignObject&gt;</code>.</strong> Chrome refuses to export a canvas that has drawn HTML inside SVG. The tool says so instead of producing nothing.</li>
  <li><strong>Empty output.</strong> A fully transparent result is flagged; it usually means the drawing lies outside the viewBox.</li>
</ul>
<p>To shrink the SVG first, run it through the <a href="/tools/svg-optimizer/">SVG Optimizer</a>. For a React component use <a href="/tools/svg-to-jsx/">SVG to JSX</a>, for a full icon set with ICO and apple-touch-icon use the <a href="/tools/favicon-generator/">Favicon Generator</a>, and to inline the PNG in CSS or HTML use <a href="/tools/image-to-base64/">Image to Base64</a>.</p>

<h2>Limits</h2>
<ul>
  <li>Rendering is the browser's own SVG engine, so output can differ slightly between Chrome, Firefox and Safari, mostly in text antialiasing and filters.</li>
  <li>Text uses fonts installed on your device unless the font is embedded as a data: URI. A PNG made on another computer can use a different font.</li>
  <li><code>&lt;foreignObject&gt;</code> cannot be exported in Chrome (tested in version 152) or Edge, which uses the same engine.</li>
  <li>Animated SVG (SMIL <code>&lt;animate&gt;</code>) is saved as its first frame.</li>
  <li>A browser that cannot encode WebP from a canvas returns PNG instead; the tool saves that PNG and says so.</li>
  <li>The largest output is 65,535 px per side and whatever area your browser's canvas allows (see the FAQ).</li>
  <li><code>.svgz</code> (gzip-compressed SVG) is not supported; decompress it first.</li>
</ul>

<h2>Batch conversion on the command line</h2>

<p>For many files or a build step, the Node.js library <a href="https://sharp.pixelplumbing.com/">sharp</a> converts SVG with librsvg. Tested with sharp 0.34.5 (librsvg 2.61.2) on a viewBox-only 24 × 24 icon:</p>

```javascript
import sharp from 'sharp'; // npm install sharp

await sharp('icon.svg').resize(512, 512).png().toFile('icon-512.png');   // 512 × 512
await sharp('icon.svg', { density: 288 }).png().toFile('icon@4x.png');   // 4 × the SVG size
```

<p>Without <code>resize</code> or <code>density</code> the PNG is the SVG's own size (24 × 24 here). The default density is 72, so <code>density: 288</code> gives 96 × 96. librsvg is a different renderer from the browser: text that depends on web fonts or CSS <code>@import</code> can come out differently, so compare one file with this page before converting a whole folder.</p>
