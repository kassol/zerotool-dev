<h2>ハッシュアルゴリズムについて</h2>
<p>このツールは5種類のハッシュアルゴリズムに対応しています：</p>
<ul>
  <li><strong>MD5</strong>（128ビット）：後方互換性のためのレガシー用途</li>
  <li><strong>SHA-1</strong>（160ビット）：レガシーシステムとの互換性</li>
  <li><strong>SHA-256</strong>（256ビット）：一般的なセキュリティ用途に推奨</li>
  <li><strong>SHA-384</strong>（384ビット）：高セキュリティ要件</li>
  <li><strong>SHA-512</strong>（512ビット）：最高レベルのセキュリティ</li>
</ul>

## 結果を確かめる

`hello` の 5 文字をハッシュ化すると次のとおりです。

| アルゴリズム | 出力 |
|---|---|
| MD5 | `5d41402abc4b2a76b9719d911017c592` |
| SHA-1 | `aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d` |
| SHA-256 | `2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824` |

ターミナルの結果と違う場合は、見えない改行を疑ってください。`echo "hello" | sha256sum` は `hello` に改行を足したものをハッシュ化し、`5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03` を出力します。`printf 'hello' | sha256sum` なら表と一致します。このツールでも同じで、入力欄の末尾にスペースや改行が 1 つあるだけで、すべてのハッシュ値が変わります。

## ファイルのハッシュ

このページはテキスト専用です。ファイルをアップロードせずにハッシュを計算するには [ファイルハッシュチェッカー](/ja/tools/file-hash-checker/) を使うか、次のコマンドを実行してください。

```bash
sha256sum archive.tar.gz                            # Linux
shasum -a 256 archive.tar.gz                        # macOS
certutil -hashfile archive.tar.gz SHA256            # Windows cmd
Get-FileHash archive.tar.gz -Algorithm SHA256       # PowerShell
```

## パスワードには遅いハッシュを

MD5、SHA-1、SHA-2 系は高速に計算できるよう設計されているため、攻撃者は推測を素早く試せます。パスワードの保存には [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) が推奨する Argon2id、scrypt、bcrypt を使ってください。

## 制限事項

- テキストのみ対応し、UTF-8 に変換してからハッシュ化します。同じ文字でも Shift_JIS など別の文字コードではハッシュ値が変わります。
- 入力が空のときは計算しません。参考までに、空文字列の SHA-256 は `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855` です。
- 出力は小文字の 16 進数のみです。
