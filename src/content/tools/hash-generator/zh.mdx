<h2>使用方法</h2>
<ol>
  <li>在输入框中粘贴或输入文本。</li>
  <li>点击 <strong>Generate Hashes</strong>。</li>
  <li>五种哈希值会即时显示。</li>
  <li>点击任意哈希值旁的 <strong>Copy</strong> 可复制到剪贴板。</li>
</ol>

<h2>该用哪种哈希算法？</h2>
<ul>
  <li><strong>MD5：</strong>仅用于传统校验和非安全性文件验证。</li>
  <li><strong>SHA-1：</strong>安全性已过时，仅在旧版 Git 提交和证书中仍有使用。</li>
  <li><strong>SHA-256：</strong>当前通用密码学哈希的标准，广泛用于数字签名和 TLS。</li>
  <li><strong>SHA-512：</strong>安全余量更高，在 64 位平台上速度与 SHA-256 相当。</li>
</ul>
<p>
  <strong>切勿使用 MD5 或 SHA-1 进行密码哈希。</strong>密码应使用
  bcrypt、scrypt 或 Argon2 等慢速哈希函数。
</p>

## 核对结果

对 `hello` 这 5 个字符计算哈希，结果如下：

| 算法 | 结果 |
|---|---|
| MD5 | `5d41402abc4b2a76b9719d911017c592` |
| SHA-1 | `aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d` |
| SHA-256 | `2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824` |

如果终端算出的值不同，先检查有没有看不见的换行。`echo "hello" | sha256sum` 算的是 `hello` 加一个换行符，输出 `5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03`；`printf 'hello' | sha256sum` 才与上表一致。本工具也一样：输入框末尾多一个空格或换行，所有哈希值都会变。

## 计算文件的哈希

本页只对文本计算哈希。要在不上传的前提下计算文件哈希，请用[文件哈希校验](/zh/tools/file-hash-checker/)，或者运行下面的命令：

```bash
sha256sum archive.tar.gz                            # Linux
shasum -a 256 archive.tar.gz                        # macOS
certutil -hashfile archive.tar.gz SHA256            # Windows cmd
Get-FileHash archive.tar.gz -Algorithm SHA256       # PowerShell
```

## 存储密码要用慢哈希

MD5、SHA-1 和 SHA-2 系列都为速度而设计，攻击者可以很快地尝试大量猜测。存储密码请用 Argon2id、scrypt 或 bcrypt，参见 [OWASP 密码存储速查表](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。

## 限制

- 只支持文本，计算前按 UTF-8 编码。同样的字符如果用 GBK 等其他编码，哈希值不同。
- 输入为空时不计算。作为参考，空字符串的 SHA-256 是 `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`。
- 只输出小写十六进制。
