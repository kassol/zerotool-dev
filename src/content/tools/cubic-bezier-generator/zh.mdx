<h2>什么时候需要自定义 cubic-bezier</h2>

<p>linear、ease、ease-in、ease-out、ease-in-out 这五个关键字够日常用。需要自定义 cubic-bezier 的时候通常是：</p>
<ul>
  <li>设计系统已经定好了动效曲线 —— Material Design 2 标准曲线 <code>(0.4, 0, 0.2, 1)</code>、Material 3 的 <code>(0.2, 0, 0, 1)</code>、Tailwind 的 <code>ease-in-out</code>，或下面例子里的 Ant Design 动效令牌。</li>
  <li>动画需要过冲或预拉 —— 弹窗弹出、抽屉拖拽、按钮按下回弹。</li>
  <li>要让 Figma / After Effects 里的曲线和上线代码用同一组数值。</li>
</ul>

<h2>一眼读懂曲线</h2>

<p>X 轴是归一化的时间（起点 0，终点 1）；Y 轴是动画进度。对角直线就是 linear。曲线凹在对角线下方代表起步慢、末段追上（ease-in 感）；鼓在上方代表起步快、随后减速（ease-out 感）；先下后上的 S 形就是 ease-in-out。曲线低于 0 或高于 1 时会出现「弹簧」效果 —— 适合点缀型 UI，功能性流程里用多了反而打断节奏。</p>

<h2>用 Ant Design 的动效令牌做两个例子</h2>

<p>Ant Design 6.6.5 的种子令牌（<a href="https://github.com/ant-design/ant-design/blob/6.6.5/components/theme/themes/seed.ts" target="_blank" rel="noopener">components/theme/themes/seed.ts</a>）里定义了一组 <code>motionEase*</code> 曲线，很多数值是三位小数。下面的代码块都是编辑器的实际输出；<code>x → y</code> 一行表示动画进行到 x 这个时间点时，预览用的进度，保留三位小数。</p>

<h3>motionEaseInOut：三位小数要原样保留</h3>

<p>在 P1、P2 四个数字框依次输入 <code>0.645</code>、<code>0.045</code>、<code>0.355</code>、<code>1</code>：</p>

{/* cbg-check: {"p":["0.645","0.045","0.355","1"],"x":["0.3","0.5","0.7"]} */}

```css
transition-timing-function: cubic-bezier(0.645, 0.045, 0.355, 1);
```

```
x = 0.3 → y = 0.132
x = 0.5 → y = 0.517
x = 0.7 → y = 0.891
```

<p>如果把这四个数四舍五入成两位小数再用：</p>

{/* cbg-check: {"p":["0.65","0.05","0.36","1"],"x":["0.5"]} */}

```css
transition-timing-function: cubic-bezier(0.65, 0.05, 0.36, 1);
```

```
x = 0.5 → y = 0.508
```

<p>中点的进度从 0.517 变成 0.508，肉眼几乎看不出，但它已经不是 Ant Design 的那条曲线了。在代码评审或设计走查里对令牌时，这种差异会让人困惑，所以编辑器保留三位小数。</p>

<h3>motionEaseOutBack：过冲有多少</h3>

<p>输入 <code>0.12</code>、<code>0.4</code>、<code>0.29</code>、<code>1.46</code>，切到 SCSS 标签：</p>

{/* cbg-check: {"p":["0.12","0.4","0.29","1.46"],"format":"scss","x":["0.5","0.7","0.9"]} */}

```scss
$ease-custom: cubic-bezier(0.12, 0.4, 0.29, 1.46);
```

```
x = 0.5 → y = 1.066
x = 0.7 → y = 1.113
x = 0.9 → y = 1.057
```

<p>到时长的一半时进度已经超过 1，x = 0.7 时冲过终点约 11%，最后回到 1。用在弹出的气泡上会有一点「弹」的感觉；用在页面切换上，内容会先越过目标位置再退回，通常不合适。</p>

<p>两个控制点的 x 值必须在 0 到 1 之间，因为时间不能倒流，编辑器会自动夹紧；y 值可以超出这个范围，Back 预设的回弹就是这样来的。</p>

<h2>限制</h2>

<ul>
  <li>数值最多保留三位小数。拖动得到的更细数值会在数字框和复制结果里四舍五入到三位。</li>
  <li>y 只能在 −2 到 2 之间，因为预览区只给这个范围留了空间。CSS 本身接受任意 y 值；超出时编辑器按边界值复制，并在状态栏提示，更大的值请手动写进 CSS。</li>
  <li>x 输入超出 0–1 时会被夹紧并提示；直接写进 CSS 的话，浏览器会丢弃整条声明。</li>
  <li>只生成 <code>cubic-bezier()</code>，不生成 <code>steps()</code>，也不生成多点的 <code>linear()</code> 函数，所以做不出多次回弹。</li>
  <li>预览时长（100–10,000 毫秒）和「循环」只影响预览，不写进复制的代码，<code>transition-duration</code> 需要自己加。</li>
  <li>Tailwind 标签输出的是 v3 的 <code>tailwind.config.js</code> 写法，键名固定为 <code>custom</code>；v4 项目请用 <code>@config</code> 或 <code>--ease-*</code> 主题变量。</li>
</ul>
