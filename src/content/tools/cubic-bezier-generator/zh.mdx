<h2>什么时候需要自定义 cubic-bezier</h2>

<p>linear / ease / ease-in / ease-out / ease-in-out 这五个关键字够日常用。你需要自定义 cubic-bezier 的时候通常是：</p>
<ul>
  <li>设计系统已有明确的运动语言 —— Material Design 2 标准曲线 <code>(0.4, 0, 0.2, 1)</code>、Material 3 的 <code>(0.2, 0, 0, 1)</code>、Tailwind 的 <code>ease-in-out</code>。</li>
  <li>动画需要 overshoot 或 anticipation —— modal 弹出、抽屉拖拽、按钮按下回弹。</li>
  <li>要让 Figma / After Effects 的曲线和上线代码视觉完全一致。</li>
</ul>

<h2>一眼读懂曲线</h2>

<p>X 轴是归一化的时间（起点 0，终点 1）；Y 轴是动画进度。对角直线就是 linear。曲线凹在对角线下方代表起步慢、末段追上（ease-in 感）；鼓在上方代表起步快、随后减速（ease-out 感）；先下后上的 S 形就是 ease-in-out。当曲线下探低于 0 或高出 1，就出现「弹簧」效果 —— 适合点缀型 UI，但功能性流程里用多了反而打断节奏。</p>
