<h2>When to reach for a custom cubic-bezier</h2>

<p>The four built-in CSS keywords (linear, ease, ease-in, ease-out, ease-in-out) cover the everyday cases. You need a custom cubic-bezier when:</p>
<ul>
  <li>Your design system has a defined motion language — Material Design 2's standard curve <code>(0.4, 0, 0.2, 1)</code>, Material 3's <code>(0.2, 0, 0, 1)</code>, or Tailwind's <code>ease-in-out</code>.</li>
  <li>The animation should overshoot or anticipate — modal pop-ins, drawer drags, button press feedback.</li>
  <li>You want to match a Figma or After Effects timing curve exactly so the prototype and the production build feel the same.</li>
</ul>

<h2>Reading the curve at a glance</h2>

<p>The X axis is normalized time (0 at the start, 1 at the end). The Y axis is animation progress. A diagonal line means linear. A curve that sags below the diagonal starts slowly and catches up at the end (ease-in feel). A curve that bulges above starts fast and slows down (ease-out feel). An S-shape, below then above, is ease-in-out. When the curve dips below 0 or above 1, you get the "spring" effect — useful for playful UI but distracting in functional flows.</p>
