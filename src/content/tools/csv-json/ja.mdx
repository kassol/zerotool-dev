<h2>使い方</h2>
<ol>
  <li><strong>CSV → JSON</strong>：CSVデータを入力欄に貼り付け、<strong>変換</strong>をクリックします。</li>
  <li><strong>JSON → CSV</strong>：JSONオブジェクト配列を入力欄に貼り付け、<strong>変換</strong>をクリックします。</li>
  <li>結果を<strong>コピー</strong>またはダウンロードします。</li>
</ol>

<h2>CSVとJSONについて</h2>
<p>CSVはスプレッドシートやデータベースのエクスポートによく使われ、JSONはAPIやWebアプリで広く使われるデータ形式です。両者の変換はデータ処理・分析・移行作業でよく必要になります。</p>

## エッジケース：このコンバーターの動作

**空のフィールド。** 次の CSV では、Bob の email と 3 行目の name が空です。

```csv
id,name,email
1,Alice,alice@example.com
2,Bob,
3,,charlie@example.com
```

既定では空のフィールドは `""` になります。「空フィールド → null」にチェックを入れると `null` になります。

```json
[
  { "id": 1, "name": "Alice", "email": "alice@example.com" },
  { "id": 2, "name": "Bob", "email": null },
  { "id": 3, "name": null, "email": "charlie@example.com" }
]
```

**型の自動変換。** 「数値・真偽値を自動変換」にチェックがある場合（既定）、引用符のない `true`・`false`・`null`（大文字小文字は問わない）は JSON のリテラルに、数値は JSON の数値になります。情報を失わないよう、次の 3 種類は文字列のまま残ります：引用符付きのフィールド（`"42"`）、先頭が 0 の値（`007`、`0123`）、JavaScript の数値で正確に表せない大きな整数（2^53 − 1 超。長い注文番号など）。

**ヘッダー行。** 1 行目は常にヘッダーとして扱います。ヘッダーのない CSV は、先頭にヘッダー行を追加してから変換してください。同じ名前の列が 2 つあると、後の列が前の列を上書きするので、先に名前を変えてください。ヘッダーより多いフィールドは捨てられ、足りないフィールドは空として扱われます。

**区切り文字。** カンマだけを認識します。セミコロン区切りやタブ区切りのファイルは、先にカンマ区切りに変換してください。

**JSON → CSV。** 入力はオブジェクトの配列である必要があります。列名は最初のオブジェクトのキーから取るので、後のオブジェクトにしかないキーは出力されません。ネストしたオブジェクトは展開されず、`[object Object]` という文字列になるので、先にフラットにしてください。
