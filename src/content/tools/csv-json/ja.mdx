## 郵便番号データを JSON にする

郵便番号は先頭が 0 のものがあるので、数値にすると桁が落ちます。このツールは先頭が 0 の値を文字列のまま残します。データは [zipcloud の郵便番号検索API](https://zipcloud.ibsnet.co.jp/doc/api) のレスポンスサンプルにある 2 件です。

{/* cj-check: {"to":"json"} */}

```csv
郵便番号,都道府県,市区町村,町域
0790177,北海道,美唄市,上美唄町協和
0790177,北海道,美唄市,上美唄町南
```

```json
[
  {
    "郵便番号": "0790177",
    "都道府県": "北海道",
    "市区町村": "美唄市",
    "町域": "上美唄町協和"
  },
  {
    "郵便番号": "0790177",
    "都道府県": "北海道",
    "市区町村": "美唄市",
    "町域": "上美唄町南"
  }
]
```

`0790177` が `790177` にならずに残っています。数値になるのは、[RFC 8259 の 6 章](https://www.rfc-editor.org/rfc/rfc8259#section-6)にある JSON の数値の書き方（先頭の 0 や `+` がなく、小数点の両側に数字がある）で、しかも JavaScript の数値で正確に表せる値だけです。引用符付きのフィールド（`"42"`）、`007`、`+81`、`.5`、2^53 − 1 を超える整数、`-0` や `1e-400` は文字列のまま残ります。`true`・`false`・`null`（大文字小文字は問わない）は JSON のリテラルになります。

## API のレスポンスを CSV にする

逆方向も試します。同じ API のレスポンスから `results` の配列だけを JSON 欄に貼ると、キーがそのまま列名になります。

{/* cj-check: {"to":"csv"} */}

```json
[
  {
    "address1": "北海道",
    "address2": "美唄市",
    "address3": "上美唄町協和",
    "kana1": "ﾎｯｶｲﾄﾞｳ",
    "kana2": "ﾋﾞﾊﾞｲｼ",
    "kana3": "ｶﾐﾋﾞﾊﾞｲﾁｮｳｷｮｳﾜ",
    "prefcode": "1",
    "zipcode": "0790177"
  },
  {
    "address1": "北海道",
    "address2": "美唄市",
    "address3": "上美唄町南",
    "kana1": "ﾎｯｶｲﾄﾞｳ",
    "kana2": "ﾋﾞﾊﾞｲｼ",
    "kana3": "ｶﾐﾋﾞﾊﾞｲﾁｮｳﾐﾅﾐ",
    "prefcode": "1",
    "zipcode": "0790177"
  }
]
```

```csv
address1,address2,address3,kana1,kana2,kana3,prefcode,zipcode
北海道,美唄市,上美唄町協和,ﾎｯｶｲﾄﾞｳ,ﾋﾞﾊﾞｲｼ,ｶﾐﾋﾞﾊﾞｲﾁｮｳｷｮｳﾜ,1,0790177
北海道,美唄市,上美唄町南,ﾎｯｶｲﾄﾞｳ,ﾋﾞﾊﾞｲｼ,ｶﾐﾋﾞﾊﾞｲﾁｮｳﾐﾅﾐ,1,0790177
```

半角カナはそのまま書き出され、カンマも改行も含まないので引用符は付きません。レスポンス全体（`message`・`results`・`status` を持つオブジェクト）を貼ると配列ではないので変換されません。たとえばエラー時のサンプルを貼った場合：

{/* cj-check: {"to":"csv","error":true} */}

```json
{"message": "必須パラメータが指定されていません。", "results": null, "status": 400}
```

ステータスには `エラー：JSON はオブジェクトの配列である必要があります。` と表示され、CSV 欄は空のままです。

## 全角で入力した値

IME をオンにしたまま数字を打つと、全角数字が混ざることがあります。

{/* cj-check: {"to":"json"} */}

```csv
商品,数量,単価
ノート,３,１２０
ペン,2,"1,100"
```

```json
[
  {
    "商品": "ノート",
    "数量": "３",
    "単価": "１２０"
  },
  {
    "商品": "ペン",
    "数量": 2,
    "単価": "1,100"
  }
]
```

半角の `2` だけが数値になり、全角の `３`・`１２０` と、桁区切りのカンマを含む `"1,100"` は文字列です。区切りに全角カンマ（，）を使った行は、行全体が 1 つのフィールドになります。

## ヘッダーの扱い

1 行目は常にヘッダーです。ヘッダーのない CSV は、先頭にヘッダー行を追加してから変換してください。同じ名前の列があると 2 つ目以降に `_2`、`_3` を付け、ヘッダーより多いフィールドには `column_N`（N は列の位置）というキーを付けます。どちらの場合もステータスに表示されます。足りないフィールドは空として扱い、「空フィールド → null」にチェックがあれば `null` になります。

## 制限事項

- **区切り文字は半角カンマだけ。** タブ・セミコロン・全角カンマは区切りになりません。
- **引用符として扱うのはフィールド先頭のダブルクォートだけです。** 引用符のないフィールドの途中にある `"` はただの文字なので、`5" パイプ,x` は `5" パイプ` と `x` の 2 つのフィールドになります。閉じられていない引用符があると変換を止め、引用符が始まる行をエラーで示します。JSON 欄は空のままです。

{/* cj-check: {"to":"json","error":true} */}

```csv
郵便番号,住所
"0790177,北海道美唄市
1000001,東京都千代田区
```

  ステータスには `エラー：2 行目で始まる引用符付きフィールドが閉じられていません。閉じる " を追加するか、開始の " を削除してください。` と表示されます。
- **国番号などは文字列のままです。** 先頭に `+` が付く値は JSON の数値の書き方ではないので、数値になりません。

{/* cj-check: {"to":"json"} */}

```csv
国,国番号
日本,+81
韓国,+82
```

```json
[
  {
    "国": "日本",
    "国番号": "+81"
  },
  {
    "国": "韓国",
    "国番号": "+82"
  }
]
```
- **JSON → CSV で大きな数値は元の桁のまま書き出します。** `12345678901234567890`・`1e-400`・`-0` のように JavaScript の数値で正確に表せない JSON の数値は、JSON に書かれたとおりに CSV へ出力します。これには `JSON.rawJSON` が必要で、Chrome 114・Firefox 135・Safari 18.4 以降が対応しています。それより古いブラウザーではこうした数値を文字列として書き出し（配列のセルの中では `"12345678901234567890"` のように引用符が付きます）、ステータスに対象の数値を表示します。丸めた値を出力することはありません。
- **ヘッダーの空白はキーに残ります。** [RFC 4180 の 2 節](https://www.rfc-editor.org/rfc/rfc4180#section-2)では空白もフィールドの一部なので、カンマの後の空白はキーや値に入ります。全角スペースも空白として扱います。先頭か末尾に空白があるヘッダー名はステータスに表示します。不要なら元のデータから空白を消してください。

{/* cj-check: {"to":"json","status":true} */}

```csv
氏名,　電話番号
山田,　03-1234-5678
```

```json
[
  {
    "氏名": "山田",
    "　電話番号": "　03-1234-5678"
  }
]
```

  ステータスには `1 行を JSON に変換しました。 次のヘッダー名は先頭か末尾に空白があり、その空白もキーに含まれます："　電話番号"。` と表示されます。
- **キーの順序。** `2024` のような整数に見えるキーは、ほかのキーより前に並びます（どちらの方向でも同じ）。値は変わりません。
- **文字コードは扱いません。** 貼り付けたテキストを処理するだけなので、Shift_JIS で保存された CSV がエディターで文字化けしていれば、そのまま文字化けした文字列になります。先に正しい文字コードでファイルを開いてください。
- **JSON の構文エラー**があると変換を止めて CSV 欄を空にし、エラーのある行・列と原因をステータスに表示します。行と列は JSON 欄の先頭から数えます。たとえば全角のカンマが混ざった場合：

{/* cj-check: {"to":"csv","error":true} */}

```json
[{"名前": "山田"，"年齢": 30}]
```

  ステータスには `有効な JSON ではありません：1 行 13 列目、全角文字 ， があります。JSON の記号と空白は半角です。` と表示されます。
