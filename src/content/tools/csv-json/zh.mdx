<h2>使用方法</h2>
<ol>
  <li><strong>CSV → JSON</strong>：将带表头的 CSV 数据粘贴到左侧面板，点击 <strong>CSV → JSON</strong> 按钮。</li>
  <li><strong>JSON → CSV</strong>：将 JSON 对象数组粘贴到右侧面板，点击 <strong>JSON → CSV</strong> 按钮。</li>
  <li>点击面板上的 <strong>Copy</strong> 按钮，将结果复制到剪贴板。</li>
  <li>按钮下方的状态栏会显示转换行数或解析错误信息。</li>
</ol>

<h2>转换示例</h2>

<h3>简单表格</h3>
<p>输入 CSV：</p>
<pre><code>name,age,city
Alice,30,London
Bob,25,Paris</code></pre>
<p>输出 JSON 包含每行对应的 name、age、city 字段的对象。</p>

<h3>含逗号的引号字段</h3>
<p>输入 CSV：</p>
<pre><code>product,description,price
Widget,"Small, round widget",9.99
Gadget,"Includes ""turbo"" mode",24.50</code></pre>
<p><code>description</code> 字段包含逗号和转义引号——均可正确处理。</p>

<h3>JSON 转回 CSV</h3>
<p>将 JSON 输出粘贴到右侧面板，点击 <strong>JSON → CSV</strong> 即可将数据往返转换。</p>

<h2>支持的 CSV 格式</h2>
<p>
  本工具遵循 <strong>RFC 4180</strong> 标准。字段以逗号分隔。
  若字段中包含逗号、换行符或双引号，则必须用双引号包裹。
  引号字段内的双引号以两个连续双引号（<code>""</code>）转义。
  第一行始终作为列标题解析。
</p>

## 边界情况：本工具怎么处理

**空字段。** 下面这份 CSV 里，Bob 没有 email，第 3 行没有 name：

```csv
id,name,email
1,Alice,alice@example.com
2,Bob,
3,,charlie@example.com
```

默认情况下空字段转成 `""`。勾选「空字段 → null」则转成 `null`：

```json
[
  { "id": 1, "name": "Alice", "email": "alice@example.com" },
  { "id": 2, "name": "Bob", "email": null },
  { "id": 3, "name": null, "email": "charlie@example.com" }
]
```

**类型推断。** 勾选「推断数字和布尔值」（默认勾选）时，未加引号的 `true`、`false`、`null`（不区分大小写）转成 JSON 字面量，数字转成 JSON 数字。有三类值保持字符串，避免信息丢失：加了引号的字段（`"42"`）、以 0 开头的值（`007`、`0123`），以及超出 JavaScript 安全整数范围（大于 2^53 − 1）的整数，比如很长的订单号。

**表头。** 第一行固定当作表头。没有表头的 CSV 需要先补一行表头。两列同名时，后一列会覆盖前一列，请先改名。超出表头列数的字段会被丢弃，缺少的尾部字段按空值处理。

**分隔符。** 只识别逗号。分号或制表符分隔的文件请先转成逗号分隔。

**JSON → CSV。** 输入必须是对象数组。列名取第一个对象的键，只在后面对象里出现的键不会导出。嵌套对象不会展开，对象值会写成文本 `[object Object]`，请先把嵌套数据拍平再转换。
