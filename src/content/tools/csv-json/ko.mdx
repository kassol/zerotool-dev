## 회원 목록을 JSON으로

쇼핑몰 회원 목록을 내려받은 CSV라고 해 봅시다(예시 데이터).

{/* cj-check: {"to":"json"} */}

```csv
이름,생년월일,연락처,회원
김민준,19900101,010-1234-5678,Y
이서연,20010315,010-9876-5432,N
```

```json
[
  {
    "이름": "김민준",
    "생년월일": 19900101,
    "연락처": "010-1234-5678",
    "회원": "Y"
  },
  {
    "이름": "이서연",
    "생년월일": 20010315,
    "연락처": "010-9876-5432",
    "회원": "N"
  }
]
```

생년월일은 쉼표나 기호가 없는 여덟 자리 숫자라서 JSON 숫자가 됩니다. 받는 쪽에서 날짜 문자열을 기대한다면 이 열을 따옴표로 감싸거나 '숫자 및 불리언 추론'을 끄세요. 하이픈이 있는 연락처는 숫자로 읽히지 않아 문자열로 남고, `Y`·`N`도 불리언이 아니라 문자열입니다. 불리언으로 바뀌는 것은 따옴표 없는 `true`, `false`(대소문자 무관)뿐이고, `null`은 JSON의 `null`이 됩니다.

## 천 단위 쉼표 주의

가격에 천 단위 쉼표를 넣고 따옴표를 빠뜨리면 이렇게 됩니다.

{/* cj-check: {"to":"json","status":true} */}

```csv
상품,가격
키보드,15,000
마우스,"9,900"
```

```json
[
  {
    "상품": "키보드",
    "가격": 15,
    "column_3": "000"
  },
  {
    "상품": "마우스",
    "가격": "9,900",
    "column_3": ""
  }
]
```

상태 표시줄에는 `2행을 JSON으로 변환했습니다. 헤더보다 필드가 많은 행이 있어 다음 키를 추가했습니다: column_3.`이 나옵니다. 키보드 가격은 `15`와 `"000"`으로 갈라졌고(앞자리가 0인 값은 문자열로 남습니다), 따옴표로 감싼 마우스 가격은 문자열 하나로 남았습니다.

## 카카오 로컬 API 응답을 CSV로

[카카오 로컬 API](https://developers.kakao.com/docs/latest/ko/local/dev-guide) ‘키워드로 장소 검색’ 응답 예제의 `documents` 배열을 JSON 패널에 붙여 넣었습니다.

{/* cj-check: {"to":"csv"} */}

```json
[
  {
    "place_name": "카카오프렌즈 코엑스점",
    "distance": "418",
    "place_url": "http://place.map.kakao.com/26338954",
    "category_name": "가정,생활 > 문구,사무용품 > 디자인문구 > 카카오프렌즈",
    "address_name": "서울 강남구 삼성동 159",
    "road_address_name": "서울 강남구 영동대로 513",
    "id": "26338954",
    "phone": "02-6002-1880",
    "category_group_code": "",
    "category_group_name": "",
    "x": "127.05902969025047",
    "y": "37.51207412593136"
  }
]
```

```csv
place_name,distance,place_url,category_name,address_name,road_address_name,id,phone,category_group_code,category_group_name,x,y
카카오프렌즈 코엑스점,418,http://place.map.kakao.com/26338954,"가정,생활 > 문구,사무용품 > 디자인문구 > 카카오프렌즈",서울 강남구 삼성동 159,서울 강남구 영동대로 513,26338954,02-6002-1880,,,127.05902969025047,37.51207412593136
```

쉼표가 든 `category_name`만 큰따옴표로 감싸졌습니다. CSV에는 문자열과 숫자의 구분이 없으므로, 이 CSV를 다시 JSON으로 바꾸면 원래 문자열이던 `distance`, `id`, `x`, `y`가 숫자가 됩니다. 문자열로 되돌리려면 '숫자 및 불리언 추론'을 끄고 변환하세요.

## 헤더 규칙

첫 행은 항상 헤더로 봅니다. 헤더가 없는 CSV는 헤더 행을 먼저 추가하세요. 같은 이름의 열이 또 나오면 뒤의 열에 `_2`, `_3`을 붙이고, 헤더보다 많은 필드에는 위치에 따라 `column_N` 키를 붙입니다. 모자란 필드는 빈 값이 되며, '빈 필드 → null'을 체크하면 `null`이 됩니다.

## 제한 사항

- **구분자는 쉼표뿐입니다.** 탭과 세미콜론은 구분자가 아니므로, 스프레드시트에서 복사한 탭 구분 텍스트는 한 줄이 통째로 필드 하나가 됩니다.
- **필드 중간의 큰따옴표는 따옴표 구간을 엽니다.** `5" 파이프,x` 같은 행에서는 `"` 뒤의 쉼표와 줄바꿈이 다음 `"`가 나올 때까지 한 필드로 묶입니다. 필드 전체를 큰따옴표로 감싸고 안쪽 따옴표는 두 번 쓰세요(`"5"" 파이프"`). 닫히지 않은 따옴표는 나머지 텍스트를 모두 가져가며 오류를 내지 않습니다.
- **숫자 판정은 JavaScript `Number()`를 따릅니다.** 따옴표로 감싼 값, 0으로 시작하는 값, 2^53 − 1을 넘는 정수를 빼면 `+82`는 `82`로, `.5`는 `0.5`로 바뀝니다.
- **JSON → CSV에서 큰 숫자는 원래 자릿수 그대로 씁니다.** `12345678901234567890`, `1e-400`, `-0`처럼 JavaScript 숫자로 정확히 표현할 수 없는 JSON 숫자는 JSON에 적힌 그대로 CSV에 씁니다. 이를 위해 `JSON.rawJSON`이 필요하며 Chrome 114, Firefox 135, Safari 18.4 이상에서 지원합니다. 그보다 오래된 브라우저에서는 이런 숫자를 텍스트로 쓰고(배열 셀 안에서는 `"12345678901234567890"`처럼 따옴표가 붙습니다) 상태 표시줄에 해당 숫자를 알려 줍니다. 반올림한 값을 쓰는 일은 없습니다.
- **키 순서.** `2024`처럼 정수로 보이는 키는 다른 키보다 앞에 놓입니다(두 방향 모두). 값은 바뀌지 않습니다.
- **문자 인코딩은 처리하지 않습니다.** 붙여 넣은 텍스트만 다루므로, EUC-KR로 저장된 CSV가 편집기에서 이미 깨져 보인다면 깨진 글자 그대로 변환됩니다. 먼저 올바른 인코딩으로 파일을 여세요.
- **JSON 문법 오류**는 브라우저가 내는 영어 메시지 그대로 표시됩니다.
