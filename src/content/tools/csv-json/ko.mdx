<h2>사용 방법</h2>
<ol>
  <li><strong>CSV → JSON</strong>: CSV 데이터를 입력창에 붙여넣고 <strong>변환</strong>을 클릭합니다.</li>
  <li><strong>JSON → CSV</strong>: JSON 객체 배열을 입력창에 붙여넣고 <strong>변환</strong>을 클릭합니다.</li>
  <li>결과를 <strong>복사</strong>하거나 다운로드합니다.</li>
</ol>

<h2>CSV와 JSON에 대하여</h2>
<p>CSV는 스프레드시트나 데이터베이스 내보내기에 자주 사용되고, JSON은 API와 웹 앱에서 널리 사용되는 데이터 형식입니다. 두 형식 간 변환은 데이터 처리·분석·마이그레이션 작업에서 자주 필요합니다.</p>

## 경계 사례: 이 변환기의 동작

**빈 필드.** 아래 CSV에서 Bob은 email이, 3행은 name이 비어 있습니다.

```csv
id,name,email
1,Alice,alice@example.com
2,Bob,
3,,charlie@example.com
```

기본적으로 빈 필드는 `""`가 됩니다. '빈 필드 → null'을 체크하면 `null`이 됩니다.

```json
[
  { "id": 1, "name": "Alice", "email": "alice@example.com" },
  { "id": 2, "name": "Bob", "email": null },
  { "id": 3, "name": null, "email": "charlie@example.com" }
]
```

**타입 추론.** '숫자 및 불리언 추론'이 체크되어 있으면(기본값), 따옴표 없는 `true`, `false`, `null`(대소문자 무관)은 JSON 리터럴로, 숫자는 JSON 숫자로 바뀝니다. 정보가 사라지지 않도록 세 가지는 문자열로 남습니다: 따옴표로 감싼 필드(`"42"`), 0으로 시작하는 값(`007`, `0123`), JavaScript 숫자로 정확히 표현할 수 없는 큰 정수(2^53 − 1 초과, 예: 긴 주문 번호).

**헤더 행.** 첫 행은 항상 헤더로 봅니다. 헤더가 없는 CSV는 헤더 행을 먼저 추가하세요. 같은 이름의 열이 두 개면 뒤 열이 앞 열을 덮어쓰므로 먼저 이름을 바꾸세요. 헤더보다 많은 필드는 버려지고, 모자란 필드는 빈 값으로 처리됩니다.

**구분자.** 쉼표만 인식합니다. 세미콜론이나 탭으로 구분한 파일은 먼저 쉼표 구분으로 바꾸세요.

**JSON → CSV.** 입력은 객체 배열이어야 합니다. 열 이름은 첫 번째 객체의 키에서 가져오므로, 뒤쪽 객체에만 있는 키는 내보내지 않습니다. 중첩 객체는 펼쳐지지 않고 `[object Object]`라는 텍스트로 기록되므로, 먼저 평탄화하세요.
