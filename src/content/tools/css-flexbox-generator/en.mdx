<h2>How to Use</h2>
<ol>
  <li>Adjust the <strong>flex-direction</strong> to set the main axis: row (horizontal) or column (vertical).</li>
  <li>Set <strong>flex-wrap</strong> to allow items to wrap onto multiple lines.</li>
  <li>Configure <strong>justify-content</strong> to control spacing along the main axis.</li>
  <li>Set <strong>align-items</strong> to control how items align on the cross axis.</li>
  <li>Adjust <strong>align-content</strong> for multi-line wrap behaviour.</li>
  <li>Change <strong>gap</strong> to set gutters between items. One value sets both gaps; two values are row gap, then column gap.</li>
  <li>Use <strong>Items</strong> (1–8) to add or remove preview boxes and see how they respond.</li>
  <li>Click <strong>Copy</strong> to copy the generated <code>.container &#123; ... &#125;</code> rule.</li>
</ol>

<h2>Understanding the Generated CSS</h2>
<p>
  The generator outputs a <code>.container</code> rule with seven declarations:
  <code>display: flex</code>, <code>flex-direction</code>, <code>flex-wrap</code>,
  <code>justify-content</code>, <code>align-items</code>, <code>align-content</code>,
  and <code>gap</code>. Paste it into your stylesheet and rename
  <code>.container</code> to your own class name. Every property is written out, even at its default, so you can delete the lines you do not need.
</p>

<h2>Example: a Navigation Bar</h2>
<p>Keep <code>row</code> and <code>nowrap</code>, set justify-content to <code>space-between</code>, align-items to <code>center</code> and gap to <code>16px</code>:</p>

```css
.container {
  display: flex;
  flex-direction: row;
  flex-wrap: nowrap;
  justify-content: space-between;
  align-items: center;
  align-content: flex-start;
  gap: 16px;
}
```

<p>In a 600px container with three 100px items, Chrome placed them at 0, 250 and 500px: the first and last items touch the edges and the free space goes between them. With <code>space-around</code> the same items started at 50, 250 and 450px (half-size space at the ends), and with <code>space-evenly</code> at 75, 250 and 425px (equal space everywhere). The <code>align-content</code> line does nothing here because the container does not wrap; you can delete it.</p>

<h2>Example: Tags That Wrap</h2>
<p>Set flex-wrap to <code>wrap</code>, align-items to <code>flex-start</code>, align-content to <code>center</code>, and gap to <code>8px 12px</code>:</p>

```css
.container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  justify-content: flex-start;
  align-items: flex-start;
  align-content: center;
  gap: 8px 12px;
}
```

<p>Here <code>align-content</code> matters. In a 200px-tall container whose three 40px items fit on one line, the line moved down to 80px from the top. The same settings with <code>nowrap</code> left the items at the top, because a single-line flex container ignores <code>align-content</code> (<a href="https://www.w3.org/TR/css-flexbox-1/#align-content-property">CSS Flexbox Level 1 §8.4</a>).</p>

<h2>Limits and Common Surprises</h2>
<ul>
  <li><strong>Container properties only.</strong> There are no controls for the items: <code>flex-grow</code>, <code>flex-shrink</code>, <code>flex-basis</code>, <code>order</code> and <code>align-self</code> must be added by hand. A common next step is <code>flex: 1</code> on the item that should take the remaining space.</li>
  <li><strong>Long words do not shrink.</strong> A flex item's minimum width is <code>auto</code>, its longest unbreakable content. In a 300px row, an item holding a long URL stayed 684px wide and overflowed. Add <code>min-width: 0</code> (plus <code>overflow-wrap: anywhere</code> or <code>text-overflow</code>) to that item.</li>
  <li><strong>Missing values.</strong> justify-content has no <code>stretch</code> or <code>start</code>/<code>end</code>, and align-content has no <code>space-evenly</code>; type them into the copied CSS if you need them.</li>
  <li><strong>Reverse directions</strong> change only the visual order. Keyboard focus and screen readers still follow the HTML order.</li>
  <li>The gap field is not validated: an invalid value is copied as written, and the browser drops it.</li>
</ul>

<h2>Flexbox vs Grid</h2>
<p>
  Use Flexbox when you have a one-dimensional layout — items along a single row or column.
  Use CSS Grid when you need two-dimensional control over both rows and columns simultaneously.
  In practice, Flexbox excels at component-level layout (navigation, button groups, form rows),
  while Grid is better for page-level structure.
</p>
