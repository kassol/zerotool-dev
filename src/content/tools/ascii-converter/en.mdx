<h2>How to Use</h2>
<ol>
  <li>To convert <strong>Text → ASCII</strong>: type or paste text in the left panel and click <strong>Text → ASCII</strong>.</li>
  <li>To convert <strong>ASCII → Text</strong>: enter space-separated codes in the right panel and click <strong>ASCII → Text</strong>.</li>
  <li>Select the output format (Decimal, Hex, Octal, Binary) before converting.</li>
  <li>Click <strong>Copy</strong> to copy the result.</li>
</ol>

<h2>Worked Examples</h2>
<h3>Text to ASCII</h3>
<p>Input: <code>Hello</code></p>
<p>Decimal output: <code>72 101 108 108 111</code></p>
<p>Hex output: <code>0x48 0x65 0x6C 0x6C 0x6F</code></p>

<h3>ASCII to Text</h3>
<p>Input: <code>87 111 114 108 100</code></p>
<p>Output: <code>World</code></p>

<h3>Accented letters and symbols</h3>
<p>Input <code>café ☕</code> with Hex selected gives <code>0x63 0x61 0x66 0xE9 0x20 0x2615</code>. The space is <code>0x20</code>. <code>é</code> (U+00E9) and the coffee cup (U+2615) are outside ASCII, so the tool writes their Unicode code points. Those numbers are not the UTF-8 bytes: <code>é</code> is stored as the two bytes <code>C3 A9</code>. To see bytes, use <a href="/tools/text-to-binary/">Text to Binary</a>.</p>

<h3>Line breaks</h3>
<p>Text copied from a Windows file often ends lines with CR LF. <code>a</code>, a Windows line break and <code>b</code> convert to <code>97 13 10 98</code> in Decimal. Control characters are written as numbers like any other character; going back, <code>10</code> becomes a real line break in the text box.</p>

<h3>Mixed input formats</h3>
<p>The codes box accepts any mix of the four formats, separated by spaces, commas or line breaks. <code>0b1001111 0b1001011</code> decodes to <code>OK</code>, and <code>72, 0x69 0o41</code> decodes to <code>Hi!</code>. The prefix chooses the base (upper or lower case); a token without a prefix is decimal.</p>

<h2>Output Formats</h2>
<ul>
  <li><strong>Decimal</strong>: the code point in base 10, such as <code>65</code>.</li>
  <li><strong>Hex</strong>: upper-case digits with a <code>0x</code> prefix, such as <code>0x41</code>.</li>
  <li><strong>Octal</strong>: a <code>0o</code> prefix, as in JavaScript and Python 3 literals, such as <code>0o101</code>.</li>
  <li><strong>Binary</strong>: a <code>0b</code> prefix and no leading zeros, such as <code>0b1000001</code>. It is not padded to 8 bits.</li>
</ul>
<p>The output depends on the format selected when you click <strong>Text → ASCII</strong>. Changing the format afterwards does not convert again; click the button once more.</p>

<h2>Limits</h2>
<ul>
  <li>Text → ASCII works on Unicode code points. An emoji built from several code points, such as 👍🏽 (thumbs up plus skin tone), gives two codes: <code>128077 127997</code>.</li>
  <li>ASCII → Text accepts code points from 0 to 1114111 (<code>0x10FFFF</code>). Surrogate values 55296–57343 (<code>0xD800</code>–<code>0xDFFF</code>) are not characters and give "Code point out of range".</li>
  <li>A token that is not entirely digits of its base, such as <code>72abc</code>, <code>1.5</code> or <code>0b102</code>, gives "Invalid code" with the token shown. Nothing is converted until the error is fixed.</li>
  <li>The two error messages are in English on every language version of the page.</li>
</ul>
<p>For base conversion of single numbers, with two's complement and other bases, use the <a href="/tools/number-base/">Binary to Decimal &amp; Hex Converter</a>.</p>

<h2>What is ASCII?</h2>
<p>ASCII (American Standard Code for Information Interchange) is a character encoding standard that assigns numbers to 128 characters including letters, digits, punctuation, and control characters. It forms the foundation of modern text encoding systems like UTF-8.</p>
