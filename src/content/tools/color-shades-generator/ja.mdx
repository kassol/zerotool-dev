<h2>使い方</h2>
<ol>
  <li><strong>カラーピッカー</strong>を使うか、<strong>HEX値</strong>（例：<code>#3b82f6</code>）を直接入力してベースカラーを設定します。</li>
  <li>パレットが即座に更新され、最も明るい（50）から最も暗い（900）まで10シェードが表示されます。</li>
  <li>各シェードカードに <strong>HEX</strong>・<strong>HSL</strong>・<strong>RGB</strong> 値が表示されます。</li>
  <li>シェードカードをクリックすると、その<strong>HEX値をクリップボードにコピー</strong>します。</li>
  <li><strong>CSS変数としてすべてコピー</strong>をクリックすると、全シェードを <code>:root</code> CSSブロックとしてコピーします。</li>
</ol>

<h2>コピー全体の出力形式</h2>

既定の色 `#3b82f6` での実際の出力：

```css
:root {
  --color-50: #ECF3FE;
  --color-100: #D3E3FD;
  --color-200: #9EC1FA;
  --color-300: #639CF8;
  --color-400: #2474F5;
  --color-500: #0A56D1;
  --color-600: #0842A1;
  --color-700: #06327A;
  --color-800: #042253;
  --color-900: #021431;
}
```

## 入力色の扱い

ツールはベースカラーを HSL に変換し、色相と彩度を整数に丸めてそのまま使います。明度は入力色から取らず、各段階に固定値を使います（50 が 96%、900 が 10%）。そのため、ベースカラー自体がスケールに入るのは、その明度がたまたま固定値のどれかと一致したときだけです。

上の「コピー全体の出力形式」の既定色 `#3b82f6` は `hsl(217, 91%, 60%)` です。明度 60% は 300（68%）と 400（55%）の間なので、`#3B82F6` 自体はリストになく、500 はより暗い `#0A56D1` になります。ブランドカラーを特定の段階に置きたい場合は、コピー後にその段階を手で差し替えてください。

## コントラストは色相で変わる

HSL の明度は知覚上の明るさと一致しないため、同じ段階でも色相によってコントラストが大きく違います。WCAG 2.2 は[通常の文字で 4.5:1、大きな文字で 3:1](https://www.w3.org/TR/WCAG22/#contrast-minimum) を求めています。生成された各段階と白（`#FFFFFF`）のコントラスト比（WCAG の式で計算）：

| 段階 | 青 `#3b82f6` | 黄 `#ffd700` |
|---|---|---|
| 500 | 6.43 | 1.90 |
| 600 | 9.11 | 3.18 |
| 700 | 12.03 | 5.17 |
| 800 | 15.45 | 8.81 |

青は 500 で白地に対して 4.5:1 を満たしますが、黄は 700 まで下げる必要があります。文字色と背景色の組み合わせごとに[カラーコントラストチェッカー](/ja/tools/color-contrast-checker/)で確認し、どの色相にも同じ段階番号を使い回さないでください。

## Tailwind CSS で使う

コピーされる変数名は `--color-50` … `--color-900` です。Tailwind CSS v4 は `@theme` 内のテーマ変数からユーティリティを作るので、色名を付けて書き換えます：

```css
@import "tailwindcss";

@theme {
  --color-brand-50: #ECF3FE;
  --color-brand-500: #0A56D1;
  --color-brand-900: #021431;
}
```

これで `bg-brand-500` や `text-brand-900` が使えます（[Tailwind CSS: Theme variables](https://tailwindcss.com/docs/theme)）。Tailwind v3 では同じ値を `tailwind.config.js` の `theme.extend.colors.brand` に書きます。

## 制限事項

- **10 段階（50〜900）。** Tailwind 標準パレットは 950 を加えた 11 段階です（[Tailwind CSS: Colors](https://tailwindcss.com/docs/colors)）。このツールに 950 はありません。
- **明度は固定値**なので、ベースカラー自身の明度は無視されます（上記参照）。ごく明るい色や暗い色を入れても、明度の範囲はほかの色と同じです。
- **HSL を使い、知覚的に均等な色空間ではありません。** Tailwind v4 のパレットは OKLCH で定義されています。ここでの各段階は色相をまたいで均等ではありません。
- **入力は `#RRGGBB` のみ。** 3 桁の hex（`#39f`）、`rgb()`、`hsl()` は受け付けません。カラーピッカーは常に 6 桁を返します。
- **変数名は `--color-{段階}` 固定**です。
