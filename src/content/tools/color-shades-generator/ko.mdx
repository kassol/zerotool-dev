<h2>사용 방법</h2>
<ol>
  <li><strong>색상 선택기</strong>를 사용하거나 <strong>HEX 값</strong>(예: <code>#3b82f6</code>)을 직접 입력하여 기본 색상을 설정합니다.</li>
  <li>팔레트가 즉시 업데이트되어 가장 밝은(50)부터 가장 어두운(900)까지 10단계 색상을 표시합니다.</li>
  <li>각 쉐이드 카드에 <strong>HEX</strong>, <strong>HSL</strong>, <strong>RGB</strong> 값이 표시됩니다.</li>
  <li>쉐이드 카드를 클릭하면 해당 <strong>HEX 값이 클립보드에 복사</strong>됩니다.</li>
  <li><strong>모두 CSS 변수로 복사</strong>를 클릭하면 모든 쉐이드를 <code>:root</code> CSS 블록으로 복사합니다.</li>
</ol>

<h2>복사 전체 출력 형식</h2>

기본 색상 `#3b82f6`의 실제 출력:

```css
:root {
  --color-50: #ECF3FE;
  --color-100: #D3E3FD;
  --color-200: #9EC1FA;
  --color-300: #639CF8;
  --color-400: #2474F5;
  --color-500: #0A56D1;
  --color-600: #0842A1;
  --color-700: #06327A;
  --color-800: #042253;
  --color-900: #021431;
}
```

<h2>디자인 시스템에서 쉐이드 활용</h2>
<p>10단계 쉐이드 스케일은 다음에 적합합니다:</p>
<ul>
  <li><strong>기본/강조 색상:</strong> 500을 주 브랜드 색상으로 사용하고, 밝은 쉐이드는 배경과 호버 상태에, 어두운 쉐이드는 텍스트와 테두리에 사용</li>
  <li><strong>상태 피드백:</strong> 50–100을 알림 배경 색조에, 700–900을 그 위의 텍스트 색상에 사용</li>
  <li><strong>다크 모드:</strong> 스케일 방향을 반전시켜 900을 배경으로, 50을 텍스트로 사용</li>
  <li><strong>컴포넌트 변형:</strong> 버튼의 기본, 호버, 활성 상태에 각각 500, 600, 700 사용</li>
</ul>

## 입력 색상 처리 방식

도구는 기본 색상을 HSL로 바꾸고, 색조와 채도를 정수로 반올림해 그대로 씁니다. 밝기는 입력 색상에서 가져오지 않고 단계마다 고정값을 씁니다(50은 96%, 900은 10%). 그래서 기본 색상 자체가 스케일에 들어가는 것은 그 밝기가 고정값 중 하나와 우연히 같을 때뿐입니다.

위 "복사 전체 출력 형식"의 기본 색상 `#3b82f6`은 `hsl(217, 91%, 60%)`입니다. 밝기 60%는 300(68%)과 400(55%) 사이이므로 `#3B82F6` 자체는 목록에 없고, 500은 더 어두운 `#0A56D1`입니다. 브랜드 색상을 특정 단계에 두어야 한다면 복사한 뒤 그 단계를 직접 바꾸세요.

## 대비는 색조에 따라 달라진다

HSL 밝기는 눈으로 느끼는 밝기와 같지 않아서, 같은 단계라도 색조에 따라 대비가 크게 다릅니다. WCAG 2.2는 [일반 텍스트 4.5:1, 큰 텍스트 3:1](https://www.w3.org/TR/WCAG22/#contrast-minimum)을 요구합니다. 생성된 각 단계와 흰색(`#FFFFFF`)의 대비(WCAG 공식으로 계산):

| 단계 | 파랑 `#3b82f6` | 초록 `#16a34a` | 노랑 `#ffd700` |
|---|---|---|---|
| 500 | 6.43 | 2.38 | 1.90 |
| 600 | 9.11 | 3.93 | 3.18 |
| 700 | 12.03 | 6.20 | 5.17 |

파랑은 500에서 흰 배경 대비 4.5:1을 넘지만, 초록과 노랑은 700이 되어야 합니다. 글자색과 배경색 조합마다 [색상 대비 검사기](/ko/tools/color-contrast-checker/)로 확인하고, 모든 색조에 같은 단계 번호를 쓰지 마세요.

## Tailwind CSS에서 쓰기

복사되는 변수 이름은 `--color-50` … `--color-900`입니다. Tailwind CSS v4는 `@theme` 안의 테마 변수로 유틸리티를 만들기 때문에 색 이름을 붙여 바꿉니다:

```css
@import "tailwindcss";

@theme {
  --color-brand-50: #ECF3FE;
  --color-brand-500: #0A56D1;
  --color-brand-900: #021431;
}
```

이제 `bg-brand-500`, `text-brand-900` 등을 쓸 수 있습니다([Tailwind CSS: Theme variables](https://tailwindcss.com/docs/theme)). Tailwind v3에서는 같은 값을 `tailwind.config.js`의 `theme.extend.colors.brand`에 넣습니다.

## 제한 사항

- **10단계, 50–900.** Tailwind 기본 팔레트는 950을 더한 11단계입니다([Tailwind CSS: Colors](https://tailwindcss.com/docs/colors)). 이 도구에는 950이 없습니다.
- **밝기는 고정값**이라 기본 색상 자체의 밝기는 무시됩니다(위 참고). 아주 밝거나 어두운 색을 넣어도 밝기 범위는 다른 색과 같습니다.
- **HSL을 쓰며, 지각적으로 균일한 색 공간이 아닙니다.** Tailwind v4 팔레트는 OKLCH로 정의되어 있습니다. 여기서의 단계는 색조 간에 고르지 않습니다.
- **입력은 `#RRGGBB`만.** 세 자리 hex(`#39f`), `rgb()`, `hsl()`은 받지 않습니다. 색상 선택기는 항상 여섯 자리를 줍니다.
- **변수 이름은 `--color-{단계}`로 고정**입니다.
