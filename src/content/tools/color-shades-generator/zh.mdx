## 色阶是怎么算出来的

工具把颜色换算到 OKLCH（Oklab 空间的明度、彩度、色相，见 [CSS Color 4 §9.2](https://www.w3.org/TR/css-color-4/#ok-lab)），再按 [Tailwind CSS 默认调色板](https://tailwindcss.com/docs/colors)的命名生成 50 到 950 共 11 级：

- **明度**取 Tailwind v4 调色板里色相最接近的两套色板，按色相插值。Tailwind 的黄色每一级都比蓝色亮，所以不同色相的明度阶梯本来就不同。灰色和接近灰色的输入用 9 套中性色板的中位数。整条阶梯会缩放到恰好经过你的颜色。
- **彩度**沿用同一套色板的曲线：50 级最低，400 到 600 附近最高，再向 950 降低。
- **色相**保持你输入的值，除非在「色相偏移」里设了角度。
- **超出 sRGB 的级别**保持明度和色相，只降低彩度（[CSS Color 4 §14](https://www.w3.org/TR/css-color-4/#gamut-mapping)）。

基础色本身不改动，逐字节放进它那一级。自动模式下，从 50 到 950 明度和 WCAG 相对亮度逐级下降，级别数字越小颜色越浅。

## 示例：Ant Design 主色 #1677ff

Ant Design 的品牌色是 `#1677ff`（[Ant Design 色彩](https://ant.design/docs/spec/colors-cn)）。把它输进工具：

{/* csg-scale: {"input":"#1677ff"} */}

| 级别 | HEX | 白字 |
|---|---|---|
| 50 | `#eff6ff` | 1.08 |
| 100 | `#dbe9fe` | 1.22 |
| 200 | `#bed8ff` | 1.45 |
| 300 | `#95beff` | 1.89 |
| 400 | `#5899ff` | 2.83 |
| 500 | `#1677ff` | 4.10 |
| 600 | `#0061dc` | 5.60 |
| 700 | `#0052bd` | 7.13 |
| 800 | `#00439d` | 9.17 |
| 900 | `#003886` | 10.99 |
| 950 | `#052453` | 15.17 |

`#1677ff` 的彩度很高，300、400 和 600 到 900 级按原彩度都超出 sRGB，状态栏下方会列出这几级。

同一个颜色交给 `@ant-design/colors` 8.0.1 的 `generate()`，得到 `#e6f4ff #bae0ff #91caff #69b1ff #4096ff #1677ff #0958d9 #003eb3 #002c8c #001d66`：10 个颜色，主色在第 6 个，与文档「建议选择色板从浅至深的第六个颜色作为主色」一致。它在 HSB 模型里有意偏转色相，换算到 OKLCH 后，最浅一级色相 241.3 度，最深一级 262.6 度，相差约 21 度；本工具除 50 级外，各级色相都在 258.4 到 259.4 度之间（50 级彩度只有 0.014，取整到 8 位后色相读数偏到 254.6 度）。两种做法各有用途：想要 Ant Design 那种浅色偏青、深色偏紫的味道，可以在「色相偏移」里分别给 50 级和 950 级设一个角度。

## 导出到 Sass 项目

选「SCSS」，颜色名填 `primary`，得到每级一个变量和一个 map：

{/* csg: {"input":"#1677ff","export":"scss","values":"hex","name":"primary"} */}
```scss
// base: primary-500
$primary-50: #eff6ff;
$primary-100: #dbe9fe;
$primary-200: #bed8ff;
$primary-300: #95beff;
$primary-400: #5899ff;
$primary-500: #1677ff;
$primary-600: #0061dc;
$primary-700: #0052bd;
$primary-800: #00439d;
$primary-900: #003886;
$primary-950: #052453;

$primary: (
  50: $primary-50,
  100: $primary-100,
  200: $primary-200,
  300: $primary-300,
  400: $primary-400,
  500: $primary-500,
  600: $primary-600,
  700: $primary-700,
  800: $primary-800,
  900: $primary-900,
  950: $primary-950
);
```

用 `@use "sass:map";` 后，`map.get($primary, 600)` 取到 `#0061dc`。工具的回归测试会把每种导出交给真实的解析器：CSS 用 PostCSS，Tailwind v4 用 Tailwind 4.3.3 的编译器，SCSS 用 Dart Sass 1.105，JSON 用 `JSON.parse`，取回的每个值都要和卡片上的颜色一致。

## 对比度看卡片上的数字

Tailwind 让明度随色相变化，本工具也照做，所以同一级在不同色相下对比度不同：

{/* csg-contrast: {"inputs":["#1677ff","#16a34a"]} */}

| 级别 | 蓝 `#1677ff` | 绿 `#16a34a` |
|---|---|---|
| 500 | 4.10 | 2.27 |
| 600 | 5.60 | 3.29 |
| 700 | 7.13 | 5.05 |

WCAG 2.2 对正文要求 [4.5:1，大号文字 3:1](https://www.w3.org/TR/WCAG22/#contrast-minimum)。绿色要到 700 级才能放白色正文。具体文字和背景的搭配，可以在[颜色对比度检测器](/zh/tools/color-contrast-checker/)里再确认。

## 与其他色阶工具的实测对比

2026-10-01 实测：

- **in5.cn 色阶生成器**同样按 OKLCH 分布明度并标出白字、黑字对比度。差异在边界情况：输入 `#ffff00` 后它把纯黄放在 50 级，其余各级都是 `#919100` 这类橄榄色；输入只有 5 位的 `#12345` 时不提示错误，页面仍显示上一个颜色的色阶；Tailwind 导出只有 v3 的 `theme.extend.colors` 片段，没有 v4 的 `@theme`。本工具对 `#12345` 提示「十六进制颜色应为 3、4、6 或 8 位」。
- **uicolors.app** 对 `#1a73e8` 把颜色放在 700 级，浅色几级的色相向天蓝偏转约 24 度；CSS、SCSS 导出和 OKLCH / HSL / RGB 取值需要付费版。
- **tints.dev** 默认把颜色放在 500 级，它导出的 `oklch()` 里 50 级色相比 500 级大约 18 度，浅色偏紫。

## 限制

- **只输出 sRGB**，没有 Display P3。Tailwind v4 自带色板有一部分超出 sRGB，在 P3 屏幕上会比这里的 HEX 更鲜艳。
- **固定 11 级**，50 到 950，不能自定义级别名，也不能生成 Ant Design 那样的 10 级。
- **固定位置可能让几级重合**：白色固定在 500 时，100 到 500 都是白色，状态栏会写出重合的级别。
- **输入格式**：3、4、6、8 位 HEX，`rgb()`、`hsl()`、`oklch()`。透明度会被忽略；`blue` 这类颜色名和 `lab()`、`color()` 不支持。
- **Tailwind v3 配合 oklch()**：在 Tailwind CSS 3.4.19 中，`bg-primary-500` 正常，但 `bg-primary-500/50` 这类透明度写法对 oklch() 值不生成任何样式（2026-10-01 实测）。v3 项目请选 HEX、RGB 或 HSL。
- **对比度只算 WCAG 2.2**，只对纯白和纯黑，不算 APCA，也不算两级颜色之间的对比度。
