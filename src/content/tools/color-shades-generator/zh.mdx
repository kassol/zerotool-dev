## 生成器如何处理你的颜色

工具把基础色转成 HSL，色相和饱和度取整后保持不变。亮度不取自你的颜色：每一档用固定值，50 为 96%，900 为 10%。所以只有当基础色的亮度恰好是其中某个值时，它本身才会出现在色阶里。

上面「复制全部的输出格式」里的默认色 `#3b82f6` 是 `hsl(217, 91%, 60%)`。60% 的亮度落在 300（68%）与 400（55%）之间，`#3B82F6` 本身不在列表里，500 是更深的 `#0A56D1`。如果品牌色必须出现在某一档，复制后手动替换那一档。

## 对比度随色相变化

HSL 的亮度不等于人眼感知的亮度，同一档在不同色相下的对比度差别很大。WCAG 2.2 要求[正文 4.5:1、大字 3:1](https://www.w3.org/TR/WCAG22/#contrast-minimum)。下表是生成的各档与白色（`#FFFFFF`）的对比度，按 WCAG 公式计算：

| 档位 | 蓝 `#3b82f6` | 红 `#e11d48` | 绿 `#16a34a` |
|---|---|---|---|
| 400 | 4.29 | 4.22 | 1.69 |
| 500 | 6.43 | 6.00 | 2.38 |
| 600 | 9.11 | 8.71 | 3.93 |
| 700 | 12.03 | 11.69 | 6.20 |

蓝色和红色的 500 在白底上已达到 4.5:1，绿色要到 700。每一组文字与背景都用[颜色对比度检查器](/zh/tools/color-contrast-checker/)核对，不要所有色相都套同一个档位。

## 在 Tailwind CSS 中使用

复制出的变量名是 `--color-50` … `--color-900`。Tailwind CSS v4 从 `@theme` 里的主题变量生成工具类，所以要加上颜色名：

```css
@import "tailwindcss";

@theme {
  --color-brand-50: #ECF3FE;
  --color-brand-500: #0A56D1;
  --color-brand-900: #021431;
}
```

这样就能用 `bg-brand-500`、`text-brand-900` 等类（[Tailwind CSS：Theme variables](https://tailwindcss.com/docs/theme)）。Tailwind v3 则把同样的值写进 `tailwind.config.js` 的 `theme.extend.colors.brand`。

## 限制

- **10 档，50–900。** Tailwind 自带调色板有 11 档，多一个 950（[Tailwind CSS：Colors](https://tailwindcss.com/docs/colors)），本工具没有 950。
- **亮度是固定值**，基础色自身的亮度会被忽略（见上文）；很浅或很深的输入，得到的亮度范围和其他颜色一样。
- **使用 HSL，不是感知均匀的色彩空间。** Tailwind v4 的调色板用 OKLCH 定义；这里的各档在不同色相之间并不等距。
- **只接受 `#RRGGBB`。** 三位 hex（`#39f`）、`rgb()`、`hsl()` 都不接受；取色器始终给出六位。
- **变量名固定**为 `--color-{档位}`。
