<h2>サンプル</h2>
<h3>圧縮前</h3>

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <!-- ページメタ情報 -->
    <title>こんにちは</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>太字を含む <strong>テキスト</strong>。</p>
  </body>
</html>
```

<h3>圧縮後</h3>

```html
<!doctype html><html lang="ja"><head>  <title>こんにちは</title> </head> <body> <h1>Hello World</h1> <p>太字を含む <strong>テキスト</strong>。</p> </body></html>
```

<p>ステータス行：<code>圧縮完了 — 234 B → 176 B (−24.8%)</code>。コメントが消え、インデントはそれぞれ 1 つのスペースになっています。タグ間のスペースが残るのは、空白だけのテキストノードをすべて 1 つのスペースとして残すためです。<code>&lt;p&gt;Hello &lt;strong&gt;world&lt;/strong&gt;!&lt;/p&gt;</code> では <code>&lt;strong&gt;</code> の前のスペースが表示されるので、ツールはどのスペースを消してよいかを判断しません。<a href="https://github.com/terser/html-minifier-terser" target="_blank" rel="noopener">html-minifier-terser</a> などビルド時の圧縮ツールは <code>collapseWhitespace</code> などのオプションでさらに削れます。</p>

<h2>圧縮されるもの</h2>
<ul>
  <li>タグ間の空白（inter-tag whitespace）が折りたたまれます。</li>
  <li>HTML コメントは削除されます — IE 条件付きコメント（<code>&lt;!--[if IE]&gt;</code>）は例外として保持されます。</li>
  <li><code>disabled=""</code> のような boolean 属性は <code>disabled</code> に簡略化されます。</li>
  <li>テキスト内の連続した空白は 1 つのスペースにまとめます。タグ間の空白だけのテキストは削除せず 1 つのスペースにします。どの空白が表示されるかはパーサーでは判断できないためです。</li>
  <li><code>&lt;p&gt;</code> や <code>&lt;h1&gt;</code> などのブロック要素の中身がテキストだけの場合、そのテキストの前後の空白を取り除きます。<code>&lt;strong&gt;</code>・<code>&lt;a&gt;</code>・<code>&lt;span&gt;</code> などのインライン要素は、見える空白なので両端に 1 つずつ残します。<code>&lt;strong&gt;Note: &lt;/strong&gt;read this.</code> はそのままです。</li>
</ul>

<h2>そのまま保持されるもの</h2>
<ul>
  <li><code>&lt;script&gt;</code>、<code>&lt;style&gt;</code>、<code>&lt;pre&gt;</code>、<code>&lt;textarea&gt;</code>、<code>&lt;code&gt;</code>、<code>&lt;samp&gt;</code>、<code>&lt;kbd&gt;</code> 内のコンテンツ。</li>
  <li>属性値（引用符内の空白や、インラインイベントハンドラを含む）。</li>
</ul>

<h2>HTML を手動圧縮するタイミング</h2>
<p>モダンなビルドチェーン（Vite、Webpack、Astro、Next.js）はバンドル時に HTML を自動圧縮します。本ツールは単発の作業に向いています — CMS からエクスポートされたコード、圧縮前後のサイズ比較、手書きテンプレートの確認など。整形は日常的に使える機能で、本番環境の 1 行 HTML を貼り付けてデバッグや diff のための可読版を得られます。</p>

<h2>制限</h2>
<ul>
  <li>インライン要素の両端の空白は、CSS で見えなくなる位置（行頭など）でも残ります。ツールは CSS を読まないため、<code>display</code> や <code>white-space</code> で空白の表示が変わるかどうかは判断できません。</li>
  <li>まとめるのは HTML の空白（スペース・タブ・改行・改ページ・復帰）だけです。ノーブレークスペースは残ります。<code>Price:&amp;nbsp;&amp;nbsp;10&amp;nbsp;EUR</code> は 3 つのノーブレークスペースを保ったまま、<code>&amp;nbsp;</code> ではなく文字 U+00A0 として出力されます。全角スペース U+3000 も残ります。</li>
  <li>フラグメントで HTML パーサーが <code>&lt;body&gt;</code> の外へ移す内容は、元の順序で書き戻します。最初の要素より前の <code>&lt;!--[if mso]&gt;</code> のような条件付きコメントと、本文より前の <code>&lt;title&gt;</code>・<code>&lt;meta&gt;</code>・<code>&lt;link&gt;</code>・<code>&lt;style&gt;</code> です。通常のコメントはどこにあっても削除します。</li>
  <li>インラインの JavaScript と CSS はそのままコピーし、圧縮はしません。</li>
  <li>HTML はブラウザーの <code>DOMParser</code> で解析するため、不正なマークアップは修復された形で出力され（閉じタグの補完、余分なタグの削除）、doctype は <code>&lt;!doctype html&gt;</code> と書き出されます。</li>
</ul>
