<h2>示例</h2>
<h3>压缩前</h3>

```html
<!DOCTYPE html>
<html lang="zh">
  <head>
    <!-- 页面元信息 -->
    <title>你好</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>一段 <strong>加粗</strong> 文本。</p>
  </body>
</html>
```

<h3>压缩后</h3>

```html
<!doctype html><html lang="zh"><head>  <title>你好</title> </head> <body> <h1>Hello World</h1> <p>一段 <strong>加粗</strong> 文本。</p> </body></html>
```

<p>状态栏：<code>已压缩 — 211 B → 159 B (−24.6%)</code>。注释被删除，每段缩进变成一个空格。标签之间的空格之所以保留，是因为工具把只含空白的文本节点一律保留为一个空格：在 <code>&lt;p&gt;Hello &lt;strong&gt;world&lt;/strong&gt;!&lt;/p&gt;</code> 里，<code>&lt;strong&gt;</code> 前的空格是看得见的，工具不去判断哪些空格可以安全删掉。<a href="https://github.com/terser/html-minifier-terser" target="_blank" rel="noopener">html-minifier-terser</a> 这类构建期压缩器可以用 <code>collapseWhitespace</code> 等选项删得更多。</p>

<h2>会被压缩的内容</h2>
<ul>
  <li>标签之间的空白（inter-tag whitespace）会折叠。</li>
  <li>HTML 注释被删除——IE 条件注释（<code>&lt;!--[if IE]&gt;</code>）除外。</li>
  <li><code>disabled=""</code> 这类布尔属性会简化为 <code>disabled</code>。</li>
  <li>文本中连续的空白折叠为一个空格。标签之间只有空白的文本变成一个空格，不会删掉，因为解析器无法判断哪些空格是可见的。</li>
  <li><code>&lt;p&gt;</code>、<code>&lt;h1&gt;</code> 这类块级元素内只有文本时，文本首尾的空白被去掉。<code>&lt;strong&gt;</code>、<code>&lt;a&gt;</code>、<code>&lt;span&gt;</code> 等行内元素两端各保留一个空格，因为这个空格看得见：<code>&lt;strong&gt;Note: &lt;/strong&gt;read this.</code> 保持不变。</li>
</ul>

<h2>会原样保留的内容</h2>
<ul>
  <li><code>&lt;script&gt;</code>、<code>&lt;style&gt;</code>、<code>&lt;pre&gt;</code>、<code>&lt;textarea&gt;</code>、<code>&lt;code&gt;</code>、<code>&lt;samp&gt;</code>、<code>&lt;kbd&gt;</code> 内的内容。</li>
  <li>属性值，包括带引号的空白和内联事件处理函数。</li>
  <li><code>&lt;!DOCTYPE&gt;</code> 声明。</li>
</ul>

<h2>什么时候手动压缩 HTML</h2>
<p>现代构建链路（Vite、Webpack、Astro、Next.js）通常会在 bundle 阶段自动压缩 HTML。这个工具适合一次性场景——从 CMS 导出的代码、想对比压缩前后体积、或检查手写模板。美化则是日常使用：把生产环境的一行式 HTML 粘进来，拿到可读副本用于调试或 diff。</p>

<h2>限制</h2>
<ul>
  <li>行内元素两端保留折叠后的空格，即使 CSS 会把它藏起来（例如在行首）。工具不读取你的 CSS，无法判断 <code>display</code> 或 <code>white-space</code> 是否改变了空格的显示。</li>
  <li>只折叠 HTML 空白（空格、制表符、换行、换页、回车）。不换行空格会保留：<code>Price:&amp;nbsp;&amp;nbsp;10&amp;nbsp;EUR</code> 输出后仍是三个不换行空格，只是写成字符 U+00A0 而不是 <code>&amp;nbsp;</code>。全角空格 U+3000 同样保留。</li>
  <li>片段中被 HTML 解析器移出 <code>&lt;body&gt;</code> 的内容会按原顺序写回：第一个元素之前的 <code>&lt;!--[if mso]&gt;</code> 这类条件注释，以及正文之前的 <code>&lt;title&gt;</code>、<code>&lt;meta&gt;</code>、<code>&lt;link&gt;</code>、<code>&lt;style&gt;</code>。普通注释无论在哪里都会删除。</li>
  <li>内联 JavaScript 与 CSS 原样复制，不做压缩。</li>
  <li>HTML 由浏览器的 <code>DOMParser</code> 解析，不合法的标记输出时已被修正（补上缺失的结束标签、丢掉多余的标签），doctype 写成 <code>&lt;!doctype html&gt;</code>。</li>
</ul>
