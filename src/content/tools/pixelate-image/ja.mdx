<h2>どの効果を使うべきか</h2>
<ul>
  <li><strong>モザイク</strong> — ブロックごとの平均色に置き換えます。意図的なモザイク表現や一般的な目隠しに向いています。文字情報には不向きで、ブロックを大きくしても顔が識別されないとは限りません。</li>
  <li><strong>ぼかし</strong> — なめらかなソフトフォーカス効果です。見た目は「検閲」っぽくありませんが、強力な逆ぼかし処理で復元される可能性があり、文字に対しては同様に安全ではありません。</li>
  <li><strong>塗りつぶし</strong> — 範囲を単色で完全に置き換えます。元の画素情報を完全に破棄する唯一の方法です。パスワード・トークン・API キー、AI チャットに貼り付ける内容には必ずこれを使ってください。</li>
</ul>

<h2>3 つの効果はピクセルをどう変えるか</h2>
<p>
  設定を変えるたびに、ツールは元画像を描き直してから効果をかけ直すため、効果が重なることはありません。以下の数値はツール自身のモザイク関数で計算したものです。
</p>
<ul>
  <li><strong>モザイク</strong>（ブロックサイズ 4〜64 px、既定 16）は、範囲の左上を起点に正方形のセルへ分け、各セルをその中のピクセルの平均色で塗ります。黒 2 つと白 2 つの 2 × 2 セルは <code>rgb(128, 128, 128)</code> になります。色は透明度で重み付けされるため、不透明な赤 2 つと完全に透明なピクセル 2 つのセルは、暗い赤ではなく半透明の赤（<code>255, 0, 0、alpha 128</code>）になります。</li>
  <li><strong>端のセルは残りの幅に合わせて小さくなります。</strong>幅 100 px の範囲をブロック 16 で処理すると、16 px の列が 6 つと、最後に 4 px の列（96〜99 列目）ができます。端のセルは自分のピクセルだけを平均し、範囲外のピクセルは読みません。</li>
  <li><strong>ぼかし</strong>（半径 2〜40 px、既定 12）は、範囲を <code>ceil(幅 / 半径)</code> × <code>ceil(高さ / 半径)</code> の小さなキャンバスにスムージング付きで描き、元の大きさに拡大し直します。300 × 40 の範囲を半径 12 でぼかすと残るサンプルは 25 × 4 = 100 個、同じ範囲をブロック 16 でモザイクにすると 19 × 3 = 57 セルです。ぼかしが残す情報量はモザイクとほぼ同じで、スムージングはセルの境目を隠すだけです。</li>
  <li><strong>塗りつぶし</strong>は範囲を 1 色の不透明色（既定は黒）で塗り、元のピクセルは何も残りません。</li>
  <li>点線の枠はプレビューにだけ描かれます。ダウンロードと画像コピーでは描き直すため、枠は入りません。</li>
</ul>

<h2>モザイクをかけた文字が復元される理由</h2>
<p>モザイクもぼかしも情報を失いますが、攻撃者は計算を逆にたどる必要がありません。同じフォントで候補の文字を描き、同じフィルターをかけ、ブロックごとに比べるだけです。既知のフォントで書かれた文字は候補が少ないため、この方法がよく効きます。</p>
<ul>
  <li><a href="https://github.com/spipm/Depix">Depix</a>（2020 年）は、線形ボックスフィルターでモザイクをかけたスクリーンショットから、描画した文字列とブロックを照合して文字を復元します。このツールのモザイクも同じ種類のフィルターです。</li>
  <li>Bishop Fox の <a href="https://bishopfox.com/blog/unredacter-tool-never-pixelation">Unredacter</a>（2022 年）は 1 文字ずつ推測し、グリッドのずれもすべて試すため、グリッドが文字に揃っていなくても防げません。</li>
  <li><a href="https://petsymposium.org/popets/2016/popets-2016-0047.php">Hill・Zhou・Saul・Shacham（PoPETs 2016）</a>は、モザイクのセルが文字サイズより大きい場合、強い JPEG 圧縮の後、ぼかした文字のいずれでも読める文字を復元し、モザイクとぼかしは文字を隠す方法として使えないと結論づけています。</li>
</ul>
<p>顔については、<a href="https://arxiv.org/abs/1609.00408">McPherson・Shokri・Shmatikov（2016 年）</a>がモザイクやぼかしをかけた画像の人物を識別するモデルを示しています。身元を隠す必要があるときは塗りつぶしを使ってください。</p>

<h2>正しく隠した後も残る情報</h2>
<ul>
  <li><strong>文字数。</strong>文字にぴったり合わせた黒塗りは、何文字あったかを示します。等幅フォントなら正確な文字数です。PIN のような短い秘密は、文字より広く塗ってください。</li>
  <li><strong>ファイル名。</strong>ダウンロードしたファイルは元の名前に <code>-pixelated</code> が付き、<code>免許証-山田.jpg</code> は <code>免許証-山田-pixelated.png</code> になります。貼り付けた画像は <code>pasted-image-pixelated</code> です。名前から人が特定できるなら、共有前に変更してください。</li>
  <li><strong>スクリーンショットの他の部分。</strong>タブのタイトル、アドレスバー、通知、入力候補、ログの下の方に出てくる同じキーなどに、隠したはずの情報がもう一度写っていることがあります。</li>
  <li><strong>元のファイル。</strong>加工すると新しいファイルができるだけで、元画像はディスクや写真のバックアップに残ります。書き出したファイルはキャンバスのピクセルだけから作るため、元画像の EXIF や GPS も、元ファイルのバイトも含みません。2023 年の aCropalypse では、Google Pixel のマークアップ（<a href="https://www.cve.org/CVERecord?id=CVE-2023-21036">CVE-2023-21036</a>）と Windows の Snipping Tool（<a href="https://www.cve.org/CVERecord?id=CVE-2023-28303">CVE-2023-28303</a>）が切り抜き後の画像で元ファイルを上書きしても切り詰めず、切り抜く前の部分がファイル末尾から復元できました。</li>
</ul>

<h2>よくある使い方</h2>
<ul>
  <li><strong>AI チャットやサポート窓口、フォーラムに貼る前のスクリーンショット整理</strong> — API キー・トークン・アカウント ID・メールアドレス・社内 URL を塗りつぶしで隠します。</li>
  <li><strong>写真を公開する前に顔やナンバープレートを隠す</strong> — 身元を確実に隠したい場合は塗りつぶしを使います。モザイクやぼかしをかけた顔も認識モデルで照合される可能性があります。</li>
  <li><strong>レトロなドット絵風エフェクト</strong> — 「画像全体に適用」をオンにし、大きめのモザイクブロックサイズを選びます。</li>
</ul>

<h2>プライバシー：アップロードなし</h2>
<p>
  デコード・効果の描画・書き出しはすべて <code>createImageBitmap</code> と Canvas 2D API を使ってブラウザ内で行われます。
  サーバー側の処理は一切なく、機内モードでも問題なく動作します。このツールの永続化ポリシーは <code>disabled</code> で、
  画像をローカルストレージに書き込むこともなく、このページはアクセス解析や広告スクリプトも読み込みません。
</p>

<h2>制限事項</h2>
<ul>
  <li>顔や文字の自動検出はありません。範囲は自分で描く必要があります。信頼できる顔・文字検出には機械学習モデルが必要で、それは専用の AI 画像ツールに任せるほうが適切です。</li>
  <li>描いた範囲は後から移動・リサイズしたり、個別に効果を変えたりできません。やり直す場合は元に戻してから描き直してください。</li>
  <li>一度に処理できるのは 1 枚のみで、複数ファイルの一括処理には対応していません。</li>
  <li>アニメーション GIF は仕様として静止画の 1 フレームとして書き出されます。全フレームを個別の画像にするには <a href="/ja/tools/gif-splitter/">GIF 分解ツール</a> を使ってください。</li>
  <li>効果は一度に 1 種類で、すべての範囲に同じ効果がかかります。同じ画像で顔にモザイク、パスワードに塗りつぶしをしたいときは、1 回目の結果をダウンロードし、そのファイルを読み込み直して 2 つ目の効果をかけてください。</li>
  <li>幅か高さが 2 px 未満の範囲は破棄されるため、クリックミスで空の範囲は増えません。「画像全体に適用」がオンの間は範囲を描けません。</li>
  <li>JPEG には透明がないため、透明な部分は白で埋められます。ブラウザーが WebP を書き出せない場合（MDN の互換性データでは Safari）、WebP を選んでも PNG ファイルとして保存されます。「画像をコピー」でクリップボードに入るのは常に PNG です。</li>
  <li>キャンバスの大きさにはブラウザーの上限があり、書き出せないときは「書き出しに失敗しました — より小さい画像でお試しください」と表示されます。</li>
  <li>HEIC 写真を開けるのは Safari 17 以降だけです（<a href="https://caniuse.com/heif">Can I use</a>）。他のブラウザーでは先に JPEG に変換してください。</li>
  <li>PDF の黒塗りには対応していません。ローカルの PDF 編集ソフトの黒塗り機能を使ってください。</li>
</ul>
