<h2>使い方</h2>
<ol>
  <li>画像をドロップするか、クリックしてファイルを選ぶか、<strong>Ctrl/Cmd+V</strong> でスクリーンショットを直接貼り付けます。</li>
  <li>効果を選びます：<strong>モザイク</strong>、<strong>ぼかし</strong>、<strong>塗りつぶし</strong>。</li>
  <li>隠したい範囲をドラッグして矩形を描きます。いくつでも描けて、点線の枠それぞれが独立した範囲になります。</li>
  <li>強度スライダー（モザイクはブロックサイズ、ぼかしは半径）を調整するか、塗りつぶし色を選びます。すべての範囲が即座に更新されます。</li>
  <li><strong>画像全体に適用</strong> をオンにすると、描いた範囲ではなく画像全体に効果がかかります。</li>
  <li><strong>ダウンロード</strong> で保存するか、<strong>画像をコピー</strong> で他のアプリに直接貼り付けます。</li>
</ol>

<h2>どの効果を使うべきか</h2>
<ul>
  <li><strong>モザイク</strong> — ブロックごとの平均色に置き換えます。意図的なモザイク表現や、大きめのブロックで顔を隠す用途に向いています。文字情報には不向きです。</li>
  <li><strong>ぼかし</strong> — なめらかなソフトフォーカス効果です。見た目は「検閲」っぽくありませんが、強力な逆ぼかし処理で復元される可能性があり、文字に対しては同様に安全ではありません。</li>
  <li><strong>塗りつぶし</strong> — 範囲を単色で完全に置き換えます。元の画素情報を完全に破棄する唯一の方法です。パスワード・トークン・API キー、AI チャットに貼り付ける内容には必ずこれを使ってください。</li>
</ul>

<h2>よくある使い方</h2>
<ul>
  <li><strong>AI チャットやサポート窓口、フォーラムに貼る前のスクリーンショット整理</strong> — API キー・トークン・アカウント ID・メールアドレス・社内 URL を塗りつぶしで隠します。</li>
  <li><strong>写真を公開する前に顔やナンバープレートを隠す</strong> — 認識できる細部が消えるくらい大きめのブロック／半径でモザイクまたはぼかしをかけます。</li>
  <li><strong>レトロなドット絵風エフェクト</strong> — 「画像全体に適用」をオンにし、大きめのモザイクブロックサイズを選びます。</li>
</ul>

<h2>プライバシー：アップロードなし</h2>
<p>
  デコード・効果の描画・書き出しはすべて <code>createImageBitmap</code> と Canvas 2D API を使ってブラウザ内で行われます。
  サーバー側の処理は一切なく、機内モードでも問題なく動作します。このツールの永続化ポリシーは <code>disabled</code> で、
  画像をローカルストレージに書き込むこともなく、このページはアクセス解析や広告スクリプトも読み込みません。
</p>

<h2>制限事項</h2>
<ul>
  <li>顔や文字の自動検出はありません。範囲は自分で描く必要があります。信頼できる顔・文字検出には機械学習モデルが必要で、それは専用の AI 画像ツールに任せるほうが適切です。</li>
  <li>描いた範囲は後から移動・リサイズしたり、個別に効果を変えたりできません。やり直す場合は元に戻してから描き直してください。</li>
  <li>一度に処理できるのは 1 枚のみで、複数ファイルの一括処理には対応していません。</li>
  <li>アニメーション GIF は仕様として静止画の 1 フレームとして書き出されます。</li>
  <li>PDF の黒塗りには対応していません。ローカルの PDF 編集ソフトの黒塗り機能を使ってください。</li>
</ul>
