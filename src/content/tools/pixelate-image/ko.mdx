<h2>사용 방법</h2>
<ol>
  <li>이미지를 드롭하거나 클릭해서 파일을 선택하거나, <strong>Ctrl/Cmd+V</strong>로 스크린샷을 바로 붙여넣습니다.</li>
  <li>효과를 선택합니다: <strong>모자이크</strong>, <strong>블러</strong>, <strong>단색 채우기</strong>.</li>
  <li>가리고 싶은 영역을 드래그해 사각형을 그립니다. 여러 개 그릴 수 있고, 점선 박스 하나하나가 독립된 영역입니다.</li>
  <li>강도 슬라이더(모자이크는 블록 크기, 블러는 반경)를 조절하거나 채우기 색상을 고릅니다. 모든 영역이 즉시 갱신됩니다.</li>
  <li><strong>전체 이미지에 적용</strong>을 켜면 그린 영역 대신 이미지 전체에 효과가 적용됩니다.</li>
  <li><strong>다운로드</strong>로 저장하거나 <strong>이미지 복사</strong>로 다른 앱에 바로 붙여넣습니다.</li>
</ol>

<h2>어떤 효과를 써야 할까</h2>
<ul>
  <li><strong>모자이크</strong> — 블록별 평균 색상으로 채웁니다. 의도적인 모자이크 느낌을 내거나 큼직한 블록으로 얼굴을 가리는 데 적합합니다. 텍스트에는 적합하지 않습니다.</li>
  <li><strong>블러</strong> — 부드럽게 흐리는 효과입니다. 보기에는 "가림 처리"처럼 보이지 않지만, 강력한 디블러 처리로 복원될 수 있어 텍스트에는 마찬가지로 안전하지 않습니다.</li>
  <li><strong>단색 채우기</strong> — 영역을 단색으로 완전히 덮습니다. 원본 픽셀 정보를 완전히 없애는 유일한 방법입니다. 비밀번호, 토큰, API 키, AI 채팅에 붙여넣을 내용에는 반드시 이것을 사용하세요.</li>
</ul>

<h2>주요 활용 예시</h2>
<ul>
  <li><strong>AI 채팅, 고객 지원 티켓, 포럼에 올리기 전 스크린샷 정리</strong> — API 키, 토큰, 계정 ID, 이메일 주소, 내부 URL을 단색 채우기로 가립니다.</li>
  <li><strong>사진 공개 전 얼굴이나 번호판 가리기</strong> — 알아볼 수 있는 디테일이 사라질 만큼 큰 블록/반경으로 모자이크나 블러를 적용합니다.</li>
  <li><strong>레트로 픽셀 아트 효과</strong> — "전체 이미지에 적용"을 켜고 큼직한 모자이크 블록 크기를 선택합니다.</li>
</ul>

<h2>개인정보: 업로드 없음</h2>
<p>
  디코딩, 효과 렌더링, 내보내기는 모두 <code>createImageBitmap</code>과 Canvas 2D API를 통해 브라우저에서 처리됩니다.
  서버 처리 과정이 전혀 없어 비행기 모드에서도 그대로 동작합니다. 이 도구의 저장 정책은 <code>disabled</code>로,
  이미지를 로컬 스토리지에 저장하지 않으며 이 페이지는 분석·광고 스크립트도 불러오지 않습니다.
</p>

<h2>제한 사항</h2>
<ul>
  <li>얼굴이나 텍스트 자동 인식 기능은 없습니다. 영역은 직접 그려야 합니다. 신뢰할 만한 얼굴·텍스트 인식에는 머신러닝 모델이 필요하며, 이는 전용 AI 이미지 도구가 더 적합한 역할입니다.</li>
  <li>그린 영역은 이후 이동, 크기 조절, 개별 효과 지정이 불가능합니다. 다시 그리려면 실행 취소 후 새로 그리세요.</li>
  <li>한 번에 이미지 한 장만 처리하며, 여러 파일 일괄 처리는 지원하지 않습니다.</li>
  <li>애니메이션 GIF는 설계상 정적 이미지 한 프레임으로 내보내집니다.</li>
  <li>PDF 가림 처리는 지원 범위 밖입니다. 로컬 PDF 편집기의 가림 처리 기능을 사용하세요.</li>
</ul>
