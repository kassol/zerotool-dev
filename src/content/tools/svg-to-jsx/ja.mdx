<h2>使い方</h2>
<ol>
  <li>左のテキストエリアにSVGコードを貼り付けます。</li>
  <li>コンポーネント名を入力します（デフォルト：<code>MyIcon</code>）。先頭文字は自動で大文字になります。</li>
  <li>TypeScript・forwardRef・memoオプションを必要に応じて切り替えます。</li>
  <li>JSXコンポーネントが右のテキストエリアに即座に表示されます。</li>
  <li><strong>コピー</strong>ボタンでクリップボードにコピーします。</li>
</ol>

<h2>属性変換ルール</h2>

| SVG | JSX |
|-----|-----|
| `stroke-width` | `strokeWidth` |
| `stroke-linecap` | `strokeLinecap` |
| `fill-rule` | `fillRule` |
| `clip-path` | `clipPath` |
| `class` | `className` |
| `font-size` | `fontSize` |
| `text-anchor` | `textAnchor` |
| `xmlns="..."` | *(削除)* |

<h2>出力モード</h2>
<ul>
  <li><strong>デフォルト</strong>：TypeScript注釈なしのプレーンな関数コンポーネント。</li>
  <li><strong>TypeScript</strong>：<code>React.FC&lt;React.SVGProps&lt;SVGSVGElement&gt;&gt;</code>型を付与。className・style・onClickなどが型安全に使えます。</li>
  <li><strong>forwardRef</strong>：<code>React.forwardRef</code>でラップし、親コンポーネントにSVG要素のrefを公開します。</li>
  <li><strong>memo</strong>：最終エクスポートを<code>React.memo</code>でラップし、不要な再レンダリングをスキップします。</li>
</ul>

<h2>主な用途</h2>
<ul>
  <li>FigmaやIllustratorからエクスポートしたSVGをReactアイコンコンポーネントに変換</li>
  <li>SVGアイコンライブラリをJSXベースのデザインシステムに移行</li>
  <li>SVGアイコンにclassName・styleなどのReact propsを受け取れるようにする</li>
  <li>propsスプレッドでaria-labelを受け取るアクセシブルなアイコンコンポーネントの構築</li>
</ul>

## 変換例

24 × 24 のプラスアイコンを、コンポーネント名 `PlusIcon`、オプションはすべてオフで変換します：

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" fill="none" viewBox="0 0 24 24"><path stroke="#000" stroke-width="2" stroke-linecap="round" d="M12 5v14M5 12h14"/></svg>
```

出力：

```jsx
import React from 'react';

function PlusIcon(props) {
  return (
    <svg {...props} width="24" height="24" fill="none" viewBox="0 0 24 24"><path stroke="#000" strokeWidth="2" strokeLinecap="round" d="M12 5v14M5 12h14"/></svg>
  );
}

export default PlusIcon;
```

`xmlns` が消え、`stroke-width` と `stroke-linecap` がキャメルケースになり、それ以外のマークアップはそのままです。値は文字列のまま（`strokeWidth="2"`）ですが、React は文字列も数値も受け付けます。TypeScript・forwardRef・memo をすべてオンにすると、同じアイコンは `const PlusIcon = forwardRef<SVGSVGElement, React.SVGProps<SVGSVGElement>>(function PlusIcon(props, ref) { ... })` になり、`<svg>` に `ref={ref} {...props}`、末尾に `export default memo(PlusIcon);` が付きます。React 19 では [`forwardRef` は不要](https://react.dev/reference/react/forwardRef)になり、関数コンポーネントは `ref` を props として受け取れます。

## 貼り付ける前に：書き出し設定

- **Figma**：レイヤーを選び Export → SVG。ID で要素を操作しないなら「Include "id" attribute」はオフのままにします。
- **Illustrator**：File → Export → Export As → SVG で、Styling を Presentation Attributes にします（メニュー名は英語版の表記）。ほかの Internal CSS と Inline Style は `<style>` ブロックや `style="..."` 文字列を出力し（[Adobe：SVG 書き出しオプション](https://helpx.adobe.com/illustrator/using/exporting-artwork.html)）、このツールはどちらも書き換えません（下の表を参照）。
- `<!-- Generator: ... -->` のようなコメントがあれば、貼り付ける前に削除します。`<?xml ... ?>` 宣言はツールが取り除きますが、コメントは残ります。

## 手で直す必要があるもの

各行は、出力を esbuild 0.28 でコンパイルし React 19 でレンダリングして確認しました。

| 貼り付けた SVG | ツールの出力 | React での結果 | 修正後 |
|---|---|---|---|
| `<!-- コメント -->` | そのまま | 構文エラー：HTML コメントは JSX ではない | 削除するか `{/* ... */}` に |
| `<style>.cls-1{fill:#e11d48;}</style>` | そのまま | 構文エラー：`{` が JSX の式として解釈される | Presentation Attributes で書き出し直すか、CSS をテンプレートリテラルで囲む：`` <style>{`.cls-1{fill:#e11d48;}`}</style> `` |
| `style="fill:#e11d48"` | 文字列のまま | レンダリングエラー「The `style` prop expects a mapping from style properties to values, not a string」 | `style={{ fill: '#e11d48' }}` |
| `xlink:href="#a"` | そのまま（`xmlns:xlink` 宣言は削除） | React が「Invalid DOM property」を警告。Babel は既定で名前空間付き属性を拒否 | `href="#a"` |
| ルート `<svg>` の `width="24"`・`fill="black"` | `{...props}` がその前に入る | SVG 側の値が優先され、`<PlusIcon width={48} />` でも 24 px のまま | 呼び出し側で指定したい属性をルートから削除 |
| 固定の `fill` / `stroke` 色 | そのまま | アイコンが文字色に追従しない | `fill="currentColor"` / `stroke="currentColor"` |

## 制限事項

- **XML パーサーではなく正規表現で処理します。** 属性値に `>` があるとタグがそこで終わったと見なされます。
- **属性値の中の属性名も置き換わります。** 置換はタグ全体に対して行われるため、`aria-label="class schedule"` は `aria-label="className schedule"` になります。変換後に `aria-label` などのテキスト値を確認してください。
- **1 回の貼り付けで 1 コンポーネント。** `{...props}` が付くのは最初の `<svg>` だけです。スプライトは 1 アイコンずつ貼り付けてください。
- **コンポーネント名**：英数字・`_`・`$` 以外は削除され、先頭は大文字になります（`plus-icon` → `Plusicon`）。日本語の名前はすべて削除され `MyIcon` になります。
- `data-*` と `aria-*` 属性はハイフンのまま残ります。React の仕様どおりです。
