<h2>사용 방법</h2>
<ol>
  <li>정규식 패턴을 "패턴" 창에 입력합니다.</li>
  <li>테스트할 텍스트를 "테스트 문자열" 창에 입력합니다.</li>
  <li>매치 위치가 실시간으로 하이라이트됩니다.</li>
  <li>캡처 그룹의 내용은 하단 상세 패널에 표시됩니다.</li>
</ol>

<h2>정규식에 대하여</h2>
<p>정규식(RegEx)은 문자열의 패턴 매칭을 위한 강력한 미니 언어입니다. 텍스트 검색·추출·치환·유효성 검사에 사용되며, 프로그래밍·데이터 처리·텍스트 편집의 모든 상황에서 활약합니다.</p>

## 실제 동작 예시

`g`를 켰을 때 테스터가 돌려주는 결과입니다.

| 정규식 | 테스트 문자열 | 일치 |
|---|---|---|
| `^01[016789]-?\d{3,4}-?\d{4}$` | `010-1234-5678` | 전체 일치 (휴대전화 번호 형식) |
| `[가-힣]+` | `주문 번호 12345` | `주문`, `번호` |
| `<.+>` | `<a>foo</a>` | `<a>foo</a>` (탐욕적: 첫 `<`부터 마지막 `>`까지) |
| `<.+?>` | `<a>foo</a>` | `<a>`, `</a>` (게으른 매칭) |
| `(?<=\$)\d+` | `cost $42` | `42` (후방 탐색) |
| `^(?<ts>\S+)\s+(?<level>\w+)\s+(?<msg>.+)$` | `2026-04-07T14:23:01 ERROR connection refused` | 1개. 그룹은 `2026-04-07T14:23:01`, `ERROR`, `connection refused` |

정규식은 형식만 확인합니다. `^\d{4}-(?:0[1-9]|1[0-2])-(?:0[1-9]|[12]\d|3[01])$`는 `2026-02-31`도 통과시키므로 날짜는 날짜 라이브러리로 파싱하세요. 휴대전화 정규식도 번호가 실제로 존재하는지는 확인하지 않습니다.

## 자주 하는 실수

- **메타 문자 이스케이프 누락.** `.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `^` `$` `|` `\`는 특별한 의미가 있습니다. 마침표 자체는 `\.`로 씁니다.
- **여러 줄 텍스트의 `^`와 `$`.** `m`을 끄면 전체 텍스트의 처음과 끝에만 일치합니다.
- **`\w`는 ASCII만 해당.** `café 서울`에 `\w+`를 쓰면 `caf`만 일치하고 한글은 일치하지 않습니다. 한글에는 `[가-힣]` 같은 범위를 씁니다.
- **중첩된 수량자.** `(a+)+$`를 `a` 28개와 `b` 하나에 쓰면 Node.js 24(Chrome과 같은 V8 엔진)에서 18초가 걸렸습니다. 테스터는 페이지에서 바로 실행되고 시간 제한이 없어서, 끝날 때까지 탭이 응답하지 않습니다.

## 제한 사항

- **JavaScript 문법만 지원합니다.** Python의 `(?P<name>...)`은 「Invalid group」 오류가 나므로 `(?<name>...)`로 씁니다. Go(RE2), PCRE, Java용 정규식은 다르게 동작할 수 있습니다.
- **플래그는 4개.** `g`, `i`, `m`, `s`만 쓸 수 있습니다. `u`가 없어서 `\p{L}`은 문자열 `p{L}`로 해석되고, `y`, `d`, `v`도 쓸 수 없습니다.
- **그룹은 번호로 표시됩니다.** 이름 있는 그룹도 그룹 1, 그룹 2로 나옵니다.
- **일치 목록은 처음 100개만 보여 줍니다.** 강조 표시는 모두에 적용됩니다. index는 UTF-16 코드 단위라 일치 앞의 이모지 하나마다 2씩 늘어납니다.
- **치환은 지원하지 않습니다.** 테스터는 일치를 찾기만 하고 `replace()`는 실행하지 않습니다.
