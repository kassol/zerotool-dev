<h2>Understanding the Generated CSS</h2>
<p>
  The generated rule always starts with <code>width: 0</code> and <code>height: 0</code>.
  For cardinal directions (top, right, bottom, left), two transparent borders define the base width
  and one solid border defines the height of the triangle.
  For corner directions (e.g. top-left), one solid border and one transparent border
  form a right-angle triangle from a corner.
  Paste the output into your stylesheet and rename <code>.triangle</code> to your own class.
</p>

<h2>Example: the Default Triangle</h2>
<p>The tool opens with direction <strong>top</strong>, width 100, height 100 and color <code>#3b82f6</code>:</p>

```css
.triangle {
  width: 0;
  height: 0;
  border-left: 50px solid transparent;
  border-right: 50px solid transparent;
  border-bottom: 100px solid #3b82f6;
}
```

<p>The element has no content box, so its whole 100 × 100px box is border. The bottom border is a trapezoid whose top edge has shrunk to a point, and the two transparent side borders cut away the corners next to it. Because the side borders are half the width each, the tip sits in the middle.</p>

<h2>Example: a Tooltip Arrow</h2>
<p>Choose <strong>bottom</strong>, width 16, height 8, and the tooltip's background color, for example <code>#111827</code>:</p>

```css
.triangle {
  width: 0;
  height: 0;
  border-left: 8px solid transparent;
  border-right: 8px solid transparent;
  border-top: 8px solid #111827;
}
```

<p>To attach it, use the arrow as a pseudo-element of the tooltip instead of an extra <code>div</code>: copy the declarations into <code>.tooltip::after</code>, add <code>{'content: ""'}</code>, <code>position: absolute</code>, <code>top: 100%</code>, <code>left: 50%</code> and <code>margin-left: -8px</code> (half the width), and give <code>.tooltip</code> <code>position: relative</code>.</p>

<h2>Limits</h2>
<ul>
  <li><strong>Odd widths become one pixel wider.</strong> For top and bottom triangles the tool splits the width into two side borders and rounds each half: width 25 gives two 13px borders, a 26px base. The same applies to the height of left and right triangles. Use even numbers when the size must be exact.</li>
  <li><strong>Solid color only.</strong> A border has one color, so there is no gradient, image fill, outline or <code>box-shadow</code> that follows the slanted edges. For those, cut the shape with <code>clip-path: polygon(50% 0, 100% 100%, 0 100%)</code> in the <a href="/tools/css-clip-path-generator/">clip-path generator</a>.</li>
  <li><strong>Pixel sizes only.</strong> Border widths cannot be percentages, so the border trick does not scale with its container.</li>
  <li><strong>Hex colors only.</strong> The text field accepts a 6-digit code with <code>#</code>; edit the copied CSS to use <code>currentColor</code> or a custom property.</li>
  <li>The HTML snippet is always <code>{'<div class="triangle"></div>'}</code>. A triangle drawn only for decoration carries no meaning for screen readers; if it is the only sign of state (for example an expand caret), put that state in text or <code>aria-expanded</code> as well.</li>
</ul>
