<h2>Spelling Codes, Hashes and Hostnames</h2>

<p>The alphabet is useful whenever an opaque string has to be read aloud: an error code on a support call, a commit hash during an incident bridge, a license key or a serial number. Outputs from the tool:</p>

<ul>
  <li><code>{"F9C2"}</code> → <code>{"Foxtrot Niner Charlie Two"}</code></li>
  <li><code>{"e3b0c44"}</code> (a short Git commit hash) → <code>{"Echo Three Bravo Zero Charlie Four Four"}</code></li>
  <li><code>{"db-07"}</code> → <code>{"Delta Bravo [?] Zero Seven"}</code></li>
</ul>

<ul>
  <li>The tool does not mark upper and lower case: <code>{"e"}</code> and <code>{"E"}</code> are both Echo. For case-sensitive strings (Base64, API tokens, passwords) say "capital" or "lower" before each letter yourself.</li>
  <li>Punctuation has no code word in the ICAO alphabet, so <code>{"-"}</code>, <code>{"_"}</code>, <code>{"."}</code> and similar characters appear as <code>{"[?]"}</code>. Say them by name ("dash", "underscore", "dot").</li>
  <li>Table mode lists one character per row, which makes it easier for the listener to read back and confirm each character.</li>
</ul>

<h2>Limitations</h2>
<ul>
  <li>Only the 26 letters A–Z and the digits 0–9 have code words. Accented and non-Latin letters are written as <code>{"[?]"}</code>; spell them as their base letter plus the accent name, or use a national spelling alphabet.</li>
  <li>Line breaks and tabs are also written as <code>{"[?]"}</code>, so convert one line at a time if the input has several.</li>
  <li>Digits use the ICAO word list. ICAO also gives radio pronunciations such as TREE for 3 and FIFE for 5; the tool writes the spelled words (Three, Five) except for 9, which it writes as Niner.</li>
  <li>The output is text only. There is no audio, and the tool does not convert code words back to letters.</li>
</ul>

<p>The current word list was adopted by ICAO and came into use in 1956; <a href="https://www.nato.int/cps/en/natohq/declassified_136216.htm" target="_blank" rel="noopener">NATO</a> describes its development and testing.</p>
