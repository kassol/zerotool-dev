<h2>Cron 표현식 필드 참조</h2>

| 필드 | 위치 | 허용 값 | 특수 문자 |
|-----|------|---------|----------|
| 분 | 1번째 | 0–59 | `*` `/` `-` `,` |
| 시 | 2번째 | 0–23 | `*` `/` `-` `,` |
| 일 | 3번째 | 1–31 | `*` `/` `-` `,` |
| 월 | 4번째 | 1–12 | `*` `/` `-` `,` |
| 요일 | 5번째 | 0–7 (일 = 0 또는 7) | `*` `/` `-` `,` |

<h2>자주 사용되는 Cron 일정 예시</h2>

| 표현식 | 의미 |
|--------|------|
| `* * * * *` | 매분 |
| `0 * * * *` | 매시 정각 |
| `0 0 * * *` | 매일 자정 |
| `0 9 * * 1-5` | 평일 오전 9시 |
| `*/5 * * * *` | 5분마다 |
| `0 0 1 * *` | 매월 1일 |
| `0 0 * * 0` | 매주 일요일 자정 |
| `0 0 1 1 *` | 매년 1월 1일 |
