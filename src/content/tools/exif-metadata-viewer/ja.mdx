<h2>共有前に EXIF を除去すべき理由</h2>

<p>位置情報をオンにしたスマートフォンやカメラは、撮影のたびに GPS 座標、機種、撮影日時を写真に書き込みます。EXIF を取り除かずに掲示板・ブログ・メタデータを消さないチャットへ送ると、無料ツールだけで撮影場所を数メートル単位で読み取られかねません。</p>

<p>このツールでは、写真に何が書かれているかを確かめてから、メタデータを除去したコピーをダウンロードできます。読み込みも除去も、開いているブラウザタブの中で行います。</p>

<h2>除去対象のセグメント</h2>

<p>除去処理は JPEG のマーカーストリームをスキャンし、個人情報を持ちやすいセグメントを取り除きます：</p>

<ul>
  <li><strong>APP1</strong> — EXIF（カメラ、GPS、タイムスタンプ）と XMP（Adobe メタデータ、編集履歴）</li>
  <li><strong>APP13</strong> — Photoshop / IPTC（キャプション、著作権、連絡先）</li>
</ul>

<p>ブラウザが画像を正しくデコードするために必要なセグメントはそのまま残します：SOI、JFIF（APP0）、ICC カラープロファイル（APP2）、Adobe カラー変換マーカー（APP14。CMYK 画像はこれがないと色が崩れます）、SOS、圧縮画像データ、EOI。唯一の例外は APP1 にある向き（Orientation）情報です。値が 2〜8 のとき、元の APP1 の位置にこの 1 項目だけを含む APP1（Exif 2.32 / 3.0 の IFD0 タグ 0x0112、36 バイト）を書き戻します。スマートフォンは縦に撮った写真を横向きのまま保存し、向き情報 6 または 8 で回転表示させるため、これを消すと除去後の写真が横向きに表示されます。向き情報は回転方法を示すだけで、個人情報は含みません。結果は <code>{"exiftool -all= -tagsfromfile @ -Orientation photo.jpg"}</code> と同じです。値が 1（正位置）または 1〜8 以外のときは書き戻しません。XMP だけに書かれた向きは XMP と一緒に消えます。</p>

<h2>例：日本時間で撮影したテスト写真</h2>

<p>以下の例で使うファイルは、テストスクリプトが作った 64 × 48 の単色 JPEG に、書かれているフィールドだけを書き込んだものです（ExifTool 13.55 で読み戻して確認）。実在の写真ではなく、座標は東京タワー付近の公開されたランドマークで、特定の個人とは関係ありません。</p>

<p>書き込んだ値：Make <code>Example Camera</code>、Model <code>Test Model</code>、撮影日時 <code>2026:10:09 09:30:00</code> と、その時差 OffsetTimeOriginal <code>+09:00</code>、更新日時 <code>2026:10:09 09:45:00</code>、F 値 8、シャッター 1/250、ISO 100、焦点距離 35 mm、GPS 北緯 35°39′30.89″・東経 139°44′43.56″。ツールの表示は次のとおりです。</p>

<p>撮影日時は 09:30:00 とだけ表示され、<code>+09:00</code> はどこにも出ません。Exif 規格（CIPA DC-008-2023）では OffsetTimeOriginal は撮影日時の UTC からの時差を「+HH:MM」で記録するタグですが、このツールは読み取らないためです。海外旅行中に撮った写真などで時差を確かめたいときは、ExifTool などで OffsetTimeOriginal を確認してください。</p>

<h2>例：旧日本測地系（TOKYO）で記録された座標</h2>

<p>Exif 規格の GPSMapDatum は GPS 受信機が使った測地系を記録するタグで、規格本文には日本に限った場合の値として「TOKYO」または「WGS-84」が挙げられています。国土地理院の<a href="https://www.gsi.go.jp/LAW/G2000-g2000-h3.htm">「日本測地系と世界測地系」</a>によると、日本測地系の経緯度を世界測地系で表すと東京付近で経度が約 −12 秒、緯度が約 +12 秒変わり、距離にして北西へ約 450 m ずれることに相当します。</p>

<p>GPSMapDatum に <code>TOKYO</code> と書いたテストファイルで「EXIF JSON をコピー」を押すと、次のテキストがコピーされます。</p>

```json

    "ExifIFDPointer": 38,
    "GPSIFDPointer": 96
  },
  "exif": {
    "DateTimeOriginal": "2026:10:09 09:30:00"
  },
  "gps": {
    "GPSLatitudeRef": "N",
    "GPSLatitude": [
      35,
      39,
      30.89
    ],

      139,
      44,
      43.56
    ]
  }
}
```

<p>GPSMapDatum も OffsetTimeOriginal も JSON に入っていません。ツールは座標を世界測地系とみなして地図リンクを作るため、TOKYO で記録された座標なら、地図上の点は実際の撮影場所から数百メートル離れます。<code>ExifIFDPointer</code> と <code>GPSIFDPointer</code> はファイル内の位置を示す数値で、写真の内容とは関係ありません。</p>

<h2>表示される EXIF フィールド</h2>

<ul>
  <li><strong>カメラ</strong>：メーカー、モデル、レンズモデル</li>
  <li><strong>日時</strong>：撮影日時、最終更新日時（タイムゾーンなし）</li>
  <li><strong>露出</strong>：絞り（F 値）、シャッタースピード、ISO、焦点距離</li>
  <li><strong>GPS</strong>：緯度、経度、高度、Google マップへのリンク</li>
  <li><strong>ソフトウェア</strong>：書き出し時に使われた OS や編集アプリ</li>
</ul>

<h2>制限事項</h2>

<ul>
  <li><strong>JPEG のみ、100 MB まで。</strong>PNG、HEIC、WebP、TIFF は受け付けません。貼り付けはクリップボードの中身が JPEG のときだけ動き、スクリーンショットは多くの場合 PNG です。</li>
  <li><strong>表示するフィールドは決まっています。</strong>シリアル番号、時差（OffsetTimeOriginal）、測地系（GPSMapDatum）などは表示も JSON コピーもしませんが、ダウンロード時には EXIF ブロックごと削除されます。</li>
  <li><strong>文字コード。</strong>ASCII 型のフィールドは、バイト列が正しい UTF-8 なら UTF-8 として表示し、そうでなければ 1 バイト 1 文字で表示します（Shift_JIS で書かれた日本語は文字化けします）。Exif 3.0 で追加された UTF-8 型（129）は解読せず、その行は表示されず、JSON では <code>null</code> になります。</li>
  <li><strong>EXIF 内のオフセットがファイルの外を指しているとき</strong>は、読めたフィールドだけを表示し、「EXIF ブロックの形式が不正です。解析できた項目のみ表示します。」と知らせます。ダウンロードはそのまま使えます。<strong>ファイル自体が画像データより前で途切れているとき</strong>（マーカーセグメントの途中で終わっているとき）は除去する画像がないため、ダウンロードはファイルを保存せず、「JPEG ファイルが画像データより前で途切れているため、除去済みのコピーを作れません。」と表示します。</li>
  <li><strong>削除するのは APP1 と APP13 だけです。</strong>コメント（COM）、その他のアプリケーションセグメント（APP3〜APP12、APP15）、終了マーカーの後ろに付いたデータ（一部のスマートフォンが付ける HDR や深度の画像など）は残ります。完全に消すには <code>{"exiftool -all= photo.jpg"}</code> を実行するか、編集ソフトで保存し直してください。</li>
</ul>

<h2>プライバシーに関する補足</h2>

<ul>
  <li>このページは写真をアップロードしません。使用中にブラウザのネットワークタブを開いて確認できます。アクセス解析と広告のスクリプトも読み込みません。</li>
  <li>Google マップリンクはローカルで作られ、クリックするまでリクエストは送られません。</li>
  <li>元のメタデータを記録として残したい場合は、<strong>EXIF JSON をコピー</strong>を先に行ってからクリーンなコピーをダウンロードしてください。</li>
</ul>
