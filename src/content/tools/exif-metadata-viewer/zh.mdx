<h2>为什么分享照片前要剥离 EXIF</h2>

<p>开启定位的手机和相机会把精确的 GPS 坐标、机型和拍摄时间写进照片。把这种照片直接发到论坛、博客或不会自动剥离元数据的聊天工具，任何人用免费工具都能读出拍摄地点，误差往往只有几米。</p>

<p>这个工具让你先看清照片里写了哪些信息，再下载一份移除元数据的副本。读取和剥离都在当前浏览器标签页内完成。</p>

<h2>工具移除了哪些段</h2>

<p>剥离过程会逐段扫描 JPEG 的标记段（marker），移除常见的隐私敏感段：</p>

<ul>
  <li><strong>APP1</strong> — EXIF（相机、GPS、时间戳）和 XMP（Adobe 元数据、编辑历史）</li>
  <li><strong>APP13</strong> — Photoshop / IPTC（说明、版权、联系方式）</li>
</ul>

<p>浏览器解码图像所需的段会原样保留：SOI 起始标记、JFIF（APP0）、ICC 色彩配置（APP2）、Adobe 色彩变换标记（APP14，CMYK 图片缺了它颜色会出错）、SOS 扫描段、压缩图像数据以及 EOI 结束标记。唯一例外是 APP1 里的方向（Orientation）标记：值为 2–8 时，工具在原 APP1 的位置写回一个只含这一项的 APP1（Exif 2.32 / 3.0 的 IFD0 标签 0x0112，共 36 字节）。手机竖拍的照片常以横向存储、靠方向标记 6 或 8 旋转显示，去掉它清理后的照片会横着显示；方向标记只说明怎样旋转，不含个人信息。效果与 <code>{"exiftool -all= -tagsfromfile @ -Orientation photo.jpg"}</code> 相同。值为 1（正向）或超出 1–8 时不写回；只写在 XMP 里的方向随 XMP 一起删除。</p>

<h2>常见 EXIF 字段</h2>

<ul>
  <li><strong>相机</strong>：品牌、型号、镜头型号</li>
  <li><strong>时间</strong>：原始拍摄时间、最后修改时间（不含时区）</li>
  <li><strong>曝光</strong>：光圈（f 值）、快门、ISO、焦距</li>
  <li><strong>GPS</strong>：纬度、经度、海拔，附带 Google 地图链接</li>
  <li><strong>软件</strong>：写入文件时使用的操作系统或处理软件</li>
</ul>

<h2>限制</h2>

<ul>
  <li><strong>只支持 JPEG，最大 100 MB。</strong> PNG、HEIC、WebP、TIFF 会被拒绝；粘贴只接受剪贴板里的 JPEG，截图通常是 PNG。</li>
  <li><strong>只显示固定的一组字段。</strong> 机身序列号、时区偏移（OffsetTimeOriginal）、大地基准（GPSMapDatum）等标签不显示，复制 EXIF JSON 里也没有，但下载时会随 EXIF 块一起删除。</li>
  <li><strong>文字编码。</strong> ASCII 类型字段的字节是有效 UTF-8 时按 UTF-8 显示，否则按一个字节一个字符显示（GBK 写入的中文会显示成乱码）。Exif 3.0 新增的 UTF-8 类型（129）不解码：该行不显示，复制 EXIF JSON 里是 <code>null</code>。</li>
  <li><strong>EXIF 里的偏移指向文件之外时</strong>，工具显示能读出的字段，并提示「EXIF 块格式异常，仅展示可解析的字段。」，下载照常可用。<strong>文件本身在图像数据之前就被截断时</strong>（结束在某个标记段中间），没有可清理的图像，下载不保存文件，并提示「JPEG 文件在图像数据之前就被截断了，无法生成清理后的副本。」</li>
  <li><strong>只删除 APP1 和 APP13。</strong> 注释段（COM）、其他应用段（APP3–APP12、APP15）以及结束标记之后附加的数据（部分手机附加的 HDR、景深图）会保留。要彻底清理，请运行 <code>{"exiftool -all= photo.jpg"}</code> 或用编辑软件另存。</li>
</ul>
