<h2>Why strip EXIF before sharing photos</h2>

<p>Phones and cameras with location turned on write precise GPS coordinates, the camera model and the capture time into each photo. When you share such a photo on a forum, blog, or chat that does not strip metadata, anyone with a free EXIF tool can pinpoint where the picture was taken — often to within a few meters of your house, office, or hotel.</p>

<p>This tool gives you a fast way to inspect what a photo reveals and to download a clean copy with the metadata blocks removed. Everything happens inside your browser tab.</p>

<h2>What the tool removes</h2>

<p>The strip pass walks the JPEG marker stream and drops the segments that typically carry personal data:</p>

<ul>
  <li><strong>APP1</strong> — EXIF (camera, GPS, timestamps) and XMP (Adobe metadata, edit history)</li>
  <li><strong>APP13</strong> — Photoshop / IPTC (caption, copyright, contact info)</li>
</ul>

<p>Marker segments that the browser needs to decode the photo correctly are kept untouched: the SOI start marker, JFIF (APP0), ICC color profile (APP2), the Adobe color transform marker (APP14, without which CMYK JPEGs decode with wrong colors), the SOS scan marker, the compressed image data, and the EOI end marker. Color appearance is preserved.</p>

<p>If the photo has an Orientation tag with a value from 2 to 8, the tool writes a new APP1 in place of the old one that holds only that tag (IFD0 tag 0x0112 in the Exif 2.32 and 3.0 standard, 36 bytes). Phones store a portrait photo sideways and set Orientation 6 or 8 so viewers rotate it; without the tag the cleaned copy would be shown sideways. The tag only says how to rotate the image. The result is the same as <code>{"exiftool -all= -tagsfromfile @ -Orientation photo.jpg"}</code>.</p>

<h2>What EXIF fields you may see</h2>

<ul>
  <li><strong>Camera</strong>: make, model, lens model — e.g. Apple iPhone 15 Pro, iPhone back camera 6.86mm f/1.78</li>
  <li><strong>Date</strong>: original capture time, last modification time</li>
  <li><strong>Exposure</strong>: aperture (f-number), shutter speed, ISO, focal length</li>
  <li><strong>GPS</strong>: latitude, longitude, altitude, plus a direct Google Maps link</li>
  <li><strong>Software</strong>: the OS or editing app that wrote the file</li>
</ul>

<h2>Limitations</h2>

<ul>
  <li><strong>Orientation is kept.</strong> It is the only tag left in the cleaned copy (see above). Value 1 (upright) and values outside 1–8 are not written back. An orientation stored only in XMP is removed with the XMP block.</li>
  <li><strong>JPEG only, up to 100 MB.</strong> PNG, HEIC, WebP and TIFF are rejected. Pasting works only when the clipboard holds a JPEG; screenshots are usually PNG.</li>
  <li><strong>The viewer shows a fixed set of fields:</strong> the ones in the table above. Other tags, such as the camera serial number, the time zone offset (OffsetTimeOriginal) or the GPS datum (GPSMapDatum), are not listed and are not in Copy EXIF JSON, but are removed by the download.</li>
  <li><strong>Text encoding.</strong> Text tags of the ASCII type are read as UTF-8 when the bytes are valid UTF-8 (ExifTool writes non-ASCII text this way), otherwise one character per byte. Text tags stored with the UTF-8 type added in Exif 3.0 are not decoded: the row is hidden and Copy EXIF JSON shows <code>null</code> (example below).</li>
  <li><strong>Damaged or cut-off files.</strong> When an offset in the EXIF block points outside the file, the tool shows the fields it could read with the notice "EXIF block looks malformed. Showing what could be parsed." Download still works. When the file itself ends inside a marker segment, before the image data, there is nothing to clean: Download saves no file and shows "The JPEG file is cut off before the image data, so no cleaned copy can be made."</li>
  <li><strong>Only APP1 and APP13 are removed.</strong> Comment segments (COM), other application segments (APP3–APP12, APP15) and any data after the end-of-image marker, such as the extra images that some phones append for HDR or depth, are kept. For a full clean, run <code>{"exiftool -all= photo.jpg"}</code> or re-save the image in an editor.</li>
</ul>
