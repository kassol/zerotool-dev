<h2>생성되는 항목</h2>
<ul>
  <li><strong>기본 SEO 메타</strong> — <code>title</code>, <code>description</code>, <code>canonical</code>, <code>author</code>, <code>keywords</code>, <code>theme-color</code>, <code>viewport</code>, <code>robots</code>.</li>
  <li><strong>Open Graph</strong> — <code>og:type</code>, <code>og:title</code>, <code>og:description</code>, <code>og:url</code>, <code>og:site_name</code>, <code>og:image</code>(width / height / alt 포함), <code>og:locale</code>.</li>
  <li><strong>Twitter 카드</strong> — <code>twitter:card</code>, <code>twitter:site</code>, <code>twitter:creator</code>, <code>twitter:title</code>, <code>twitter:description</code>, <code>twitter:image</code>.</li>
  <li><strong>Schema.org JSON-LD</strong> — 최소한의 <code>WebPage</code>, <code>Article</code>, <code>Product</code>, <code>Organization</code> 블록(name / description / url / image).</li>
</ul>

<h2>예시: 블로그 글과 JSON-LD</h2>
<p>여행 블로그 글에 Article 구조화 데이터를 붙이는 경우입니다. 제목에 큰따옴표와 <code>&amp;</code>를 넣고, og:type은 <strong>article</strong>, Schema.org는 <strong>Article</strong>로 고른 뒤 작성자를 입력했습니다. 앞의 예와 같은 방법으로 입력하되, 이미지 너비·높이 칸의 1200과 630(Ctrl/⌘+L로는 지워지지 않습니다)도 지우면 다음과 같습니다.</p>

{/* mtg-check: {"title":"제주 3박 4일 \"뚜벅이\" 일정표 & 예산 정리","description":"버스로만 다닌 제주 3박 4일 코스와 하루 예산을 정리했습니다.","canonical":"https://travel.example.kr/jeju-4days/","siteName":"민지의 여행 노트","author":"김민지","ogType":"article","ogLocale":"ko_KR","ogImage":"https://travel.example.kr/og/jeju-4days.jpg","schemaType":"Article"} */}
```html
<title>제주 3박 4일 &quot;뚜벅이&quot; 일정표 &amp; 예산 정리</title>
<meta name="description" content="버스로만 다닌 제주 3박 4일 코스와 하루 예산을 정리했습니다.">
<link rel="canonical" href="https://travel.example.kr/jeju-4days/">
<meta name="author" content="김민지">
<meta name="robots" content="index, follow">

<!-- Open Graph / Facebook -->
<meta property="og:type" content="article">
<meta property="og:title" content="제주 3박 4일 &quot;뚜벅이&quot; 일정표 &amp; 예산 정리">
<meta property="og:description" content="버스로만 다닌 제주 3박 4일 코스와 하루 예산을 정리했습니다.">
<meta property="og:url" content="https://travel.example.kr/jeju-4days/">
<meta property="og:site_name" content="민지의 여행 노트">
<meta property="og:image" content="https://travel.example.kr/og/jeju-4days.jpg">
<meta property="og:locale" content="ko_KR">

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="제주 3박 4일 &quot;뚜벅이&quot; 일정표 &amp; 예산 정리">
<meta name="twitter:description" content="버스로만 다닌 제주 3박 4일 코스와 하루 예산을 정리했습니다.">
<meta name="twitter:image" content="https://travel.example.kr/og/jeju-4days.jpg">

<!-- Schema.org JSON-LD -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "name": "제주 3박 4일 \"뚜벅이\" 일정표 & 예산 정리",
  "description": "버스로만 다닌 제주 3박 4일 코스와 하루 예산을 정리했습니다.",
  "url": "https://travel.example.kr/jeju-4days/",
  "image": "https://travel.example.kr/og/jeju-4days.jpg",
  "author": {
    "@type": "Person",
    "name": "김민지"
  }
}
</script>
```

<p>속성 안에서는 큰따옴표가 <code>&amp;quot;</code>, <code>&amp;</code>가 <code>&amp;amp;</code>로 바뀌고, JSON-LD에서는 JSON 규칙대로 큰따옴표 앞에 역슬래시가 붙습니다. 너비·높이 칸이 비어 있으므로 <code>og:image:width</code>와 <code>og:image:height</code> 줄은 나오지 않습니다. 이미지 크기 태그를 원하면 실제 이미지 크기를 숫자로 넣으세요. 이 칸은 태그만 바꿀 뿐 이미지 크기를 조정하지는 않습니다.</p>

{/* mtg-count: {"title":"제주 3박 4일 \"뚜벅이\" 일정표 & 예산 정리","description":"버스로만 다닌 제주 3박 4일 코스와 하루 예산을 정리했습니다."} */}
<p>글자 수 카운터는 제목에 <code>26 / 60</code>, 설명에 <code>35 / 160</code>을 표시합니다. 자바스크립트 문자열 길이를 세기 때문에 한글 한 글자, 영문 한 글자, 공백이 모두 1입니다. Google의 <a href="https://developers.google.com/search/docs/appearance/snippet">스니펫 문서</a>는 meta description의 길이에 제한이 없고, 검색 결과에서는 필요에 따라, 보통 기기 너비에 맞춰 잘린다고 설명합니다. 60과 160은 참고용으로만 보세요.</p>

<h2>제한 사항</h2>
<ul>
  <li><strong>JSON-LD는 최소 항목만 씁니다.</strong> name, description, url, image와 Article일 때의 author뿐입니다. Google의 <a href="https://developers.google.com/search/docs/appearance/structured-data/article">Article 문서</a>는 <code>headline</code>, <code>datePublished</code>를 권장하고, Product가 제품 리치 결과 대상이 되려면 <code>offers</code>, <code>review</code>, <code>aggregateRating</code> 중 하나가 있어야 합니다. 필요한 항목은 직접 추가하고 Google 리치 결과 테스트로 확인하세요.</li>
  <li><strong>짝이 되는 항목이 없는 선택지가 있습니다.</strong> Twitter의 <code>player</code>, <code>app</code> 카드에는 <code>twitter:player</code>나 <code>twitter:app:&#42;</code>가 필요하지만 이 도구는 출력하지 않습니다. og:type의 <code>product</code>는 ogp.me에 정의된 유형이 아닙니다. <code>article:published_time</code>, <code>og:image:type</code>, hreflang도 출력하지 않습니다.</li>
  <li><strong>robots는 항상 출력됩니다.</strong> <code>index, follow</code>는 크롤러의 기본 동작과 같으므로 noindex나 nofollow로 바꾸지 않는다면 그 줄을 지워도 됩니다.</li>
  <li><strong>미리보기는 근사치입니다.</strong> 정규 URL이 비어 있으면 사이트 이름으로 미리보기용 도메인을 만드는데, ‘숲속상회’처럼 반각 영문자나 숫자가 없는 이름이면 <code>example.com</code>으로 표시합니다. 실제 카드는 공개 후 각 서비스의 디버거로 확인하세요.</li>
  <li><strong>네트워크:</strong> 태그 내용은 브라우저 안에 남지만, Facebook, Twitter, Discord 미리보기는 입력한 이미지 URL을 불러오므로 이미지 호스트에 요청이 갑니다. 처음 보이는 Google 미리보기에는 이미지가 없습니다.</li>
  <li><strong>Ctrl/⌘+L은 텍스트 칸만 지웁니다.</strong> og:locale과 테마 색상 텍스트를 포함한 텍스트 칸이 비워지고, URL 칸, 숫자 칸, 선택 상자, viewport 체크는 그대로 둔 채 head를 다시 만듭니다.</li>
</ul>
