<h2>生成される内容</h2>
<ul>
  <li><strong>基本 SEO メタ</strong>——<code>title</code>、<code>description</code>、<code>canonical</code>、<code>author</code>、<code>keywords</code>、<code>theme-color</code>、<code>viewport</code>、<code>robots</code>。</li>
  <li><strong>Open Graph</strong>——<code>og:type</code>、<code>og:title</code>、<code>og:description</code>、<code>og:url</code>、<code>og:site_name</code>、<code>og:image</code>（width / height / alt 含む）、<code>og:locale</code>。</li>
  <li><strong>Twitter カード</strong>——<code>twitter:card</code>、<code>twitter:site</code>、<code>twitter:creator</code>、<code>twitter:title</code>、<code>twitter:description</code>、<code>twitter:image</code>。</li>
  <li><strong>Schema.org JSON-LD</strong>——最小の <code>WebPage</code> / <code>Article</code> / <code>Product</code> / <code>Organization</code> ブロック（name / description / url / image）。</li>
</ul>

<p><a href="https://ogp.me/">ogp.me</a> がすべてのページに必須としている 4 つ（<code>og:title</code>、<code>og:type</code>、<code>og:image</code>、<code>og:url</code>）がそろっています。Twitter 画像の欄が空なので、<code>twitter:image</code> には og:image と同じ URL が入ります。「言語」のプルダウンは og:locale が空のときに入力例を出すだけで、それ自体はタグを出力しません。locale を変えるときは og:locale の欄を直接書き換えます。公開前に、サンプル値はすべて自分のサイトの値に置き換えてください。</p>

<h2>例：日本語のブログ記事に OGP と JSON-LD を付ける</h2>
<p>家計ブログの記事を例にします。タイトルには「」と <code>&amp;</code>、説明には <code>&lt;</code> を含めました。og:type を <strong>article</strong>、Schema.org を <strong>Article</strong> にして著者名を入れます。同じ出力を得るには、Ctrl/⌘+L でサンプルの文字を消し、viewport のチェックを外し、2 つのサンプル URL を書き換えてから、次の値を入力します。</p>

{/* mtg-check: {"title":"「はじめての確定申告」e-Tax の手順 & 必要書類まとめ","description":"スマホで e-Tax を使う手順と、事前にそろえる書類を図解でまとめました（所要時間 <30分）。","canonical":"https://example.jp/tax/e-tax-guide/","siteName":"家計メモ帳","author":"佐藤 花子","ogType":"article","ogLocale":"ja_JP","ogImage":"https://example.jp/ogp/e-tax-guide.png","ogImageWidth":"1200","ogImageHeight":"630","ogImageAlt":"スマホの e-Tax 画面と書類","twSite":"@kakeimemo","schemaType":"Article"} */}
```html
<title>「はじめての確定申告」e-Tax の手順 &amp; 必要書類まとめ</title>
<meta name="description" content="スマホで e-Tax を使う手順と、事前にそろえる書類を図解でまとめました（所要時間 &lt;30分）。">
<link rel="canonical" href="https://example.jp/tax/e-tax-guide/">
<meta name="author" content="佐藤 花子">
<meta name="robots" content="index, follow">

<!-- Open Graph / Facebook -->
<meta property="og:type" content="article">
<meta property="og:title" content="「はじめての確定申告」e-Tax の手順 &amp; 必要書類まとめ">
<meta property="og:description" content="スマホで e-Tax を使う手順と、事前にそろえる書類を図解でまとめました（所要時間 &lt;30分）。">
<meta property="og:url" content="https://example.jp/tax/e-tax-guide/">
<meta property="og:site_name" content="家計メモ帳">
<meta property="og:image" content="https://example.jp/ogp/e-tax-guide.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="スマホの e-Tax 画面と書類">
<meta property="og:locale" content="ja_JP">

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:site" content="@kakeimemo">
<meta name="twitter:title" content="「はじめての確定申告」e-Tax の手順 &amp; 必要書類まとめ">
<meta name="twitter:description" content="スマホで e-Tax を使う手順と、事前にそろえる書類を図解でまとめました（所要時間 &lt;30分）。">
<meta name="twitter:image" content="https://example.jp/ogp/e-tax-guide.png">

<!-- Schema.org JSON-LD -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "name": "「はじめての確定申告」e-Tax の手順 & 必要書類まとめ",
  "description": "スマホで e-Tax を使う手順と、事前にそろえる書類を図解でまとめました（所要時間 \u003c30分）。",
  "url": "https://example.jp/tax/e-tax-guide/",
  "image": "https://example.jp/ogp/e-tax-guide.png",
  "author": {
    "@type": "Person",
    "name": "佐藤 花子"
  }
}
</script>
```

<p>属性の中では <code>&amp;</code> が <code>&amp;amp;</code>、<code>&lt;</code> が <code>&amp;lt;</code> になり、「」はそのまま残ります。JSON-LD では <code>&lt;</code> だけが <code>\u003c</code> に置き換わります。値に <code>&lt;/script&gt;</code> が含まれていても、貼り付け先のページで script 要素が途中で終わらないようにするためで、JSON として読めば元の <code>&lt;</code> に戻ります。</p>

{/* mtg-count: {"title":"「はじめての確定申告」e-Tax の手順 & 必要書類まとめ","description":"スマホで e-Tax を使う手順と、事前にそろえる書類を図解でまとめました（所要時間 <30分）。"} */}
<p>文字数カウンターはタイトルが <code>30 / 60</code>、説明が <code>49 / 160</code> と表示します。JavaScript の文字列の長さを数えているので、全角も半角も、スペースも 1 文字です。Google の<a href="https://developers.google.com/search/docs/appearance/snippet">スニペットのドキュメント</a>には、meta description の長さに上限はなく、検索結果では必要に応じて、たいていは端末の幅に合わせて切り詰めるとあります。60 と 160 は目安として使ってください。</p>

<h2>LINE とはてなブックマークでの見え方</h2>
<p>生成したタグのうち、LINE とはてなブックマークが何を使うかは、それぞれ次のように説明されています。</p>
<ul>
  <li><strong>LINE：</strong><a href="https://developers.line.biz/ja/faq/#how-are-the-url-previews-generated">LINE Developers の FAQ</a> は「LINEで使用されるのは上記の3つのOGPタグのみです」としています。3 つとは <code>og:title</code>・<code>og:description</code>・<code>og:image</code> です。上の例なら、トークのプレビューにはタイトル、説明、<code>e-tax-guide.png</code> が使われ、<code>og:site_name</code> の「家計メモ帳」や <code>og:image:alt</code> はプレビューには使われません。</li>
  <li><strong>はてなブックマーク：</strong><a href="https://bookmark.hatenastaff.com/entry/2021/11/10/175747">はてなブックマーク開発ブログ（2021-11-10）</a>によると、エントリーの画像に og:image を使っていることに合わせて、og:title が設定されていればエントリーのタイトルにそれを優先して使うようになりました。このツールは <code>&lt;title&gt;</code> と <code>og:title</code> に同じタイトルを入れるので、<code>&lt;title&gt;</code> にだけサイト名を付けたい場合は、コピー後に <code>&lt;title&gt;</code> の行を書き換えます。</li>
</ul>

<h2>制限事項</h2>
<ul>
  <li><strong>JSON-LD は最小限です。</strong>name・description・url・image と、Article の場合の author だけです。Google の <a href="https://developers.google.com/search/docs/appearance/structured-data/article">Article のドキュメント</a>は <code>headline</code> や <code>datePublished</code> を推奨しており、Product が商品のリッチリザルトの対象になるには <code>offers</code>・<code>review</code>・<code>aggregateRating</code> のいずれかが必要です。必要な項目は手で追加し、Google のリッチリザルト テストで確認してください。</li>
  <li><strong>対応する項目がない選択肢があります。</strong>Twitter の <code>player</code> と <code>app</code> カードには <code>twitter:player</code> や <code>twitter:app:&#42;</code> が必要ですが、このツールは出力しません。og:type の <code>product</code> は ogp.me に定義された型ではありません。<code>article:published_time</code>、<code>og:image:type</code>、hreflang も出力しません。</li>
  <li><strong>robots は常に出力されます。</strong><code>index, follow</code> はクローラーの既定の動作と同じなので、noindex や nofollow にしないなら行ごと削除してかまいません。</li>
  <li><strong>プレビューは見た目の近似です。</strong>正規 URL が空のときはサイト名からプレビュー用のドメインを作りますが、「家計メモ帳」のように半角英数字を含まない名前では <code>example.com</code> と表示します。実際のカードは公開後に各サービスのデバッガーで確認してください。</li>
  <li><strong>通信について：</strong>タグの内容はブラウザー内にとどまりますが、Facebook・Twitter・Discord のプレビューは入力した画像 URL を読み込むので、画像のホストにはリクエストが届きます。最初に表示される Google のプレビューには画像がありません。</li>
  <li><strong>Ctrl/⌘+L で消えるのはテキスト欄だけです。</strong>og:locale やテーマカラーの文字欄を含むテキスト欄が空になり、URL 欄・数値欄・プルダウン・viewport のチェックは残ったまま head が作り直されます。</li>
</ul>

<h2>出力をどこに貼るか</h2>
<p>生成されたメタブロックは <code>&lt;head&gt;</code> の中、<code>&lt;meta charset&gt;</code> の後、サードパーティのスクリプトより前に置くのがおすすめです。クローラーは順番を気にしませんが、SNS 用のメタタグを 1 か所にまとめておくと、あとで確認しやすくなります。</p>
<p>同じ SEO の作業でよく併用するツール：<a href="/ja/tools/robots-txt-generator/">Robots.txt ジェネレーター</a>（クロール規則）と <a href="/ja/tools/favicon-generator/">Favicon ジェネレーター</a>（アイコンセット）。</p>
