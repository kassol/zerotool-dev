## 白色卡片和深色图片说明

默认设置是白色、15% 不透明度、12px 模糊、180% 饱和度。增强规则中的关键声明如下，复制按钮得到的完整代码还包括回退和媒体查询：

{/* gsg-check: {"settings":{},"contains":"background: rgba(255, 255, 255, 0.15);"} */}
```css
background: rgba(255, 255, 255, 0.15);
backdrop-filter: blur(12px) saturate(180%);
```

默认文字 `#111111` 与白色实心回退背景的对比度为 **18.88:1**。这个数值不能代替图片上的透明卡片结果。把预览背景切成「深夜」，同一填充色下的文字可读性就会变化。

再试一张中文商品海报：玻璃颜色 `#036`，不透明度 70%，模糊 16px，饱和度 100%，文字选白色，回退色设为 `#003366`。这是演示参数，页面没有声称它符合某个电商平台的设计规定。

{/* gsg-check: {"settings":{"bg":"#003366","alpha":70,"blur":16,"saturation":100},"contains":"background: rgba(0, 51, 102, 0.70);"} */}
```css
background: rgba(0, 51, 102, 0.70);
backdrop-filter: blur(16px) saturate(100%);
```

白字与该实心回退色为 **12.60:1**。打开图片后，要再次看「毛玻璃」那一行；海报里的白色区域会透过填充色改变结果。增加模糊会平滑背景细节，普通文字能否达到 4.5:1 仍由合成后的颜色决定。

## H5 样式与小程序配置分开使用

微信小程序的[全局配置文档](https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/app.html)把 `navigationBarBackgroundColor` 定义为 HexColor，把 `navigationBarTextStyle` 限为 black 或 white。这些是 `app.json` 配置项。本工具导出的是网页 CSS，不能把整段毛玻璃代码直接放进导航栏配置。

给 H5 活动页制作文字卡片时，可以在这里检查背景图片与文字；给小程序原生导航栏选实心色时，可用[颜色对比度检测器](/zh/tools/color-contrast-checker/)比较黑字、白字与背景。两种场景都需要检查文字，输入位置和支持的样式各有自己的约束。

## 三种状态各自有背景

输出先写不透明回退，再通过 `@supports` 加上半透明填充和背景滤镜。前缀只是同一功能的另一种属性名，不能让不支持滤镜的浏览器自动获得实心背景。

「减少透明效果」媒体查询会恢复回退色并关闭滤镜。网页上的自定义开关可为已有 `glass` 类的元素再加 `glass-opaque`；本工具的「关闭透明效果」则直接导出实心版本。强制颜色模式使用 `Canvas`、`CanvasText`，去掉阴影并关闭滤镜，颜色交给用户的系统。

Tailwind v4 输出是 `@utility glass`，应放进导入 Tailwind 的样式文件，HTML 使用 `class="glass"`。本项目以 Tailwind 4.3.3 实际编译过输出，规则依据[自定义工具类文档](https://tailwindcss.com/docs/adding-custom-styles#adding-custom-utilities)。工具没有生成组件模板，也没有替你的应用绑定开关事件。

## 模糊失效时检查祖先元素

[Filter Effects Level 2 草案](https://drafts.fxtf.org/filter-effects-2/#BackdropRoot)说明 backdrop root 会限制背景采样。2026-10-02 在 Chromium 中放置黑白条纹，再给卡片祖先分别设置 `filter: brightness(1)`、`opacity: .99`、`will-change: opacity`，三者都让外部条纹不再被卡片模糊。对照的 `transform: translateZ(0)` 仍保留模糊。

即使滤镜看起来没有改变颜色，也可能改变采样边界。草案注明该定义尚未获得工作组共识，实际页面应以目标浏览器复核。需要处理图片本身的滤镜时，使用[CSS Filter 生成器](/zh/tools/css-filter-generator/)；毛玻璃滤镜作用于元素背后的区域。

## 估计值、兼容性与上限

工具用 Canvas 滤镜估计背景，再叠加玻璃填充色，对卡片内侧矩形逐像素取最低文字对比度。按指定文字色计算，避免把抗锯齿边缘当成前景色。它不检查边框、焦点、链接与全部 WCAG 条款。[WCAG 2.2 的对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)要求普通文字 4.5:1、大字 3:1；4.499 不能四舍五入当作通过。

[MDN 兼容数据](https://developer.mozilla.org/en-US/docs/Web/CSS/backdrop-filter#browser_compatibility)列出 Chrome 76、Edge 79、Firefox 103、Safari 18 的无前缀支持，Safari 9–17 需前缀。[减少透明效果查询](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-transparency#browser_compatibility)的支持更窄：Chromium 118 起支持，Firefox 需偏好开关，Safari 未列出支持，因此仍应提供手动入口。

2026-10-02 实测 css.glass 调不透明度、Hype4 调模糊都会立即改写 CSS，编辑期间没有观察到 fetch/XHR 上传。其检查到的输出主要是半透明声明，本工具额外生成状态规则，并允许用本地图片估计对比度。

图片上限为 20 MB、5000 万像素。Canvas 与 CSS 在模糊边缘可能不同；不支持 Canvas 滤镜时显示提示。预览不模拟视频、滚动背景、多层玻璃或实际页面的祖先效果。不支持 RGB/HSL 输入。阴影固定为 `0 4px 24px`，需要改偏移与扩散时使用[CSS 阴影生成器](/zh/tools/box-shadow-generator/)。
