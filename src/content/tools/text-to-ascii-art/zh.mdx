<h2>使用方法</h2>
<ol>
  <li>在<strong>输入文字</strong>栏中输入或粘贴文本，最多 80 个字符。</li>
  <li>从下拉菜单中选择<strong>字体</strong>以切换 ASCII 艺术风格。</li>
  <li>输出自动更新，点击<strong>复制</strong>即可复制结果。</li>
</ol>

## 示例

输入 `Deploy`，字体选 **Standard**：

```
  ____             _             
 |  _ \  ___ _ __ | | ___  _   _ 
 | | | |/ _ \ '_ \| |/ _ \| | | |
 | |_| |  __/ |_) | | (_) | |_| |
 |____/ \___| .__/|_|\___/ \__, |
            |_|            |___/ 
```

同样的输入，字体选 **Slant**：

```
    ____             __           
   / __ \___  ____  / /___  __  __
  / / / / _ \/ __ \/ / __ \/ / / /
 / /_/ /  __/ /_/ / / /_/ / /_/ / 
/_____/\___/ .___/_/\____/\__, /  
          /_/            /____/   
```

工具使用 figlet.js 1.11，按各字体的默认字距排版。`pyfiglet.figlet_format("Deploy", font="slant")`（pyfiglet 1.0.4）输出完全相同的 6 行，之后想在脚本里生成同样的横幅可以直接用它。

## 输出有多宽

用 figlet.js 1.11 实测。输出不会自动换行，输入越长，横幅越宽。

| 字体 | 行数 | `Hello World` 占的列数 | 80 列内能放下的大写字母数 |
|---|---|---|---|
| Mini | 4 | 38 | 20 |
| Small | 5 | 44 | 16 |
| Doom | 8 | 50 | 12 |
| Standard | 6 | 53 | 13 |
| Big | 8 | 55 | 11 |
| Slant | 6 | 57 | 12 |
| Script | 7 | 59 | 12 |
| Shadow | 5 | 65 | 11 |
| Banner | 8 | 76 | 10 |
| Block | 8 | 93 | 7 |
| Lean | 8 | 97 | 7 |
| 3D-ASCII | 10 | 117 | 7 |

80 列是终端的传统宽度。放进 README 或终端横幅时，优先选表格上方的字体，或者缩短文字。

## 粘贴到不同地方

- **Markdown（README、Discord、Slack）**：放进三个反引号的代码块。代码块外的连续空格会被合并，字形就散了。
- **Shell 脚本与 `~/.zshrc`**：用带引号定界符的 heredoc，`cat << 'EOF'`，Shell 就不会展开图案里的 `$` 和 `` ` ``。
- **JSON**：换行要写成 `\n`，图案里每个 `\` 都要转义成 `\\`。
- **YAML**：用字面块标量（`|`）保留换行。
- **字体**：只有等宽字体下图案才能对齐。

## 限制

- **输入最多 80 个字符**，首尾空格会被去掉。
- **字体里没有的字符会被直接丢掉，不提示。** 12 种字体只覆盖 ASCII 字母、数字和标点，中文、日文、韩文和 emoji 都会消失：输入 `你好 OK` 只渲染出 `OK`。想做中文字符画需要换别的工具。
- **只有 12 种字体**：Standard、Banner、Big、Block、Doom、Lean、Mini、Script、Shadow、Slant、Small、3D-ASCII。没有宽度、换行或字距设置。
- 每种字体在第一次选中时从本站加载，同一会话内之后的渲染直接使用已加载的字体。
