## 使用步骤

1. 在「文字」框输入英文、数字或符号。换行会另起一段艺术字，最多 2000 个字符。
2. 选「字体」。拿不准时点「预览全部 12 种字体」，在喜欢的那一种上点「使用」。
3. 「字距」一般保持「字体默认」，觉得字母太松或太挤再换（见下表）。
4. 要放进终端或代码注释时，在「宽度」里选列数。80 列与 figlet 命令的默认值相同。
5. 在「复制为」里选格式后点「复制」，或下载 `.txt`、PNG。
6. 输出下方给出等价的 `figlet` 命令，写脚本时直接用。

## 示例

### Spring Boot 启动横幅

Spring Boot 会在启动时打印 classpath 里的 `banner.txt`，也可以用 `spring.banner.location` 指定文件；文件里还能用 `${spring-boot.formatted-version}` 等占位符（见 [Spring Boot 文档](https://docs.spring.io/spring-boot/reference/features/spring-application.html#features.spring-application.banner)）。把服务名 `order-api` 用 Slant 生成，保存为 `src/main/resources/banner.txt`：

{/* figlet: {"font":"Slant","text":"order-api"} */}

```text
                  __                            _
  ____  _________/ /__  _____      ____ _____  (_)
 / __ \/ ___/ __  / _ \/ ___/_____/ __ `/ __ \/ /
/ /_/ / /  / /_/ /  __/ /  /_____/ /_/ / /_/ / /
\____/_/   \__,_/\___/_/         \__,_/ .___/_/
                                     /_/
```

文件不是 UTF-8 编码时，用 `spring.banner.charset` 指定编码。

### 生产服务器登录提示

登录成功后，系统会显示 `/etc/motd` 的内容（[motd(5)](https://man7.org/linux/man-pages/man5/motd.5.html)）。在生产机上放一个醒目的 `PROD`，能减少把命令敲错机器的情况。用 Big 生成后下载 `.txt`，复制到 `/etc/motd`：

{/* figlet: {"font":"Big","text":"PROD"} */}

```text
 _____  _____   ____  _____
|  __ \|  __ \ / __ \|  __ \
| |__) | |__) | |  | | |  | |
|  ___/|  _  /| |  | | |  | |
| |    | | \ \| |__| | |__| |
|_|    |_|  \_\\____/|_____/
```

### 中文会被跳过

输入 `你好 OK`，Standard 字体只画出 `OK`，输出下方提示「已跳过：Standard 字体里没有这些字符：你 好」：

{/* figlet: {"font":"Standard","text":"你好 OK"} */}

```text
   ___  _  __
  / _ \| |/ /
 | | | | ' /
 | |_| | . \
  \___/|_|\_\
```

开头多出的空白来自 `你好` 后面的空格。

## 与 figlet 命令逐字一致

排版代码移植自 [figlet 2.2.5](https://github.com/cmatsuoka/figlet/tree/2.2.5)。测试用同一批字体文件跑 figlet 2.2.5，覆盖 12 种字体、5 种字距、多行、5 种宽度下的换行，以及字体里没有的字符，共 840 组，逐字相同。

此前本页用的是 [figlet.js](https://github.com/patorjk/figlet.js) 1.11。同样输入 `Hello World`，12 种字体中有 8 种与 figlet 不同：Standard、Big、Banner、Block、Script、Small 每行前多一列空格；Mini 和 Shadow 的字体文件要求字母重叠，figlet.js 没有照做，Mini 宽 37 列，figlet 只有 26 列。

输出下方的命令可以复现同样的结果。Banner、Big、Block、Lean、Mini、Script、Slant、Small、Standard 与 figlet 2.2.5 自带的字体逐字形一致；Doom 和 3D-ASCII 不在 figlet 自带字体里；本站的 Shadow 是 2007 年加宽空格的修订版。用到这三种字体，或在 Standard 里输入 ಠ 时，命令改用本站的 `.flf` 文件，旁边有下载链接。

## 字距选项

[FIGfont 规范](https://github.com/cmatsuoka/figlet/blob/2.2.5/figfont.txt)允许每种字体指定默认排法，以及最多 6 条「合并」规则，例如两个相同字符合成一个、`/` 遇到 `\` 合成 `|`。

| 选项 | figlet 参数 | 效果 |
|---|---|---|
| 字体默认 | 无 | 按字体作者设定 |
| 全宽（-W） | `-W` | 每个字母保留完整宽度，包括空白列 |
| 紧贴（-k） | `-k` | 字母靠拢到相接为止，不重叠 |
| 合并（-S） | `-S` | 按字体规则重叠一列，默认是紧贴的字体也照样合并 |
| 重叠（-o） | `-o` | 不论相遇的是什么字符，都重叠一列 |

## 各字体的宽度

本工具实测，开启「去掉行尾空格和首尾空行」：

| 字体 | `Hello World` 行数 | `Hello World` 列数 | 宽度 80 时每行能放 `ABC…Z` 的字母数 |
|---|---|---|---|
| Mini | 2 | 26 | 26 |
| Small | 4 | 43 | 16 |
| Doom | 6 | 50 | 12 |
| Standard | 5 | 52 | 13 |
| Big | 6 | 54 | 11 |
| Slant | 5 | 57 | 12 |
| Block | 5 | 90 | 7 |
| 3D-ASCII | 7 | 117 | 7 |

Standard、Big、Block、Lean、Mini、Script、Shadow、Slant、Small 还能画 é、ñ、Å 等 Latin-1 字母，Standard 另有 ł、š、ő 等东欧字母。

## 粘贴时注意

- **README、博客等 Markdown 文档**：选「Markdown 代码块」。不放进代码块时，Markdown 会合并连续空格，行尾两个空格还会变成[强制换行](https://spec.commonmark.org/0.31.2/#hard-line-breaks)。
- **代码注释**：选 `#` 或 `//` 注释，并保持「去掉行尾空格」勾选。遵循 [EditorConfig](https://spec.editorconfig.org/) `trim_trailing_whitespace` 的编辑器会删掉行尾空格，pycodestyle 也会报 [W291](https://pycodestyle.pycqa.org/en/latest/intro.html#error-codes)。
- **Shell 脚本**：选 heredoc 格式。分隔符带引号，shell 不会展开艺术字里的 `$`、`` ` `` 和 `\`（[POSIX here-document](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html#tag_19_07_04)）。
- **JSON 或 JavaScript 字符串**：先把 `\` 和换行转义，可以用[字符串转义工具](/zh/tools/string-escape/)。

## 与其他在线工具的对比

2026-10-01 用 `Hello World` 和 `Hi 中文` 实测：

- [在线工具大全 lddgo](https://www.lddgo.net/string/text-to-ascii-art)：「字符宽度」默认为 Full，字母之间不合并；`Hi 中文` 只输出 `Hi`，没有提示。
- [TAAG](https://patorjk.com/software/taag/)：基于 figlet.js，Standard 首列多一列空格，Mini 宽 37 列，中文同样被静默丢掉；字体数量远多于本工具，可以存成图片。
- [asciiart.eu](https://www.asciiart.eu/text-to-ascii-art)：Standard 与 figlet 一致，Mini 不重叠（37 列）；文字里有任何中文时整段输出为空。

本工具与 figlet 命令逐字一致，列出被跳过的字，并给出复现用的命令。想在聊天或昵称里用不换行的花体英文，可以用[花体字生成器](/zh/tools/unicode-text-converter/)；想看 README 里的效果，可以贴进 [Markdown 预览](/zh/tools/markdown-preview/)。

## 限制

- **只有 12 种字体**，不能上传字体。
- **只支持拉丁字母等少数文字**。字体里没有的字不画，并列在输出下方；Tab 按 figlet 的规则变成空格，其他控制字符被丢弃，也会列出。
- **最多 2000 个字符**，超出时显示提示，不生成。
- **每行文字一段艺术字**。figlet 2.2.5 不做纵向合并，多行原样上下排列。
- **PNG 尺寸**：每边不超过 16,384 像素、总面积不超过 16,777,216 像素（iOS Safari 的画布上限），更宽时会提示，请设置宽度。
- 只有等宽字体才能对齐。
