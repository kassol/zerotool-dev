## 使い方

1. 「テキスト」に英数字や記号を入力します。改行すると別の段になり、上限は 2,000 文字です。
2. 「フォント」を選びます。迷ったら「12 フォントをすべてプレビュー」を押し、気に入ったものの「使う」をクリックします。
3. 「字間」は通常「フォント既定」のままで構いません。詰まりすぎ・空きすぎに見えるときだけ変えます（下の表を参照）。
4. ターミナルやコードコメントに収めたいときは「幅」を指定します。80 桁は figlet コマンドの既定値です。
5. 「コピー形式」を選んで「コピー」を押すか、`.txt` や PNG で保存します。
6. 出力の下に同じ結果を出す `figlet` コマンドが表示されるので、スクリプトにはそれを使えます。

## カタカナを描けるのは Banner だけ

Banner フォントにはカタカナの字形が入っています。`テスト` を Banner で組むと次のようになります。

{/* figlet: {"font":"Banner","text":"テスト"} */}

```text
  ######   ######## #
                  # #
##########       #  ##
     #         ##   # #
     #       ## #   #  #
    #       ##   #  #
  ##       #      # #
```

収録されているのは清音の大きい文字だけで、`ガ` のような濁音・半濁音、`ッ` などの小書き文字、長音記号 `ー` はありません。ひらがな・漢字はどのフォントにもなく、`こんにちは OK` と入れると `OK` だけが描かれ、「スキップしました：Standard フォントにない文字：こ ん に ち は」と表示されます。

日本語を大きく描きたい場合は、フォントを点に分解して `■` で描く方式のツール（例：LAZE SOFTWARE の[巨大文字AAジェネレーター](https://lazesoftware.com/ja/tool/hugeaagen/)）が向いています。FIGlet のアスキーアートとは別の仕組みです。

## バックスラッシュが ¥ に見える問題

FIGlet のフォントは `\` を多く使います。`Deploy` を Standard で組んだ例です。

{/* figlet: {"font":"Standard","text":"Deploy"} */}

```text
 ____             _
|  _ \  ___ _ __ | | ___  _   _
| | | |/ _ \ '_ \| |/ _ \| | | |
| |_| |  __/ |_) | | (_) | |_| |
|____/ \___| .__/|_|\___/ \__, |
           |_|            |___/
```

日本語版 Windows のコードページ 932 では 0x5C が円記号で、システムロケールが日本語のとき、日本語フォントは U+005C を `¥` の形で表示します（Microsoft の Michael Kaplan による解説「[When is a backslash not a backslash?](http://archives.miloush.net/michkap/archive/2005/09/17/469941.html)」、[Win32 ドキュメント](https://learn.microsoft.com/en-us/windows/win32/intl/security-considerations--international-features)）。そのためメモ帳やターミナルのフォントによっては、上の `\` がすべて `¥` になり、絵が崩れて見えます。データは `\` のままなので、Qiita や Zenn に貼った内容自体は正しく、`¥` に見えるのはその環境のフォントによるものです。自分の画面で確認するときは、Consolas や Cascadia Code など欧文の等幅フォントに切り替えてください。

## 字間の選び方

[FIGfont 仕様](https://github.com/cmatsuoka/figlet/blob/2.2.5/figfont.txt)では、フォントごとに既定の組み方と最大 6 個の「結合」規則（同じ文字どうしは 1 文字にする、`/` と `\` は `|` にする、など）を決められます。`Qiita` を Standard で組むと、既定は次のとおりです。

{/* figlet: {"font":"Standard","text":"Qiita"} */}

```text
  ___  _ _ _
 / _ \(_|_) |_ __ _
| | | | | | __/ _` |
| |_| | | | || (_| |
 \__\_\_|_|\__\__,_|
```

「全幅（-W）」にすると、各文字が空白の列も含めた本来の幅を保ち、20 桁が 30 桁になります。

{/* figlet: {"font":"Standard","text":"Qiita","layout":"full"} */}

```text
   ___    _   _   _
  / _ \  (_) (_) | |_    __ _
 | | | | | | | | | __|  / _` |
 | |_| | | | | | | |_  | (_| |
  \__\_\ |_| |_|  \__|  \__,_|
```

| 選択肢 | figlet オプション | 内容 |
|---|---|---|
| フォント既定 | なし | フォント作者が決めた組み方 |
| 全幅（-W） | `-W` | 各文字が空白の列も含めた全幅を保つ |
| 詰める（-k） | `-k` | 接するまで寄せる。重ねない |
| 結合（-S） | `-S` | フォントの規則で 1 桁重ねる。既定が「詰める」のフォントでも結合する |
| 重ねる（-o） | `-o` | どの文字が出会っても 1 桁重ねる |

## figlet コマンドと同じ出力

組版部分は [figlet 2.2.5](https://github.com/cmatsuoka/figlet/tree/2.2.5) を移植したものです。同じフォントファイルで figlet 2.2.5 を実行した 840 通り（12 フォント × 5 種の字間、複数行、5 種の幅での折り返し、フォントにない文字）と 1 文字ずつ比較し、すべて一致しています。以前のこのページは [figlet.js](https://github.com/patorjk/figlet.js) 1.11 を使っており、`Hello World` では 12 フォント中 8 フォントで figlet と結果が違いました。

Banner、Big、Block、Lean、Mini、Script、Slant、Small、Standard は figlet 2.2.5 付属のフォントと字形が同じです。Doom と 3D-ASCII は付属しておらず、このサイトの Shadow は空白を広げた 2007 年の改訂版です。この 3 フォントを使うとき（と Standard で ಠ を使うとき）は、表示されるコマンドがこのサイトの `.flf` ファイルを読み込みます。

## 他のジェネレーターとの違い

2026-10-01 に `Hello World` と `Hi 中文` で確認しました。

- [TAAG](https://patorjk.com/software/taag/)：figlet.js を使っており、Standard の先頭に空白が 1 桁多く、Mini は 37 桁（figlet は 26 桁）です。漢字は通知なしに消えます。フォント数はこのツールよりずっと多く、画像保存もできます。
- [asciiart.eu](https://www.asciiart.eu/text-to-ascii-art)：Standard は figlet と同じですが、Mini は重ならず 37 桁です。漢字が 1 文字でも入ると出力が空になります。

このツールは figlet コマンドと一致し、スキップした文字を明示し、同じ結果を出すコマンドも示します。チャットやプロフィールで 1 行のまま飾り文字にしたいときは[フォント変換（おしゃれ英数字）](/ja/tools/unicode-text-converter/)を、README での見え方は [Markdown プレビュー](/ja/tools/markdown-preview/)で確認できます。JSON の文字列に入れる場合は、先に[文字列エスケープ](/ja/tools/string-escape/)で `\` と改行をエスケープしてください。

## 制限事項

- **フォントは 12 種類**で、フォントの追加はできません。
- **対応文字はラテン文字が中心です**。フォントにない文字は描かれず、出力の下に表示されます。タブは figlet と同じく空白になり、その他の制御文字は捨てられて表示されます。
- **入力は 2,000 文字まで**です。超えると出力の代わりにメッセージが出ます。
- **1 行のテキストが 1 段になります**。figlet 2.2.5 は縦方向の結合をしないため、段はそのまま縦に並びます。
- **PNG の大きさ**は 1 辺 16,384 ピクセル、総面積 16,777,216 ピクセル（iOS Safari のキャンバス上限）までです。超える場合は幅を指定してください。
- 等幅フォントでないと行が揃いません。
