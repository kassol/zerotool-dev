<h2>使い方</h2>
<ol>
  <li><strong>入力テキスト</strong>フィールドにテキストを入力または貼り付けます（最大80文字）。</li>
  <li>ドロップダウンから<strong>フォント</strong>を選択してASCIIアートのスタイルを変更します。</li>
  <li>出力は自動更新されます。<strong>コピー</strong>をクリックして結果をコピーします。</li>
</ol>

<h2>利用可能なフォント</h2>

| フォント | スタイル |
|---------|---------|
| Standard | クリーンでクラシックなfigletデフォルト |
| Doom | 太字のターミナル風 |
| Slant | 斜体の対角線文字 |
| Shadow | ドロップシャドウ付き文字 |
| Big | 超大型ブロック文字 |
| Block | 塗りつぶし長方形 |
| Banner | 横長フラット文字 |
| Script | 筆記体風ストローク |
| Lean | 細身のコンデンスドグリフ |
| Mini | コンパクトな2行高さ |
| Small | Standardの小型版 |
| 3D-ASCII | 3Dパースペクティブ押し出し |

<h2>主な用途</h2>
<ul>
  <li>GitHubのREADMEヘッダーとセクション区切り</li>
  <li>ターミナルウェルカムバナーとMOTDスクリプト</li>
  <li>DiscordやSlackのメッセージ装飾</li>
  <li>コードコメントとセクションマーカー</li>

## 生成例

入力 `Deploy`、フォント **Standard**：

```
  ____             _             
 |  _ \  ___ _ __ | | ___  _   _ 
 | | | |/ _ \ '_ \| |/ _ \| | | |
 | |_| |  __/ |_) | | (_) | |_| |
 |____/ \___| .__/|_|\___/ \__, |
            |_|            |___/ 
```

同じ入力でフォント **Slant**：

```
    ____             __           
   / __ \___  ____  / /___  __  __
  / / / / _ \/ __ \/ / __ \/ / / /
 / /_/ /  __/ /_/ / / /_/ / /_/ / 
/_____/\___/ .___/_/\____/\__, /  
          /_/            /____/   
```

このツールは figlet.js 1.11 を使い、各フォントの既定の字間で組みます。`pyfiglet.figlet_format("Deploy", font="slant")`（pyfiglet 1.0.4）もまったく同じ 6 行を出力するので、あとでスクリプトから同じバナーを作れます。

## 出力の幅

figlet.js 1.11 で実測しました。出力は折り返されないため、入力が長いほど横に長いバナーになります。

| フォント | 行数 | `Hello World` の桁数 | 80 桁に収まる大文字の数 |
|---|---|---|---|
| Mini | 4 | 38 | 20 |
| Small | 5 | 44 | 16 |
| Doom | 8 | 50 | 12 |
| Standard | 6 | 53 | 13 |
| Big | 8 | 55 | 11 |
| Slant | 6 | 57 | 12 |
| Script | 7 | 59 | 12 |
| Shadow | 5 | 65 | 11 |
| Banner | 8 | 76 | 10 |
| Block | 8 | 93 | 7 |
| Lean | 8 | 97 | 7 |
| 3D-ASCII | 10 | 117 | 7 |

80 桁は昔からの端末幅です。README やターミナルのバナーには表の上のほうのフォントを選ぶか、文字数を減らしてください。

## 貼り付け先ごとの注意

- **Markdown（README、Discord、Slack）**：バッククォート 3 つのコードブロックに入れます。コードブロックの外では連続した空白がまとめられ、文字が崩れます。
- **シェルスクリプトと `~/.zshrc`**：区切り文字を引用符で囲んだヒアドキュメント `cat << 'EOF'` を使うと、アート内の `$` や `` ` `` が展開されません。
- **JSON**：改行は `\n`、アート内の `\` はすべて `\\` にエスケープします。
- **YAML**：リテラルブロックスカラー（`|`）で改行を保ちます。
- **フォント**：等幅フォントでないと行がそろいません。

## 制限事項

- **入力は 80 文字まで**で、前後の空白は取り除かれます。
- **フォントにない文字はスキップされ、出力の下にその文字が表示されます。** 12 フォントのどれもひらがな・漢字・ハングル・絵文字を持っていません。`こんにちは OK` と入れると `OK` だけが描かれ、「スキップしました：Standard フォントにない文字：こ ん に ち は」と表示されます。3D-ASCII は `(`・`)`・`_`・`{` など 14 個の記号と Ä Ö Ü ä ö ü ß も描けず、これらも表示されます。タブなど見えない文字は `U+0009` の形で出ます。日本語のアスキーアートには別のツールが必要です。
- **フォントは 12 種類**：Standard、Banner、Big、Block、Doom、Lean、Mini、Script、Shadow、Slant、Small、3D-ASCII。幅・折り返し・字間の設定はありません。
- フォントファイルは初めて選んだときに本サイトから読み込まれ、同じセッション内では読み込み済みのものを使います。
