## Same output as the figlet command

The renderer is a port of [figlet 2.2.5](https://github.com/cmatsuoka/figlet/tree/2.2.5), the last release of the original program. Its test compares 840 renders against figlet 2.2.5 run with the same font files: every font, every spacing option, line breaks, word wrap at five widths, and characters the fonts lack. All 840 match character for character.

The previous version of this page used [figlet.js](https://github.com/patorjk/figlet.js) 1.11, which gives different output for 8 of the 12 fonts on `Hello World`. Standard, Big, Banner, Block, Script and Small get an extra blank first column. Mini and Shadow are not overlapped, although their font files ask for it: Mini comes out 37 columns wide instead of 26.

The command in the FIGlet command section reproduces the art. Banner, Big, Block, Lean, Mini, Script, Slant, Small and Standard are glyph-for-glyph the same as the fonts in the figlet 2.2.5 package. Doom and 3D-ASCII are not in that package. Shadow here is a 2007 revision with a wider space. For these three, and for Standard text that contains ಠ, the command loads the `.flf` file from this site, with a download link next to it.

## Spacing options

The [FIGfont specification](https://github.com/cmatsuoka/figlet/blob/2.2.5/figfont.txt) lets each font name a default layout and up to six "smushing" rules, such as "two equal characters become one" or "`/` and `\` become `|`".

| Option | figlet flag | What it does |
|---|---|---|
| Font default | none | The layout the font author chose |
| Full width (-W) | `-W` | Each letter keeps its full width, blank columns included |
| Fitted (-k) | `-k` | Letters move together until they touch; nothing overlaps |
| Smushed (-S) | `-S` | Overlaps by one column using the font's rules, even in fonts whose default is fitted |
| Overlapped (-o) | `-o` | Overlaps by one column regardless of which characters meet |

## Where to paste it

- **README and Markdown**: use **Copy as → Markdown code block**. Outside a code block, Markdown collapses spaces, and two spaces at the end of a line become a [hard line break](https://spec.commonmark.org/0.31.2/#hard-line-breaks).
- **Source code**: use the `#` or `//` format. Keep **Trim** on: editors that follow [EditorConfig](https://spec.editorconfig.org/) `trim_trailing_whitespace` and linters such as pycodestyle ([W291](https://pycodestyle.pycqa.org/en/latest/intro.html#error-codes)) flag or remove spaces at the end of a line.
- **Shell scripts and `~/.bashrc`**: the heredoc format quotes the delimiter, so the shell does not expand `$`, `` ` `` or `\` inside the art ([POSIX here-documents](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html#tag_19_07_04)).
- **Login banner**: the text of `/etc/motd` is printed after a successful login ([motd(5)](https://man7.org/linux/man-pages/man5/motd.5.html)). Download the `.txt` file and copy it there.
- **JSON or a JavaScript string**: escape every `\` and line break first, for example with the [String Escape](/tools/string-escape/) tool.

## Compared with other generators

Checked on 2026-10-01 with `Hello World` and `Hi 中文`:

- [TAAG](https://patorjk.com/software/taag/) runs on figlet.js, which was written for it. Standard gets the extra blank first column, Mini is 37 columns wide, and the CJK characters disappear without a message. It offers far more fonts than this tool and a Save as image button.
- [asciiart.eu](https://www.asciiart.eu/text-to-ascii-art) gives the figlet result for Standard, but Mini is not overlapped (37 columns). With any CJK character in the text, the output is empty. Its width defaults to 80, so `Hello World` in Block wraps.
- This tool matches the figlet command, lists skipped characters by name, and gives you the command to rebuild the art.

For styled letters that stay on one line in a chat or a profile, try the [Fancy Text Generator](/tools/unicode-text-converter/). To check how the art looks in a README, paste the Markdown into [Markdown Preview](/tools/markdown-preview/).

## Limits

- **12 fonts.** There is no font upload.
- **Latin script only.** Characters the font lacks draw nothing and are listed under the output. figlet turns a tab into a space and drops other control characters; these are listed too.
- **2,000 characters.** Longer text shows a message instead of output.
- **One block per line of text.** figlet 2.2.5 has no vertical smushing, so lines are stacked as they are.
- **PNG size.** The image stays within 16,384 pixels per side and 16,777,216 pixels in total, the canvas limit of iOS Safari. Wider art shows a message; set a width.
- The art lines up only in a monospaced font.
