<h2>Text to ASCII Art Online</h2>
<p>Turn plain text into large ASCII banners directly in your browser. Choose a FIGlet font, preview the output instantly, and copy the result for a README, terminal welcome message, Discord post, or code comment.</p>

<h2>How to Use</h2>
<ol>
  <li>Type or paste text in the <strong>Input Text</strong> field — up to 80 characters.</li>
  <li>Select a <strong>Font</strong> from the dropdown to change the ASCII art style.</li>
  <li>The output updates automatically. Click <strong>Copy</strong> to copy the result.</li>
</ol>

## Example

Input `Deploy`, font **Standard**:

```
  ____             _             
 |  _ \  ___ _ __ | | ___  _   _ 
 | | | |/ _ \ '_ \| |/ _ \| | | |
 | |_| |  __/ |_) | | (_) | |_| |
 |____/ \___| .__/|_|\___/ \__, |
            |_|            |___/ 
```

Same input, font **Slant**:

```
    ____             __           
   / __ \___  ____  / /___  __  __
  / / / / _ \/ __ \/ / __ \/ / / /
 / /_/ /  __/ /_/ / / /_/ / /_/ / 
/_____/\___/ .___/_/\____/\__, /  
          /_/            /____/   
```

The tool uses figlet.js 1.11 with each font's default spacing. `pyfiglet.figlet_format("Deploy", font="slant")` (pyfiglet 1.0.4) prints the same six lines, so you can script the same banner later.

80 columns is the classic terminal width. For a README or a terminal banner, pick a font from the top of the table or shorten the text.

## Pasting the Result

- **Markdown (README, Discord, Slack)**: put the art inside a fenced code block (three backticks). Outside a code block, Markdown collapses the spaces and the letters fall apart.
- **Shell scripts and `~/.zshrc`**: use a heredoc with a quoted delimiter, `cat << 'EOF'`, so the shell does not expand `$` or `` ` `` characters in the art.
- **JSON**: newlines must be written as `\n`, and every `\` in the art must be escaped as `\\`.
- **YAML**: use a literal block scalar (`|`) so the line breaks stay.
- **Fonts**: the art lines up only in a monospace font.

## Limits

- **Input is capped at 80 characters**, and leading and trailing spaces are removed.
- **Characters the font does not have are dropped without a warning.** The 12 fonts cover ASCII letters, digits and punctuation, so Chinese, Japanese, Korean and emoji disappear: `你好 OK` renders only `OK`.
- **12 fonts only**: Standard, Banner, Big, Block, Doom, Lean, Mini, Script, Shadow, Slant, Small and 3D-ASCII. There is no width, wrapping or letter-spacing setting.
- Each font file loads from this site the first time you select it; later renders in the same session use the loaded copy.
