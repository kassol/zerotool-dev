<ul>
  <li><strong>私钥必须保密</strong>。任何持有私钥的人都可以解密信息或伪造签名。</li>
  <li>只需分享<strong>公钥</strong>——它本就是设计为公开的。</li>
  <li>此工具适合测试和开发使用。生产环境请使用专用密钥管理服务（AWS KMS、HashiCorp Vault 等）。</li>

## 输出格式

**PEM** 输出的公钥是 SubjectPublicKeyInfo（`-----BEGIN PUBLIC KEY-----`），私钥是未加密的 PKCS#8（`-----BEGIN PRIVATE KEY-----`）。OpenSSL 3.6 可以直接读取（`Private-Key: (2048 bit, 2 primes)`）。只认 PKCS#1（`-----BEGIN RSA PRIVATE KEY-----`）的旧软件需要先转换，命令见下文。

**JWK**（[RFC 7517](https://www.rfc-editor.org/rfc/rfc7517)）是浏览器 Web Crypto API 导出的格式。用 RSA-OAEP 生成的 2048 位公钥有下面这些字段。模数 `n` 每次都不同，这里只写它的长度：

{/* rkg-check: {"size":2048,"algo":"RSA-OAEP","format":"jwk","part":"public","mask":"<{n} 个字符>","nLength":342} */}
```json
{
  "alg": "RSA-OAEP-256",
  "e": "AQAB",
  "ext": true,
  "key_ops": [
    "encrypt"
  ],
  "kty": "RSA",
  "n": "<342 个字符>"
}
```

2048 位的模数是 256 字节，所以 `n` 总是 `342` 个 base64url 字符。选 RSASSA-PKCS1-v1_5 时，公钥 JWK 为 `"alg": "RS256"`、`"key_ops": ["verify"]`。输出里没有 `kid` 和 `use`；放到 JWKS 端点前请加上 `kid`，因为 JWT 头部按 `kid` 查找公钥。

## 示例：给支付宝开放平台准备 RSA2 密钥

支付宝把长度为 2048 位的密钥称为 RSA2 密钥，签名方式是 RSA(SHA256)（[如何从 RSA1 升级到 RSA2](https://opendoc.alipay.com/support/01raus)）。在本工具里对应的选项是 2048 位、RSASSA-PKCS1-v1_5、PEM。

支付宝的《[使用 OpenSSL 工具生成密钥](https://opendoc.alipay.com/common/02khjt)》要求把应用公钥文件去掉头尾、换行和空格，转成一行字符串再上传。下载的 `public-key.pem` 可以这样处理：

```bash
grep -v -- '-----' public-key.pem | tr -d '\n'
```

{/* rkg-check: {"size":2048,"algo":"RSASSA-PKCS1-v1_5","format":"pem","part":"public","oneLine":392,"start":"MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA","end":"IDAQAB"} */}
得到的一行总是 `392` 个字符，以 `MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA` 开头、以 `IDAQAB` 结尾。前面这段记录的是密钥类型和长度，结尾一段包含公钥指数 65537，每把 2048 位公钥都一样，中间才是随机的模数。粘贴到开放平台之前数一下长度、看一眼开头结尾，就能发现复制时漏掉了一截。

私钥的处理按开发语言分开。同一篇文档说明：Java 使用 PKCS8 格式的私钥，同样去掉头尾、换行和空格后填进代码；PHP、.NET 使用标准的 PKCS1 私钥文件。本工具的私钥就是 PKCS8（`-----BEGIN PRIVATE KEY-----`），Java 可以直接用；其他语言先用下一节的 `openssl rsa … -traditional` 转成 `-----BEGIN RSA PRIVATE KEY-----`。私钥只配置在自己的服务端，不要上传到开放平台。

## 配合 OpenSSH 与 OpenSSL 使用

以下命令在 macOS 的 OpenSSH 与 OpenSSL 3.6.1 上对下载的文件实际运行过。私钥文件别人可读时 `ssh-keygen` 会拒绝（「Permissions 0644 … are too open」），先收紧权限：

```bash
chmod 600 private-key.pem

# OpenSSH public key for ~/.ssh/authorized_keys
ssh-keygen -y -f private-key.pem
ssh-keygen -i -m PKCS8 -f public-key.pem      # same result from the public key

# PKCS#1 ("BEGIN RSA PRIVATE KEY") for older software
openssl rsa -in private-key.pem -traditional -out private-key-pkcs1.pem

# Inspect the key
openssl pkey -in private-key.pem -noout -text
```

## 选择长度和算法

| 密钥长度 | 安全强度（[NIST SP 800-57 Part 1 Rev. 5](https://csrc.nist.gov/pubs/sp/800/57/pt1/r5/final) 表 2） |
|---|---|
| 1024 位 | 80 位，已不允许使用 |
| 2048 位 | 112 位 |
| 3072 位 | 128 位（本工具不提供） |
| 4096 位 | 介于 128 与 192 位之间 |

算法选项决定浏览器允许密钥做什么，也决定 JWK 里的声明：**RSA-OAEP**（SHA-256）用于加密，**RSASSA-PKCS1-v1_5**（SHA-256，对应 JWT 的 `RS256`）用于签名。PEM 文件不携带算法信息，OpenSSL 可以把同一个 PEM 密钥用于两种用途。

{/* rkg-check: {"size":4096,"algo":"RSA-OAEP","format":"pem","part":"public","oneLine":736,"lines":12,"start":"MIICIjANBgkqhkiG9w0BAQEFAAOCAg8AMIICCgKCAgEA","end":"AwEAAQ=="} */}
选 4096 位时公钥也会变长：Base64 部分是 `736` 个字符、`12` 行，以 `MIICIjANBgkqhkiG9w0BAQEFAAOCAg8AMIICCgKCAgEA` 开头、以 `AwEAAQ==` 结尾。支付宝文档把 RSA2 定义为 2048 位密钥，给支付宝配置时请选 2048 位；其他平台先查清它要求的长度再选。

## 限制

- 只有 2048 和 4096 位；公钥指数固定为 65537（`AQAB`）。
- 私钥 PEM 没有用口令加密。请把文件放在受保护的位置，或用 `openssl pkcs8 -topk8 -in private-key.pem -out encrypted.pem` 加密。
- 不输出 OpenSSH 私钥格式，也不生成证书或 CSR；这些请用 `ssh-keygen` 和 `openssl req`。支付宝的公钥证书模式需要 CSR，本工具做不到。
- 4096 位明显比 2048 位慢。页面等待 `crypto.subtle.generateKey` 返回的 Promise；Chromium 在名为 “WebCrypto” 的单独线程上执行这些运算（[源码](https://chromium.googlesource.com/chromium/src/+/main/components/webcrypto/webcrypto_impl.cc)），等待期间页面不会卡住。
- 没有清除按钮。在工具内按 Ctrl 或 Command + L 可以清空两个结果。
