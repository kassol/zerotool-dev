Pick widths that divide evenly (multiples of 16 for 16:9) when the ratio must be exact.</p>

<h2>How Lock Ratio and Presets Work</h2>
<ul>
  <li>Lock Ratio stores width ÷ height at the moment you turn it on. Every later change to one side recalculates the other from that stored ratio and rounds it to a whole number, so typing 1000 and then 1920 as the width returns to 1080.</li>
  <li>A preset sets the size to 120 × the ratio numbers: 16:9 becomes 1920 × 1080, 4:3 becomes 480 × 360 and 21:9 becomes 2520 × 1080. The ratio is shown in lowest terms, so the 21:9 preset displays 7:3.</li>
  <li>Decimal sizes are accepted. The ratio is then computed from the rounded values, so 1.5 × 1 shows 1.5:1.</li>
</ul>

<p>In CSS, the <code>aspect-ratio</code> property takes the same pair as a fraction, such as <code>aspect-ratio: 16 / 9</code> (<a href="https://developer.mozilla.org/en-US/docs/Web/CSS/aspect-ratio" target="_blank" rel="noopener">MDN</a>). The calculator only works out numbers; it does not crop or resize image files.</p>

<h2>Aspect Ratio in Web Design</h2>
<p>Understanding aspect ratios is crucial for responsive design, video embeds, image cropping, and CSS <code>aspect-ratio</code> property. This calculator helps designers and developers quickly find the right dimensions for any target ratio.</p>

<h2>Limits</h2>
{/* ar-check: {"w":"33.867","h":"19.05"} */}
<ul>
  <li>Width and Height must be positive. An empty field, 0 or a negative number shows — for the ratio and the decimal, without an error message.</li>
  <li>The ratio is simplified with whole numbers. With decimal sizes the result keeps the decimals: 33.867 × 19.05 shows <code>33.867:19.05</code>, not 16:9, although the decimal is <code>1.7778</code>.</li>
  <li>Resize and Lock Ratio round the calculated side to the nearest whole pixel, so a result can be up to half a pixel off the exact ratio.</li>
  <li>The preview is a shape within 300 × 200 pixels with each side at least 20 pixels; very narrow or very wide ratios are approximate.</li>
  <li>The calculator works only with numbers. It does not open, crop or resize image or video files.</li>
</ul>
