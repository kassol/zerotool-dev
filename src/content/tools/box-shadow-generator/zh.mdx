## box-shadow 语法参考

```css
/* 基础外阴影 */
box-shadow: offsetX offsetY blur spread color;

/* 内阴影 */
box-shadow: inset offsetX offsetY blur spread color;

/* 多重阴影 */
box-shadow: shadow1, shadow2, shadow3;
```

按 [CSS Backgrounds and Borders Level 3](https://www.w3.org/TR/css-backgrounds-3/#box-shadow) 的语法，一个阴影由 2 到 4 个长度组成：没写的长度按 0 处理；模糊半径不能是负数，写了负数整条声明都会失效；没写颜色时用 `currentColor`，也就是元素的文字颜色。本工具每次都写出全部四个长度和一个具体颜色，所以复制出去的阴影不会因为元素文字颜色不同而变色。

## 先看默认输出

打开页面时，五个滑块依次是 5、5、10、0 和 30%，颜色为黑色，输出如下：

{/* bsg-check: {"h":5,"v":5,"blur":10,"spread":0,"opacity":30,"color":"#000000","inset":false} */}
```css
box-shadow: 5px 5px 10px 0px rgba(0, 0, 0, 0.30);
```

四个长度都带单位，值为 0 时也写成 `0px`；不透明度 30% 写成 alpha 值 `0.30`。模糊半径并不等于柔边的宽度。规范要求按标准差为模糊半径一半的高斯模糊来近似，并在注释里说明：对一条长直边，过渡带的长度约为模糊半径的两倍，以阴影边缘为中心。所以 10px 的模糊会在边缘内外各延伸约 10px，扩散为 0 时阴影看起来也比盒子大一圈。

## 按 Ant Design 的 boxShadow 令牌逐层生成

[Ant Design](https://github.com/ant-design/ant-design/blob/master/components/theme/util/alias.ts) 6.6.5 的主题源码里，令牌 `boxShadow` 由三层阴影组成，阴影颜色 `colorShadow` 默认是 `#000`。三层的数值分别是：

- 第一层：水平 0、垂直 6px、模糊 16px、扩散 0，不透明度 8%
- 第二层：水平 0、垂直 3px、模糊 6px、扩散 −4px，不透明度 12%
- 第三层：水平 0、垂直 9px、模糊 28px、扩散 8px，不透明度 5%

本工具一次只出一层。按上面的数值各调一次，三次复制的结果是：

{/* bsg-check: {"layers":[{"h":0,"v":6,"blur":16,"spread":0,"opacity":8,"color":"#000000","inset":false},{"h":0,"v":3,"blur":6,"spread":-4,"opacity":12,"color":"#000000","inset":false},{"h":0,"v":9,"blur":28,"spread":8,"opacity":5,"color":"#000000","inset":false}]} */}
```css
box-shadow: 0px 6px 16px 0px rgba(0, 0, 0, 0.08);
box-shadow: 0px 3px 6px -4px rgba(0, 0, 0, 0.12);
box-shadow: 0px 9px 28px 8px rgba(0, 0, 0, 0.05);
```

去掉每行开头的 `box-shadow: ` 和结尾的分号，用逗号连起来，就是一条三层的声明：

```css
.dropdown {
  box-shadow: 0px 6px 16px 0px rgba(0, 0, 0, 0.08),
              0px 3px 6px -4px rgba(0, 0, 0, 0.12),
              0px 9px 28px 8px rgba(0, 0, 0, 0.05);
}
```

顺序要照源码写：规范规定列表中的第一个阴影在最上层，其余依次垫在下面。第二层的扩散是负数，阴影形状先向四周收进 4px，再向下偏 3px，四条边都还在盒子里面，靠 6px 的模糊才渗出去，渗出最多的是底边，所以它主要在盒子下方加深一条；第三层模糊最大、透明度最低，负责远处那层很淡的晕。

## 内阴影：标签栏左边缘的渐隐

同一个文件里还有给标签页（Tabs）溢出边缘准备的令牌 `boxShadowTabsOverflowLeft`，写法是 `inset 10px 0 8px -8px`，不透明度 8%。在工具里打开内阴影，把水平偏移设为 10、垂直偏移 0、模糊 8、扩散 −8、不透明度 8%：

{/* bsg-check: {"h":10,"v":0,"blur":8,"spread":-8,"opacity":8,"color":"#000000","inset":true} */}
```css
box-shadow: inset 10px 0px 8px -8px rgba(0, 0, 0, 0.08);
```

内阴影可以理解为在盒子内部挖出一个「洞」，洞以外的部分涂上阴影。水平偏移 10px 让洞向右移，扩散 −8px 让洞向四周扩大 8px，于是上、下、右三边都被洞盖住，只在左边缘剩下约 2px 宽的阴影，再经过 8px 模糊变成一条渐隐的竖条。改成 `-10px` 的水平偏移，渐隐就出现在右边缘，对应源码里的 `boxShadowTabsOverflowRight`。

## 中文输入法的全角字符

颜色文本框只认 `#` 加六位半角十六进制。中文输入法在全角状态下打出的 `＃１６７７ｆｆ` 不符合这个格式，工具不会报错，只是保留上一次的颜色。下面是同一组滑块（全部为 0，只有扩散 2px、不透明度 20%），分别输入全角和半角时的输出：

{/* bsg-check: {"h":0,"v":0,"blur":0,"spread":2,"opacity":20,"color":"#000000","inset":false,"hex":"＃１６７７ｆｆ"} */}
```css
box-shadow: 0px 0px 0px 2px rgba(0, 0, 0, 0.20);
```

{/* bsg-check: {"h":0,"v":0,"blur":0,"spread":2,"opacity":20,"color":"#000000","inset":false,"hex":"#1677ff"} */}
```css
box-shadow: 0px 0px 0px 2px rgba(22, 119, 255, 0.20);
```

`#1677ff` 是 Ant Design 种子令牌 `colorPrimary` 的默认值（[seed.ts](https://github.com/ant-design/ant-design/blob/master/components/theme/themes/seed.ts)）。如果复制出来的 rgba 仍是 `0, 0, 0`，先检查文本框里的 `#` 和字母是不是全角。

## 限制

- **一次只生成一个阴影。** 多层效果要像上面那样逐层生成，再手动用逗号拼接。
- **滑块范围有限。** 偏移和扩散为 −50 到 50px，模糊为 0 到 100px，不透明度只能取整数百分比。超出这个范围的值，或者 `rem`、`em` 这类 px 以外的单位，需要复制后手动修改。
- **颜色只接受 `#` 加六位十六进制。** 三位简写（`#abc`）、颜色名和全角字符都会保留原来的颜色。
- **强制颜色模式下没有阴影。** 在 Windows 高对比度等强制颜色模式里，`box-shadow` 的计算值是 `none`（[CSS Color Adjust Level 1 §3.1](https://www.w3.org/TR/css-color-adjust-1/#forced-colors-properties)）。只用阴影画出的焦点环会随之消失，请同时保留 `outline`。
- **外阴影不会透过盒子显示。** 外阴影只画在边框以外，盒子背景半透明时也看不到下面的阴影。要让阴影贴合透明 PNG 或文字的形状，需要手写 `filter: drop-shadow(...)`。
- **阴影不占位置。** 规范规定阴影不影响布局，也不会扩大可滚动的溢出区域，相邻元素可能盖住阴影，排版时要自己留出间距。
