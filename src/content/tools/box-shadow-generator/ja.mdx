## 書き方と省略できる値

```css
/* 外側の影 */
box-shadow: offsetX offsetY blur spread color;

/* 内側の影 */
box-shadow: inset offsetX offsetY blur spread color;

/* 複数の影 */
box-shadow: shadow1, shadow2, shadow3;
```

[CSS Backgrounds and Borders Level 3](https://www.w3.org/TR/css-backgrounds-3/#box-shadow) では、1枚の影は2〜4個の長さで表します。書かなかった長さは0、ブラー半径に負の値を書くと宣言全体が無効になり、色を省略すると `currentColor`（要素の文字色）が使われます。このツールは長さを毎回4つとも書き出し、`0` も `0px` と出力します。色も具体的な値で書くので、貼り付け先の文字色に左右されません。

ブラー半径はぼけた部分の幅そのものではありません。仕様は「標準偏差がブラー半径の半分のガウスぼかし」で近似するよう求めており、注記では、長い直線の縁ならブラー半径の約2倍の長さの色の変化が縁を中心にできると説明しています。ブラー10pxなら、縁の内側と外側に約10pxずつ広がります。

## デジタル庁デザインシステムのエレベーションを1枚ずつ作る

デジタル庁がMITライセンスで公開しているデザイントークン（npmの [`@digital-go-jp/design-tokens`](https://github.com/digital-go-jp/design-tokens) 2.0.1、`dist/tokens.css`）では、浮き上がりの段階（エレベーション）を2枚の影で表しています。4段目は次の値です。

```css
--elevation-4: 0 6px 20px 4px rgba(0,0,0,0.1), 0 2px 6px 0 rgba(0,0,0,0.3);
```

1枚目は広く薄い影、2枚目は狭く濃い影です。ツールで再現するには、色を黒のまま、1枚目を水平0・垂直6・ブラー20・スプレッド4・不透明度10%、2枚目を0・2・6・0・30%に設定して、それぞれコピーします。

{/* bsg-check: {"layers":[{"h":0,"v":6,"blur":20,"spread":4,"opacity":10,"color":"#000000","inset":false},{"h":0,"v":2,"blur":6,"spread":0,"opacity":30,"color":"#000000","inset":false}]} */}
```css
box-shadow: 0px 6px 20px 4px rgba(0, 0, 0, 0.10);
box-shadow: 0px 2px 6px 0px rgba(0, 0, 0, 0.30);
```

それぞれの `box-shadow: ` と末尾のセミコロンを外し、トークンと同じ順番でカンマでつなげば `--elevation-4` と同じ見た目になります。`0.1` と `0.10`、`0` と `0px` は値として同じです。仕様では、リストの最初の影がいちばん手前に描かれます。ただしこの2枚はどちらも黒なので、順番を入れ替えても見た目は変わりません。Chromium で両方の順番を描画して画素を比べると、差は色の値で最大1でした。赤と青のように色の違う影を重ねると、入れ替えたときに箱の下の色が変わります。トークンと同じ順に並べておけば、どちらの場合も同じ仕上がりになります。

## 下側だけに影を出す

カードの下辺だけに影を付けたいときは、スプレッドを負にしてブラーと同じ量だけ影を縮め、同じ量だけ下へずらします。

{/* bsg-check: {"h":0,"v":6,"blur":6,"spread":-6,"opacity":35,"color":"#000000","inset":false} */}
```css
box-shadow: 0px 6px 6px -6px rgba(0, 0, 0, 0.35);
```

影の形は箱より四方6pxずつ小さくなり、6px下へずれるので、上辺は箱の上端より12px内側、左右は6px内側、下辺はちょうど箱の下端に重なります。ブラーは縁の両側へ約6pxずつ広がるだけなので、箱の外へはみ出すのは主に下側です。スプレッドの絶対値をブラーより小さくすると、左右にも薄く影が見えてきます。

## 全角で入力したカラーコード

カラーコードのテキスト欄が受け付けるのは、半角の `#` と6桁（または8桁）の16進数だけです。日本語入力がオンのまま打った `＃００１７ｃ１` は形式に合わないので、状態行にヒントが表示され、色は直前のまま残ります。スライダーをすべて0、スプレッドだけ3px、不透明度100%にして、全角と半角でそれぞれ入力した結果です。

{/* bsg-check: {"h":0,"v":0,"blur":0,"spread":3,"opacity":100,"color":"#000000","inset":false,"hex":"＃００１７ｃ１"} */}
```css
box-shadow: 0px 0px 0px 3px rgba(0, 0, 0, 1.00);
```

{/* bsg-check: {"h":0,"v":0,"blur":0,"spread":3,"opacity":100,"color":"#000000","inset":false,"hex":"#0017c1"} */}
```css
box-shadow: 0px 0px 0px 3px rgba(0, 23, 193, 1.00);
```

`#0017c1` は同じトークンファイルの `--color-primitive-blue-900` です。コピーした rgba が `0, 0, 0` のままなら、`#` や英字が全角になっていないか確認してください。オフセットとブラーが0の影は、要素の `border-radius` に沿った幅3pxの帯になります。

## 制限

- **影は1回に1枚です。** 重ねる場合は上のように1枚ずつ作り、カンマで手作業でつなぎます。
- **スライダーの範囲：** オフセットとスプレッドは−50〜50px、ブラーは0〜100px、不透明度は整数のパーセントです。範囲外の値や `rem`・`em` など px 以外の単位は、コピー後に手で書き換えてください。
- **色は `#` と6桁または8桁の16進数だけです。** 8桁では最後の2桁をアルファ値 / 255 として整数のパーセントに丸め、`#0000001f`（31/255）は12%になります。3桁の省略形（`#abc`）、色名、`rgba()`、全角文字では色は変わらず、状態行にヒントが出ます。
- **強制カラーモードでは影が消えます。** Windowsのハイコントラストなどの強制カラーモードでは `box-shadow` の計算値が `none` になります（[CSS Color Adjust Level 1 §3.1](https://www.w3.org/TR/css-color-adjust-1/#forced-colors-properties)）。影だけで描いたフォーカスリングは見えなくなるので、`outline` も残してください。
- **外側の影は箱の下に描かれません。** 外側の影はボーダーの外側にだけ描かれ、背景が半透明でも透けて見えません。透過PNGや文字の形に沿った影が必要なら、`filter: drop-shadow(...)` を手で書きます。
- **影はレイアウトに影響しません。** 仕様上、影は配置にもスクロールできる範囲にも影響しないので、隣の要素に重なることがあります。必要な余白は自分で取ります。
