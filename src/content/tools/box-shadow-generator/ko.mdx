## box-shadow 값의 구성

```css
/* 기본 외부 그림자 */
box-shadow: offsetX offsetY blur spread color;

/* 인셋 그림자 */
box-shadow: inset offsetX offsetY blur spread color;

/* 다중 그림자 */
box-shadow: shadow1, shadow2, shadow3;
```

[CSS Backgrounds and Borders Level 3](https://www.w3.org/TR/css-backgrounds-3/#box-shadow)에 따르면 그림자 하나는 길이 값 2~4개로 이루어집니다. 쓰지 않은 길이는 0이고, 블러 반경에 음수를 쓰면 선언 전체가 무효가 되며, 색상을 생략하면 `currentColor`(요소의 글자 색)가 쓰입니다. 이 도구는 항상 길이 4개와 구체적인 색상을 모두 출력하므로 0도 `0px`로 쓰이고, 붙여 넣을 요소의 글자 색에 영향을 받지 않습니다.

블러 반경은 흐린 부분의 너비가 아닙니다. 사양은 표준편차가 블러 반경의 절반인 가우스 블러로 근사하라고 정하고 있고, 주석에서는 긴 직선 테두리라면 블러 반경의 약 2배 길이에 걸쳐 색이 바뀌며 그 구간의 중심이 그림자의 테두리라고 설명합니다. 블러 10px이면 테두리 안팎으로 약 10px씩 번집니다.

## KRDS 도움말 패널 그림자를 한 겹씩 만들기

대한민국 정부 디자인 시스템 KRDS가 배포하는 [krds-uiux](https://github.com/KRDS-uiux/krds-uiux) 1.1.0의 `component.css`에는 도움말 패널 그림자가 다음과 같이 정의되어 있습니다.

```css
--krds-help-panel--shadow: 0 0 0.2rem 0 var(--krds-light-color-alpha-shadow2), 0 0.8rem 1.6rem 0 var(--krds-light-color-alpha-shadow3);
```

이 값을 이 도구로 옮길 때 확인할 점은 두 가지입니다.

- **단위:** 도구는 px만 다룹니다. KRDS의 `common.css`는 `html`의 글자 크기를 `62.5%`로 두므로, 브라우저 기본 글자 크기가 16px일 때 1rem은 10px입니다. 그러면 0.2rem은 2px, 0.8rem은 8px, 1.6rem은 16px입니다.
- **색상:** 두 색은 `krds_tokens.css`에서 `#00000014`와 `#0000001f`처럼 8자리 hex로 정의되어 있습니다. 도구의 텍스트 칸에 8자리 hex를 그대로 넣으면 앞 6자리는 색상, 마지막 두 자리는 불투명도가 됩니다. 불투명도는 정수 퍼센트로 반올림되므로 0x14(20/255 ≈ 0.078)는 8%, 0x1f(31/255 ≈ 0.122)는 12%가 됩니다.

첫째 겹은 수평 0·수직 0·블러 2·스프레드 0으로 두고 텍스트 칸에 `#00000014`를, 둘째 겹은 0·8·16·0으로 두고 `#0000001f`를 입력해 각각 복사하면 다음과 같습니다.

{/* bsg-check: {"layers":[{"h":0,"v":0,"blur":2,"spread":0,"opacity":30,"color":"#000000","inset":false,"hex":"#00000014"},{"h":0,"v":8,"blur":16,"spread":0,"opacity":30,"color":"#000000","inset":false,"hex":"#0000001f"}]} */}
```css
box-shadow: 0px 0px 2px 0px rgba(0, 0, 0, 0.08);
box-shadow: 0px 8px 16px 0px rgba(0, 0, 0, 0.12);
```

각 줄의 `box-shadow: `와 세미콜론을 지우고 원래 순서대로 쉼표로 이으면 됩니다. 사양상 목록의 첫 번째 그림자가 가장 위에 그려지므로, 테두리를 감싸는 얇은 그림자가 앞에, 아래로 넓게 퍼지는 그림자가 뒤에 옵니다. 불투명도는 정수 퍼센트만 되므로 12%는 원래 값 31/255보다 아주 조금 옅습니다. 원래 값을 그대로 쓰려면 복사한 뒤 rgba를 8자리 hex로 되돌리면 됩니다.

## 입력란의 인셋 그림자

인셋을 켜고 수평 0·수직 2·블러 4·스프레드 0·불투명도 10%로 두면, 위쪽 안쪽 가장자리가 살짝 어두운 입력란이 됩니다.

{/* bsg-check: {"h":0,"v":2,"blur":4,"spread":0,"opacity":10,"color":"#000000","inset":true} */}
```css
box-shadow: inset 0px 2px 4px 0px rgba(0, 0, 0, 0.10);
```

인셋 그림자는 패딩 박스 안쪽에만 그려지고 테두리 아래에 깔립니다. 그래서 요소의 크기나 주변 배치는 바뀌지 않고, 배경색 위에 그림자가 덮입니다.

## 포커스 링

오프셋과 블러를 0으로 두고 스프레드만 주면 테두리를 따라가는 띠가 생깁니다. 텍스트 칸에 KRDS `krds_tokens.css`의 `--krds-color-light-primary-50` 값인 `#256ef4`를 입력하고 스프레드 2px, 불투명도 40%로 설정한 결과입니다.

{/* bsg-check: {"h":0,"v":0,"blur":0,"spread":2,"opacity":40,"color":"#000000","inset":false,"hex":"#256ef4"} */}
```css
box-shadow: 0px 0px 0px 2px rgba(37, 110, 244, 0.40);
```

사양은 스프레드만큼 모서리 반경도 키우므로 둥근 버튼에는 둥근 띠가 생깁니다. 다만 Windows 고대비 같은 강제 색상 모드에서는 `box-shadow`의 계산값이 `none`이 되어([CSS Color Adjust Level 1 §3.1](https://www.w3.org/TR/css-color-adjust-1/#forced-colors-properties)) 이 띠가 사라집니다. 포커스 표시를 그림자로만 하지 말고 `outline`도 함께 남겨 두세요.

## 제한

- **한 번에 그림자 하나만 만듭니다.** 여러 겹은 위처럼 한 겹씩 만들어 직접 쉼표로 잇습니다.
- **슬라이더 범위:** 오프셋과 스프레드는 −50~50px, 블러는 0~100px, 불투명도는 정수 퍼센트입니다. 범위를 벗어난 값이나 `rem`처럼 px가 아닌 단위는 복사한 뒤 직접 고쳐야 합니다.
- **색상은 # 뒤 6자리 또는 8자리 16진수만 받습니다.** 8자리의 마지막 두 자리는 정수 퍼센트 불투명도로 반올림됩니다. 3자리 축약형(`#abc`), 색상 이름, `rgba()`, 전각 문자를 입력하면 기존 색상이 유지되고 상태 줄에 안내가 표시됩니다.
- **외부 그림자는 상자 아래에 그려지지 않습니다.** 외부 그림자는 테두리 바깥에만 그려지므로 배경이 반투명해도 비치지 않습니다. 투명 PNG나 글자 모양을 따르는 그림자가 필요하면 `filter: drop-shadow(...)`를 직접 작성합니다.
- **그림자는 레이아웃에 영향을 주지 않습니다.** 사양상 그림자는 배치와 스크롤 가능한 영역을 바꾸지 않으므로 옆 요소와 겹칠 수 있습니다. 필요한 여백은 따로 확보하세요.
