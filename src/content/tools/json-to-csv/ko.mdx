<h2>사용 방법</h2>
<ol>
  <li>왼쪽 패널에 JSON 객체 배열을 붙여넣으면 자동으로 변환됩니다.</li>
  <li><strong>구분자</strong>를 선택: 쉼표(기본), 세미콜론, 또는 탭.</li>
  <li><strong>중첩 객체 펼치기</strong>를 켜면 중첩 키가 점 경로 열(예: <code>address.city</code>)로 펼쳐집니다.</li>
  <li><strong>헤더 포함</strong>으로 헤더 행 포함 여부를 전환합니다.</li>
  <li>다른 사람에게서 받은 데이터라면 <strong>수식 방지</strong>를 고릅니다(아래 참고). 기본값은 꺼짐입니다.</li>
  <li><strong>복사</strong>로 클립보드에 복사하거나 <strong>.csv 다운로드</strong>로 파일을 저장합니다. 다운로드 파일에는 기본적으로 UTF-8 BOM이 붙습니다("다운로드에 UTF-8 BOM 추가"에서 끔).</li>
</ol>

<h2>예제</h2>

<h3>기본 변환</h3>
<p>입력 JSON:</p>
<pre><code>{`[{"id":1,"name":"Alice"},{"id":2,"name":"Bob"}]`}</code></pre>
<p>출력 CSV:</p>
<pre><code>{`id,name\n1,Alice\n2,Bob`}</code></pre>

<h3>중첩 객체 펼치기</h3>
<p>입력 JSON:</p>
<pre><code>{`[{"user":{"name":"Alice","age":30}}]`}</code></pre>
<p>출력 CSV (펼치기 켬):</p>
<pre><code>{`user.name,user.age\nAlice,30`}</code></pre>

<h2>RFC 4180 준수</h2>
<p>
  이 도구는 RFC 4180 CSV 표준을 따릅니다. 구분자, 큰따옴표, 줄바꿈을 포함한 필드는 큰따옴표로 감싸지며, 필드 내 큰따옴표는 <code>""</code>로 이스케이프됩니다. 행 구분은 RFC 4180의 CR LF가 아니라 LF입니다(Excel, LibreOffice, pandas 모두 읽을 수 있음).
</p>

<h2>수식 방지</h2>
<p>
  <code>=</code>, <code>+</code>, <code>-</code>, <code>@</code>, 탭, 줄바꿈으로 시작하는 셀은 스프레드시트에서 열 때 수식으로 실행될 수 있습니다(<a href="https://owasp.org/www-community/attacks/CSV_Injection" target="_blank" rel="noopener">OWASP: CSV Injection</a>). 도구는 이런 문자열 값을 세어 상태 줄에 표시합니다. <strong>수식 방지</strong>를 켜면 OWASP 권장대로 앞에 문자를 붙이고 따옴표로 감쌉니다. <strong>' 붙이기</strong>는 <code>'</code>를, <strong>탭 붙이기 (Excel)</strong>는 탭을 붙입니다(OWASP에 따르면 Excel에서 저장 후 다시 열어도 탭은 남습니다). 입력:
</p>
<pre><code>{`[{"name":"Ann","comment":"=HYPERLINK(\"http://example.com\",\"Click\")"}]`}</code></pre>
<p>"' 붙이기" 출력:</p>
<pre><code>{`name,comment
Ann,"'=HYPERLINK(""http://example.com"",""Click"")"`}</code></pre>
<p>JSON 문자열만 바꾸며, <code>-5</code> 같은 숫자, 불리언, JSON 텍스트로 쓰는 배열·객체는 그대로입니다. <code>+82 2 1234 5678</code> 같은 전화번호에도 접두 문자가 붙어 데이터가 바뀌므로 기본값은 꺼짐이고, 해당 값이 있으면 상태 줄에 알려 줍니다.</p>

<h2>Excel과 BOM</h2>
<p>
  다운로드한 파일은 기본적으로 UTF-8 BOM(바이트 <code>EF BB BF</code>)으로 시작합니다. Microsoft 지원 페이지 <a href="https://support.microsoft.com/en-us/office/opening-csv-utf-8-files-correctly-in-excel-8a935af5-3416-4edd-ba7e-3dfd2bc4a032" target="_blank" rel="noopener">Opening CSV UTF-8 files correctly in Excel</a>은 BOM과 함께 저장된 UTF-8 CSV는 그대로 열 수 있다고 설명합니다. BOM이 없으면 Windows용 Excel은 더블클릭으로 연 CSV를 시스템 코드 페이지(한국어 환경은 CP949)로 읽어 한글이 깨집니다. BOM을 예상하지 않는 프로그램은 BOM을 첫 열 이름의 일부로 읽을 수 있습니다(Python에서 <code>encoding="utf-8"</code>이면 <code>\ufeffid</code>, <code>"utf-8-sig"</code>이면 제거됨). 이때는 "다운로드에 UTF-8 BOM 추가"를 끄세요. <strong>복사</strong>한 내용에는 BOM이 붙지 않습니다.
</p>

<h2>제한 사항</h2>
<ul>
  <li>빈 중첩 객체와 배열은 펼치지 않습니다. <code>{`"meta":{}`}</code>는 <code>meta</code> 열이 되고 값은 <code>{`{}`}</code>입니다.</li>
  <li>2<sup>53</sup>을 넘는 정수는 JSON을 읽을 때 정밀도가 떨어집니다. 긴 ID는 JSON에서 문자열로 두세요.</li>
</ul>
