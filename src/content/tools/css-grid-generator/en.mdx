<h2>Understanding the Generated CSS</h2>
<p>
  The generator outputs a single <code>.container</code> rule with five properties:
  <code>display: grid</code>, <code>grid-template-columns</code>, <code>grid-template-rows</code>,
  <code>column-gap</code>, and <code>row-gap</code>. Paste it into your stylesheet and rename
  <code>.container</code> to match your own class name. The rule describes the container only; the children are placed automatically, one per cell, in source order.
</p>

<h2>Example: the Default 3 × 2 Grid</h2>

{/* cgg-check: {"cols":3,"rows":2,"colGap":"1rem","rowGap":"1rem"} */}

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 1fr);
  column-gap: 1rem;
  row-gap: 1rem;
}
```

<p>In a 1000px-wide container with a 16px root font size, Chrome resolved the columns to 322.664px each: (1000 − 2 × 16) ÷ 3. The rows behave less obviously. When the container has no fixed height, <code>1fr</code> rows are sized from their content and then equalized, so one 200px-tall item made both rows 200px tall. With <code>repeat(2, auto)</code> the same items gave rows of 20px and 200px. Use <code>auto</code> rows unless you want every row to match the tallest one.</p>

<h2>Example: Sidebar and Main Area</h2>
<p>Set Columns to 2 and Rows to 3, type <code>240px 1fr</code> into grid-template-columns and <code>auto 1fr auto</code> into grid-template-rows, then set the column gap to <code>24px</code> and the row gap to <code>0</code>:</p>

{/* cgg-check: {"cols":2,"rows":3,"colGap":"24px","rowGap":"0","tmplCols":"240px 1fr","tmplRows":"auto 1fr auto"} */}

```css
.container {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr auto;

```

<p>At 960px wide, the main column measured 696px (960 − 240 − 24). The middle row takes whatever height is left once the container has a height, for example <code>min-height: 100vh</code>, which keeps a footer at the bottom of short pages.</p>

<h2>Limits and Common Surprises</h2>
<ul>
  <li><strong>Container only.</strong> There are no controls for <code>grid-column</code>, <code>grid-row</code>, <code>grid-template-areas</code>, named lines or alignment; spanning a header across both columns needs <code>grid-column: 1 / -1</code> on that child.</li>
  <li><strong>Preview cell count.</strong> The preview always draws Columns × Rows cells. If your template has a different number of tracks, the extra cells go into implicit rows, just as real children would.</li>
  <li><strong>Long content stretches 1fr.</strong> A <code>1fr</code> column has a minimum of <code>auto</code>. With an unbroken URL in the middle cell of a 600px <code>repeat(3, 1fr)</code> grid, the columns came out 9.6px, 751px and 9.6px and overflowed the container; <code>repeat(3, minmax(0, 1fr))</code> kept them at 200px each.</li>
  <li><strong>auto-fill vs auto-fit.</strong> With two items in a 1000px container, <code>repeat(auto-fill, minmax(180px, 1fr))</code> kept five 187.2px columns (three empty), while <code>auto-fit</code> collapsed the empty ones and gave each item 492px. A container narrower than 180px overflows; <code>minmax(min(180px, 100%), 1fr)</code> prevents that.</li>
  <li>The template and gap fields are not validated. An invalid value such as <code>repeat(3 1fr)</code> is copied as written, and the preview keeps showing the last valid template because the browser ignores the invalid value.</li>
</ul>
<p>The track sizing rules are in <a href="https://www.w3.org/TR/css-grid-2/">CSS Grid Layout Level 2</a>. For one-dimensional rows of items, the <a href="/tools/css-flexbox-generator/">flexbox generator</a> is often the simpler fit.</p>

<h2>Common Grid Patterns</h2>
<ul>
  <li><strong>Equal columns</strong> — <code>repeat(3, 1fr)</code> creates three equal columns.</li>
  <li><strong>Sidebar layout</strong> — <code>250px 1fr</code> gives a fixed sidebar and a flexible main area.</li>
  <li><strong>Holy grail</strong> — <code>200px 1fr 200px</code> columns with <code>auto 1fr auto</code> rows; the header and footer children span all three columns with <code>grid-column: 1 / -1</code>.</li>
  <li><strong>Responsive tiles</strong> — <code>repeat(auto-fill, minmax(180px, 1fr))</code> auto-wraps at any screen width.</li>
</ul>
