<h2>使い方</h2>
<ol>
  <li>左側のテキストエリアにHTMLを貼り付けます。</li>
  <li>入力と同時に右側のテキストエリアにJSX出力が即座に表示されます。</li>
  <li><strong>コピー</strong>をクリックしてJSX出力をクリップボードにコピーします。</li>
</ol>

<h2>変換ルール</h2>

| HTML | JSX |
|------|-----|
| `class="..."` | `className="..."` |
| `for="..."` | `htmlFor="..."` |
| `style="color:red"` | `style={{ color: 'red' }}` |
| `onclick="save()"` | `onClick={(event) => { save() }}` |
| `ondblclick="..."` / `onmouseover="..."` | `onDoubleClick={...}` / `onMouseOver={...}` |
| `tabindex` | `tabIndex` |
| `readonly` | `readOnly` |
| `maxlength` | `maxLength` |
| `colspan` | `colSpan` |
| `rowspan` | `rowSpan` |
| `crossorigin` | `crossOrigin` |
| `contenteditable` | `contentEditable` |
| `<br>` | `<br />` |
| `<img src="...">` | `<img src="..." />` |
| `<input ...>` | `<input ... />` |
| `<!-- コメント -->` | `{/* コメント */}` |

<h2>主な用途</h2>
<ul>
  <li>静的HTMLテンプレートをReactコンポーネントに移行する</li>
  <li>デザインツール（Figma、Webflow）からエクスポートしたHTMLスニペットをJSXファイルに貼り付ける</li>
  <li>HTMLとJSXの属性名の違いを学習する</li>
  <li>HTMLメールテンプレートをReactメールライブラリ用に変換する</li>
  <li>サードパーティのHTMLウィジェットをReactプロジェクトに素早く適応させる</li>
</ul>

## 変換例

入力：

```html
<label for="email" class="lbl">Email</label>
<input id="email" type="email" required>
<div style="background-image: url('a.png'); font-size:14px">x</div>
<!-- footer -->
```

出力：

```jsx
<label htmlFor="email" className="lbl">Email</label>
<input id="email" type="email" required />
<div style={{ backgroundImage: 'url(\'a.png\')', fontSize: '14px' }}>x</div>
{/* footer */}
```

`data-*` と `aria-*` 属性はハイフンのまま残ります。React ではこれが正しい書き方です。数値の属性は `colSpan="2"` のように文字列のままですが、React はそのまま受け付けます。

## 手で直す必要があるところ

| 変換結果 | React での問題 | 修正 |
|---|---|---|
| `onClick={(event) => { save(); return false; }}` | コードはアロー関数の中で動く。`this` は要素ではなく、`return false` でも既定の動作は止まらない | `event.currentTarget`、`event.preventDefault()` を使うか、関数を渡す：`onClick={save}` |
| `<input type="checkbox" checked>` | `onChange` のない `checked` は読み取り専用になる | `defaultChecked` |
| `<option selected>` | React では選択状態を `<select>` 側で指定する | `<select defaultValue="...">` |
| `<textarea>hi</textarea>` | [`<textarea>` は子要素を受け付けない](https://ja.react.dev/reference/react-dom/components/textarea) | `<textarea defaultValue="hi" />` |
| `<p>a < b and {name}</p>` | テキスト中の `<` と `{` は JSX の構文 | `a {'<'} b and {'{'}name{'}'}` |
| トップレベルの要素が 2 つ以上 | コンポーネントが返せる要素は 1 つ | `<>...</>` で囲む |
| `<path stroke-width="2">` | SVG の属性は変換されない | [SVG → JSX](/ja/tools/svg-to-jsx/) を使う |

## 制限事項

- **属性値はそのまま残ります。** 変わるのは属性名だけなので、`href="/search?for=1&class=2"` は書き換わりません。[htmltojsx](https://github.com/reactjs/react-magic/blob/master/src/htmltojsx.js) も同じ扱いです。値が変わるのは 2 つだけです。`style` はオブジェクトになり、イベントハンドラーのコードは `(event) => { ... }` に入ります。React には文字列ではなく[関数が必要](https://ja.react.dev/learn/responding-to-events)だからです。そのコード中の `&quot;` などの実体参照はデコードします。DOM イベントではない `on*` 属性（カスタム要素の `onfoo` など）はそのまま残ります。
- **変換するのはタグだけ。** タグの間のテキストはそのまま残り、文書全体を貼ると `<!DOCTYPE>`、`<html>`、`<head>`、`<body>` も残ります。コンポーネントに入れる部分だけを貼り付けてください。
- **コンポーネントの外枠は作りません。** 出力はマークアップだけなので、コンポーネントの `return (...)` の中に入れて使います。
