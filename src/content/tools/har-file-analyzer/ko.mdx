<h2>사용 방법</h2>
<ol>
  <li>브라우저 DevTools의 Network 패널에서 세션을 <strong>.har</strong>로 내보냅니다.</li>
  <li>파일을 드롭존에 끌어다 놓거나 클릭하여 선택합니다. 파싱은 브라우저 안에서 진행됩니다.</li>
  <li><strong>개요</strong>(통계) / <strong>워터폴</strong>(타이밍) / <strong>상세</strong>(헤더·쿠키·본문) / <strong>필터 및 내보내기</strong>(부분 다운로드) 사이를 전환합니다.</li>
  <li>워터폴의 임의 행을 클릭하면 해당 요청의 상세 화면으로 바로 이동합니다.</li>
  <li><strong>리셋</strong>으로 메모리에 있는 HAR 데이터를 지웁니다.</li>
</ol>

<h2>워터폴 단계</h2>
<p>워터폴은 HAR 1.2 <code>timings</code>를 6단계로 그립니다:</p>
<ul>
  <li><strong>대기 / Stalled</strong> — <code>blocked</code></li>
  <li><strong>DNS 조회</strong> — <code>dns</code></li>
  <li><strong>초기 연결</strong> — <code>connect</code> (HAR 1.2에서 <code>ssl</code> 포함)</li>
  <li><strong>요청 전송</strong> — <code>send</code></li>
  <li><strong>대기 (TTFB)</strong> — <code>wait</code></li>
  <li><strong>콘텐츠 다운로드</strong> — <code>receive</code></li>
</ul>

<h2>개인정보 보호</h2>
<p>HAR에는 Authorization, Cookie, 응답 본문 등 민감한 정보가 자주 포함됩니다. 호스팅된 분석기에 업로드하는 것은 위험합니다. ZeroTool은 <code>FileReader</code> + <code>JSON.parse</code>로 브라우저 내에서 처리하며 업로드도 리로드를 넘어선 저장도 하지 않습니다.</p>

<h2>예시: cURL로 요청 다시 보내기</h2>
<p>HTTP/2로 <code>{'{"note":"costs $5"}'}</code>를 POST한 Chrome HAR 항목이라면 상세 보기의 cURL 탭은 다음을 만듭니다.</p>

```bash
curl -X "POST" "https://api.example.com/v1/orders" -H ":authority: api.example.com" -H "content-type: application/json" -H "cookie: session=abc123" --data-raw "{\"note\":\"costs $5\"}"
```

<p>실행 전에 명령을 확인하세요. 값이 큰따옴표로 감싸져 있어 POSIX 셸이 <code>$5</code>를 확장하고, 서버는 <code>{'{"note":"costs "}'}</code>를 받습니다(curl 8.7.1, 로컬 서버로 확인). 본문에 <code>$</code>, 백틱, <code>{'\\'}</code>가 있으면 본문 양쪽 따옴표를 작은따옴표로 바꾸세요. <code>:authority</code> 같은 HTTP/2 의사 헤더는 HAR에서 그대로 복사됩니다. curl 8.7.1은 이를 보내지 않으므로 문제는 없지만 지워도 됩니다.</p>

<h2>제한</h2>
<ul>
  <li>50MB를 넘는 파일은 '파일이 너무 큽니다'로 거부됩니다.</li>
  <li><code>log.entries</code> 배열이 있는 JSON이어야 합니다. 다른 JSON은 '이 JSON은 HAR 아카이브가 아닙니다 — log.entries 누락.'으로 표시됩니다.</li>
  <li>쿠키나 토큰을 지우지 않습니다. HAR를 민감한 데이터 포함으로 내보냈다면 상세 보기, 내보낸 .har 하위 집합, '전체 cURL 복사'에 파일의 모든 헤더(<code>Cookie</code>, <code>Authorization</code> 포함)가 들어갑니다. Chrome의 기본 sanitized 내보내기에는 이 세 헤더가 처음부터 빠져 있습니다.</li>
  <li>값이 <code>-1</code>인 타이밍 필드는 해당 요청에 그 단계가 없었다는 뜻이며(재사용한 연결에는 DNS·연결 시간이 없음 등) N/A로 표시됩니다.</li>
</ul>
