<h2>How to Use</h2>
<ol>
  <li>Open your browser DevTools, go to the Network tab, and export the session as a <strong>.har</strong> file.</li>
  <li>Drop the file into the dropzone (or click to choose). Parsing happens locally in your browser.</li>
  <li>Switch between <strong>Overview</strong> for stats, <strong>Waterfall</strong> for timing, <strong>Detail</strong> for headers/cookies/body, and <strong>Filter &amp; Export</strong> to slice and download.</li>
  <li>Click any waterfall row to jump straight into its Detail view.</li>
  <li>Use <strong>Reset</strong> to clear the HAR from memory.</li>
</ol>

<h2>Waterfall Phases</h2>
<p>The waterfall draws six segments per request, mapped from HAR 1.2 <code>timings</code>:</p>
<ul>
  <li><strong>Queued / Stalled</strong> — <code>blocked</code></li>
  <li><strong>DNS Lookup</strong> — <code>dns</code></li>
  <li><strong>Initial Connection</strong> — <code>connect</code> (already includes <code>ssl</code> per HAR 1.2)</li>
  <li><strong>Request Sent</strong> — <code>send</code></li>
  <li><strong>Waiting (TTFB)</strong> — <code>wait</code></li>
  <li><strong>Content Download</strong> — <code>receive</code></li>
</ul>

<h2>Privacy</h2>
<p>HAR files routinely contain Authorization headers, Cookie headers, response bodies, and other sensitive material. Uploading them to a hosted analyzer is risky. ZeroTool runs the parser in your browser using <code>FileReader</code> and <code>JSON.parse</code>; nothing is uploaded and nothing is persisted across reloads.</p>

<h2>Example: Replaying a Request with cURL</h2>
<p>For a Chrome HAR entry that posts <code>{'{"note":"costs $5"}'}</code> over HTTP/2, the Detail view's cURL tab produces:</p>

```bash
curl -X "POST" "https://api.example.com/v1/orders" -H ":authority: api.example.com" -H "content-type: application/json" -H "cookie: session=abc123" --data-raw "{\"note\":\"costs $5\"}"
```

<p>Check the command before running it. The values are wrapped in double quotes, so a POSIX shell expands <code>$5</code> and the server receives <code>{'{"note":"costs "}'}</code> (curl 8.7.1, tested against a local server). Change the quotes around the body to single quotes when it contains <code>$</code>, a backtick or <code>{'\\'}</code>. HTTP/2 pseudo-headers such as <code>:authority</code> are copied from the HAR; curl 8.7.1 does not send them, so they do no harm, but you can delete them.</p>

<h2>Limits</h2>
<ul>
  <li>Files larger than 50 MB are refused with "File too large".</li>
  <li>The file must be JSON with a <code>log.entries</code> array; other JSON produces "This JSON is not a HAR archive — missing log.entries."</li>
  <li>The tool does not remove cookies or tokens. The Detail view, the exported .har subset and "Copy all as cURL" contain every header in the file, including <code>Cookie</code> and <code>Authorization</code> if the HAR was exported with sensitive data. Chrome's default sanitized export already leaves those three headers out.</li>
  <li>Timing fields set to <code>-1</code> mean the phase did not happen for that request (for example, a reused connection has no DNS or connect time) and are shown as N/A.</li>
</ul>
