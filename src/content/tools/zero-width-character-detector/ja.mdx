<h2>ゼロ幅文字検出器の概要</h2>
<p>
  テキストには、目に見えない Unicode 文字がしばしば隠されています。ゼロ幅文字、バイトオーダーマーク、双方向制御文字、隠しテキストを運ぶタグ文字などです。これらの不可視文字はコピー&ペースト、リッチテキストエディタ、Web ページや AI チャットの内容、サプライチェーン攻撃から発生し、追跡が困難なバグ、監査リスク、データ漏洩の危険を引き起こすことができます。
</p>
<p>
  このツールは、貼り付けたテキスト内のすべての不可視文字をリアルタイムでスキャンしハイライト表示し、タイプごとに統計を取ります。必要に応じて選択的に削除することができます。すべてを削除するか、特定のタイプ（ゼロ幅文字、双方向制御文字、タグ文字など）だけを削除できます。ワンクリックでクリーンテキストをコピーまたはダウンロードできます。
</p>

<h2>検出対象</h2>
<p>このツールは以下の不可視 Unicode 文字カテゴリをカバーしています：</p>
<ul>
  <li><strong>ゼロ幅文字</strong>（Zero-Width）：ZWSP（U+200B）、ZWNJ（U+200C）、ZWJ（U+200D）、Word Joiner（U+2060）</li>
  <li><strong>バイトオーダーマーク</strong>（BOM）：U+FEFF、クロスプラットフォームファイル転送で頻繁に発生</li>
  <li><strong>双方向制御文字</strong>（Bidi Control）：LRE、RLE、PDF、LRO、RLO（U+202A-202E）、暗黙的方向マーク（U+200E、U+200F）、隔離符（U+2066-2069）、Trojan-Source 攻撃の一般的なベクトルを含む</li>
  <li><strong>軟ハイフン</strong>（Soft Hyphen）：U+00AD、自動改行位置に挿入されますが実際には表示されません</li>
  <li><strong>フォント変体セレクタ</strong>（Variation Selectors）：U+FE00-FE0F、U+E0100-E01EF、文字形を調整しますが文字として表示されません</li>
  <li><strong>タグ文字</strong>（Tag Characters）：U+E0000-E007F、元は言語タグ用で、現在は絵文字の地域旗に使われます。ASCII と 1 対 1 に対応するため、テキストを隠す用途（ASCII smuggling）にも使えます</li>
</ul>

<h2>使い方</h2>
<ol>
  <li>「コンテンツを貼り付け」ボックスにテキストを貼り付けます。</li>
  <li>ツールはリアルタイムでスキャンし、すべての不可視文字を色でハイライト表示します。下部にはタイプ別の数量統計が表示されます。</li>
  <li>削除モードを選択します：<ul><li><strong>すべて削除</strong> — すべての不可視文字を削除</li><li><strong>ゼロ幅文字のみ削除</strong> — ZWSP、ZWNJ、ZWJ、Word Joiner のみ削除</li><li><strong>双方向制御文字のみ削除</strong> — 双方向制御文字のみ削除</li><li><strong>タグ文字のみ削除</strong> — タグ文字のみ削除</li><li><strong>フォント変体セレクタのみ削除</strong> — フォント変体セレクタのみ削除</li></ul></li>
  <li>「クリーンテキストをコピー」または「.txt をダウンロード」をクリックして結果を取得します。</li>
</ol>

<h2>主なシナリオ</h2>
<ul>
  <li><strong>LLM に渡す前のチェック</strong> — タグ文字で書かれた指示は人には見えませんが、言語モデルは読み取れます。Web ページ、文書、チャット出力をアシスタントに渡したり公開したりする前にここで確認し、不要なタグ文字を削除できます。</li>
  <li><strong>サプライチェーン・コードレビュー</strong> — サードパーティコードまたは依存関係を受け取る前に Trojan-Source 攻撃をスキャンします。特に双方向制御文字で偽装されたロジック反転に注意してください。</li>
  <li><strong>フィッシングメール検査</strong> — メール、インスタントメッセージから複製されたテキストにはトラッキングピクセル、形式制御文字、または悪意のある双方向文字が含まれる可能性があります。削除後はより安全です。</li>
  <li><strong>コピー&ペーストのクリーンアップ</strong> — Word、Google Docs、オンライン記事からプレーンテキストエディタに貼り付けるときは、隠れた形式マークが残ることが多くあります。このツールでワンクリック清掃できます。</li>
  <li><strong>テキスト漏洩調査</strong> — タグ文字またはその他の不可視マークを使用して、機密文書を隠蔽的に追跡します。このツールは隠された メタデータラベルを識別するのに役立ちます。</li>
</ul>

<h2>クライアントサイド処理が必要な理由</h2>
<p>
  隠れ文字を含むテキストをサーバーに送信して検出する場合、複数のリスクが存在します：
</p>
<ul>
  <li><strong>プライバシー漏洩</strong> — コード スニペット、メール内容、AI 出力がサーバーログまたは分析システムによってキャプチャされ、組織の機密性要件に違反する可能性があります。</li>
  <li><strong>Trojan-Source サンプル外部送信不要</strong> — 受け取った疑わしいコードはローカル環境を出るべきではなく、ローカル分析によってウイルスや悪意のあるサンプルの伝播リスクが回避されます。</li>
  <li><strong>完全なオフライン使用可能</strong> — このツールは純粋なブラウザ JavaScript で実行され、ネットワーク接続またはアカウントログインは不要です。ネットワークなしの状態でも機能します。</li>
</ul>
