<h2>How to use the color palette generator</h2>
<ol>
  <li>Type or paste a base color in the input: <code>#3B82F6</code>, <code>3b82f6</code>, <code>rgb(59 130 246)</code>, <code>hsl(217 91% 60%)</code>, <code>oklch(62% 0.19 260)</code> or a name such as <code>tomato</code>. You can also use the color picker or <strong>Random</strong>.</li>
  <li>Choose the color wheel: <strong>HSL</strong> (classic) or <strong>OKLCH</strong> (equal perceived lightness).</li>
  <li>Read the seven cards: complementary, split complementary, analogous, triadic, tetradic (rectangle), square and monochromatic. The swatch labeled <strong>Base</strong> is your input, unchanged.</li>
  <li>Click a swatch to copy its value in the selected <strong>Color format</strong>. Click <strong>Copy</strong> on a card to copy the scheme in the selected <strong>Code</strong> format, or open <strong>All schemes as code</strong> to copy every scheme.</li>
</ol>

<h2>What each scheme means</h2>
<p>Every scheme except monochromatic keeps the saturation and lightness (or OKLCH lightness and chroma) of the base and only turns the hue. Tetradic is the rectangle (two complementary pairs); square is a separate card. HSL results for <code>#3B82F6</code>, the <code>blue-500</code> of the <a href="https://v3.tailwindcss.com/docs/customizing-colors" rel="noopener">Tailwind CSS v3 palette</a>:</p>

<p>Monochromatic uses five fixed lightness steps; the step closest to the base (67.5% here, because the base is at 59.8%) is replaced by the base itself, so the base always appears exactly once. The HSL math follows <a href="https://www.w3.org/TR/css-color-4/#hsl-to-rgb" rel="noopener">CSS Color 4 §7</a>; channels that land exactly on .5 round up, as CSS specifies. For an 11-step scale (50–950) of one color, use the <a href="/tools/color-shades-generator/">Color Shades Generator</a>.</p>

<h2>HSL wheel or OKLCH wheel</h2>
<p>HSL hue is cheap to compute but not perceptually even: turning the same blue by 180° gives <code>#F6AF3B</code>, which is much lighter than the base. On white it reaches only 1.89:1, while the base reaches 3.68:1. The OKLCH wheel turns the hue in <a href="https://bottosson.github.io/posts/oklab/" rel="noopener">Oklab's polar form</a> and keeps lightness and chroma, so the complement becomes <code>#B57A00</code> at almost the same lightness (OKLCH L 62.5% against 62.3%).</p>

{/* palette: {"base":"#3B82F6","space":"oklch","scheme":"complementary","expect":["#3B82F6","#B57A00"],"mapped":1} */}
{/* palette: {"base":"#3B82F6","space":"oklch","scheme":"triadic","expect":["#3B82F6","#E24956","#3BA01B"],"mapped":0} */}
<p>Equal lightness is useful for tags, chart series and buttons that share one text color: the OKLCH triad <code>#3B82F6</code>, <code>#E24956</code>, <code>#3BA01B</code> gives 3.68, 3.95 and 3.37:1 against white, while the HSL triad gives 3.68, 3.58 and 1.38:1. The same property has a cost: <code>#E24956</code> and <code>#3BA01B</code> are only 1.17:1 apart, so a red/green pair that differs in hue alone is hard to tell apart for people with red-green color vision deficiency. Check such pairs with the <a href="/tools/color-blindness-simulator/">Color Blindness Simulator</a> and do not use color as the only signal (<a href="https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html" rel="noopener">WCAG 1.4.1</a>).</p>
<p>A turned OKLCH color can fall outside sRGB. The tool then runs the <a href="https://www.w3.org/TR/css-color-4/#binsearch" rel="noopener">CSS Color 4 gamut mapping</a> (binary search on chroma with local MINDE, JND 0.02), marks the swatch with ◆ and tells you how many colors were mapped. For <code>#3B82F6</code>, 11 of the 24 OKLCH swatches are mapped. The swatch labels use WCAG 2.2 relative luminance to pick black or near-white text, whichever has more contrast.</p>

<h2>Copy as CSS, SCSS, Tailwind or JSON</h2>
<p>Variable names are the scheme name plus a position, such as <code>--complementary-2</code>. With OKLCH values and Tailwind v4 selected, the complementary card copies:</p>

```css
@theme {
  --color-complementary-1: oklch(62.31% 0.188 259.81);
  --color-complementary-2: oklch(62.47% 0.1317 75.15);
}
```

<p>Paste that block after <code>@import "tailwindcss";</code> and Tailwind v4 creates utilities such as <code>bg-complementary-2</code>; the <code>--color-*</code> namespace is how <a href="https://tailwindcss.com/docs/colors" rel="noopener">Tailwind adds custom colors</a>. The other formats are a value list, CSS variables in <code>:root</code>, SCSS <code>$variables</code>, a Tailwind v3 config and JSON. HSL and OKLCH values keep enough decimals to convert back to the same hex, because integer HSL loses colors: <code>hsl(217, 100%, 61%)</code> is #3884FF, not #3A86FF.</p>

<h2>How it differs from Adobe Color and Coolors</h2>
<p>Tested on 2026-10-01 with base <code>#3B82F6</code>:</p>
<ul>
  <li><strong>Adobe Color</strong> uses a different wheel. Its Triad rule put #C5F53B and #F5533B next to the base, and its Complementary rule put #F5B83B there (each with two muted variants added). On the HSL wheel the triad is #F63B82 and #82F63B. Neither result is wrong; they come from different wheels, and this tool states which one it uses.</li>
  <li><strong>Coolors</strong> exports CSS variables without a selector (lines such as <code>--azure-blue: #3a86ffff;</code>), so the block is not valid on its own in a .css file, and its HSL export rounds to integers (<code>hsla(217, 100%, 61%, 1)</code> for #3A86FF converts back to #3884FF). Its Tailwind export builds a 50–950 scale whose 500 step is #0062ff, not the palette color. This tool wraps CSS in <code>:root</code>, keeps decimals and exports the exact palette colors; the test suite parses each format with css-tree, Dart Sass, Tailwind v4 and JSON.parse.</li>
</ul>
<p>Both can lock colors while shuffling the rest, start from an image and save palettes to an account; this tool does none of that. To pull colors from a photo, use the <a href="/tools/image-color-palette/">Image Color Palette Extractor</a>.</p>

<h2>Limitations</h2>
<ul>
  <li>Output is sRGB only. Colors are not mapped to Display P3, and input in <code>lab()</code>, <code>lch()</code>, <code>oklab()</code>, <code>hwb()</code> or <code>color()</code> is rejected.</li>
  <li>Alpha is dropped; palettes are opaque.</li>
  <li>Harmony rules give hue relationships, not a finished design. Check text contrast with the <a href="/tools/color-contrast-checker/">Color Contrast Checker</a> before you ship.</li>
  <li>The wheel is HSL or OKLCH, not the painter's red-yellow-blue wheel, so results differ from tools that use an RYB-style wheel.</li>
</ul>
