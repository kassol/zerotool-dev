<h2>배색 7가지의 정의</h2>
<p>단색 배색을 뺀 나머지는 기준 색의 채도와 명도(OKLCH에서는 명도와 채도)를 그대로 두고 색상만 돌립니다. 직사각형 배색은 보색 두 쌍이고 정사각형 배색은 따로 둡니다. 아래는 카카오 로그인 버튼의 컨테이너 색 <code>#FEE500</code>을 기준으로 한 HSL 결과입니다.</p>

{/* palette: {"base":"#FEE500","space":"hsl","scheme":"complementary","expect":["#FEE500","#0019FE"]} */}
{/* palette: {"base":"fee500","space":"hsl","scheme":"triadic","expect":["#FEE500","#00FEE5","#E500FE"]} */}
{/* palette: {"base":"#FEE500","space":"hsl","scheme":"monochromatic","expect":["#4D4500","#A69500","#FEE500","#FFEF59","#FFF7B3"]} */}
<table>
  <thead><tr><th>배색</th><th>색상 차이</th><th>#FEE500 결과(HSL)</th></tr></thead>
  <tbody>
    <tr><td>보색</td><td>0°, 180°</td><td>#FEE500, #0019FE</td></tr>
    <tr><td>분할 보색</td><td>0°, 150°, 210°</td><td>#FEE500, #0098FE, #6600FE</td></tr>
    <tr><td>유사색</td><td>−30°, 0°, +30°</td><td>#FE6600, #FEE500, #98FE00</td></tr>
    <tr><td>삼각 배색</td><td>0°, 120°, 240°</td><td>#FEE500, #00FEE5, #E500FE</td></tr>
    <tr><td>직사각형 배색</td><td>0°, 60°, 180°, 240°</td><td>#FEE500, #19FE00, #0019FE, #E500FE</td></tr>
    <tr><td>정사각형 배색</td><td>0°, 90°, 180°, 270°</td><td>#FEE500, #00FE66, #0019FE, #FE0098</td></tr>
    <tr><td>단색 배색</td><td>색상은 같고 명도 15 / 32.5 / 50 / 67.5 / 85%</td><td>#4D4500, #A69500, #FEE500, #FFEF59, #FFF7B3</td></tr>
  </tbody>
</table>
<p>단색 배색은 명도를 다섯 단계로 고정하고, 기준 색과 가장 가까운 단계(여기서는 기준 명도 49.8%에 가까운 50%)를 기준 색으로 바꿉니다. 그래서 기준 색은 늘 한 번만 나옵니다. HSL 계산은 <a href="https://www.w3.org/TR/css-color-4/#hsl-to-rgb" rel="noopener">CSS Color 4 7장</a>을 따르며, 채널 값이 정확히 .5이면 CSS와 같이 올림합니다. 한 색의 밝기 단계 11개(50–950)가 필요하면 <a href="/ko/tools/color-shades-generator/">색상 쉐이드 생성기</a>를 쓰세요.</p>

<h2>카카오 로그인 버튼 색과 함께 쓸 때</h2>
<p><a href="https://developers.kakao.com/docs/latest/ko/kakaologin/design-guide" rel="noopener">카카오 로그인 디자인 가이드</a>는 컨테이너 #FEE500, 심볼 #000000, 레이블 #000000 85%로 색을 정하고 이 규정을 벗어난 색을 쓰지 말라고 합니다. 버튼 색은 바꿀 수 없으니, 배색 도구는 버튼 주변의 강조색과 배경색을 고를 때 씁니다.</p>
<p>노란색은 명도가 높아서 색상환에 따라 결과가 크게 갈립니다. HSL 보색 <code>#0019FE</code>는 매우 어두운 파랑이라 흰 글자가 8.17:1, #FEE500 위에서도 6.39:1로 링크나 강조색으로 쓸 수 있습니다. OKLCH 보색은 기준과 같은 밝기(OKLCH L 약 91%)를 유지하므로 <code>#DBDEFF</code> 같은 옅은 라벤더가 되고, 검은 글자 15.90:1로 넓은 배경에 알맞습니다. 색 위의 글자색은 WCAG 2.2 상대 휘도로 검정과 흰색에 가까운 색 중 대비가 큰 쪽을 고르며, #FEE500 위에서는 검정(16.42:1)이 선택됩니다.</p>

{/* palette: {"base":"#FEE500","space":"oklch","scheme":"complementary","expect":["#FEE500","#DBDEFF"],"mapped":1} */}
{/* palette: {"base":"#FEE500","space":"oklch","scheme":"splitComplementary","expect":["#FEE500","#C4E6FF","#F5D3FF"],"mapped":2} */}
<p>OKLCH 색상환에서 돌린 색은 sRGB 밖으로 나가는 일이 많습니다. 이때 <a href="https://www.w3.org/TR/css-color-4/#binsearch" rel="noopener">CSS Color 4 색역 매핑</a>으로 채도를 낮추고 ◆ 표시와 함께 몇 색을 조정했는지 상태 줄에 알려 줍니다. #FEE500은 노란색 밖의 색상을 같은 높은 명도로 내기 어려워 24색 중 16색이 조정 대상이었습니다. 위 두 결과도 모두 조정된 색입니다.</p>

<h2>코드로 내보내기</h2>
<p>‘코드’에서 고른 형식이 카드의 ‘복사’와 페이지 아래 패널에 쓰입니다. 값 목록, <code>:root</code> 안의 CSS 변수, SCSS 변수, Tailwind v4 <code>@theme</code>, Tailwind v3 설정 파일, JSON 중에서 고릅니다. 보색을 HEX와 CSS 변수로 복사하면 다음과 같습니다.</p>

```css
:root {
  --complementary-1: #FEE500;
  --complementary-2: #0019FE;
}
```

<p>HSL과 OKLCH 값은 HEX로 되돌렸을 때 같은 색이 되도록 필요한 만큼 소수 자리를 남깁니다. 테스트는 각 형식을 css-tree, Dart Sass, Tailwind v4, JSON.parse로 실제 해석해 확인합니다.</p>

<h2>다른 배색 도구와의 차이</h2>
<p>2026-10-01, Bing에서 ‘컬러 팔레트 생성기’와 ‘색 조합’ 검색 결과에 나오는 teck-tani.com의 컬러 팔레트 생성기로 같은 입력을 시험했습니다. <code>#FEE500</code>을 넣고 보색을 고르자 팔레트의 첫 색이 #FFE600으로 나왔고, <code>#3B82F6</code>은 #3C83F6이 되었습니다. 카카오 가이드처럼 색이 정해진 경우에는 기준 색이 바뀌면 그대로 쓸 수 없습니다. <code>rgb(254, 229, 0)</code>을 넣으면 이전 팔레트가 그대로 남았고 메시지는 없었으며, <code>#808080</code>을 넣으면 같은 회색이 두 번씩 나왔지만 이유는 표시되지 않았습니다. 이 도구는 기준 색을 입력값 그대로 두고, 읽은 결과와 오류 이유를 상태 줄에 보여 줍니다.</p>
<p>Adobe Color는 다른 색상환을 씁니다. 같은 #3B82F6의 삼각 배색이 Adobe Color에서는 #C5F53B와 #F5533B, HSL 색상환에서는 #F63B82와 #82F63B입니다. 어느 쪽이 틀린 것은 아니며, 이 도구는 어떤 색상환인지 밝혀 둡니다. 색 고정 후 나머지 섞기, 이미지에서 색 뽑기, 계정에 팔레트 저장은 이 도구에 없습니다. 이미지에서 색을 뽑으려면 <a href="/ko/tools/image-color-palette/">이미지 컬러 팔레트 추출기</a>를 쓰세요.</p>
