<h2>使い方</h2>
<ol>
  <li>入力欄にベースカラーを入力するか貼り付けます。<code>#F08300</code>、<code>f08300</code>、<code>rgb(240 131 0)</code>、<code>hsl(33 100% 47%)</code>、<code>oklch(72% 0.17 58)</code>、<code>orange</code> のような色名に対応します。カラーピッカーや「ランダム」も使えます。</li>
  <li>色相環を選びます。<strong>HSL</strong> は一般的な色相環、<strong>OKLCH</strong> は見た目の明るさをそろえる色相環です。</li>
  <li>補色・分割補色・類似色・トライアド・テトラード（長方形）・スクエア・モノクロマティックの 7 枚のカードが表示されます。「ベース」と書かれた色が入力した色で、値は変わりません。</li>
  <li>色をクリックすると「カラー形式」で選んだ値を 1 つコピーします。カードの「コピー」は「コード」で選んだ形式で配色全体を、ページ下部の「すべての配色をコードで」は 7 つの配色をまとめてコピーします。</li>
</ol>

<h2>IME の全角入力もそのまま使える</h2>
<p>日本語入力をオンにしたまま <code>＃Ｆ０８３００</code> と打っても、Unicode の互換正規化（NFKC）で半角に直して #F08300 として読みます。色名や関数以外の文字はエラーになり、何が問題かを表示します。</p>

<h2>7 つの配色の決め方</h2>
<p>モノクロマティック以外は、ベースの彩度と明度（OKLCH では明度と彩度）を保ったまま色相だけを回します。テトラードは補色のペア 2 組でできる長方形、スクエアは 90° ずつの正方形で、別のカードにしています。ベースを <code>#F08300</code> にしたときの HSL の結果です。</p>

{/* palette: {"base":"＃Ｆ０８３００","space":"hsl","scheme":"triadic","expect":["#F08300","#00F083","#8300F0"]} */}
{/* palette: {"base":"#F08300","space":"hsl","scheme":"complementary","expect":["#F08300","#006DF0"]} */}
{/* palette: {"base":"#F08300","space":"hsl","scheme":"monochromatic","expect":["#4D2A00","#A65A00","#F08300","#FFB459","#FFDCB3"]} */}

  <thead><tr><th>配色</th><th>色相の差</th><th>#F08300 の結果（HSL）</th></tr></thead>
  <tbody>
    <tr><td>補色</td><td>0°・180°</td><td>#F08300、#006DF0</td></tr>
    <tr><td>分割補色</td><td>0°・150°・210°</td><td>#F08300、#00E5F0、#0B00F0</td></tr>
    <tr><td>類似色</td><td>−30°・0°・+30°</td><td>#F00B00、#F08300、#E5F000</td></tr>

    <tr><td>モノクロマティック</td><td>色相は同じ、明度 15 / 32.5 / 50 / 67.5 / 85%</td><td>#4D2A00、#A65A00、#F08300、#FFB459、#FFDCB3</td></tr>

<p>モノクロマティックは明度を 5 段階に固定し、ベースに最も近い段（ここではベースの明度 47.1% に近い 50%）をベース自身に置き換えます。そのためベースは必ず 1 回だけ現れます。HSL の計算は <a href="https://www.w3.org/TR/css-color-4/#hsl-to-rgb" rel="noopener">CSS Color 4 の 7 章</a>に従い、ちょうど .5 になるチャンネルは CSS と同じく切り上げます。1 色の濃淡を 10 段階でほしいときは<a href="/ja/tools/color-shades-generator/">カラーシェード生成器</a>を使ってください。</p>

<h2>HSL と OKLCH の違いと、色覚への配慮</h2>
<p>HSL の色相は計算が簡単な反面、見た目の明るさがそろいません。<code>#F08300</code> のトライアドは #00F083 がかなり明るく、#8300F0 は暗くなります。OKLCH の色相環は <a href="https://bottosson.github.io/posts/oklab/" rel="noopener">Oklab</a> の極座標で色相を回し、明度と彩度を保つので、トライアドは <code>#F08300</code>、<code>#00C1A4</code>、<code>#B288FF</code> になり、3 色の明度（OKLCH L）は 71.6〜72.5% にそろいます。</p>

{/* palette: {"base":"#F08300","space":"oklch","scheme":"triadic","expect":["#F08300","#00C1A4","#B288FF"],"mapped":2} */}
<p>明るさがそろうと、同じ文字色を全部の色に載せやすくなります。一方で、色の区別は色相の差だけに頼ることになります。上の OKLCH トライアドは、どの 2 色を比べてもコントラスト比が 1.01〜1.17:1 しかありません。HSL トライアドでは #F08300 と #00F083 が 1.73:1、#00F083 と #8300F0 が 4.28:1 です。</p>
<p>カラーユニバーサルデザイン機構（CUDO）の<a href="https://cudo.jp/?page_id=1565" rel="noopener">推奨配色セット ガイドブック</a>は「できるだけ明度差をつけた配色にしましょう」と書き、赤と緑を使う場合は赤を黄みに、緑を青みに寄せると見分けやすいとしています。グラフの系列や地図の塗り分けのように色で意味を分ける場面では、OKLCH の配色をそのまま使わず、モノクロマティックで明度差をつけるか推奨配色セットを使い、<a href="/ja/tools/color-blindness-simulator/">色覚シミュレーター</a>で確認してください。</p>
<p>OKLCH で回した色は sRGB の外に出ることがあります。そのときは <a href="https://www.w3.org/TR/css-color-4/#binsearch" rel="noopener">CSS Color 4 の色域マッピング</a>で彩度を下げ、◆ 印を付け、何色を調整したかをステータス欄に出します。#F08300 では 24 色中 14 色が対象でした。色の上の文字は WCAG 2.2 の相対輝度で、黒と白に近い色のうちコントラストの高いほうを選んでいます。</p>

<h2>コードとして書き出す</h2>
<p>「コード」で選んだ形式が、カードの「コピー」とページ下部のパネルに使われます。値の一覧、<code>:root</code> 内の CSS 変数、SCSS 変数、Tailwind v4 の <code>@theme</code>、Tailwind v3 の設定ファイル、JSON から選べます。変数名は配色名と番号です。補色を HEX・SCSS でコピーすると次のようになります。</p>

```scss
$complementary-1: #F08300;
$complementary-2: #006DF0;
```

<p>テストでは Dart Sass と Tailwind v4 で実際にコンパイルし、出力がそのまま使えることを確認しています。HSL と OKLCH の値は HEX に戻したときに同じ色になるだけの小数を残します。</p>

<h2>ほかの配色ツールとの違い</h2>
<p>2026-10-01 に「カラーパレット 作成」の検索結果に出る colortool.blog のカラーパレット ジェネレーターで試しました。ベースに <code>3B82F6</code> を入れて補色を生成すると、1 色目が #3C83F6 になり、入力した色がパレットに残りませんでした。入力は 6 桁の HEX だけで、<code>rgb(59, 130, 246)</code> を貼ると入力欄が「B59」に書き換わり「基準色は6桁のHEXで入力してください」と表示されました。このツールはベースを入力どおりに残し、3 桁の HEX、rgb()、hsl()、oklch()、色名も読み取ります。</p>
<p>Adobe Color は別の色相環を使います。同じ #3B82F6 のトライアドは Adobe Color では #C5F53B と #F5533B、HSL の色相環では #F63B82 と #82F63B です。どちらが正しいということではなく、このツールはどの色相環かを明示しています。色のロックとシャッフル、画像からの抽出、アカウントへの保存はこのツールにはありません。画像から色を取るときは<a href="/ja/tools/image-color-palette/">画像カラーパレット抽出</a>を使ってください。</p>

<h2>制限</h2>
<ul>
  <li>出力は sRGB だけで、Display P3 には対応しません。<code>lab()</code>・<code>lch()</code>・<code>oklab()</code>・<code>hwb()</code>・<code>color()</code> の入力はエラーになります。</li>
  <li>透明度は無視し、不透明色だけで配色を作ります。</li>
  <li>色相環のルールは色相の関係を出すだけで、デザインの完成形ではありません。文字のコントラストは<a href="/ja/tools/color-contrast-checker/">カラーコントラストチェッカー</a>で確認してください。</li>
  <li>色相環は HSL か OKLCH で、絵の具の赤・黄・青の色相環ではありません。</li>
</ul>
