<h2>JSONPath 구문 참조 (RFC 9535)</h2>
<ul>
  <li><code>{"$"}</code> — 문서 루트</li>
  <li><code>{".key"}</code>, <code>{"['key']"}</code>, <code>{"[\"key\"]"}</code> — 객체 멤버</li>
  <li><code>{"[n]"}</code>, <code>{"[-1]"}</code> — 배열 요소. 음수 인덱스는 끝에서부터 셈</li>
  <li><code>{"[start:end:step]"}</code> — 슬라이스. 예: <code>{"[0:2]"}</code>, <code>{"[1:]"}</code>, <code>{"[::-1]"}</code></li>
  <li><code>{"[0,2]"}</code>, <code>{"['title','price']"}</code> — 대괄호 하나에 여러 선택자. 결과는 선택자 순서</li>
  <li><code>{"[*]"}</code>, <code>{".*"}</code> — 배열의 모든 요소 또는 객체의 모든 멤버 값</li>
  <li><code>{"..key"}</code>, <code>{"..[0]"}</code>, <code>{"..*"}</code> — 깊이에 관계없는 자손</li>
  <li><code>{"[?@.price < 10]"}</code> — 필터. <code>{"[?(@.price < 10)]"}</code>으로도 씀</li>
  <li><code>{"[?@.isbn]"}</code>, <code>{"[?!@.isbn]"}</code> — 멤버가 있음 / 없음</li>
  <li><code>{"[?@.a.b == 'x' && @.c > $.min]"}</code> — 필터 안의 중첩 경로, <code>{"&&"}</code> <code>{"||"}</code> <code>{"!"}</code>, $로 시작하는 절대 경로</li>
  <li><code>{"length()"}</code>, <code>{"count()"}</code>, <code>{"match()"}</code>, <code>{"search()"}</code>, <code>{"value()"}</code> — RFC 9535가 정의한 5개 함수</li>
</ul>

## 예시: 똑같아 보이는 한글 이름

HFS+(Mac OS 확장) 볼륨은 파일 이름을 분해형 유니코드(NFD에 가까운 형태)로 저장합니다(<a href="https://developer.apple.com/library/archive/qa/qa1173/_index.html" target="_blank" rel="noopener">Apple Technical Q&A QA1173</a>). 이렇게 저장된 이름을 그대로 JSON으로 내보내면 '보'가 초성 ㅂ(U+1107)과 중성 ㅗ(U+1169) 두 글자로 들어갑니다. 아래 예시는 그 상태를 이스케이프로 적은 파일 목록입니다. 첫 번째 이름도 화면에서는 '보고서.pdf'로 보입니다.

{/* jpt-check: {"q": "$.files[?@.name == '보고서.pdf'].size", "json": "block"} */}
```json
{"files": [
  {"name": "\u1107\u1169\u1100\u1169\u1109\u1165.pdf", "size": 120400},
  {"name": "보고서.pdf", "size": 98000}
]}
```

키보드로 입력한 <code>{"$.files[?@.name == '보고서.pdf'].size"}</code>는 완성형 이름만 찾아 <code>{"[98000]"}</code>을 돌려줍니다. RFC 9535 §2.3.1.2에 따라 문자열은 유니코드 스칼라 값을 하나씩 비교하고 정규화하지 않기 때문입니다.

{/* jpt-check: {"q": "$.files[?length(@.name) == 10].size", "json": "{\"files\": [{\"name\": \"보고서.pdf\", \"size\": 120400}, {\"name\": \"보고서.pdf\", \"size\": 98000}]}"} */}
두 이름을 구별하려면 길이를 보면 됩니다. <code>{"length()"}</code>는 코드 포인트 수를 세므로 완성형 '보고서.pdf'는 7, 분해형은 10이고, <code>{"$.files[?length(@.name) == 10].size"}</code>는 <code>{"[120400]"}</code>을 돌려줍니다. 두 형태를 함께 찾으려면 JSON을 붙여 넣기 전에 NFC로 정규화해 두세요(JavaScript의 <code>{"normalize('NFC')"}</code> 등).

## 숫자처럼 보이는 키의 순서

<code>{"$.순위.*"}</code> 같은 와일드카드 조회는 JavaScript가 객체 멤버를 보관하는 순서대로 값을 돌려줍니다. '1', '10'처럼 배열 인덱스로 읽히는 이름이 먼저 숫자 오름차순으로 오고, 나머지 이름은 JSON에 적힌 순서를 따릅니다.

{/* jpt-check: {"q": "$.순위.*", "json": "block"} */}
```json
{"순위": {"10": "로또", "2": "환율", "1": "날씨"}}
```

JSON에는 "10", "2", "1" 순서로 적었지만 결과는 <code>{'["날씨","환율","로또"]'}</code>입니다. 결과 창에 표시되는 객체도 같은 순서로 다시 정렬됩니다. RFC 9535 §2.3.2.2는 객체 멤버의 순서를 정하지 않으므로 다른 구현에서는 달라질 수 있습니다. 순서가 중요하면 배열로 바꿔 두세요.

<h2>제한 사항</h2>
<ul>
  <li>RFC 9535에 없는 구문은 "지원하지 않는 구문"과 문자 위치를 표시합니다: 스크립트 표현식 <code>{"[(...)]"}</code>, <code>{"=~"}</code>, <code>{"in"}</code> / <code>{"nin"}</code>, 다른 라이브러리의 <code>{"~"}</code>(멤버 이름 가져오기) 같은 확장.</li>
  <li><code>{"$.store.book.length"}</code>는 <code>{"length"}</code>라는 이름의 멤버를 선택합니다. 배열에는 그런 멤버가 없으므로 결과가 비어 있습니다. 길이로 거르려면 필터 안에서 <code>{"length()"}</code>를 쓰세요(예: <code>{"$[?length(@.book) > 3]"}</code>).</li>
  <li>결과에는 매칭된 값만 나오고 정규화 경로(<code>{"$['store']['book'][0]"}</code> 등)는 표시하지 않습니다.</li>
  <li>한 객체에 같은 이름이 두 번 있으면 <code>{"JSON.parse"}</code>가 뒤의 값만 남깁니다.</li>
  <li><code>{"match()"}</code>와 <code>{"search()"}</code>는 <code>{"."}</code>을 <code>{"[^\\n\\r]"}</code>로 바꾼 뒤 <code>{"u"}</code> 플래그가 붙은 JavaScript 정규식으로 실행합니다(RFC 9485 §5.3). JavaScript가 거부하는 패턴은 false가 되고, <code>{"\\d"}</code>나 전방 탐색처럼 JavaScript에만 있는 구문도 받아들입니다.</li>
  <li>숫자는 <code>{"JSON.parse"}</code>로 JavaScript 숫자가 됩니다. 2<sup>53</sup>보다 큰 정수, 자릿수가 많은 소수, <code>{"-0"}</code>, 배정밀도 범위를 넘는 수는 비교와 표시 전에 값이 바뀌며 상태 줄에 목록이 나옵니다(예: <code>{"9007199254740993 → 9007199254740992"}</code>).</li>
  <li>JSON 구문 오류 메시지는 브라우저의 JavaScript 파서가 만든 것이라 문구가 브라우저마다 다릅니다.</li>
</ul>

<h2>다른 JSONPath 방언과의 차이</h2>
<p>
  kubectl의 <code>{"-o jsonpath"}</code> 템플릿은 표현식을 중괄호로 감싸고 맨 앞의 <code>{"$"}</code>를 생략할 수 있습니다. 여기에 붙여 넣을 때는 중괄호 안쪽만 가져와 앞에 <code>{"$"}</code>를 붙이세요.
  Java의 Jayway JsonPath는 스크립트 표현식, <code>{"=~"}</code>, 경로 끝의 <code>{".length()"}</code>를 받아들이지만 이 도구는 RFC 9535를 따르므로 위치를 표시하며 오류로 처리합니다.
  JSON의 구조를 바꾸려면 <a href="/ko/tools/jq-playground/">jq Playground</a>를 쓰세요.
</p>
