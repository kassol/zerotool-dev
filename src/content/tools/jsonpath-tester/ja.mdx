<h2>JSONPath 構文リファレンス（RFC 9535）</h2>
<ul>
  <li><code>{"$"}</code> — 文書のルート</li>
  <li><code>{".key"}</code>、<code>{"['key']"}</code>、<code>{"[\"key\"]"}</code> — オブジェクトのメンバー</li>
  <li><code>{"[n]"}</code>、<code>{"[-1]"}</code> — 配列の要素。負のインデックスは末尾から数える</li>
  <li><code>{"[start:end:step]"}</code> — スライス。例：<code>{"[0:2]"}</code>、<code>{"[1:]"}</code>、<code>{"[::-1]"}</code></li>
  <li><code>{"[0,2]"}</code>、<code>{"['title','price']"}</code> — 1 つの角括弧に複数のセレクター。結果はセレクターの順</li>
  <li><code>{"[*]"}</code>、<code>{".*"}</code> — 配列のすべての要素、またはオブジェクトのすべての値</li>
  <li><code>{"..key"}</code>、<code>{"..[0]"}</code>、<code>{"..*"}</code> — 任意の深さの子孫</li>
  <li><code>{"[?@.price < 10]"}</code> — フィルター。<code>{"[?(@.price < 10)]"}</code> とも書ける</li>
  <li><code>{"[?@.isbn]"}</code>、<code>{"[?!@.isbn]"}</code> — メンバーがある / ない</li>
  <li><code>{"[?@.a.b == 'x' && @.c > $.min]"}</code> — フィルター内の入れ子のパス、<code>{"&&"}</code> <code>{"||"}</code> <code>{"!"}</code>、$ で始まる絶対パス</li>
  <li><code>{"length()"}</code>、<code>{"count()"}</code>、<code>{"match()"}</code>、<code>{"search()"}</code>、<code>{"value()"}</code> — RFC 9535 が定める 5 つの関数</li>
</ul>

<h2>制限事項</h2>
<ul>
  <li>RFC 9535 にない構文は「サポートされていない構文」と文字位置を表示します：スクリプト式 <code>{"[(...)]"}</code>、<code>{"=~"}</code>、<code>{"in"}</code> / <code>{"nin"}</code>、他のライブラリの <code>{"~"}</code>（メンバー名の取得）などの拡張。</li>
  <li><code>{"$.store.book.length"}</code> は <code>{"length"}</code> という名前のメンバーを選びます。配列にはそのメンバーがないため結果は空です。長さで絞り込むにはフィルター内で <code>{"length()"}</code> を使います（例：<code>{"$[?length(@.book) > 3]"}</code>）。</li>
  <li>結果はマッチした値の一覧です。正規化パス（<code>{"$['store']['book'][0]"}</code> など）は表示しません。</li>
  <li>オブジェクトのメンバーは JSON テキストに書かれた順で返します。RFC 9535 はこの順序を定めていないため、他の実装では順序が変わることがあります。</li>
  <li><code>{"match()"}</code> と <code>{"search()"}</code> は <code>{"."}</code> を <code>{"[^\\n\\r]"}</code> に置き換えたうえで、<code>{"u"}</code> フラグ付きの JavaScript 正規表現として実行します（RFC 9485 §5.3）。JavaScript が受け付けないパターンは false になり、<code>{"\\d"}</code> や先読みなど JavaScript だけの構文も受け付けます。</li>
  <li>数値は <code>{"JSON.parse"}</code> で JavaScript の数値になるため、2<sup>53</sup> を超える整数は比較の前に精度が落ちます。</li>
</ul>

<h2>主な使用シーン</h2>
<p>
  JSONPathはAPIレスポンスからのデータ抽出、kubectl の <code>{"-o jsonpath"}</code> 出力テンプレート、
  AWS Step Functions の InputPath などで使われます。
  ただしそれぞれ方言があり、kubectl は式を波括弧で囲み、Step Functions の ResultPath ではフィルターを使えません。このツールは RFC 9535 に従って解析します。
  JSONPath クエリを使いこなすことで、ネストされたJSON構造の処理効率が大幅に向上します。
</p>
