<h2>JSONPath 構文リファレンス（RFC 9535）</h2>
<ul>
  <li><code>{"$"}</code> — 文書のルート</li>
  <li><code>{".key"}</code>、<code>{"['key']"}</code>、<code>{"[\"key\"]"}</code> — オブジェクトのメンバー</li>
  <li><code>{"[n]"}</code>、<code>{"[-1]"}</code> — 配列の要素。負のインデックスは末尾から数える</li>
  <li><code>{"[start:end:step]"}</code> — スライス。例：<code>{"[0:2]"}</code>、<code>{"[1:]"}</code>、<code>{"[::-1]"}</code></li>
  <li><code>{"[0,2]"}</code>、<code>{"['title','price']"}</code> — 1 つの角括弧に複数のセレクター。結果はセレクターの順</li>
  <li><code>{"[*]"}</code>、<code>{".*"}</code> — 配列のすべての要素、またはオブジェクトのすべての値</li>
  <li><code>{"..key"}</code>、<code>{"..[0]"}</code>、<code>{"..*"}</code> — 任意の深さの子孫</li>
  <li><code>{"[?@.price < 10]"}</code> — フィルター。<code>{"[?(@.price < 10)]"}</code> とも書ける</li>
  <li><code>{"[?@.isbn]"}</code>、<code>{"[?!@.isbn]"}</code> — メンバーがある / ない</li>
  <li><code>{"[?@.a.b == 'x' && @.c > $.min]"}</code> — フィルター内の入れ子のパス、<code>{"&&"}</code> <code>{"||"}</code> <code>{"!"}</code>、$ で始まる絶対パス</li>
  <li><code>{"length()"}</code>、<code>{"count()"}</code>、<code>{"match()"}</code>、<code>{"search()"}</code>、<code>{"value()"}</code> — RFC 9535 が定める 5 つの関数</li>
</ul>

## 例：気象庁の天気予報 JSON

気象庁の天気予報ページが読み込む JSON（東京都、<code>{"130000.json"}</code>）から、2026 年 10 月 8 日 17 時発表分の地域名と天気だけを抜き出したものです（各地域の名前と天気以外は省略）。最上位が配列なので、式は <code>{"$[0]"}</code> から始まります。

{/* jpt-check: {"q": "$[0].timeSeries[0].areas[*].area.name", "json": "block"} */}
```json
[{"publishingOffice": "気象庁", "reportDatetime": "2026-10-08T17:00:00+09:00", "timeSeries": [{"areas": [
  {"area": {"name": "東京地方", "code": "130010"}, "weathers": ["晴れ", "晴れ", "晴れ　時々　くもり"]},
  {"area": {"name": "伊豆諸島北部", "code": "130020"}, "weathers": ["晴れ　夜遅く　くもり", "晴れ", "晴れ　時々　くもり"]},
  {"area": {"name": "伊豆諸島南部", "code": "130030"}, "weathers": ["くもり　夜のはじめ頃　晴れ　三宅島　では　夜のはじめ頃　まで　雨", "晴れ　昼前　から　時々　くもり", "くもり　時々　晴れ"]},
  {"area": {"name": "小笠原諸島", "code": "130040"}, "weathers": ["くもり　夜のはじめ頃　晴れ", "くもり　時々　晴れ", "くもり"]}
]}]}]
```

<code>{"$[0].timeSeries[0].areas[*].area.name"}</code> は <code>{'["東京地方","伊豆諸島北部","伊豆諸島南部","小笠原諸島"]'}</code> を返します。

{/* jpt-check: {"q": "$..areas[?search(@.weathers[0], '雨')].area.name", "json": "[{\"publishingOffice\": \"気象庁\", \"reportDatetime\": \"2026-10-08T17:00:00+09:00\", \"timeSeries\": [{\"areas\": [{\"area\": {\"name\": \"東京地方\", \"code\": \"130010\"}, \"weathers\": [\"晴れ\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島北部\", \"code\": \"130020\"}, \"weathers\": [\"晴れ　夜遅く　くもり\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島南部\", \"code\": \"130030\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ　三宅島　では　夜のはじめ頃　まで　雨\", \"晴れ　昼前　から　時々　くもり\", \"くもり　時々　晴れ\"]}, {\"area\": {\"name\": \"小笠原諸島\", \"code\": \"130040\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ\", \"くもり　時々　晴れ\", \"くもり\"]}]}]}]"} */}
今日の天気に「雨」を含む地域は <code>{"$..areas[?search(@.weathers[0], '雨')].area.name"}</code> で <code>{'["伊豆諸島南部"]'}</code> です。<code>{"search()"}</code> は部分一致、<code>{"match()"}</code> は文字列全体の一致です。

## 全角スペースと全角記号

上の JSON の天気は「晴れ　時々　くもり」のように語の間が全角スペース（U+3000）です。半角スペースで書いた式は何も選びません。

{/* jpt-check: {"q": "$..areas[?@.weathers[2] == '晴れ 時々 くもり'].area.name", "json": "[{\"publishingOffice\": \"気象庁\", \"reportDatetime\": \"2026-10-08T17:00:00+09:00\", \"timeSeries\": [{\"areas\": [{\"area\": {\"name\": \"東京地方\", \"code\": \"130010\"}, \"weathers\": [\"晴れ\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島北部\", \"code\": \"130020\"}, \"weathers\": [\"晴れ　夜遅く　くもり\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島南部\", \"code\": \"130030\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ　三宅島　では　夜のはじめ頃　まで　雨\", \"晴れ　昼前　から　時々　くもり\", \"くもり　時々　晴れ\"]}, {\"area\": {\"name\": \"小笠原諸島\", \"code\": \"130040\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ\", \"くもり　時々　晴れ\", \"くもり\"]}]}]}]", "show": ["panel"]} */}
- <code>{"$..areas[?@.weathers[2] == '晴れ 時々 くもり'].area.name"}</code>（半角スペース）→ <code>{"マッチなし"}</code>

{/* jpt-check: {"q": "$..areas[?@.weathers[2] == '晴れ　時々　くもり'].area.name", "json": "[{\"publishingOffice\": \"気象庁\", \"reportDatetime\": \"2026-10-08T17:00:00+09:00\", \"timeSeries\": [{\"areas\": [{\"area\": {\"name\": \"東京地方\", \"code\": \"130010\"}, \"weathers\": [\"晴れ\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島北部\", \"code\": \"130020\"}, \"weathers\": [\"晴れ　夜遅く　くもり\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島南部\", \"code\": \"130030\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ　三宅島　では　夜のはじめ頃　まで　雨\", \"晴れ　昼前　から　時々　くもり\", \"くもり　時々　晴れ\"]}, {\"area\": {\"name\": \"小笠原諸島\", \"code\": \"130040\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ\", \"くもり　時々　晴れ\", \"くもり\"]}]}]}]"} */}
- <code>{"$..areas[?@.weathers[2] == '晴れ　時々　くもり'].area.name"}</code>（全角スペース）→ <code>{'["東京地方","伊豆諸島北部"]'}</code>

引用符の中の文字はデータと 1 文字ずつ比べるので、全角か半角かも区別されます。表記の揺れを吸収したいときは、<code>{"search(@.weathers[2], '時々')"}</code> のように変わらない部分だけで探します。

全角英数の状態で入力すると、記号も全角で入ることがあります。

{/* jpt-check: {"q": "$..areas[*].area．name", "json": "[{\"publishingOffice\": \"気象庁\", \"reportDatetime\": \"2026-10-08T17:00:00+09:00\", \"timeSeries\": [{\"areas\": [{\"area\": {\"name\": \"東京地方\", \"code\": \"130010\"}, \"weathers\": [\"晴れ\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島北部\", \"code\": \"130020\"}, \"weathers\": [\"晴れ　夜遅く　くもり\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島南部\", \"code\": \"130030\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ　三宅島　では　夜のはじめ頃　まで　雨\", \"晴れ　昼前　から　時々　くもり\", \"くもり　時々　晴れ\"]}, {\"area\": {\"name\": \"小笠原諸島\", \"code\": \"130040\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ\", \"くもり　時々　晴れ\", \"くもり\"]}]}]}]", "show": ["panel", "status"]} */}
- 名前の途中の <code>{"．"}</code> はエラーになりません。<code>{"$..areas[*].area．name"}</code> は「area．name」という名前のメンバーを探すので <code>{"マッチなし"}</code> になり、ステータス行に <code>{"式に全角文字（．）があります。JSONPath はメンバー名の一部として読み、. [ ] * や $ としては扱いません。半角（ASCII）で入力し直してください。"}</code> と表示されます。

{/* jpt-check: {"q": "$[0].timeSeries[0].areas[０]", "json": "[{\"publishingOffice\": \"気象庁\", \"reportDatetime\": \"2026-10-08T17:00:00+09:00\", \"timeSeries\": [{\"areas\": [{\"area\": {\"name\": \"東京地方\", \"code\": \"130010\"}, \"weathers\": [\"晴れ\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島北部\", \"code\": \"130020\"}, \"weathers\": [\"晴れ　夜遅く　くもり\", \"晴れ\", \"晴れ　時々　くもり\"]}, {\"area\": {\"name\": \"伊豆諸島南部\", \"code\": \"130030\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ　三宅島　では　夜のはじめ頃　まで　雨\", \"晴れ　昼前　から　時々　くもり\", \"くもり　時々　晴れ\"]}, {\"area\": {\"name\": \"小笠原諸島\", \"code\": \"130040\"}, \"weathers\": [\"くもり　夜のはじめ頃　晴れ\", \"くもり　時々　晴れ\", \"くもり\"]}]}]}]", "show": ["status"]} */}
- 角括弧の中の全角数字は構文エラーです。<code>{"$[0].timeSeries[0].areas[０]"}</code> は <code>{"構文エラーまたは未対応の構文: 角括弧の中に「０」は書けません（26 文字目） · 式に全角文字（０）があります。半角（ASCII）で入力し直してください。"}</code> になります。

<h2>制限事項</h2>
<ul>
  <li>構文エラーと RFC 9535 にない構文は「構文エラーまたは未対応の構文」と文字位置を表示します。RFC 9535 にない構文には次のものがあります：スクリプト式 <code>{"[(...)]"}</code>、<code>{"=~"}</code>、<code>{"in"}</code> / <code>{"nin"}</code>、他のライブラリの <code>{"~"}</code>（メンバー名の取得）などの拡張。</li>
  <li><code>{"$.store.book.length"}</code> は <code>{"length"}</code> という名前のメンバーを選びます。配列にはそのメンバーがないため結果は空です。長さで絞り込むにはフィルター内で <code>{"length()"}</code> を使います（例：<code>{"$[?length(@.book) > 3]"}</code>）。</li>
  <li>結果はマッチした値の一覧です。正規化パス（<code>{"$['store']['book'][0]"}</code> など）は表示しません。</li>
  <li>オブジェクトのメンバーは JavaScript が保持する順で返します。<code>{'"10"'}</code> のような配列の添字に見える名前が先に数値の昇順で並び、それ以外は JSON に書かれた順です。RFC 9535 §2.3.2.2 はこの順序を定めていないため、他の実装では変わることがあります。</li>
  <li>同じオブジェクトに同じ名前が 2 回あると、<code>{"JSON.parse"}</code> は後の値だけを残します。</li>
  <li>名前は符号位置ごとに比べ、Unicode の正規化はしません（名前セレクターは RFC 9535 §2.3.1.2。フィルター内の文字列比較もこのツールは同じ方法で行います）。全角と半角も別の文字です。</li>
  <li><code>{"match()"}</code> と <code>{"search()"}</code> は <code>{"."}</code> を <code>{"[^\\n\\r]"}</code> に置き換えたうえで、<code>{"u"}</code> フラグ付きの JavaScript 正規表現として実行します（RFC 9485 §5.3）。JavaScript が受け付けないパターンは false になり、<code>{"\\d"}</code> や先読みなど JavaScript だけの構文も受け付けます。</li>
  <li>数値は <code>{"JSON.parse"}</code> で JavaScript の数値になります。2<sup>53</sup> を超える整数、桁数の多い小数、<code>{"-0"}</code>、倍精度に収まらない数は比較と表示の前に値が変わり、ステータス行に一覧が出ます（例：<code>{"9007199254740993 → 9007199254740992"}</code>）。</li>
  <li>JSON の構文エラーのメッセージはブラウザーの JavaScript パーサーのもので、文言はブラウザーによって異なります。</li>
</ul>

<h2>他の JSONPath 方言との違い</h2>
<p>
  kubectl の <code>{"-o jsonpath"}</code> テンプレートは式を波括弧で囲み、先頭の <code>{"$"}</code> を省略できます。ここに貼るときは波括弧の中だけを取り出し、先頭に <code>{"$"}</code> を付けてください。
  Java の Jayway JsonPath はスクリプト式や <code>{"=~"}</code>、パス末尾の <code>{".length()"}</code> を受け付けますが、このツールは RFC 9535 に従い、位置を示してエラーにします。
  JSON の形を組み替えたいときは <a href="/ja/tools/jq-playground/">jq Playground</a> を使ってください。
</p>
