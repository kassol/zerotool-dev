## 버튼별 동작

모든 버튼은 **입력** 칸을 읽어 **출력** 칸에 씁니다. 입력은 바뀌지 않습니다. 여러 단계(공백 제거 → 중복 삭제 → 정렬)를 이어서 하려면 단계마다 출력을 입력 칸에 다시 복사하세요.

| 버튼 | 규칙 |
|---|---|
| 중복 제거 | 각 줄의 첫 번째 항목을 원래 순서대로 남깁니다. 대소문자와 공백까지 완전히 같아야 중복으로 봅니다. `awk '!seen[$0]++'`와 같은 결과 |
| A→Z 정렬 / Z→A 정렬 | 브라우저 기본 로캘의 `String.prototype.localeCompare` |
| 숫자 정렬 | 각 줄을 `parseFloat`로 읽고, 숫자로 읽히지 않는 줄은 끝으로 보내 오름차순 정렬 |
| 역순 | 줄 순서를 뒤집음 |
| 섞기 | 무작위 순서(클릭할 때마다 다름) |
| 공백 제거 | 각 줄 앞뒤의 공백 삭제 |
| 빈 줄 제거 | 비어 있거나 공백만 있는 줄 삭제 |

## 예시: 섞인 목록의 정렬과 중복 삭제

{/* lt-check: {"op": "sort-asc", "locale": "en"} */}

입력(마지막 줄 끝에 공백이 하나 있음):

```text
banana
Apple
apple
Cherry
_x
10
9
éclair
Zebra
apple
apple 
```

**A→Z 정렬**(브라우저 언어가 영어일 때):

```text
_x
10
9
apple
apple
Apple
apple 
banana
Cherry
éclair
Zebra
```

순서는 바이트 값이 아니라 로캘 규칙을 따릅니다. 대문자와 소문자가 나란히 오고 `é`는 `e` 근처에 놓입니다. 숫자가 아니라 문자 단위로 비교하므로 `10`이 `9`보다 앞입니다. 셸의 `LC_ALL=C sort`는 바이트 순서로 정렬합니다:

```text
10
9
Apple
Cherry
Zebra
_x
apple
apple
apple 
banana
éclair
```

{/* lt-check: {"op": "dedup", "locale": "ko", "input": "banana\nApple\napple\nCherry\n_x\n10\n9\néclair\nZebra\napple\napple "} */}

같은 입력으로 **중복 제거**를 하면 `apple` 하나가 빠지고, `apple `(끝 공백 포함)은 다른 줄로 남습니다:

```text
banana
Apple
apple
Cherry
_x
10
9
éclair
Zebra
apple 
```

끝 공백을 구분하지 않으려면 먼저 **공백 제거**를 하고 결과를 입력에 다시 넣은 뒤 중복을 삭제하세요.

## 예시: 숫자 정렬이 읽는 값

{/* lt-check: {"op": "sort-num", "locale": "ko"} */}

```text
1,000
v2
-3
1e3
10px
3
0x10
 4
```

결과:

```text
-3
0x10
1,000
3
 4
10px
1e3
v2
```

`parseFloat`는 앞부분의 숫자를 읽다가 쓸 수 없는 문자에서 멈춥니다. `0x10`은 `0`, `1,000`은 `1`, `10px`는 `10`, `1e3`는 `1000`으로 읽힙니다. ` 4`는 앞 공백이 그대로 남습니다. `v2`는 숫자로 시작하지 않아 맨 끝으로 갑니다.

## 예시: 한글과 영문이 섞인 목록

**A→Z 정렬**은 브라우저 기본 언어의 규칙으로 문자열을 비교하므로, 같은 목록도 브라우저 언어에 따라 순서가 달라집니다. 회사 이름 목록을 넣어 보겠습니다.

{/* lt-check: {"op": "sort-asc", "locale": "ko"} */}

```text
카카오
네이버
삼성전자
LG전자
SK하이닉스
쿠팡
```

브라우저 언어가 한국어이면 한글 이름이 가나다순으로 먼저 오고, 영문으로 시작하는 이름은 그 뒤에 놓입니다.

```text
네이버
삼성전자
카카오
쿠팡
LG전자
SK하이닉스
```

{/* lt-check: {"op": "sort-asc", "locale": "en", "input": "카카오\n네이버\n삼성전자\nLG전자\nSK하이닉스\n쿠팡"} */}

브라우저 언어가 영어이면 반대로 영문 이름이 먼저 옵니다.

```text
LG전자
SK하이닉스
네이버
삼성전자
카카오
쿠팡
```

여러 사람이 같은 목록을 정렬해 공유한다면, 순서가 다를 수 있다는 점을 염두에 두세요.

## 예시: 원화 가격 목록의 숫자 정렬

쇼핑몰 가격처럼 천 단위 쉼표가 들어간 값은 **숫자 정렬**이 의도대로 읽지 못합니다. `parseFloat`는 쉼표에서 멈추기 때문입니다.

{/* lt-check: {"op": "sort-num", "locale": "ko"} */}

```text
2,500원
10,000원
9,900원
980원
₩5,000
```

결과:

```text
2,500원
9,900원
10,000원
980원
₩5,000
```

`2,500원`은 2, `9,900원`은 9, `10,000원`은 10으로 읽혀 앞에 오고, 쉼표가 없는 `980원`은 980으로 읽혀 그 뒤에 옵니다. `₩5,000`은 숫자로 시작하지 않으므로 맨 끝입니다. 금액 순서로 정렬하려면 먼저 쉼표와 `₩` 기호를 지우세요. 쉼표를 지운 목록은 다음과 같이 정렬됩니다.

{/* lt-check: {"op": "sort-num", "locale": "ko", "input": "2500원\n10000원\n9900원\n980원\n5000"} */}

```text
980원
2500원
5000
9900원
10000원
```

## 명령줄 대응

| 작업 | 셸 | 이 도구와의 차이 |
|---|---|---|
| 순서를 유지하며 중복 삭제 | `awk '!seen[$0]++' file.txt` | 같은 결과 |
| 인접한 중복 삭제 | `sort file.txt \| uniq` | 출력이 정렬됨 |
| 정렬 | `sort file.txt` | `LC_COLLATE`를 따름, `LC_ALL=C`이면 바이트 순서 |
| 숫자 정렬 | `sort -n file.txt` | `1,000`, `0x10`, `1e3` 처리 규칙이 다름 |
| 역순 | `tac file.txt`(GNU) / `tail -r file.txt`(macOS) | 같은 결과 |
| 빈 줄 삭제 | `sed '/^[[:space:]]*$/d' file.txt` | 같은 결과 |
| 줄마다 공백 제거 | `sed 's/^[[:space:]]*//;s/[[:space:]]*$//' file.txt` | ASCII 공백이면 같은 결과 |

## 제한 사항

- 대소문자를 무시하는 모드가 없습니다. 필요하면 먼저 [텍스트 대소문자 변환](/ko/tools/text-case/)으로 소문자로 바꾸세요.
- 줄바꿈(LF)으로 줄을 나눕니다. 붙여넣은 Windows 줄바꿈은 브라우저 입력 칸이 LF로 맞춥니다.
- 알파벳 순서는 브라우저 언어 설정에 따라 달라지므로, 악센트나 대소문자가 섞인 줄은 기기마다 순서가 다를 수 있습니다.
- 줄 수 제한은 없으며 브라우저 메모리가 한계입니다.
