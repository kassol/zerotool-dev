<h2>使い方</h2>
<ol>
  <li>左側の欄に元のテキスト（旧バージョン）を貼り付けます。</li>
  <li>右側の欄に新しいテキスト（新バージョン）を貼り付けます。</li>
  <li><strong>比較</strong>をクリックすると差分がハイライトされます。</li>
  <li>緑色が追加行、赤色が削除行を示します。</li>
</ol>

<h2>テキスト差分について</h2>
<p>差分チェックはコードレビュー、ドキュメントの変更追跡、設定ファイルの比較などで重宝します。gitのような版管理システムでも同様の機能が使われています。</p>

## 結果の読み方

「統合表示」は両方のテキストの全行を 1 列に並べます。先頭の 2 つの数字列は、元テキストと変更後テキストでの行番号です。`-` は元テキストにだけある行、`+` は変更後テキストにだけある行で、記号のない行は両方で同じです。たとえば

```text
timeout = 30
retries = 3
```

と

```text
timeout = 60
retries = 3
```

を比べると、`- timeout = 30`、`+ timeout = 60`、変わっていない `retries = 3` の順に表示されます。「並列表示」では、削除された行とその直後に追加された行を同じ行に並べます。

## 制限事項

- **行単位の比較のみ。** 1 文字の変更でも行全体が削除と追加として表示され、単語・文字単位のハイライトはありません。
- **無視オプションはありません。** 空白や大文字小文字の違いも変更として扱います。
- **前後の行は折りたたみません。** 変わっていない行もすべて表示され、`@@` のハンク見出しもないため、パッチとしては使えません。
- **大きな入力は遅くなります。** アルゴリズムは元テキストの全行と変更後テキストの全行の組み合わせ表を作ります。Node.js での計測では、10,000 行どうしのファイルで約 1.3 秒・約 840 MB のメモリを使い、それより大きい入力ではタブが固まることがあります。

大きなファイル、パッチ、空白を無視した比較にはコマンドラインを使ってください。`diff -u a.txt b.txt` は unified 形式のパッチを出力し、`diff -w` は空白を無視し、`git diff --no-index a.txt b.txt` はリポジトリ外のファイルを比較でき、`git diff --word-diff` は変わった単語をハイライトします。
