<h2>사용 방법</h2>
<ol>
  <li>왼쪽 에디터에 Markdown을 입력합니다.</li>
  <li>오른쪽에 실시간으로 HTML 미리보기가 표시됩니다.</li>
  <li><strong>HTML 복사</strong>로 생성된 HTML을 복사합니다.</li>
  <li><strong>초기화</strong>로 에디터를 비웁니다.</li>
</ol>

<h2>Markdown에 대하여</h2>
<p>Markdown은 2004년 John Gruber가 만든 경량 마크업 언어입니다. 읽기 쉬운 일반 텍스트로 HTML 콘텐츠를 작성할 수 있으며, README, 문서, 블로그 글 등에 널리 사용됩니다.</p>
<p>GitHub, GitLab, Slack, Notion 등 많은 플랫폼이 Markdown 렌더링을 지원합니다.</p>

## 예시: 경계 사례를 미리보기가 처리하는 방식

미리보기는 작은 내장 파서를 쓰며, CommonMark나 GitHub의 완전한 렌더러가 아닙니다. 다음 입력:

````markdown
# Release notes

See https://example.com and `a **b** c`.

- Parent
  - Child
- [X] Done
- [x] done

3. third
4. fourth

| Item | Price |
|:-----|------:|
| Widget | $9.99 |
| a \| b | 1 |

<b>raw</b> and <img src=x alt=y>
````

에서 만들어지는 HTML(“HTML 복사” 내용):

```html
<h1>Release notes</h1><p>See https://example.com and <code>a <strong>b</strong> c</code>.</p><ul><li>Parent</li></ul><p>  - Child</p><ul><li>[X] Done</li><li><label><input type="checkbox" disabled="" checked=""> done</label></li></ul><ol><li>third</li><li>fourth</li></ol><table><thead><tr><th>Item</th><th>Price</th></tr></thead><tbody><tr><td>Widget</td><td>$9.99</td></tr><tr><td>a \</td><td>b</td><td>1</td></tr></tbody></table><p><b>raw</b> and <img src="x" alt="y"></p>
```

GitHub와 비교([GFM 명세](https://github.github.com/gfm/)):

| 입력 | GitHub | 이 미리보기 |
|---|---|---|
| 맨 URL `https://example.com` | 링크(autolink 확장) | 일반 텍스트 |
| 백틱 안의 `**b**` | `**b**` 그대로 | 코드 안에서 굵게 표시 |
| 들여쓴 `- Child` | 중첩 목록 | 별도 문단 |
| `[X]`(대문자 X) | 체크된 작업 | 글자 그대로, 소문자 `[x]`만 인식 |
| 첫 항목이 `3.` | 3부터 시작하는 목록 | 1부터 시작하는 목록 |
| `:---` / `---:` 정렬 | 왼쪽 / 오른쪽 정렬 | 정렬 무시 |
| 셀 안에서 백슬래시로 이스케이프한 세로 막대 | 세로 막대 문자 | 셀이 나뉨 |
| 원시 HTML | 정제됨 | 그대로 삽입 |

## 원시 HTML은 정제되지 않습니다

문단 안의 HTML 태그는 미리보기와 복사한 HTML에 걸러지지 않고 들어갑니다. 붙여넣은 텍스트의 `<img src=x onerror=...>`는 이 페이지에서 실행되고, “HTML 복사”로 붙여넣는 곳에도 그대로 옮겨집니다. 신뢰할 수 없는 Markdown은 미리보지 말고, 게시 전에 HTML을 정제하세요(DOMPurify 등).

## 이미지는 네트워크에서 불러옵니다

`![alt](https://…)`는 `<img>`가 되고 브라우저가 그 주소에서 이미지를 받아옵니다. 이미지 서버는 IP 주소와 브라우저 정보를 볼 수 있습니다. 텍스트와 문서의 나머지는 브라우저 안에 머뭅니다.

## 제한 사항

- 목록은 한 단계만 지원하며 중첩 목록이나 여러 문단으로 된 항목은 지원하지 않습니다.
- 자동 링크, 각주, 참조형 링크, 제목 앵커는 지원하지 않습니다.
- 코드 블록 강조 대상은 JavaScript, TypeScript, Python, Go, PHP, Ruby, Java, Bash, JSON, HTML/XML, CSS, Markdown입니다.
- GitHub와 똑같이 보여야 하는 문서는 게시 전에 GitHub 자체 미리보기로 확인하세요.
