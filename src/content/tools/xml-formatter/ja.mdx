<h2>XMLについて</h2>
<p>XML（eXtensible Markup Language）はデータの構造化・交換に使われるマークアップ言語です。HTMLと見た目は似ていますが、データの記述に特化しています。設定ファイル（Maven、Spring、Androidのmanifestなど）、Web API（SOAP）、RSS/Atomフィード、Office文書形式（DOCX/XLSXの内部）などで広く使われています。</p>

## よくあるエラー

このツールはブラウザの XML パーサーで入力を解析し、最初の[整形式](https://www.w3.org/TR/xml/#sec-well-formed)エラーで止まってブラウザのメッセージを表示します。よくある原因は次のとおりです。

| エラー | 例 | 直し方 |
|---|---|---|
| 閉じタグがない | `<person><name>Alice</person>` | `<name>` を `</name>` で閉じる |
| タグ名が一致しない | `<b>bold</i>` | 開始タグと終了タグを同じ名前にする（大文字小文字も区別） |
| 本文に `&` や `<` をそのまま書いた | `<company>AT&T</company>` | `&amp;`、`&lt;` と書く |
| ルート要素が 2 つある | `<record/><record/>` | `<records>` などの親要素で囲む |
| 属性値に引用符がない | `<item id=42/>` | 引用符で囲む：`id="42"` |

## 制限事項

- **DOCTYPE で宣言した実体は展開されます。** XML 宣言と DOCTYPE（内部サブセットを含む）はそのまま出力しますが、そこで宣言した実体の参照（`&company;` など）は置換後のテキストで書き出されます。
- **テキストの前後の空白は削除されます。** `xml:space="preserve"` も反映されません。
- **空の要素は空要素タグになります。** `<note></note>` も `<note> </note>` も `<note/>` になります。
- **整形式のチェックのみです。** DTD や XML Schema による妥当性検証はしません。
