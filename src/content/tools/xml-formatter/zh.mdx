<h2>格式化示例</h2>
<h3>格式化前</h3>

```xml
<root><user id="1"><name>Alice</name><email>alice@example.com</email></user></root>
```

<h3>格式化后</h3>

```xml
<root>
  <user id="1">
    <name>Alice</name>
    <email>alice@example.com</email>
  </user>
</root>
```

<h2>XML 格式化最佳实践</h2>
<p>正确格式化的 XML 提高可读性，更容易发现结构问题。使用一致的缩进，属性较短时保持在元素同一行，发送到 API 或配置文件之前始终验证 XML。</p>

## 常见错误

本工具用浏览器的 XML 解析器解析输入，遇到第一个[格式良好性](https://www.w3.org/TR/xml/#sec-well-formed)错误就停止，并显示浏览器给出的信息。常见原因如下：

| 错误 | 示例 | 改法 |
|---|---|---|
| 标签未闭合 | `<person><name>Alice</person>` | 用 `</name>` 闭合 `<name>` |
| 标签不匹配 | `<b>bold</i>` | 开始和结束标签用同一个名字，注意区分大小写 |
| 文本里直接写了 `&` 或 `<` | `<company>AT&T</company>` | 写成 `&amp;` 和 `&lt;` |
| 有两个根元素 | `<record/><record/>` | 用一个父元素包起来，例如 `<records>` |
| 属性值没加引号 | `<item id=42/>` | 加引号：`id="42"` |

## 限制

- **DOCTYPE 里声明的实体会被展开。** XML 声明和 DOCTYPE（含内部子集）原样保留，但引用其中声明的实体（如 `&company;`）时，输出写的是替换后的文本。
- **文本会被去掉首尾空白。** 元素内文本的首尾空白会删除，`xml:space="preserve"` 不生效。
- **空元素改成自闭合。** `<note></note>` 和 `<note> </note>` 都会变成 `<note/>`。
- **只检查格式良好性。** 不按 DTD 或 XML Schema 校验。
