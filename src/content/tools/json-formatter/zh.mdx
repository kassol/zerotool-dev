<h2>关于 JSON 格式化</h2>
<p>JSON（JavaScript Object Notation）是最常用的数据交换格式。格式化工具通过添加缩进使嵌套结构可读，而压缩工具去除空白以减少数据大小。除下文「限制」列出的情况外，两种操作都不改变解析后的数据。</p>
<p>此工具完全在浏览器中运行，数据不会离开您的设备。</p>

## 常见错误与提示信息

本工具用浏览器的 `JSON.parse` 解析输入，「无效 JSON:」后面的错误信息来自浏览器。下表是 Chrome 对几种常见错误给出的信息，Firefox 和 Safari 的措辞不同。

| 输入 | 问题 | Chrome 的提示 | 改法 |
|---|---|---|---|
| `{"a":1,}` | 末尾多余逗号 | `Expected double-quoted property name in JSON at position 7 (line 1 column 8)` | 删掉最后一个逗号 |
| `{'a':'b'}` | 单引号 | `Expected property name or '}' in JSON at position 1 (line 1 column 2)` | 改用双引号 |
| `{a: 1}` | 键名没加引号 | `Expected property name or '}' in JSON at position 1 (line 1 column 2)` | 给键名加双引号 |
| `{"x": undefined}` | `undefined` 不是 JSON 值 | `Unexpected token 'u', ... is not valid JSON` | 改成 `null` |
| `{"a":1} // 备注` | 注释 | `Unexpected non-whitespace character after JSON at position 8` | 删掉注释，[RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) 没有注释语法 |

## 限制

- **大整数会丢精度。** 数字按 JavaScript 双精度浮点数解析，超过 2^53 − 1 的整数会变：`{"id": 12345678901234567890}` 格式化后是 `{"id": 12345678901234567000}`。很长的 ID 请用字符串保存。
- **重复的键只保留最后一个。** `{"a":1,"a":2}` 会变成 `{"a":2}`。
- **数字写法会被改写。** `1.0` 变成 `1`，`1e3` 变成 `1000`。
- **缩进固定为 2 个空格。**
