<h2>使い方</h2>
<ol>
  <li>JSONを入力欄に貼り付けます。</li>
  <li><strong>整形</strong>をクリックするとスペース2つのインデントで整形されます。</li>
  <li><strong>圧縮</strong>をクリックすると1行に圧縮されます。</li>
  <li><strong>検証</strong>をクリックすると構文エラーをチェックします。</li>
  <li><strong>コピー</strong>をクリックすると結果をクリップボードにコピーします。</li>
</ol>

<h2>JSONフォーマットについて</h2>
<p>JSON（JavaScript Object Notation）は最も広く使われているデータ交換フォーマットです。フォーマッターはインデントを追加してネスト構造を読みやすくし、圧縮ツールは空白を除去してデータサイズを削減します。下の「制限事項」に挙げたケースを除き、どちらの操作も解析後のデータを変えません。</p>
<p>このツールはブラウザ上で完全に動作し、データがデバイス外に出ることはありません。</p>

## よくあるエラーと表示されるメッセージ

このツールはブラウザの `JSON.parse` で入力を解析するため、「無効な JSON:」の後に出るエラー文はブラウザが出したものです。よくある間違いに対して Chrome が表示するメッセージは次のとおりです（Firefox と Safari では文言が異なります）。

| 入力 | 問題 | Chrome のメッセージ | 直し方 |
|---|---|---|---|
| `{"a":1,}` | 末尾のカンマ | `Expected double-quoted property name in JSON at position 7 (line 1 column 8)` | 最後のカンマを消す |
| `{'a':'b'}` | シングルクォート | `Expected property name or '}' in JSON at position 1 (line 1 column 2)` | ダブルクォートにする |
| `{a: 1}` | キーに引用符がない | `Expected property name or '}' in JSON at position 1 (line 1 column 2)` | キーをダブルクォートで囲む |
| `{"x": undefined}` | `undefined` は JSON の値ではない | `Unexpected token 'u', ... is not valid JSON` | `null` にする |
| `{"a":1} // メモ` | コメント | `Unexpected non-whitespace character after JSON at position 8` | コメントを消す。[RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) にコメント構文はない |

## 制限事項

- **大きな整数は精度が落ちます。** 数値は JavaScript の倍精度浮動小数点数になるため、2^53 − 1 を超える整数は変わります。`{"id": 12345678901234567890}` は `{"id": 12345678901234567000}` と整形されます。長い ID は文字列で持ってください。
- **重複したキーは最後の値だけが残ります。** `{"a":1,"a":2}` は `{"a":2}` になります。
- **数値の表記は書き換わります。** `1.0` は `1`、`1e3` は `1000` になります。
- **インデントは 2 スペース固定です。**
