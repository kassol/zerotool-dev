<h2>二进制表示</h2>

每个字符编码为一个或多个字节，每个字节用 8 位二进制数表示。

```
H = 01001000
e = 01100101
l = 01101100
o = 01101111
```

"Hello" 的空格分隔二进制：`01001000 01100101 01101100 01101100 01101111`

## 读懂一个字节

每一位都有固定的值，从左到右依次是 128 到 1，把为 1 的位的值相加：

```
Bit value:  128  64  32  16   8   4   2   1
01001000:     0   1   0   0   1   0   0   0   → 64 + 8 = 72 = "H"
```

## 一个字符占几个字节

UTF-8 用 1 到 4 个字节表示一个字符（[RFC 3629](https://www.rfc-editor.org/rfc/rfc3629#section-3)），转换器为每个字节输出一组 8 位：

| 码点范围 | 字节数 | 示例 | 输出 |
|---|---|---|---|
| U+0000–U+007F（ASCII） | 1 | `H` | `01001000` |
| U+0080–U+07FF | 2 | `é` | `11000011 10101001` |
| U+0800–U+FFFF（常用汉字） | 3 | `中` | `11100100 10111000 10101101` |
| U+10000–U+10FFFF（多数 emoji） | 4 | `😀` | `11110000 10011111 10011000 10000000` |

所以「中文」两个字输出 6 组。GBK 编码下一个汉字是 2 个字节，本工具只按 UTF-8 输出。

## 用代码做同样的转换

```javascript
const toBinary = (text) =>
  [...new TextEncoder().encode(text)]
    .map((b) => b.toString(2).padStart(8, '0'))
    .join(' ');

toBinary('Hi'); // "01001000 01101001"
```

```python
' '.join(f'{b:08b}' for b in 'Hi'.encode('utf-8'))  # '01001000 01101001'
```

## 限制

- **只接受 8 位一组。** 「二进制 → 文本」会去掉所有空格，再按 8 位一组读取。`1001000 1101001` 这样的 7 位 ASCII 会被重新分组，结果报错或变成错误字符。
- **只支持 UTF-8。** 不是合法 UTF-8 的字节（例如只有前两个字节的汉字）会报「The encoded data was not valid for encoding utf-8」。不能解码 UTF-16、GBK 或 Shift_JIS。
- **「二进制 → 文本」需要点按钮。** 文本转二进制随输入实时更新，反方向要点击 **二进制 → 文本**。
- **状态栏统计的是字符数。** 一个 emoji 在状态栏里算 1 个字符，但输出 4 个字节。
