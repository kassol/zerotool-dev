<h2>使い方</h2>
<ol>
  <li><strong>テキスト</strong>パネルにテキストを入力または貼り付けると、バイナリ出力が自動更新されます。</li>
  <li>バイナリをテキストに戻すには、<strong>バイナリ</strong>パネルにバイナリを貼り付けて<strong>バイナリ → テキスト</strong>をクリックします。</li>
  <li>バイナリ出力形式として<strong>スペース区切り</strong>または<strong>連続</strong>を選択します。</li>
  <li><strong>コピー</strong>ボタンで各パネルの内容をクリップボードにコピーできます。</li>
</ol>

<h2>バイナリ表現</h2>

各文字は1つ以上のバイトにエンコードされ、各バイトは8ビットの二進数で表されます。

```
H = 01001000
e = 01100101
l = 01101100
o = 01101111
```

"Hello"のスペース区切りバイナリ：`01001000 01100101 01101100 01101100 01101111`

<h2>ヒント</h2>
<ul>
  <li>マルチバイトUTF-8文字（絵文字😀 = U+1F600など）は4つの8ビットグループになります。</li>
  <li>よりコンパクトなテキストセーフなエンコードには <a href="/ja/tools/base64/">Base64</a> をご利用ください。</li>
  <li>10進数・16進数・8進数の値を扱う場合は <a href="/ja/tools/ascii-converter/">ASCII変換器</a> をご利用ください。</li>
</ul>

## 1 バイトの読み方

各ビットには左から 128、64 … 1 の値があります。1 になっているビットの値を足します。

```
Bit value:  128  64  32  16   8   4   2   1
01001000:     0   1   0   0   1   0   0   0   → 64 + 8 = 72 = "H"
```

## 1 文字が何バイトになるか

UTF-8 は 1 文字を 1〜4 バイトで表します（[RFC 3629](https://www.rfc-editor.org/rfc/rfc3629#section-3)）。変換ツールは 1 バイトごとに 8 ビットのグループを出力します。

| コードポイント | バイト数 | 例 | 出力 |
|---|---|---|---|
| U+0000〜U+007F（ASCII） | 1 | `H` | `01001000` |
| U+0080〜U+07FF | 2 | `é` | `11000011 10101001` |
| U+0800〜U+FFFF（ひらがな・カタカナ・常用漢字） | 3 | `あ` | `11100011 10000001 10000010` |
| U+10000〜U+10FFFF（多くの絵文字） | 4 | `😀` | `11110000 10011111 10011000 10000000` |

Shift_JIS では `あ` は 2 バイト（`0x82A0`）ですが、このツールは UTF-8 だけを出力します。

## コードで同じ変換をする

```javascript
const toBinary = (text) =>
  [...new TextEncoder().encode(text)]
    .map((b) => b.toString(2).padStart(8, '0'))
    .join(' ');

toBinary('Hi'); // "01001000 01101001"
```

```python
' '.join(f'{b:08b}' for b in 'Hi'.encode('utf-8'))  # '01001000 01101001'
```

## 制限事項

- **8 ビット単位のみ。** 「バイナリ → テキスト」はスペースをすべて取り除き、8 ビットずつ読みます。`1001000 1101001` のような 7 ビットの ASCII は区切りがずれ、エラーか誤った文字になります。
- **UTF-8 のみ。** 3 バイト文字の途中で切れたバイト列など、UTF-8 として正しくないデータは「The encoded data was not valid for encoding utf-8」になります。UTF-16、Shift_JIS、GBK は復号できません。
- **「バイナリ → テキスト」はボタンを押して実行。** テキスト→バイナリは入力中に更新されますが、逆方向は **バイナリ → テキスト** をクリックします。
- **ステータスは文字数を表示します。** 絵文字はステータスでは 1 文字ですが、出力は 4 バイトです。
