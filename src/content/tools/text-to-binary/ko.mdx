<h2>사용 방법</h2>
<ol>
  <li><strong>텍스트</strong> 패널에 텍스트를 입력하거나 붙여 넣으면 바이너리 출력이 자동으로 업데이트됩니다.</li>
  <li>바이너리를 텍스트로 변환하려면 <strong>바이너리</strong> 패널에 바이너리를 붙여 넣고 <strong>바이너리 → 텍스트</strong>를 클릭합니다.</li>
  <li>바이너리 출력 형식으로 <strong>공백 구분</strong> 또는 <strong>연속</strong>을 선택합니다.</li>
  <li><strong>복사</strong> 버튼으로 각 패널 내용을 클립보드에 복사합니다.</li>
</ol>

<h2>바이너리 표현</h2>

각 문자는 하나 이상의 바이트로 인코딩되며, 각 바이트는 8비트 이진수로 표현됩니다.

```
H = 01001000
e = 01100101
l = 01101100
o = 01101111
```

"Hello"의 공백 구분 바이너리: `01001000 01100101 01101100 01101100 01101111`

<h2>팁</h2>
<ul>
  <li>다중 바이트 UTF-8 문자(이모지 😀 = U+1F600 등)는 4개의 8비트 그룹이 됩니다.</li>
  <li>더 간결한 텍스트 안전 인코딩에는 <a href="/ko/tools/base64/">Base64</a>를 사용하세요.</li>
  <li>10진수, 16진수, 8진수 값을 다루려면 <a href="/ko/tools/ascii-converter/">ASCII 변환기</a>를 사용하세요.</li>
</ul>

## 한 바이트 읽는 법

각 비트 자리에는 왼쪽부터 128, 64 … 1의 값이 있습니다. 1인 자리의 값을 더합니다.

```
Bit value:  128  64  32  16   8   4   2   1
01001000:     0   1   0   0   1   0   0   0   → 64 + 8 = 72 = "H"
```

## 한 글자가 몇 바이트인가

UTF-8은 한 글자를 1~4바이트로 나타냅니다([RFC 3629](https://www.rfc-editor.org/rfc/rfc3629#section-3)). 변환기는 바이트마다 8비트 묶음 하나를 출력합니다.

| 코드 포인트 | 바이트 | 예시 | 출력 |
|---|---|---|---|
| U+0000–U+007F (ASCII) | 1 | `H` | `01001000` |
| U+0080–U+07FF | 2 | `é` | `11000011 10101001` |
| U+0800–U+FFFF (한글 음절 포함) | 3 | `한` | `11101101 10010101 10011100` |
| U+10000–U+10FFFF (대부분의 이모지) | 4 | `😀` | `11110000 10011111 10011000 10000000` |

EUC-KR(CP949)에서는 한글 한 글자가 2바이트지만, 이 도구는 UTF-8로만 출력합니다.

## 코드로 같은 변환하기

```javascript
const toBinary = (text) =>
  [...new TextEncoder().encode(text)]
    .map((b) => b.toString(2).padStart(8, '0'))
    .join(' ');

toBinary('Hi'); // "01001000 01101001"
```

```python
' '.join(f'{b:08b}' for b in 'Hi'.encode('utf-8'))  # '01001000 01101001'
```

## 제한 사항

- **8비트 묶음만 받습니다.** 「바이너리 → 텍스트」는 공백을 모두 지우고 8비트씩 읽습니다. `1001000 1101001` 같은 7비트 ASCII는 묶음이 어긋나 오류나 잘못된 글자가 됩니다.
- **UTF-8만 지원합니다.** 3바이트 글자가 중간에 끊긴 경우처럼 올바른 UTF-8이 아닌 바이트는 「The encoded data was not valid for encoding utf-8」 오류가 납니다. UTF-16, EUC-KR은 디코딩하지 않습니다.
- **「바이너리 → 텍스트」는 버튼을 눌러야 합니다.** 텍스트 → 바이너리는 입력하는 동안 바뀌지만, 반대 방향은 **바이너리 → 텍스트**를 클릭합니다.
- **상태 표시는 글자 수입니다.** 이모지는 상태 표시에서 1자로 세지만 출력은 4바이트입니다.
