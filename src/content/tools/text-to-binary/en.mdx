<h2>Text to Binary Converter Online</h2>
<p>
  Convert plain text into binary <code>0</code>s and <code>1</code>s instantly, then decode binary back to readable text.
  The converter uses UTF-8, so it handles ASCII letters, numbers, punctuation, accented characters, CJK text, and emoji.
</p>
<ul>
  <li><strong>Text → Binary:</strong> turn each UTF-8 byte into an 8-bit binary group.</li>
  <li><strong>Binary → Text:</strong> paste spaced or continuous binary and decode it back to text.</li>

<h2>Binary Representation</h2>

Each character is encoded as one or more bytes. Each byte is represented as an 8-bit binary number.

```
H = 01001000
e = 01100101
l = 01101100
o = 01101111
```

"Hello" in spaced binary: `01001000 01100101 01101100 01101100 01101111`

## Reading One Byte

Each bit position has a value, from 128 on the left to 1 on the right. Add the values where the bit is 1:

```
Bit value:  128  64  32  16   8   4   2   1
01001000:     0   1   0   0   1   0   0   0   → 64 + 8 = 72 = "H"
```

## How Many Bytes a Character Uses

UTF-8 uses 1 to 4 bytes for each character ([RFC 3629](https://www.rfc-editor.org/rfc/rfc3629#section-3)). The converter shows one 8-bit group for each byte:

| Code points | Bytes | Example | Output |
|---|---|---|---|
| U+0000–U+007F (ASCII) | 1 | `H` | `01001000` |
| U+0080–U+07FF | 2 | `é` | `11000011 10101001` |
| U+0800–U+FFFF (most CJK) | 3 | `中` | `11100100 10111000 10101101` |
| U+10000–U+10FFFF (most emoji) | 4 | `😀` | `11110000 10011111 10011000 10000000` |

## The Same Conversion in Code

```javascript
const toBinary = (text) =>
  [...new TextEncoder().encode(text)]
    .map((b) => b.toString(2).padStart(8, '0'))
    .join(' ');

toBinary('Hi'); // "01001000 01101001"
```

```python
' '.join(f'{b:08b}' for b in 'Hi'.encode('utf-8'))  # '01001000 01101001'
```

## Limits

- **8-bit groups only.** Binary → Text removes all spaces and reads the bits in groups of 8. Seven-bit ASCII such as `1001000 1101001` is regrouped and gives an error or wrong characters.
- **UTF-8 only.** Bytes that are not valid UTF-8, such as an incomplete 3-byte character, give "The encoded data was not valid for encoding utf-8". The tool does not decode UTF-16, Shift_JIS, or GBK.
- **Binary → Text needs a click.** Text → Binary updates while you type; for the other direction, click **Binary → Text**.
- **The status counts characters.** An emoji counts as 1 character in the status message but gives 4 bytes of output.
