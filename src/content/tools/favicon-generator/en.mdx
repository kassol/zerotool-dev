<h2>Why a multi-file favicon set still matters</h2>

<p>A site's favicon is more than a tab icon. It shows up in search results next to your domain, in browser bookmarks, on the home screen when an iOS user adds your site to it, and in Android's install prompt. Each of those places wants a different size, and some want a different format, so a single <code>favicon.ico</code> leaves gaps.</p>

<p>This tool produces the full set in one click: an ICO for older browsers, PNGs for the <code>&lt;link rel="icon"&gt;</code> tags, an apple-touch-icon for iOS, and a webmanifest with your site name, <code>start_url</code>, <code>display</code> and the 192 and 512 icons, which is what Chrome checks before it offers to install the site.</p>

<h2>The HTML snippet, explained</h2>

<p>The generated snippet has seven lines:</p>

<ul>
  <li><code>&lt;link rel="icon" type="image/x-icon" href="/favicon.ico"&gt;</code> — for browsers and bookmarks that look for <code>favicon.ico</code>.</li>
  <li><code>&lt;link rel="icon" type="image/png" sizes="..."&gt;</code> at 16, 32, and 48 — the HTML Standard leaves the choice to the browser. In a 2026-10-02 test, Chromium 152 on a 2× screen fetched only <code>favicon.ico</code> while the ICO link was present, and <code>favicon-32.png</code> when only the PNG links were.</li>
  <li><code>&lt;link rel="apple-touch-icon"&gt;</code> at 180×180 — Safari on iOS uses this when a user adds the page to the home screen.</li>
  <li><code>&lt;link rel="manifest"&gt;</code> — points Android Chrome and PWA installers at <code>site.webmanifest</code>, which lists the site name from the Site name field, <code>"start_url": "/"</code>, <code>"display": "standalone"</code> and the 192 and 512 PNGs with <code>purpose: "any"</code>. With the Site name field empty, <code>name</code> and <code>short_name</code> are left out and Chrome does not offer to install the site.</li>
  <li><code>&lt;meta name="theme-color"&gt;</code> — the Theme color value; browsers that support it use it to tint their interface.</li>
</ul>

<h2>Examples</h2>

<p><strong>A manifest with a site name.</strong> With Site name <code>Acme Docs</code>, Short name <code>Docs</code>, Theme color <code>#1e3a8a</code> and a color background <code>#1e3a8a</code>, the package contains this <code>site.webmanifest</code>:</p>

{/* fav-mf: {"appName":"Acme Docs","shortName":"Docs","themeColor":"#1e3a8a","bgMode":"color","bgColor":"#1e3a8a","bytes":432} */}
<pre><code>{`{
  "name": "Acme Docs",
  "short_name": "Docs",
  "start_url": "/",
  "display": "standalone",
  "icons": [
    {
      "src": "/android-chrome-192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/android-chrome-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    }
  ],
  "theme_color": "#1e3a8a",
  "background_color": "#1e3a8a"
}`}</code></pre>

<p>The file list shows it as <code>432 B</code>. The <code>background_color</code> follows the Background setting; with a transparent background it is <code>#ffffff</code>.</p>

<p><strong>A wide logo shrinks to a line.</strong> An image source keeps its aspect ratio and is fitted into the square that is left after padding. A 1200 × 300 wordmark at the 32 px size with the default 8% padding is drawn at:</p>

{/* fav-fit: {"w":1200,"h":300,"size":32,"padding":8} */}
<p><code>26.88 × 6.72</code> px — less than 7 pixels tall, so the letters are not readable. Use a square mark or one or two letters for the small sizes.</p>

<p><strong>Padding for a maskable icon.</strong> Android crops a maskable icon to its launcher shape and only promises to keep the central circle whose radius is 40% of the icon (<a href="https://web.dev/articles/maskable-icon" target="_blank" rel="noopener">web.dev</a>). For a square 1000 × 1000 image at 512 px with Padding 22%, the drawn square and its corner distance from the center are:</p>

{/* fav-fit: {"w":1000,"h":1000,"size":512,"padding":22,"safe":true} */}
<p><code>286.72 × 286.72</code> px, half diagonal <code>202.74</code> px, inside the <code>204.8</code> px circle. At 21% the square is 296.96 px and the corners go outside the circle.</p>

{/* fav-fit: {"w":1000,"h":1000,"size":512,"padding":21,"safe":false} */}
<p>Padding 21%: <code>296.96 × 296.96</code> px, half diagonal <code>209.98</code> px against the <code>204.8</code> px limit. The package itself declares no maskable icon (see the FAQ); this is how to size a second 512 px image if you add one.</p>

<h2>How the package is built</h2>

<p>The renderer creates a canvas at each of the nine sizes, applies the background and shape, draws the source centered inside the padding, and asks <code>canvas.toBlob('image/png')</code> for a PNG. The 16, 32 and 48 px PNGs are packed into <code>favicon.ico</code> with PNG entries: a 6-byte <code>ICONDIR</code> header, three 16-byte <code>ICONDIRENTRY</code> records, then the three PNG files.</p>

<p>The ZIP uses the STORED method (no compression), because PNG data is already compressed. All file names in the package are ASCII; the ZIP still sets the UTF-8 name flag.</p>

<h2>Common pitfalls</h2>

<ul>
  <li><strong>SVG with external images.</strong> Inline any <code>&lt;image href="https://..."&gt;</code> as a data URI before pasting. When the browser will not let the tool read the canvas back, the status line says "SVG references external resources. Inline images first." and no package is made.</li>
  <li><strong>Empty emoji on a Linux machine.</strong> Some Linux installs have no color emoji font. The preview then shows empty boxes; switch to the Text or Image tab.</li>
  <li><strong>Fine lines at 16 px.</strong> With the default padding, a 512 × 512 artwork is drawn into a 13.44 px square at 16 px, so every line becomes about 38 times thinner. Check the 16 px preview and simplify the mark if it disappears.</li>
</ul>

<h2>Limits</h2>

<ul>
  <li><strong>Inputs.</strong> Image files must be PNG, JPG or SVG and at most 10 MB; WebP and GIF are refused. Text takes 1–4 characters and is scaled down until it fits the square. Emoji uses only the first emoji you type (a ZWJ sequence or a flag counts as one) and the emoji font of your system.</li>
  <li><strong>Fixed output.</strong> The nine PNG sizes, the three ICO sizes (no 256 px entry), the file names and the root paths (<code>/favicon.ico</code>, <code>"start_url": "/"</code>) are fixed. A site served from a subdirectory must edit the snippet and the manifest. There is no SVG favicon and no maskable icon.</li>
  <li><strong>Search results.</strong> Google asks for a square favicon of at least 8 × 8 px and recommends one larger than 48 × 48 px (<a href="https://developers.google.com/search/docs/appearance/favicon-in-search" target="_blank" rel="noopener">Google Search Central</a>). The snippet links PNGs up to 48 px only; add a line for <code>favicon-96.png</code> yourself if you want to offer a larger file.</li>
  <li><strong>Install prompt.</strong> Chrome offers installation only when the manifest has a name, so leave Site name empty only when you need favicons alone.</li>
</ul>
