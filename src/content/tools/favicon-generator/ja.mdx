<h2>ファビコンが複数ファイルになる理由</h2>

<p>ファビコンが表示されるのはタブだけではありません。検索結果のドメイン横、ブックマーク、iPhone の「ホーム画面に追加」、Android のインストール案内でも使われ、場所ごとに求められるサイズが違い、形式が違う場所もあります。<code>favicon.ico</code> 1 つでは足りない場所が出てきます。</p>

<p>このツールは一式をまとめて作ります。古いブラウザー向けの ICO、<code>&lt;link rel="icon"&gt;</code> 用の各サイズの PNG、iOS 用の apple-touch-icon、そしてサイト名・<code>start_url</code>・<code>display</code>・192 と 512 のアイコンを書いた webmanifest です。最後の 4 項目は、Chrome がサイトのインストールを案内する前に確認する項目です。</p>

<h2>HTML スニペットを 1 行ずつ</h2>

<ul>
  <li><code>&lt;link rel="icon" type="image/x-icon" href="/favicon.ico"&gt;</code>：<code>favicon.ico</code> を探しに来るブラウザーやブックマーク向け。</li>
  <li><code>&lt;link rel="icon" type="image/png" sizes="..."&gt;</code>（16・32・48・96）：どれを使うかは HTML Standard でブラウザーに任されています。2026-10-02 の計測では、2× 画面の Chromium 152 は ICO のリンクがあると <code>favicon.ico</code> だけを取得し、PNG のリンクだけのときは <code>favicon-32.png</code> を取得しました。96 px の行を加えた 2026-10-09 の計測でも、取得したのは <code>favicon.ico</code> だけです。96 px の行は、48 × 48 px より大きいファビコンを推奨する Google 検索のためのものです。</li>
  <li><code>&lt;link rel="apple-touch-icon"&gt;</code>（180×180）：iOS の Safari で「ホーム画面に追加」したときに使われます。</li>
  <li><code>&lt;link rel="manifest"&gt;</code>：<code>site.webmanifest</code> を指します。中身は「サイト名」欄の名前、<code>"start_url": "/"</code>、<code>"display": "standalone"</code>、<code>purpose: "any"</code> の 192・512 PNG です。「サイト名」が空のときは <code>name</code> と <code>short_name</code> を書かず、Chrome はインストールを案内しません。</li>
  <li><code>&lt;meta name="theme-color"&gt;</code>：「テーマカラー」の値。対応するブラウザーが画面の色付けに使います。</li>
</ul>

<h2>日本語のサイト名とマニフェスト</h2>

<p>サイト名「さくら写真館」、短い名前「さくら」、テーマカラー <code>#e91e63</code>、背景は透過のまま生成すると、<code>site.webmanifest</code> は次のとおりです。</p>

{/* fav-mf: {"appName":"さくら写真館","shortName":"さくら","themeColor":"#e91e63","bytes":446} */}
<pre><code>{`{
  "name": "さくら写真館",
  "short_name": "さくら",
  "start_url": "/",
  "display": "standalone",
  "icons": [
    {
      "src": "/android-chrome-192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/android-chrome-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    }
  ],
  "theme_color": "#e91e63",
  "background_color": "#ffffff"
}`}</code></pre>

<p>日本語は <code>\uXXXX</code> にエスケープされず、そのまま UTF-8 で保存されます（かな・漢字は 1 文字 3 バイト）。ファイル一覧では <code>446 B</code> と表示されます。名前の前後の空白は取り除かれ、全角スペースも同じく消えます。背景が透過のときの <code>background_color</code> は <code>#ffffff</code> 固定なので、別の色にしたい場合は「背景」を「カラー」にしてください。</p>

<h2>縦長ロゴと文字のアイコン</h2>

<p>「画像」素材は縦横比を保ったまま、余白を除いた正方形に収めます。縦書きのロゴのような 300 × 600 の画像を、既定の余白 8% で 32 px にすると：</p>

{/* fav-fit: {"w":300,"h":600,"size":32,"padding":8} */}
<p><code>13.44 × 26.88</code> px になり、左右に大きな空白が残ります。小さいサイズ用には、正方形に収まる部分（マークだけ、頭文字だけ）を別に用意した方が見やすくなります。</p>

<p>「テキスト」素材で漢字やかなを使う場合、全角文字は 1 文字がほぼ文字サイズと同じ幅です。ツールは文字列の幅を測り、正方形からはみ出すときはフォントサイズを小さくするので、4 文字でも切れずに収まります。ただし 16 px では 1 文字あたり 3〜4 ピクセルしかなく、画数の多い漢字はつぶれます。1 文字にするのがいちばん読みやすい選択です。</p>

<h2>マスカブル用の余白を計算する</h2>

<p>Android はマスカブルアイコンをランチャーの形に切り抜き、中心から半径 40% の円の中だけを必ず表示します（<a href="https://web.dev/articles/maskable-icon" target="_blank" rel="noopener">web.dev</a>）。1000 × 1000 の正方形画像を余白 22% で 192 px に描くと：</p>

{/* fav-fit: {"w":1000,"h":1000,"size":192,"padding":22,"safe":true} */}
<p>描かれる正方形は <code>107.52 × 107.52</code> px、中心から角までは <code>76.03</code> px で、半径 <code>76.8</code> px の円に収まります。余白を 21% にすると角がはみ出します。パッケージ自体はマスカブルを宣言しません。この割合（22%）は、512 px の画像を別に作るときにもそのまま使えます。</p>

<h2>プライバシー</h2>

<ul>
  <li>画像、テキスト、SVG、サイト名はページの中だけで使い、アップロードも localStorage への保存もしません。</li>
  <li>他のツールページと同じく Google Analytics と AdSense を読み込みます。パッケージ生成ごとに <code>generate</code>、ZIP のダウンロードごとに <code>download</code> を 1 回記録し、内容はツール名と操作だけです。</li>
</ul>

<h2>制限と注意点</h2>

<ul>
  <li><strong>素材。</strong>画像は PNG・JPG・SVG で 10 MB まで。WebP と GIF は受け付けません。テキストは 4 文字まで。絵文字は最初の 1 つだけを使い（ZWJ シーケンスや国旗は 1 つと数えます）、見た目は OS のフォントで決まります。カラー絵文字フォントのない Linux では空の枠になります。</li>
  <li><strong>外部画像を参照する SVG。</strong><code>&lt;image href="https://..."&gt;</code> はデータ URI に置き換えてから貼り付けてください。ブラウザーが canvas の読み出しを許可しないときはパッケージを作らず、SVG の中に見つかった原因を表示します。<code>&lt;foreignObject&gt;</code> 要素があるとき、外部参照があるとき（「SVG が外部リソースを参照しています。画像をインライン化してください。」）、どちらもないとき（「描画したアイコンの読み出しをブラウザーが許可しなかったため、パッケージは作られませんでした。」）で文言が変わります。</li>
  <li><strong>出力は固定。</strong>9 種の PNG サイズ、ICO の 3 サイズ（256 px なし）、ファイル名、ルート基準のパス（<code>/favicon.ico</code>、<code>"start_url": "/"</code>）は変えられません。サブディレクトリで公開するサイトはスニペットとマニフェストを書き換えてください。SVG ファビコンとマスカブルアイコンは作りません。</li>
  <li><strong>検索結果のファビコン。</strong>Google は正方形で 8 × 8 px 以上を求め、48 × 48 px より大きいサイズを推奨しています（<a href="https://developers.google.com/search/docs/appearance/favicon-in-search?hl=ja" target="_blank" rel="noopener">Google 検索セントラル</a>）。そのためスニペットは 96 × 96 の <code>favicon-96.png</code> も参照します。</li>
</ul>
