<h2>一个站点为什么要准备一整套图标</h2>

<p>网站图标不只出现在浏览器标签上。搜索结果的域名旁、收藏夹、iOS「添加到主屏幕」后的图标、Android 的安装提示，都会用到它，而且各自要的尺寸不同，有的还要不同格式。只放一个 <code>favicon.ico</code>，总有几个地方显示不好。</p>

<p>本工具一次生成整套文件：给老浏览器的 ICO、给 <code>&lt;link rel="icon"&gt;</code> 用的多尺寸 PNG、iOS 用的 apple-touch-icon，以及写明站点名称、<code>start_url</code>、<code>display</code> 和 192、512 图标的 webmanifest，这几项是 Chrome 提示安装网站前要检查的。</p>

<h2>HTML 代码片段逐行看</h2>

<ul>
  <li><code>&lt;link rel="icon" type="image/x-icon" href="/favicon.ico"&gt;</code>：给会去找 <code>favicon.ico</code> 的浏览器和收藏夹。</li>
  <li><code>&lt;link rel="icon" type="image/png" sizes="..."&gt;</code> 16、32、48、96 四档：HTML 标准把选择权交给浏览器。2026-10-02 实测，2× 屏上的 Chromium 152 在有 ICO 链接时只请求 <code>favicon.ico</code>，只有 PNG 链接时请求 <code>favicon-32.png</code>；2026-10-09 加上 96 px 这一行后，仍只请求 <code>favicon.ico</code>。96 px 这一行是给 Google 搜索的，它建议图标大于 48 × 48 px。</li>
  <li><code>&lt;link rel="apple-touch-icon"&gt;</code> 180×180：iOS Safari「添加到主屏幕」时使用。</li>
  <li><code>&lt;link rel="manifest"&gt;</code>：指向 <code>site.webmanifest</code>，里面写着「站点名称」栏的名称、<code>"start_url": "/"</code>、<code>"display": "standalone"</code>，并用 <code>purpose: "any"</code> 声明 192 与 512 PNG。「站点名称」留空时不写 <code>name</code> 与 <code>short_name</code>，Chrome 不会提示安装网站。</li>
  <li><code>&lt;meta name="theme-color"&gt;</code>：「主题色」的值，支持它的浏览器用来给界面着色。</li>
</ul>

<h2>中文站点名写进 manifest</h2>

<p>假设站点叫「张三的技术博客」，短名称填「技术博客」，主题色选 <code>#c0392b</code>，背景保持透明。图标包里的 <code>site.webmanifest</code> 是：</p>

{/* fav-mf: {"appName":"张三的技术博客","shortName":"技术博客","themeColor":"#c0392b","bytes":452} */}
<pre><code>{`{
  "name": "张三的技术博客",
  "short_name": "技术博客",
  "start_url": "/",
  "display": "standalone",
  "icons": [
    {
      "src": "/android-chrome-192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/android-chrome-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    }
  ],
  "theme_color": "#c0392b",
  "background_color": "#ffffff"
}`}</code></pre>

<p>中文按原样写进 JSON，没有转成 <code>\uXXXX</code>；文件按 UTF-8 保存，一个汉字占 3 个字节，图标包列表里这个文件显示为 <code>452 B</code>。背景透明时 <code>background_color</code> 固定写 <code>#ffffff</code>，要别的颜色就把「背景」改成「颜色」。名称前后的空格会被去掉；「短名称」留空时不写 <code>short_name</code>。</p>

<h2>横版 logo 放进 16 px 会怎样</h2>

<p>「图片」素材保持原比例，缩放进去掉内边距后的正方形。很多公司 logo 是横版的，比如 800 × 200。默认内边距 8% 时，在 16 px 图标里它被画成：</p>

{/* fav-fit: {"w":800,"h":200,"size":16,"padding":8} */}
<p><code>13.44 × 3.36</code> px，高度不到 4 个像素，文字根本看不清。小尺寸建议换成方形标志，或者改用「文字」标签只放一两个字。</p>

<p>「文字」素材里的中文也要注意：汉字是全角，一个字差不多一个字号宽。工具会测量文字宽度，超出正方形就缩小字号，所以四个汉字也能完整放下，但在 16 px 上每个字只有三四个像素宽，笔画会糊成一片。只放一个字最容易看清。</p>

<h2>做 maskable 图标时内边距要多大</h2>

<p>Android 会把 maskable 图标裁成启动器的形状，只保证中间半径为图标 40% 的圆形区域可见（<a href="https://web.dev/articles/maskable-icon" target="_blank" rel="noopener">web.dev</a>）。用 1000 × 1000 的方形图、内边距 22%、512 px 尺寸计算：</p>

{/* fav-fit: {"w":1000,"h":1000,"size":512,"padding":22,"safe":true} */}
<p>画出的正方形是 <code>286.72 × 286.72</code> px，四角到中心的距离 <code>202.74</code> px，在 <code>204.8</code> px 的圆内。内边距降到 21% 时，正方形变成 296.96 px，四角就超出了这个圆。图标包本身不声明 maskable，这里的数字用于你另外做一张 512 px 图。</p>

<ul>

  <li>本页与其他工具页一样加载 Google Analytics 和 AdSense。每生成一次图标包记录一次 <code>generate</code>，每下载一次 ZIP 记录一次 <code>download</code>，只含工具名和操作。</li>
</ul>

<h2>限制</h2>

<ul>
  <li><strong>素材。</strong>图片只收 PNG、JPG、SVG，最大 10 MB，WebP 和 GIF 会被拒绝。文字最多 4 个字符。emoji 只用第一个（ZWJ 组合和国旗算一个），样子取决于系统字体；某些 Linux 系统没有彩色 emoji 字体，会显示空框。</li>
  <li><strong>SVG 里的外部图片。</strong>粘贴前先把 <code>&lt;image href="https://..."&gt;</code> 转成 Data URI。浏览器不允许读回 canvas 时不生成图标包，状态栏按 SVG 里找到的原因提示：含 <code>&lt;foreignObject&gt;</code> 元素、引用了外部资源（「SVG 引用了外部资源，请先内联图片。」），或者两者都没有（「浏览器不允许读回绘制好的图标，没有生成图标包。」）。</li>
  <li><strong>输出固定。</strong>九种 PNG 尺寸、ICO 的三种尺寸（没有 256 px）、文件名和根目录路径（<code>/favicon.ico</code>、<code>"start_url": "/"</code>）都不能改。站点放在子目录时，要自己改代码片段和 manifest。不生成 SVG favicon，也不生成 maskable 图标。</li>
  <li><strong>搜索结果里的图标。</strong>Google 要求 favicon 是正方形、至少 8 × 8 px，并建议大于 48 × 48 px（<a href="https://developers.google.com/search/docs/appearance/favicon-in-search?hl=zh-cn" target="_blank" rel="noopener">Google 搜索中心</a>）。所以代码片段引用了 96 × 96 的 <code>favicon-96.png</code>。</li>
</ul>
