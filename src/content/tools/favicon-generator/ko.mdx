<h2>파비콘이 여러 파일로 나뉘는 이유</h2>

<p>파비콘은 브라우저 탭에만 쓰이지 않습니다. 검색 결과의 도메인 옆, 즐겨찾기, iPhone의 '홈 화면에 추가', Android의 설치 안내에도 쓰이고, 자리마다 필요한 크기가 다르며 형식이 다른 곳도 있습니다. <code>favicon.ico</code> 하나로는 빈자리가 생깁니다.</p>

<p>이 도구는 한 번에 전체 세트를 만듭니다. 오래된 브라우저용 ICO, <code>&lt;link rel="icon"&gt;</code>용 크기별 PNG, iOS용 apple-touch-icon, 그리고 사이트 이름·<code>start_url</code>·<code>display</code>·192와 512 아이콘을 적은 webmanifest입니다. 마지막 네 항목은 Chrome이 사이트 설치를 안내하기 전에 확인하는 항목입니다.</p>

<h2>HTML 스니펫 한 줄씩 보기</h2>

<ul>
  <li><code>&lt;link rel="icon" type="image/x-icon" href="/favicon.ico"&gt;</code>: <code>favicon.ico</code>를 찾는 브라우저와 즐겨찾기용입니다.</li>
  <li><code>&lt;link rel="icon" type="image/png" sizes="..."&gt;</code> 16·32·48·96: 어느 파일을 쓸지는 HTML 표준이 브라우저에 맡깁니다. 2026-10-02 측정에서 2× 화면의 Chromium 152는 ICO 링크가 있으면 <code>favicon.ico</code>만, PNG 링크만 있으면 <code>favicon-32.png</code>를 요청했습니다. 96 px 줄을 더한 2026-10-09 측정에서도 <code>favicon.ico</code>만 요청했습니다. 96 px 줄은 48 × 48 px보다 큰 파비콘을 권장하는 Google 검색을 위한 것입니다.</li>
  <li><code>&lt;link rel="apple-touch-icon"&gt;</code> 180×180: iOS Safari에서 '홈 화면에 추가'할 때 씁니다.</li>
  <li><code>&lt;link rel="manifest"&gt;</code>: <code>site.webmanifest</code>를 가리킵니다. '사이트 이름' 칸의 이름, <code>"start_url": "/"</code>, <code>"display": "standalone"</code>, <code>purpose: "any"</code>인 192·512 PNG가 들어 있습니다. '사이트 이름'이 비어 있으면 <code>name</code>과 <code>short_name</code>을 쓰지 않고, Chrome은 설치를 안내하지 않습니다.</li>
  <li><code>&lt;meta name="theme-color"&gt;</code>: '테마 색상' 값입니다. 지원하는 브라우저가 화면 색을 칠할 때 씁니다.</li>
</ul>

<h2>한글 사이트 이름을 넣은 manifest</h2>

<p>사이트 이름 '서울 맛집 지도', 짧은 이름 '맛집지도', 테마 색상 <code>#03c75a</code>, 배경은 투명 그대로 두고 생성하면 <code>site.webmanifest</code>는 다음과 같습니다.</p>

{/* fav-mf: {"appName":"서울 맛집 지도","shortName":"맛집지도","themeColor":"#03c75a","bytes":451} */}
<pre><code>{`{
  "name": "서울 맛집 지도",
  "short_name": "맛집지도",
  "start_url": "/",
  "display": "standalone",
  "icons": [
    {
      "src": "/android-chrome-192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/android-chrome-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    }
  ],
  "theme_color": "#03c75a",
  "background_color": "#ffffff"
}`}</code></pre>

<p>한글은 <code>\uXXXX</code>로 바뀌지 않고 그대로 UTF-8로 저장되며, 한 글자가 3바이트입니다. 파일 목록에는 <code>451 B</code>로 표시됩니다. 이름 앞뒤 공백은 지워지지만 이름 가운데의 띄어쓰기는 그대로 남습니다. 배경이 투명이면 <code>background_color</code>는 <code>#ffffff</code>로 고정되므로, 다른 색이 필요하면 '배경'을 '색상'으로 바꾸세요.</p>

<h2>가로로 긴 로고와 한글 텍스트</h2>

<p>'이미지' 소스는 비율을 유지한 채 여백을 뺀 정사각형 안에 들어갑니다. 1000 × 250 가로형 로고를 기본 여백 8%로 32 px에 넣으면:</p>

{/* fav-fit: {"w":1000,"h":250,"size":32,"padding":8} */}
<p><code>26.88 × 6.72</code> px로 그려집니다. 높이가 7픽셀도 안 되어 글자를 읽을 수 없으니, 작은 크기에는 심벌만 따로 쓰는 편이 낫습니다.</p>

<p>'텍스트' 소스에 한글을 쓰면 한 글자가 글자 크기만큼 넓습니다. 도구는 문자열 너비를 재서 정사각형을 넘으면 글자 크기를 줄이므로 네 글자도 잘리지 않지만, 16 px에서는 한 글자가 3~4픽셀이라 받침이 있는 글자는 뭉개집니다. 한 글자만 쓰는 것이 가장 잘 보입니다.</p>

<h2>maskable 아이콘에 필요한 여백</h2>

<p>Android는 maskable 아이콘을 런처 모양으로 잘라 내며, 중심에서 반지름 40%인 원 안만 반드시 보여 줍니다(<a href="https://web.dev/articles/maskable-icon" target="_blank" rel="noopener">web.dev</a>). 1000 × 1000 정사각형 이미지를 여백 22%로 512 px에 그리면:</p>

{/* fav-fit: {"w":1000,"h":1000,"size":512,"padding":22,"safe":true} */}
<p>정사각형은 <code>286.72 × 286.72</code> px, 중심에서 모서리까지 <code>202.74</code> px로 반지름 <code>204.8</code> px 원 안에 들어갑니다. 여백을 21%로 줄이면 모서리가 원 밖으로 나갑니다. 패키지는 maskable을 선언하지 않으므로, 이 값은 512 px 이미지를 따로 만들 때 참고하세요.</p>

<h2>개인정보</h2>

<ul>
  <li>이미지, 텍스트, SVG, 사이트 이름은 페이지 안에서만 쓰며 업로드하지도, localStorage에 저장하지도 않습니다.</li>
  <li>다른 도구 페이지처럼 Google Analytics와 AdSense를 불러옵니다. 패키지를 생성할 때마다 <code>generate</code>, ZIP을 내려받을 때마다 <code>download</code>를 한 번 기록하며, 내용은 도구 이름과 동작뿐입니다.</li>
</ul>

<h2>제한 사항</h2>

<ul>
  <li><strong>소스.</strong> 이미지는 PNG·JPG·SVG, 최대 10 MB이며 WebP와 GIF는 받지 않습니다. 텍스트는 4자까지입니다. 이모지는 첫 번째 하나만 쓰고(ZWJ 조합과 국기는 하나로 셉니다), 모양은 운영체제 글꼴에 따릅니다. 컬러 이모지 글꼴이 없는 Linux에서는 빈 상자로 나옵니다.</li>
  <li><strong>외부 이미지를 참조하는 SVG.</strong> <code>&lt;image href="https://..."&gt;</code>는 데이터 URI로 바꾼 뒤 붙여 넣으세요. 브라우저가 canvas 읽기를 허용하지 않으면 패키지를 만들지 않고, SVG에서 찾은 원인을 표시합니다. <code>&lt;foreignObject&gt;</code> 요소가 있을 때, 외부 참조가 있을 때('SVG가 외부 리소스를 참조합니다. 이미지를 인라인하세요.'), 둘 다 없을 때('브라우저가 그린 아이콘을 다시 읽도록 허용하지 않아 패키지를 만들지 못했습니다.') 문구가 다릅니다.</li>
  <li><strong>고정된 출력.</strong> PNG 9가지 크기, ICO 3가지 크기(256 px 없음), 파일 이름, 루트 기준 경로(<code>/favicon.ico</code>, <code>"start_url": "/"</code>)는 바꿀 수 없습니다. 하위 디렉터리에서 서비스하는 사이트는 스니펫과 manifest를 직접 고치세요. SVG 파비콘과 maskable 아이콘은 만들지 않습니다.</li>
  <li><strong>검색 결과의 파비콘.</strong> Google은 정사각형이고 8 × 8 px 이상일 것을 요구하며, 48 × 48 px보다 큰 크기를 권장합니다(<a href="https://developers.google.com/search/docs/appearance/favicon-in-search?hl=ko" target="_blank" rel="noopener">Google 검색 센터</a>). 그래서 스니펫은 96 × 96 <code>favicon-96.png</code>도 참조합니다.</li>
</ul>
