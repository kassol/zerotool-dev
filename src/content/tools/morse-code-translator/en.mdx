<h2>Morse Code Format</h2>
<p>Each letter is represented as a sequence of dots (<code>·</code>) and dashes (<code>−</code>) separated by spaces. Words are delimited by <code> / </code>. Example: <code>···· · ·−·· ·−·· −−− / ·−− −−− ·−· ·−·· −··</code> decodes to <code>HELLO WORLD</code>.</p>

<h2>What Is Morse Code?</h2>
<p>Morse code is a character encoding system developed in the 1830s for electrical telegraph communication. It represents letters and numbers as sequences of short (dot) and long (dash) signals. It is still used today in amateur radio (CW mode) and as an accessibility input method.</p>

<h2>Timing and Format</h2>

<p>In <a href="https://www.itu.int/rec/R-REC-M.1677-1-200910-I/" target="_blank" rel="noopener">ITU-R M.1677-1</a> a dash is three dots long; the gap inside a letter is one dot, between letters three dots, and between words seven dots. In text, the tool writes the dot as <code>{"·"}</code> (U+00B7) and the dash as <code>{"−"}</code> (U+2212), separates letters with one space and words with <code>{" / "}</code>.</p>

<ul>
  <li>The decoder accepts ASCII <code>{"."}</code> and <code>{"-"}</code> as well as <code>{"·"}</code> and <code>{"−"}</code>, so <code>{".... . .-.. .-.. --- / .-- --- .-. .-.. -.."}</code> gives <code>{"HELLO WORLD"}</code>. It also reads <code>{"•"}</code>, <code>{"_"}</code>, en / em dashes and full-width <code>{"．"}</code> <code>{"－"}</code>, and they can be mixed in one input.</li>
  <li>A code the table does not contain decodes to <code>{"[?]"}</code>, and the tool lists those codes in the status row. For example the ITU error signal (eight dots) gives <code>{"[?]"}</code>. The brackets keep it apart from <code>{"?"}</code>, which is the decoded question mark <code>{"··−−··"}</code>.</li>
  <li>É is the ITU accented e: <code>{"Café 9:30, ok?"}</code> becomes <code>{"−·−· ·− ··−· ··−·· / −−−−· −−−··· ···−− −−−−− −−··−− / −−− −·− ··−−··"}</code>. Characters without a code (other accented letters, CJK, emoji) are left out and listed in the status row: <code>{"Grüße ok"}</code> becomes <code>{"−−· ·−· · / −−− −·−"}</code> with Ü and ß listed. The tool does not expand ß to SS.</li>
  <li>Letters are case-insensitive; decoding always returns capitals.</li>
  <li>Prosigns such as AR or SK are sent without a letter gap. The tool has no prosign input and encodes <code>{"AR"}</code> as two letters.</li>
</ul>

<p>Example: a CQ call in amateur radio, <code>{"CQ DE N0CALL K"}</code>, encodes to <code>{"−·−· −−·− / −·· · / −· −−−−− −·−· ·− ·−·· ·−·· / −·−"}</code>.</p>

<h2>History</h2>

<p>Samuel Morse and Alfred Vail developed the code for the electric telegraph; the first long-distance message on the Washington–Baltimore line, "What hath God wrought", was sent on 24 May 1844. The international code in use today differs from the original American Morse in several letters. Morse is still used by amateur radio operators (CW).</p>
