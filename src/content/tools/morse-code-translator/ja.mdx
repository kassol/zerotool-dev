<h2>使い方</h2>
<ol>
  <li><strong>テキスト → モールス符号</strong>：左側にテキストを入力すると、右側にモールス符号が即座に表示されます。</li>
  <li><strong>モールス符号 → テキスト</strong>：<code>.</code>で点、<code>-</code>でダッシュを入力。文字間はスペース、単語間は<code> / </code>で区切ります。</li>
  <li><strong>コピー</strong>をクリックして結果をコピーします。</li>
</ol>

<h2>モールス符号のフォーマット</h2>
<p>各文字は点とダッシュのシーケンスで表され、文字コード間はスペースで区切られます。単語は<code> / </code>で区切られます。例：<code>···· · ·−·· ·−·· −−−</code>は<code>HELLO</code>にデコードされます（短点は <code>·</code>、長点は <code>−</code>）。</p>

<h2>モールス符号とは？</h2>
<p>モールス符号は1830年代に電信通信のために開発された文字符号化システムです。短点（·）と長線（—）の組み合わせで文字と数字を表します。現在もアマチュア無線（CWモード）やアクセシビリティ入力として使用されています。</p>

<h2>長さと書き方</h2>

<p><a href="https://www.itu.int/rec/R-REC-M.1677-1-200910-I/" target="_blank" rel="noopener">ITU-R M.1677-1</a> では、長点は短点 3 つ分の長さで、文字内の間隔は短点 1 つ分、文字間は 3 つ分、単語間は 7 つ分です。文字で書くとき、このツールは短点を <code>{"·"}</code>（U+00B7）、長点を <code>{"−"}</code>（U+2212）で表し、文字の間は空白 1 つ、単語の間は <code>{" / "}</code> で区切ります。</p>

<ul>
  <li>デコードが読むのは <code>{"·"}</code> と <code>{"−"}</code> だけです。半角の <code>{"."}</code> と <code>{"-"}</code> で入力したモールス符号は疑問符になり、<code>{".... . .-.. .-.. --- / .-- --- .-. .-.. -.."}</code> は <code>{"????? ?????"}</code> になります。先に <code>{"."}</code> を <code>{"·"}</code>、<code>{"-"}</code> を <code>{"−"}</code> に置き換えるか、このツールの出力を貼り付けてください。</li>
  <li>表にない符号は <code>{"?"}</code> になります。</li>
  <li>モールス符号のない文字（アクセント付き文字、かな・漢字、絵文字）はエンコード時に黙って落とされます。<code>{"Café 9:30, ok?"}</code> は <code>{"−·−· ·− ··−· / −−−−· −−−··· ···−− −−−−− −−··−− / −−− −·− ··−−··"}</code> になり、é が消えます。和文モールス（イロハ）には対応していません。</li>
  <li>アルファベットの大文字小文字は区別せず、デコード結果は常に大文字です。</li>
  <li>AR や SK などの略符号は文字間を空けずに送ります。ツールには略符号の入力がなく、<code>{"AR"}</code> は 2 文字として符号化されます。</li>
</ul>

<p>例：アマチュア無線の CQ 呼び出し <code>{"CQ DE N0CALL K"}</code> は <code>{"−·−· −−·− / −·· · / −· −−−−− −·−· ·− ·−·· ·−·· / −·−"}</code> になります。</p>

<h2>歴史</h2>

<p>サミュエル・モールスとアルフレッド・ヴェイルが電信のために考案し、1844 年 5 月 24 日にワシントン–ボルチモア間の回線で最初の長距離電文 "What hath God wrought" が送られました。現在の国際モールス符号は、最初のアメリカ式モールス符号といくつかの文字が異なります。アマチュア無線（CW）では今も使われています。</p>
