## 사용 방법

1. 「jq 필터」에 필터를 쓰면 출력이 바로 바뀝니다.
2. 「입력」에 JSON을 붙여 넣거나 파일을 엽니다. JSON 값이 이어서 나열된 입력(JSON Lines, NDJSON)도 jq 명령처럼 읽습니다.
3. 옵션은 jq에 넘기듯이 켭니다. `-r`은 문자열을 따옴표 없이, `-s`는 모든 입력을 배열 하나로, `-n`은 `null`에서 시작해 `input` / `inputs`로 입력을 읽고, `-R`은 텍스트를 줄 단위로, `-c`는 값 하나를 한 줄로 출력합니다.
4. 「+ 변수」로 `--arg`(문자열)나 `--argjson`(JSON)을 추가합니다.
5. 「출력」에서 결과, stderr, 종료 코드를 봅니다. 「명령줄」 상자는 같은 실행을 셸 명령으로 보여 주므로 터미널에 붙여 넣으면 같은 결과가 나옵니다.

블로그에서 본 `curl … | jq -r '.items[]'` 같은 명령을 필터 칸에 그대로 붙여 넣으면 필터와 옵션을 가져올지 묻고, 쓸 수 없는 파일 이름과 옵션을 알려 줍니다.

## 예: 네이버 블로그 검색 API 결과 정리

[네이버 검색 API 블로그 검색](https://developers.naver.com/docs/serviceapi/search/blog/blog.md) 문서에 따르면 JSON 응답은 `items` 배열로 결과를 돌려주고, `title`과 `description`에서 검색어와 일치하는 부분은 `<b>` 태그로 감싸며, `postdate`는 `20161208`처럼 `yyyymmdd` 형식입니다. 이 구조에 맞춘 응답(내용은 예시)으로 해 봅니다.

```json
{"lastBuildDate":"Fri, 02 Oct 2026 10:00:00 +0900","total":2,"start":1,"display":2,"items":[
 {"title":"<b>제주</b> 3박 4일 여행 코스","link":"https://blog.naver.com/example/1","description":"<b>제주</b> 동쪽 일정 정리","bloggername":"여행하는 개발자","bloggerlink":"blog.naver.com/example","postdate":"20260918"},
 {"title":"<b>제주</b> 카페 정리","link":"https://blog.naver.com/example/2","description":"","bloggername":"카페 기록","bloggerlink":"blog.naver.com/example2","postdate":"20260925"}]}
```

{/* jqp-check: {"input": "{\"lastBuildDate\":\"Fri, 02 Oct 2026 10:00:00 +0900\",\"total\":2,\"start\":1,\"display\":2,\"items\":[\n {\"title\":\"<b>제주</b> 3박 4일 여행 코스\",\"link\":\"https://blog.naver.com/example/1\",\"description\":\"<b>제주</b> 동쪽 일정 정리\",\"bloggername\":\"여행하는 개발자\",\"bloggerlink\":\"blog.naver.com/example\",\"postdate\":\"20260918\"},\n {\"title\":\"<b>제주</b> 카페 정리\",\"link\":\"https://blog.naver.com/example/2\",\"description\":\"\",\"bloggername\":\"카페 기록\",\"bloggerlink\":\"blog.naver.com/example2\",\"postdate\":\"20260925\"}]}", "filter": ".items[] | {title: (.title | gsub(\"</?b>\"; \"\")), date: (.postdate | strptime(\"%Y%m%d\") | strftime(\"%Y-%m-%d\"))}", "flags": {"c": true}, "stdout": "{\"title\":\"제주 3박 4일 여행 코스\",\"date\":\"2026-09-18\"}\n{\"title\":\"제주 카페 정리\",\"date\":\"2026-09-25\"}\n"} */}

`-c`를 켜고 아래 필터를 실행하면 `<b>` 태그를 지우고 날짜를 `2026-09-18` 형식으로 바꾼 결과가 한 줄씩 나옵니다.

```
.items[] | {title: (.title | gsub("</?b>"; "")),
            date: (.postdate | strptime("%Y%m%d") | strftime("%Y-%m-%d"))}
```

```
{"title":"제주 3박 4일 여행 코스","date":"2026-09-18"}
{"title":"제주 카페 정리","date":"2026-09-25"}
```

{/* jqp-check: {"input": "{\"items\":[{\"title\":\"<b>제주</b> 3박 4일\",\"postdate\":\"20260918\"},{\"title\":\"부산 맛집\",\"postdate\":\"20260920\"}]}", "filter": "[.items[] | select(.title | contains($q))] | length", "flags": {}, "args": [{"type": "string", "name": "q", "value": "제주"}], "stdout": "1\n", "command": "jq --arg q '제주' '[.items[] | select(.title | contains($q))] | length' input.json"} */}

검색어를 필터에 직접 쓰지 않고 변수로 넘기면 셸 따옴표를 신경 쓸 일이 줄어듭니다. 「+ 변수」로 `q` = `제주`를 추가하고 `[.items[] | select(.title | contains($q))] | length`를 실행하면, 제목에 「제주」가 들어간 결과 수 `1`이 나옵니다. 명령줄 상자에는 `jq --arg q '제주' '[.items[] | select(.title | contains($q))] | length' input.json`이 표시됩니다.

## 예: 오류가 나기 전의 출력도 그대로

jq는 오류가 나기 전까지 만든 값을 출력한 뒤 stderr에 오류를 쓰고 종료 코드 5로 끝납니다. 이 페이지도 둘 다 보여 줍니다.

{/* jqp-check: {"input": "[{\"name\":\"a\"},\"b\"]", "filter": ".[] | .name", "flags": {}, "stdout": "\"a\"\n", "stderr": "jq: error (at input.json:1): Cannot index string with string \"name\"\n", "exit": 5, "hint": ["indexString"], "shown": ["Cannot index string with string"]} */}

`[{"name":"a"},"b"]`에 `.[] | .name`을 실행하면 먼저 `"a"`가 나오고, 이어서 `jq: error (at input.json:1): Cannot index string with string "name"`과 종료 코드 5가 표시됩니다. 아래 힌트는 값이 문자열이며, 그 안이 JSON 텍스트라면 `fromjson`으로 먼저 파싱하라고 알려 줍니다. JSON 문법 오류는 「입력에서 보기」로 jq가 멈춘 토큰을 선택합니다. jq는 위치를 바이트 단위로 알려 주므로 한글이 섞인 줄에서도 페이지가 글자 위치로 바꿔 선택합니다.

## JSON Lines 로그 집계

한 줄에 JSON 하나인 로그는 `-n`과 `inputs`로 한 줄씩 읽을 수 있습니다.

{/* jqp-check: {"input": "{\"status\":\"200\",\"request_time\":\"0.012\",\"uri\":\"/api/v1/orders\"}\n{\"status\":\"502\",\"request_time\":\"1.503\",\"uri\":\"/api/v1/orders\"}\n{\"status\":\"200\",\"request_time\":\"0.004\",\"uri\":\"/health\"}\n{\"status\":\"200\",\"request_time\":\"0.020\",\"uri\":\"/api/v1/orders\"}", "filter": "reduce inputs as $r ({}; .[$r.status] += 1)", "flags": {"n": true, "c": true}, "stdout": "{\"200\":3,\"502\":1}\n"} */}

상태 코드가 200, 502, 200, 200인 네 줄에 `-n -c`로 `reduce inputs as $r ({}; .[$r.status] += 1)`을 실행하면 `{"200":3,"502":1}`이 나옵니다. `-s`는 파일 전체를 메모리에 올리고, `-n`과 `inputs`는 한 번에 한 값만 읽습니다.

## 터미널과 같은 결과

실행은 언제나 `jq 옵션 필터 input.json`과 같고, input.json은 입력 끝에 줄바꿈을 붙인 것입니다. 테스트에서는 옵션, 변수, JSON Lines, 문법 오류와 실행 오류, `halt_error`, `-e`, `--seq`, `--stream`을 포함한 71개 경우를 이 페이지의 엔진과 jq 1.7.1 명령줄로 실행해 stdout, stderr, 종료 코드를 바이트 단위로 비교합니다. jq 1.7.1 매뉴얼 예제 241개도 환경 변수 `$PAGER`를 읽는 2개를 빼고 모두 같습니다.

설치된 버전은 `jq --version`으로 확인합니다. Ubuntu 24.04([1.7.1-3ubuntu0.24.04](https://packages.ubuntu.com/noble/jq)), Debian 13([1.7.1-6](https://packages.debian.org/trixie/jq)), macOS 27의 `/usr/bin/jq`(`jq-1.7.1-apple` 출력)는 1.7.1이고 Homebrew는 [1.8.2](https://formulae.brew.sh/formula/jq)입니다. 1.7.1은 큰 정수를 쓴 그대로 출력하지만 계산하면 배정밀도 실수가 됩니다. 예를 들어 `9007199254740993 + 0`은 `9007199254740992`입니다.

## 다른 도구와 비교(2026-10-02 실측)

- **[play.jqlang.org](https://play.jqlang.org/)**(jq 프로젝트 공식 Playground, jqplay.org는 이리로 이동)는 브라우저에서 jq 1.8을 실행합니다. `trim`이 동작하고 입력이 담긴 요청은 보이지 않았습니다. 출력과 오류를 함께 보여 주며, `repeat(1)`은 약 30초 뒤 「Operation timed out」이 되었습니다. jq 1.8을 쓴다면 이쪽이 맞습니다.
- **jsonwiz.com/jq-online**(Bing에서 「jq 온라인」 1위)은 esm.sh에서 `jq-wasm@0.3.1`을 불러오는데 esm.sh가 404를 돌려주어, 모든 실행이 「Failed to fetch dynamically imported module」로 끝났습니다.
- **byteflow.tools의 jq 플레이그라운드**는 Chromium 152에서 모든 필터가 `Aborted(CompileError: WebAssembly.instantiate(): … violates the following Content Security Policy …)`로 끝났고, 두 줄짜리 JSON Lines는 실행 전에 「Invalid JSON: Unexpected non-whitespace character after JSON at position 8 (line 2 column 1)」로 막혔습니다.

## 제한

- 입력 외의 파일은 읽지 못합니다. `--slurpfile`, `--rawfile`, `-f`, `-L`, `import`, `include`, `--args` / `--jsonargs`는 쓸 수 없습니다.
- `$ENV`와 `env`는 WebAssembly 실행 환경의 고정값(HOME=/home/web_user)이며 사용자의 환경 변수가 아닙니다. `now`와 지역 시간 함수는 브라우저 시계를 씁니다.
- 2MB가 넘는 입력은 「실행」을 눌러야 실행됩니다. 2MB가 넘는 파일은 편집기에 표시하지 않습니다. 1MB가 넘는 출력은 출력 창에서 잘리지만 복사와 다운로드는 전체입니다.
- 10초(입력 1MB마다 1초 추가)가 넘는 실행은 중지합니다. 메모리 부족이나 너무 깊은 재귀가 나면 엔진을 다시 시작합니다.
- 색상 출력(`-C`)은 없습니다.
