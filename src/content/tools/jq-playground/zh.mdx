## 例子：处理飞书开放平台的响应

飞书开放平台的[调用说明](https://open.feishu.cn/document/server-docs/api-call-guide/calling-process/get-?lang=zh-CN)写明，响应体由 `code`、`msg`、`data` 组成，成功时 `code` 为 0，并要求「请不要依据 msg 来判定一个请求是否失败」。分页接口（如[搜索群列表](https://open.feishu.cn/document/server-docs/group/chat/search?lang=zh-CN)）在 `data` 里返回 `items`、`has_more` 和 `page_token`。下面是按这个结构写的一段响应：

```json
{"code":0,"msg":"success","data":{"items":[
  {"chat_id":"oc_a1","name":"研发周会","external":false,"chat_status":"normal"},
  {"chat_id":"oc_b2","name":"客户对接群","external":true,"chat_status":"normal"},
  {"chat_id":"oc_c3","name":"旧项目群","external":false,"chat_status":"dissolved"}],
  "page_token":"dmJCRHhpd3JR","has_more":true}}
```

{/* jqp-check: {"input": "{\"code\":0,\"msg\":\"success\",\"data\":{\"items\":[\n  {\"chat_id\":\"oc_a1\",\"name\":\"研发周会\",\"external\":false,\"chat_status\":\"normal\"},\n  {\"chat_id\":\"oc_b2\",\"name\":\"客户对接群\",\"external\":true,\"chat_status\":\"normal\"},\n  {\"chat_id\":\"oc_c3\",\"name\":\"旧项目群\",\"external\":false,\"chat_status\":\"dissolved\"}],\n  \"page_token\":\"dmJCRHhpd3JR\",\"has_more\":true}}", "filter": ".data.items[] | select((.external | not) and .chat_status == \"normal\") | \"\\(.chat_id)\\t\\(.name)\"", "flags": {"r": true}, "stdout": "oc_a1\t研发周会\n"} */}

打开 `-r`，过滤器 `.data.items[] | select((.external | not) and .chat_status == "normal") | "\(.chat_id)\t\(.name)"` 输出一行 `oc_a1	研发周会`：只留下内部、未解散的群。翻页脚本里取下一页标记可以用 `if .data.has_more then .data.page_token else empty end`。

{/* jqp-check: {"input": "{\"code\":40004,\"msg\":\"no dept authority error\"}", "filter": ".code == 0", "flags": {"e": true}, "stdout": "false\n", "exit": 1, "hint": ["exitStatus"]} */}

判断成败按文档用 `code`。对失败响应 `{"code":40004,"msg":"no dept authority error"}` 打开 `-e` 运行 `.code == 0`，输出 `false`，退出码为 1，页面在输出旁标出「退出码 1」。shell 脚本里写 `jq -e '.code == 0' resp.json > /dev/null || exit 1` 即可在失败时停下。

## 例子：中文输入法带进来的符号

在中文标点状态下输入过滤器，很容易打出中文引号或句号：

{/* jqp-check: {"input": "{\"code\":0,\"msg\":\"success\",\"data\":{\"items\":[{\"chat_id\":\"oc_a1\",\"name\":\"研发周会\"}]}}", "filter": ".data.items[] | select(.name == “研发周会”) | .chat_id", "flags": {}, "exit": 3, "hint": [], "shown": ["unexpected INVALID_CHARACTER"]} */}

`.data.items[] | select(.name == “研发周会”) | .chat_id` 在 jq 里只得到 `syntax error, unexpected INVALID_CHARACTER (Unix shell quoting issues?)`，退出码 3，不说是哪个字符。本页在过滤器下方列出字符串以外的 “ ” 、。（）｜ 和全角字母数字，点「替换」后改成 ASCII，再运行即输出 `"oc_a1"`。字符串里面的中文（如 `"研发周会"`）不会被改动。

## 例子：Nginx JSON 日志统计

Nginx 的 `log_format` 支持 `escape=json`（[ngx_http_log_module](https://nginx.org/en/docs/http/ngx_http_log_module.html#log_format)），常见写法把每个字段都放进引号，所以状态码和耗时是字符串，每行一个 JSON：

{/* jqp-check: {"input": "{\"status\":\"200\",\"request_time\":\"0.012\",\"uri\":\"/api/v1/orders\"}\n{\"status\":\"502\",\"request_time\":\"1.503\",\"uri\":\"/api/v1/orders\"}\n{\"status\":\"200\",\"request_time\":\"0.004\",\"uri\":\"/health\"}\n{\"status\":\"200\",\"request_time\":\"0.020\",\"uri\":\"/api/v1/orders\"}", "filter": "reduce inputs as $r ({}; .[$r.status] += 1)", "flags": {"n": true, "c": true}, "stdout": "{\"200\":3,\"502\":1}\n"} */}

```
{"status":"200","request_time":"0.012","uri":"/api/v1/orders"}
{"status":"502","request_time":"1.503","uri":"/api/v1/orders"}
{"status":"200","request_time":"0.004","uri":"/health"}
{"status":"200","request_time":"0.020","uri":"/api/v1/orders"}
```

打开 `-n` 和 `-c`，`reduce inputs as $r ({}; .[$r.status] += 1)` 逐行累加，输出 `{"200":3,"502":1}`。找慢请求用 `select((.request_time | tonumber) > 1) | .uri`（加 `-r`）。`-n` 加 `inputs` 一次只读一行；`-s` 会把整个文件读进内存。

## 和终端结果一致

每次运行等于 `jq 选项 过滤器 input.json`，input.json 是输入内容加一个结尾换行。测试用例里 71 组过滤器（选项、变量、JSON Lines、语法与运行错误、`halt_error`、`-e`、`--seq`、`--stream`）在本页引擎和 jq 1.7.1 命令行上逐字节比对 stdout、stderr 和退出码；jq 1.7.1 手册的 241 个例子中，除两个读取 `$PAGER` 环境变量的以外全部一致。

版本用 `jq --version` 查看。Ubuntu 24.04（[1.7.1-3ubuntu0.24.04](https://packages.ubuntu.com/noble/jq)）、Debian 13（[1.7.1-6](https://packages.debian.org/trixie/jq)）和 macOS 27 自带的 `/usr/bin/jq`（输出 `jq-1.7.1-apple`）是 1.7.1；Homebrew 是 [1.8.2](https://formulae.brew.sh/formula/jq)。1.7.1 保留大整数的原始写法，但一做运算就换成双精度浮点：

{/* jqp-check: {"input": "{\"id\": 1830000000000000123}", "filter": ".id, (.id | tostring), .id + 1", "flags": {}, "stdout": "1830000000000000123\n\"1830000000000000123\"\n1.83e+18\n"} */}

对雪花 ID `{"id": 1830000000000000123}` 运行 `.id, (.id | tostring), .id + 1`，前两个输出保持 `1830000000000000123`，第三个变成 `1.83e+18`。

## 与同类工具对比（2026-10-02 实测）

- **[play.jqlang.org](https://play.jqlang.org/)**（jq 项目的官方 Playground，jqplay.org 现跳转到这里）在浏览器里运行 jq 1.8：`trim` 可用，抓包没有发现带输入内容的请求；输出与报错一起显示；`repeat(1)` 约 30 秒后提示 “Operation timed out”。如果你用的是 jq 1.8，用它更合适。
- **json3.com 的「jq在线运行」**（cn.bing.com 搜「jq 在线」靠前）是 JavaScript 重写版：`.[] | .a` 对 `[{"a":1},2]` 只显示「无法索引 number」，不输出前面的 `1`；`9007199254740993` 变成 `9007199254740992`；两行 JSON Lines 报「JSON 不合法」。
- **jqkungfu.com** 在本地运行 jq.wasm，同一个例子只显示 `1`、不显示错误；输入 JSON 有语法错误时，上一次的输出仍留在屏幕上。

## 限制

- 只能读取输入这一个文件：不支持 `--slurpfile`、`--rawfile`、`-f`、`-L`、`import`、`include`，也不支持 `--args` / `--jsonargs`。
- `$ENV`、`env` 是 WebAssembly 运行环境的固定值（HOME=/home/web_user），不是你的环境变量；`now` 和本地时间函数用浏览器的时钟。
- 超过 2 MB 的输入要点「运行」；超过 2 MB 的文件不在编辑框里显示。输出超过 1 MB 时输出框截断显示，复制与下载是完整内容。
- 运行超过 10 秒（每 MB 输入加 1 秒）会被停止；内存耗尽或递归过深时引擎自动重启。
- 不支持彩色输出（`-C`）。
