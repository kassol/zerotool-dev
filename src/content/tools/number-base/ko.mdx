## 예시 1: C의 printf가 찍은 16진수를 음수로 되돌리기

C에서 `int x = -10;`을 `printf("%x", (unsigned)x)`로 출력하면 `int`가 32비트인 환경에서 `fffffff6`이 나옵니다. 로그에서 이 값을 봤다면 16진수를 고르고 2의 보수를 32비트로 정한 뒤 "입력을 부호 있는 수로 읽기"를 체크합니다.

{/* nb: {"in": "fffffff6", "base": 16, "signed": 32, "out": 10, "expect": "-10"} */}

10진수 줄에 `-10`이 나오고, 체크하지 않으면 같은 값을 4294967286으로 읽습니다. 반대로 `-10`을 입력하면 32비트 16진수 줄에 `FFFFFFF6`, 8비트로 바꾸면 `F6`이 나옵니다.

{/* nb: {"in": "-10", "base": 10, "twos": 32, "field": "hex", "expect": "FFFFFFF6"} */}

## 예시 2: 64비트 최댓값이 바뀌지 않는지 확인하기

JavaScript의 `Number`는 2^53 − 1까지만 정수를 정확히 담습니다([MDN](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Number/MAX_SAFE_INTEGER)). 이 도구는 BigInt로 한 자리씩 읽기 때문에 16진수 `FFFFFFFFFFFFFFFF`(부호 없는 64비트 최댓값)가 정확히 다음 값이 됩니다.

{/* nb: {"in": "FFFFFFFFFFFFFFFF", "base": 16, "out": 10, "expect": "18446744073709551615"} */}

`18446744073709551615`. Python의 `int()`는 기본 설정에서 10진수 4,300자리를 넘는 문자열을 거부합니다([Python 문서](https://docs.python.org/3/library/stdtypes.html#int-max-str-digits)). 이 도구는 20,000자리까지 변환합니다.

## 예시 3: 띄어 쓴 2진수 그대로 붙여 넣기

교재나 데이터시트는 2진수를 4자리씩 띄어 씁니다. `1101 0110`을 그대로 붙여 넣으면 공백을 구분 기호로 보고 10진수 `214`, 16진수 `D6`을 냅니다. 밑줄(`1101_0110`)과 C++14의 작은따옴표(`1101'0110`)도 같은 방식으로 처리합니다.

{/* nb: {"in": "1101 0110", "base": 2, "out": 16, "expect": "D6"} */}

## 예시 4: 소수 변환

10진수 `0.75`는 2진수 `0.11`, 16진수 `0.C`로 딱 끝납니다. `0.1`은 2진수 `0.0(0011)`, 16진수 `0.1(9)`처럼 괄호 안이 끝없이 반복됩니다. JavaScript의 수는 IEEE 754 배정밀도라서 0.1을 근삿값으로 저장하고, 그래서 `0.1 + 0.2`가 `0.3`이 되지 않습니다. 이 도구는 분수로 정확히 계산하며 반올림하지 않습니다.

{/* nb: {"in": "0.75", "base": 10, "out": 2, "expect": "0.11"} */}
{/* nb: {"in": "0.1", "base": 10, "out": 16, "expect": "0.1(9)"} */}

## 입력 규칙과 오류 메시지

| 입력 | 읽는 방법 |
|---|---|
| `1111_0000`, `1111 0000` | 숫자 사이의 구분 기호는 무시 |
| `1,234,567` | 10진수의 세 자리 구분으로만 읽음 |
| `0x1F`, `0o17`, `0b101` | 입력 진법과 맞는 접두사는 떼어 냄. 10진수를 고른 상태에서는 접두사로 진법을 판단 |
| `２５５`, `ＦＦ` | 전각 문자를 반각으로 읽음 |
| `#FF5733` | 16진수에서 색상 코드로 읽음 |

그 밖의 문자가 있으면 변환을 멈추고 위치를 알려 줍니다. 10진수에서 `1F`를 입력하면 "2번째 문자 “F”는 10진수 숫자가 아닙니다(사용 가능: 0–9). 16진수라면 16진법을 고르거나 앞에 0x를 붙이세요."라고 표시합니다.

{/* nb: {"in": "1F", "base": 10, "error": "invalidDigit"} */}

## 제한 사항

- 2~36진법(숫자 0–9와 영문 A–Z)을 지원하며 Python `int()`, JavaScript `toString()`과 같은 범위입니다. 58진법, 62진법, Base64 문자 표는 지원하지 않습니다.
- 한 수에 20,000자리까지.
- `0.0(0011)`의 괄호는 읽기용 표기라서 입력란에 다시 붙여 넣을 수 없습니다.
- 부동소수점 수의 IEEE 754 비트 구성(부호·지수·가수)은 보여 주지 않습니다.
- 2의 보수는 정수에만 쓸 수 있고, 비트 수는 8·16·32·64·128 중에서 고릅니다.
