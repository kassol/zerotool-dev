<h2>使い方</h2>
<ol>
  <li>CSVデータを左パネルに貼り付けます。</li>
  <li>列の配置を選択します：<strong>左揃え</strong>、<strong>中央揃え</strong>、または<strong>右揃え</strong>。</li>
  <li>右パネルに自動的にMarkdownテーブルが表示されます。</li>
  <li><strong>コピー</strong>をクリックして結果をクリップボードにコピーします。</li>
</ol>

<h2>Markdownテーブルの構文</h2>

Markdownテーブルはヘッダー行・区切り行・データ行で構成され、パイプ文字（`|`）で列を区切ります。

```
| Name  | Age | City     |
| :---- | :-- | :------- |
| Alice | 30  | New York |
| Bob   | 25  | London   |
```

区切り行で配置を制御します：`:---` = 左揃え、`:---:` = 中央揃え、`---:` = 右揃え。

<h2>ヒント</h2>
<ul>
  <li>セル値内のパイプ文字（<code>|</code>）は自動的に <code>\|</code> にエスケープされます。</li>
  <li>引用符付きCSVフィールド内の改行は出力では半角スペースに変換されます。</li>
  <li>JSON出力が必要な場合は <a href="/ja/tools/csv-json/">CSV to JSON</a> ツールをご利用ください。</li>
</ul>

## 変換例

入力（配置は「右揃え」）：

```csv
product,price,units
Widget,9.99,150
"Gadget, large",24.99,42
Cmd|Ctrl+C,1,2
```

出力：

```markdown
| product       | price | units |
| --------------: | ------: | ------: |
| Widget        | 9.99  | 150   |
| Gadget, large | 24.99 | 42    |
| Cmd\|Ctrl+C   | 1     | 2     |
```

- `"Gadget, large"` の引用符は外れ、カンマはセルに残ります。
- 値の中の `|` は `\|` と書き出されるので、列の区切りになりません。
- 区切り行はほかの行より幅が広くなりますが、Markdown のレンダラーは気にしないので表は正しく表示されます。

## Markdown の表が表示される場所

GitHub と GitLab では、README、Issue、プルリクエスト、Wiki でこの表の書き方が表示されます（[GFM 仕様：表](https://github.github.com/gfm/#tables-extension-)）。表は拡張構文なので、拡張なしの CommonMark ではただのテキストになります。Qiita と Zenn の Markdown も表に対応しています。Docusaurus、MkDocs、VitePress などの静的サイトジェネレーターも GFM の表を扱えます。

## 制限事項

- **区切り文字はカンマだけ。** Excel や Google スプレッドシートからコピーしたテキストはタブ区切りで、地域によってはセミコロン区切りの CSV もあります。どちらも 1 列になってしまうので、先にカンマ区切りの CSV として保存してください。
- **列数はヘッダー行で決まります。** ヘッダーより項目が多い行は、余った項目が警告なしに消えます。少ない行は空のセルで埋めます。
- **配置は全列共通。** 数値の列だけ右揃えにしたいときは、コピー後に区切り行を `| :--- | ---: | ---: |` のように書き換えます。
- **セル内の改行はスペースになります。** Markdown の表のセルには改行を入れられません。HTML が使えるレンダラーなら手で `<br>` を書きます。
- **書式は変換しません。** セルの文字はそのまま出力されるので、`*` や `_` が Markdown の強調として解釈されることがあります。
