<h2>Markdown 표 문법</h2>

Markdown 표는 헤더 행, 구분 행, 데이터 행으로 구성되며 파이프 문자(`|`)로 열을 구분합니다.

```
| Name  | Age | City     |
| :---- | :-- | :------- |
| Alice | 30  | New York |
| Bob   | 25  | London   |
```

구분 행으로 정렬을 제어합니다: `:---` = 왼쪽, `:---:` = 가운데, `---:` = 오른쪽.

## 지점별 매출 표

주간 보고서에 넣을 지점별 매출입니다(예시 데이터). 천 단위 쉼표가 있는 금액은 따옴표로 감쌌고, 비고에는 파이프가 들어 있습니다.

{/* cm-check: {"align":"left"} */}

```csv
지역,매출(원),비고
서울,"1,250,000",
부산,"980,000","신규 매장 | 10월 오픈"
```

```markdown
| 지역  | 매출(원)     | 비고              |
| :---- | :---------- | :---------------- |
| 서울  | 1,250,000 |                 |
| 부산  | 980,000   | 신규 매장 \| 10월 오픈 |
```

- 따옴표는 빠지고 `1,250,000`의 쉼표는 셀 안에 남습니다. 따옴표가 없으면 `1`, `250`, `000`이 각각 다른 열로 나뉩니다.
- 비고의 `|`는 `\|`로 바뀌어 렌더링 후에도 한 셀 안의 파이프로 보입니다.
- 열 너비는 글자 수로 세어 공백을 채웁니다. 한글은 고정폭 글꼴에서 두 칸을 차지하므로 원문에서는 열이 어긋나 보이지만, 렌더링된 표에는 영향이 없습니다.

## 일정표: 줄바꿈과 남는 필드

가운데 정렬로 바꾼 일정표입니다. 첫 일정의 내용에는 따옴표 안에 줄바꿈이 있고, 둘째 일정에는 헤더보다 필드가 하나 더 있습니다.

{/* cm-check: {"align":"center","status":true} */}

```csv
날짜,시간,내용
10/13(월),10:00,"주간 회의
(3층 회의실)"
10/15(수),14:00,고객 미팅,온라인
```

```markdown
| 날짜       | 시간    | 내용             | Column 4 |
| :--------: | :-----: | :--------------: | :--------: |
| 10/13(월) | 10:00 | 주간 회의 (3층 회의실) |          |
| 10/15(수) | 14:00 | 고객 미팅          | 온라인      |
```

상태 표시줄에는 `2행을 Markdown 표로 변환했습니다. 헤더보다 필드가 많은 행이 있어 다음 열을 추가했습니다: Column 4.`가 나옵니다. 따옴표 안의 줄바꿈은 공백 하나가 되었고, 남는 `온라인`은 버려지지 않고 `Column 4` 열에 들어갔습니다. 열 이름은 복사한 뒤 원하는 이름으로 바꾸세요.

## 영문 데이터 예시

오른쪽 정렬을 고른 경우입니다.

{/* cm-check: {"align":"right"} */}

```csv
product,price,units
Widget,9.99,150
"Gadget, large",24.99,42
Cmd|Ctrl+C,1,2
```

```markdown
| product       | price | units |
| --------------: | ------: | ------: |
| Widget        | 9.99  | 150   |
| Gadget, large | 24.99 | 42    |
| Cmd\|Ctrl+C   | 1     | 2     |
```

구분 행이 다른 행보다 넓지만 Markdown 렌더러는 이를 무시하므로 표는 정상적으로 보입니다.

## 파이프와 따옴표

둘째 행의 파이프는 이미 이스케이프되어 있고, 셋째 행에는 필드 중간에 인치 기호가 있습니다.

{/* cm-check: {"align":"left"} */}

```csv
표기,의미
a|b,a 또는 b
a\|b,이스케이프됨
5" 파이프,인치 기호
```

```markdown
| 표기     | 의미     |
| :------- | :------- |
| a\|b   | a 또는 b |
| a\|b   | 이스케이프됨 |
| 5" 파이프 | 인치 기호  |
```

그냥 `|`에는 백슬래시가 붙고 이미 `\|`인 것은 그대로라서, 두 행 모두 `a|b`로 보이고 셀이 나뉘지 않습니다. `5` 뒤의 `"`는 필드 맨 앞이 아니므로 문자로 셀에 남습니다.

## Markdown 표가 렌더링되는 곳

GitHub과 GitLab은 README, 이슈, 풀 리퀘스트, 위키에서 이 표 문법을 렌더링합니다([GFM 명세: 표](https://github.github.com/gfm/#tables-extension-)). 표는 확장 문법이라 확장 없는 CommonMark에서는 일반 텍스트로 보입니다. Docusaurus, MkDocs, VitePress 같은 정적 사이트 생성기도 GFM 표를 지원합니다. JSON이 필요하면 <a href="/ko/tools/csv-json/">CSV JSON 변환기</a>를 사용하세요.

## 제한 사항

- **쉼표만 구분자로 인식합니다.** Excel이나 Google 스프레드시트에서 바로 복사한 텍스트는 탭으로 구분되고, 일부 지역의 CSV는 세미콜론을 씁니다. 둘 다 한 열이 되므로 먼저 쉼표 구분 CSV로 저장하세요.
- **헤더보다 긴 행이 있으면 열을 추가합니다.** 열 수는 가장 긴 행에 맞춥니다. 헤더가 없는 열은 위치에 따라 `Column N`(네 번째 열이면 `Column 4`)으로 이름 붙이고 상태 표시줄에 표시합니다. 필드가 적은 행은 빈 셀로 채웁니다.
- **모든 열에 같은 정렬.** 숫자 열만 오른쪽 정렬하려면 복사한 뒤 구분 행을 `| :--- | ---: | ---: |`처럼 고치세요.
- **셀 안의 줄바꿈은 공백이 됩니다.** Markdown 표 셀에는 줄바꿈을 넣을 수 없습니다. HTML을 허용하는 렌더러라면 `<br>`을 직접 쓰세요.
- **서식은 변환하지 않습니다.** 셀 텍스트를 그대로 출력하므로 `*`, `_`가 Markdown 강조로 해석될 수 있습니다.
- **파이프는 [Markdown 표 생성기](/ko/tools/markdown-table-generator/)와 같은 규칙으로 이스케이프합니다.** 앞에 오는 백슬래시가 짝수 개인 파이프에만 백슬래시를 붙이므로, 셀에 이미 `\|`가 있으면 `\|` 그대로 출력되고 `|`로 보입니다. 백슬래시 자체를 보이게 하려면 CSV에 `\\|`라고 쓰세요. GitHub과 micromark 계열 렌더러(remark, MDX, Astro) 모두 셀이 나뉘지 않습니다.
- **필드 맨 앞의 큰따옴표만 따옴표로 봅니다.** 따옴표 없는 필드 중간의 `"`는 일반 문자라서 `5" 파이프`는 그대로 남습니다. 닫히지 않은 따옴표가 있으면 변환을 멈추고 따옴표가 시작된 행 번호를 오류로 알려 줍니다.
