<h2>사용 방법</h2>
<ol>
  <li>왼쪽 패널에 CSV 데이터를 붙여 넣습니다.</li>
  <li>열 정렬을 선택합니다: <strong>왼쪽</strong>, <strong>가운데</strong>, 또는 <strong>오른쪽</strong>.</li>
  <li>오른쪽 패널에 자동으로 Markdown 표가 표시됩니다.</li>
  <li><strong>복사</strong>를 클릭해 결과를 클립보드에 복사합니다.</li>
</ol>

<h2>Markdown 표 문법</h2>

Markdown 표는 헤더 행, 구분 행, 데이터 행으로 구성되며 파이프 문자(`|`)로 열을 구분합니다.

```
| Name  | Age | City     |
| :---- | :-- | :------- |
| Alice | 30  | New York |
| Bob   | 25  | London   |
```

구분 행으로 정렬을 제어합니다: `:---` = 왼쪽, `:---:` = 가운데, `---:` = 오른쪽.

<h2>팁</h2>
<ul>
  <li>셀 값 내의 파이프 문자(<code>|</code>)는 자동으로 <code>\|</code>로 이스케이프됩니다.</li>
  <li>따옴표 CSV 필드 내의 줄바꿈은 출력에서 공백 하나로 변환됩니다.</li>
  <li>JSON 출력이 필요한 경우 <a href="/ko/tools/csv-json/">CSV to JSON</a> 도구를 사용하세요.</li>
</ul>

## 변환 예시

입력 (정렬은 「오른쪽」):

```csv
product,price,units
Widget,9.99,150
"Gadget, large",24.99,42
Cmd|Ctrl+C,1,2
```

출력:

```markdown
| product       | price | units |
| --------------: | ------: | ------: |
| Widget        | 9.99  | 150   |
| Gadget, large | 24.99 | 42    |
| Cmd\|Ctrl+C   | 1     | 2     |
```

- `"Gadget, large"`의 따옴표는 빠지고 쉼표는 셀에 남습니다.
- 값 안의 `|`는 `\|`로 출력되어 새 열로 나뉘지 않습니다.
- 구분 행이 다른 행보다 넓지만 Markdown 렌더러는 이를 무시하므로 표는 정상적으로 보입니다.

## Markdown 표가 렌더링되는 곳

GitHub와 GitLab은 README, 이슈, 풀 리퀘스트, 위키에서 이 표 문법을 렌더링합니다([GFM 명세: 표](https://github.github.com/gfm/#tables-extension-)). 표는 확장 문법이라 확장 없는 CommonMark에서는 일반 텍스트로 보입니다. Docusaurus, MkDocs, VitePress 같은 정적 사이트 생성기도 GFM 표를 지원합니다.

## 제한 사항

- **쉼표만 구분자로 인식합니다.** Excel이나 Google 스프레드시트에서 바로 복사한 텍스트는 탭으로 구분되고, 일부 지역의 CSV는 세미콜론을 씁니다. 둘 다 한 열이 되므로 먼저 쉼표 구분 CSV로 저장하세요.
- **열 수는 헤더 행이 정합니다.** 헤더보다 필드가 많은 행은 남는 필드가 경고 없이 사라집니다. 적은 행은 빈 셀로 채웁니다.
- **모든 열에 같은 정렬.** 숫자 열만 오른쪽 정렬하려면 복사한 뒤 구분 행을 `| :--- | ---: | ---: |`처럼 고치세요.
- **셀 안의 줄바꿈은 공백이 됩니다.** Markdown 표 셀에는 줄바꿈을 넣을 수 없습니다. HTML을 허용하는 렌더러라면 `<br>`을 직접 쓰세요.
- **서식은 변환하지 않습니다.** 셀 텍스트를 그대로 출력하므로 `*`, `_`가 Markdown 강조로 해석될 수 있습니다.
