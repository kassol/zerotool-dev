<h2>使用方法</h2>
<ol>
  <li>将 CSV 数据粘贴到左侧面板。</li>
  <li>选择列对齐方式：<strong>左对齐</strong>、<strong>居中</strong>或<strong>右对齐</strong>。</li>
  <li>右侧面板自动显示 Markdown 表格。</li>
  <li>点击<strong>复制</strong>将结果复制到剪贴板。</li>
</ol>

<h2>Markdown 表格语法</h2>

Markdown 表格由表头行、分隔行和数据行组成，竖线符（`|`）分隔列。

```
| 姓名  | 年龄 | 城市     |
| :---- | :--- | :------- |
| Alice | 30   | 纽约     |
| Bob   | 25   | 伦敦     |
```

分隔行控制对齐：`:---` = 左对齐，`:---:` = 居中，`---:` = 右对齐。

<h2>使用技巧</h2>
<ul>
  <li>单元格值中的竖线（<code>|</code>）会自动转义为 <code>\|</code>。</li>
  <li>引号 CSV 字段内的换行符在输出中会被合并为空格。</li>
  <li>如需 JSON 输出，请使用 <a href="/zh/tools/csv-json/">CSV to JSON</a> 工具。</li>
</ul>

## 示例

输入，对齐方式选「右对齐」：

```csv
product,price,units
Widget,9.99,150
"Gadget, large",24.99,42
Cmd|Ctrl+C,1,2
```

输出：

```markdown
| product       | price | units |
| --------------: | ------: | ------: |
| Widget        | 9.99  | 150   |
| Gadget, large | 24.99 | 42    |
| Cmd\|Ctrl+C   | 1     | 2     |
```

- `"Gadget, large"` 的引号被去掉，逗号留在单元格里。
- 值里的 `|` 写成 `\|`，不会被当作新的一列。
- 分隔行比其他行宽，Markdown 渲染器会忽略这一点，表格照常显示。

## 哪里能渲染 Markdown 表格

GitHub、GitLab（含极狐 GitLab）的 README、Issue、PR 和 Wiki 都能渲染这种表格语法（[GFM 规范：表格](https://github.github.com/gfm/#tables-extension-)）。表格是扩展语法，不带扩展的 CommonMark 会把它显示成普通文本。Docusaurus、MkDocs、VitePress 等静态站点生成器都支持 GFM 表格。

## 限制

- **只认逗号。** 从 Excel、WPS 或 Google 表格直接复制的内容是 Tab 分隔的，有些地区的 CSV 用分号分隔，两者都会变成一列。先把表格另存为逗号分隔的 CSV。
- **比表头长的行会补列。** 表格的列数取最长的那一行。没有表头的列按位置命名为 `Column N`（第 4 列为 `Column 4`），状态栏会列出补上的列。比表头短的行补空单元格。
- **所有列用同一种对齐。** 只想让数字列右对齐时，复制后手动改分隔行，例如 `| :--- | ---: | ---: |`。
- **单元格里的换行变成空格。** Markdown 表格单元格不能换行；渲染器允许 HTML 时可以手动写 `<br>`。
- **不做格式处理。** 单元格文本原样输出，`*`、`_` 等字符仍可能被当作 Markdown 强调。
