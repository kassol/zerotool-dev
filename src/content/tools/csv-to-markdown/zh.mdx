<h2>Markdown 表格语法</h2>

Markdown 表格由表头行、分隔行和数据行组成，竖线符（`|`）分隔列。

```
| 姓名  | 年龄 | 城市     |
| :---- | :--- | :------- |
| Alice | 30   | 纽约     |
| Bob   | 25   | 伦敦     |
```

分隔行控制对齐：`:---` = 左对齐，`:---:` = 居中，`---:` = 右对齐。

## 把接口字段说明转成表格

写接口文档时，字段说明常先在表格软件里整理，再导出 CSV 贴进 README。下面这份字段表的“说明”列里有竖线，也有加了引号的全角逗号：

{/* cm-check: {"align":"left"} */}

```csv
字段,类型,必填,说明
status,int,是,0 正常 | 1 禁用
nickname,string,否,"昵称，最多 20 个字"
created_at,string,是,
```

```markdown
| 字段         | 类型     | 必填  | 说明           |
| :----------- | :------- | :---- | :------------- |
| status     | int    | 是   | 0 正常 \| 1 禁用 |
| nickname   | string | 否   | 昵称，最多 20 个字  |
| created_at | string | 是   |              |
```

- “说明”里的 `|` 写成了 `\|`，渲染后仍是一个单元格，显示为竖线。
- 引号里的全角逗号原样保留。全角逗号本来就不是分隔符，这里不加引号结果也一样。
- `created_at` 那一行以逗号结尾，说明为空，渲染为空单元格。
- 列宽按字符个数补空格。一个汉字在等宽字体里占两格，所以源码里含中文的列看起来没对齐，渲染出来的表格不受影响。

## 右对齐的数字列

对齐方式选「右对齐」：

{/* cm-check: {"align":"right"} */}

```csv
product,price,units
Widget,9.99,150
"Gadget, large",24.99,42
Cmd|Ctrl+C,1,2
```

```markdown
| product       | price | units |
| --------------: | ------: | ------: |
| Widget        | 9.99  | 150   |
| Gadget, large | 24.99 | 42    |
| Cmd\|Ctrl+C   | 1     | 2     |
```

`"Gadget, large"` 的引号被去掉，逗号留在单元格里。分隔行比其他行宽，渲染器会忽略这一点。对齐方式对所有列生效，文字列也跟着右对齐。

## 全角逗号与制表符

用中文输入法录入时容易打出全角逗号，它不是分隔符：

{/* cm-check: {"align":"left"} */}

```csv
姓名，部门
王芳，研发
```

```markdown
| 姓名，部门 |
| :------ |
| 王芳，研发 |
```

整行成了一列。从 Excel、WPS 或 Google 表格直接复制的内容是制表符分隔的，同样只有一列。先替换成半角逗号，或把表格另存为逗号分隔的 CSV 再粘贴。

## 哪里能渲染 Markdown 表格

GitHub、GitLab（含极狐 GitLab）的 README、Issue、PR 和 Wiki 都能渲染这种表格语法（[GFM 规范：表格](https://github.github.com/gfm/#tables-extension-)）。表格是扩展语法，不带扩展的 CommonMark 会把它显示成普通文本。Docusaurus、MkDocs、VitePress 等静态站点生成器都支持 GFM 表格。需要 JSON 而不是表格时，请用 <a href="/zh/tools/csv-json/">CSV JSON 互转工具</a>。

## 限制

- **只认半角逗号。** 制表符、分号、全角逗号都不是分隔符，有些地区的 CSV 用分号分隔，同样会变成一列。
- **比表头长的行会补列。** 表格的列数取最长的那一行。没有表头的列按位置命名为 `Column N`（第 4 列为 `Column 4`），状态栏会列出补上的列。比表头短的行补空单元格。
- **所有列用同一种对齐。** 只想让数字列右对齐时，复制后手动改分隔行，例如 `| :--- | ---: | ---: |`。
- **单元格里的换行变成空格。** Markdown 表格单元格不能换行；渲染器允许 HTML 时可以手动写 `<br>`。
- **不做格式处理。** 单元格文本原样输出，`*`、`_` 等字符仍可能被当作 Markdown 强调。
- **竖线前已有的反斜杠不会再转义。** 单元格里原本就是 `\|` 时，输出为 `\\|`。GitHub 把它当作一个单元格，micromark 系的渲染器（remark、MDX、Astro）会在这里切开单元格，竖线后的文字移到下一格或被丢掉。请先在 CSV 里去掉这个反斜杠。
- **字段中间的双引号会开启引号段。** 例如 `5" 管,x`，`"` 之后的逗号和换行都会并进同一个单元格，直到遇到下一个 `"`。请把整个字段加引号，并把里面的引号写成两个：`"5"" 管"`。引号一直没有闭合时，后面的全部文本都并进这一格，不会报错。
