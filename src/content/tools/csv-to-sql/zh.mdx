<h2>使用方法</h2>
<ol>
  <li>在 <strong>CSV 输入</strong>框中粘贴 CSV，或点击<strong>上传 CSV</strong> 载入 UTF-8 文件。</li>
  <li>选择 <strong>SQL 方言</strong>（MySQL、PostgreSQL 或 SQLite）。</li>
  <li>填写<strong>表名</strong>，默认 <code>my_table</code>。</li>
  <li>选择<strong>批量 INSERT</strong>（一条语句多行）或<strong>逐行 INSERT</strong>（每行一条语句）。</li>
  <li>表还不存在时，勾选<strong>添加 CREATE TABLE</strong>。</li>
  <li>SQL 输出即时更新，点击<strong>复制</strong>即可。</li>
</ol>

<h2>值的写法</h2>
<ul>
  <li>空字段输出 <code>NULL</code>。</li>
  <li>非空单元格全是普通数字（<code>42</code>、<code>-7</code>、<code>19.90</code>）的列不加引号。普通数字指没有前导零、没有 <code>+</code>、没有指数、最多 15 位数字。</li>
  <li>其他列一律输出带引号的字符串，其中的数字也加引号，所以 <code>02134</code>、<code>1e5</code>、20 位卡号都保持原文。目标列是数值类型时，MySQL、PostgreSQL、SQLite 都会自动转换带引号的数字。</li>
  <li>所有方言都把单引号写成两个（<code>O''Brien</code>）。MySQL 还会把反斜杠加倍：MySQL 默认的 SQL 模式把字符串里的 <code>\n</code> 读成换行（<a href="https://dev.mysql.com/doc/refman/8.4/en/string-literals.html" target="_blank" rel="noopener">MySQL 8.4 Reference Manual, String Literals</a>，表 11.1）。PostgreSQL 在 <code>standard_conforming_strings</code> 开启时（9.1 起的默认值，<a href="https://www.postgresql.org/docs/current/sql-syntax-lexical.html#SQL-SYNTAX-STRINGS" target="_blank" rel="noopener">PostgreSQL 4.1.2.1</a>）和 SQLite 都把反斜杠原样保存。</li>
  <li>超出表头的单元格会补上 <code>column_3</code>、<code>column_4</code> 等列，并在状态栏列出。较短的行用 <code>NULL</code> 补齐。</li>
</ul>

<h2>示例：引号、前导零与空字段</h2>

<p>输入（SQLite，批量模式，表名 <code>customers</code>）：</p>

{/* sql: {"dialect":"sqlite","table":"customers","mode":"batch"} */}

<pre><code>{`id,name,zip,note
1,"O'Brien, Pat",02134,
2,Lee,10001,"path C:\\new"`}</code></pre>

<pre><code>{`INSERT INTO "customers" ("id", "name", "zip", "note") VALUES
  (1, 'O''Brien, Pat', '02134', NULL),
  (2, 'Lee', '10001', 'path C:\\new');`}</code></pre>

<p>带引号的 <code>"O'Brien, Pat"</code> 保留了逗号，空的 <code>note</code> 成为 <code>NULL</code>。<code>02134</code> 让 zip 列成为文本列，所以 <code>10001</code> 也加了引号。在 SQLite 3 中执行后，<code>SELECT zip FROM customers</code> 返回 <code>02134</code> 和 <code>10001</code>。</p>

<p>同样的输入选 MySQL 时反斜杠加倍，存进去的仍是 <code>path C:\new</code>：</p>

{/* sql: {"dialect":"mysql","table":"customers","mode":"batch"} */}

<pre><code>{`id,name,zip,note
1,"O'Brien, Pat",02134,
2,Lee,10001,"path C:\\new"`}</code></pre>

<pre><code>{`INSERT INTO \`customers\` (\`id\`, \`name\`, \`zip\`, \`note\`) VALUES
  (1, 'O''Brien, Pat', '02134', NULL),
  (2, 'Lee', '10001', 'path C:\\\\new');`}</code></pre>

<p>如果服务器的 <code>sql_mode</code> 含 <code>NO_BACKSLASH_ESCAPES</code>，反斜杠就是普通字符，这时请改用 PostgreSQL 或 SQLite 的输出。</p>

<h2>示例：CREATE TABLE</h2>

<p>勾选<strong>添加 CREATE TABLE</strong> 后，列类型按值选择：整数为 <code>INTEGER</code>（MySQL 为 <code>INT</code>，超过 2,147,483,647 为 <code>BIGINT</code>），带小数点的数字为 <code>DOUBLE PRECISION</code>（MySQL 为 <code>DOUBLE</code>，SQLite 为 <code>REAL</code>），其余为 <code>TEXT</code>。PostgreSQL：</p>

{/* sql: {"dialect":"postgresql","table":"orders","mode":"batch","createTable":true} */}

<pre><code>{`order_id,amount,paid_at
1001,19.90,2026-09-30
1002,5,`}</code></pre>

<pre><code>{`CREATE TABLE "orders" ("order_id" INTEGER, "amount" DOUBLE PRECISION, "paid_at" TEXT);
INSERT INTO "orders" ("order_id", "amount", "paid_at") VALUES
  (1001, 19.90, '2026-09-30'),
  (1002, 5, NULL);`}</code></pre>

<p>类型有讲究时请先改再执行：金额应使用 <code>NUMERIC</code> / <code>DECIMAL</code>，<code>paid_at</code> 这类日期应使用 <code>DATE</code> 或 <code>TIMESTAMP</code>。工具不添加主键与约束。</p>

<h2>示例：单元格比表头多</h2>

{/* sql: {"dialect":"sqlite","table":"stock","mode":"individual"} */}

<pre><code>{`sku,qty
A-1,3,fragile
B-2,5`}</code></pre>

<pre><code>{`INSERT INTO "stock" ("sku", "qty", "column_3") VALUES ('A-1', 3, 'fragile');
INSERT INTO "stock" ("sku", "qty", "column_3") VALUES ('B-2', 5, NULL);`}</code></pre>

<p>状态栏会报告补上的 <code>column_3</code>，需要正式列名时在表头行里改名即可。</p>

<h2>限制</h2>
<ul>
  <li>分隔符只支持逗号，第一行总是表头。分号或制表符分隔的文件需要先转换。</li>
  <li>类型只根据文本判断，日期、布尔值和 <code>1e5</code> 都按字符串处理。</li>
  <li>表名和列名作为单个标识符加引号，<code>public.users</code> 会成为一个含点号的名字。</li>
  <li>大文件在浏览器标签页中一次性转换；上百万行请用数据库自带的批量导入（<code>LOAD DATA</code>、<code>COPY</code>、<code>.import</code>）。</li>
</ul>
