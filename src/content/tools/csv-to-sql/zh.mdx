<h2>使用方法</h2>
<ol>
  <li>将 CSV 数据粘贴到 <strong>CSV 输入</strong>区域，或点击 <strong>上传 CSV</strong> 加载文件。</li>
  <li>选择 <strong>SQL 方言</strong>（MySQL、PostgreSQL 或 SQLite）。</li>
  <li>输入<strong>表名</strong>，默认为 <code>my_table</code>。</li>
  <li>选择<strong>批量 INSERT</strong>（单条语句含多行）或<strong>逐行 INSERT</strong>（每行单独一条语句）。</li>
  <li>SQL 输出会即时更新，点击<strong>复制</strong>即可复制到剪贴板。</li>
</ol>

<h2>NULL 值处理</h2>
<ul>
  <li>CSV 中的空字段会输出为不带引号的 <code>NULL</code>。</li>
  <li>仅包含空格的字段视为字符串，不会转换为 NULL。</li>
  <li>纯数字值（整数和小数）不加引号，以数值类型存储。</li>
  <li>其他所有值用单引号包裹，内部的单引号转义为 <code>''</code>。</li>
</ul>

<h2>示例：引号、前导零与空字段</h2>

<p>输入：</p>

<pre><code>{`id,name,zip,note
1,"O'Brien, Pat",02134,
2,Lee,10001,"path C:\\new"`}</code></pre>

<p>输出（SQLite 方言，批量模式，表名 <code>{"customers"}</code>）：</p>

<pre><code>{`INSERT INTO "customers" ("id", "name", "zip", "note") VALUES
  (1, 'O''Brien, Pat', 02134, NULL),
  (2, 'Lee', 10001, 'path C:\\new');`}</code></pre>

<p>先建表，再导入 SQLite 3：</p>

<pre><code>{`CREATE TABLE customers (id INTEGER, name TEXT, zip TEXT, note TEXT);
-- run the INSERT above, then:
SELECT * FROM customers;
-- 1 | O'Brien, Pat | 2134  | NULL
-- 2 | Lee          | 10001 | path C:\\new`}</code></pre>

<ul>
  <li>带引号的字段 <code>{"\"O'Brien, Pat\""}</code> 保留了逗号，单引号被写成两个（<code>{"''"}</code>）。</li>
  <li>空的 <code>{"note"}</code> 变成 <code>{"NULL"}</code>；工具无法生成空字符串 <code>{"''"}</code>。</li>
  <li><code>{"02134"}</code> 看起来是数字，所以不加引号写出，前导零丢失——即使列是 TEXT 也一样。这类值（邮编、电话号码、编号）请手动加引号：</li>
</ul>

<pre><code>{`INSERT INTO "customers" ("id", "name", "zip", "note") VALUES
  (1, 'O''Brien, Pat', '02134', NULL),
  (2, 'Lee', '10001', 'path C:\\new');`}</code></pre>

<h2>限制</h2>

<ul>
  <li>工具只生成 <code>{"INSERT"}</code> 语句，不生成 <code>{"CREATE TABLE"}</code>；请先按需要的列类型建表。</li>
  <li>MySQL 默认把字符串里的反斜杠当作转义符，除非开启 <code>{"NO_BACKSLASH_ESCAPES"}</code>（<a href="https://dev.mysql.com/doc/refman/8.4/en/string-literals.html" target="_blank" rel="noopener">MySQL string literals</a>）。工具只把单引号写成两个，所以上面的 <code>{"C:\\new"}</code> 在 MySQL 里会存成带换行的文本。PostgreSQL（标准字符串）和 SQLite 会原样保存。</li>
  <li>类型只按模式判断：<code>{"-?数字(.数字)?"}</code> 是数字，其他都加引号当字符串。日期、布尔值和 <code>{"1e5"}</code> 都写成字符串。</li>
  <li>第一行固定当表头。超出表头列数的单元格会被丢弃，没有提示。</li>
  <li>大文件在浏览器标签页里一次性转换；百万行级别请用数据库自带的批量导入（<code>{"LOAD DATA"}</code>、<code>{"COPY"}</code>、<code>{".import"}</code>）。</li>
</ul>
