<h2>사용 방법</h2>
<ol>
  <li>CSV 데이터를 <strong>CSV 입력</strong> 텍스트 영역에 붙여넣거나 <strong>CSV 업로드</strong>를 클릭하여 파일을 불러옵니다.</li>
  <li><strong>SQL 방언</strong>(MySQL, PostgreSQL, SQLite)을 선택합니다.</li>
  <li><strong>테이블명</strong>을 입력합니다. 기본값은 <code>my_table</code>입니다.</li>
  <li><strong>배치 INSERT</strong>(하나의 문에 여러 행) 또는 <strong>개별 INSERT</strong>(행마다 하나의 문)를 선택합니다.</li>
  <li>SQL 출력이 즉시 업데이트됩니다. <strong>복사</strong>를 클릭하여 클립보드에 복사합니다.</li>
</ol>

<h2>NULL 값 처리</h2>
<ul>
  <li>CSV의 빈 필드는 SQL 출력에서 따옴표 없는 <code>NULL</code>이 됩니다.</li>
  <li>공백만 있는 필드는 문자열로 처리되며 NULL이 되지 않습니다.</li>
  <li>순수한 숫자(정수 및 소수)는 따옴표 없이 출력되어 숫자 타입으로 저장됩니다.</li>
  <li>다른 모든 값은 작은따옴표로 감싸지며, 내부의 작은따옴표는 <code>''</code>로 이스케이프됩니다.</li>
</ul>

<h2>예시: 따옴표, 앞자리 0, 빈 칸</h2>

<p>입력:</p>

<pre><code>{`id,name,zip,note
1,"O'Brien, Pat",02134,
2,Lee,10001,"path C:\\new"`}</code></pre>

<p>출력(SQLite 방언, 일괄 모드, 테이블 이름 <code>{"customers"}</code>):</p>

<pre><code>{`INSERT INTO "customers" ("id", "name", "zip", "note") VALUES
  (1, 'O''Brien, Pat', 02134, NULL),
  (2, 'Lee', 10001, 'path C:\\new');`}</code></pre>

<p>테이블을 먼저 만든 뒤 SQLite 3에 넣은 결과:</p>

<pre><code>{`CREATE TABLE customers (id INTEGER, name TEXT, zip TEXT, note TEXT);
-- run the INSERT above, then:
SELECT * FROM customers;
-- 1 | O'Brien, Pat | 2134  | NULL
-- 2 | Lee          | 10001 | path C:\\new`}</code></pre>

<ul>
  <li>따옴표로 감싼 <code>{"\"O'Brien, Pat\""}</code>는 쉼표를 유지하고, 아포스트로피는 두 번(<code>{"''"}</code>) 쓰입니다.</li>
  <li>빈 <code>{"note"}</code>는 <code>{"NULL"}</code>이 됩니다. 빈 문자열 <code>{"''"}</code>은 만들 수 없습니다.</li>
  <li><code>{"02134"}</code>는 숫자처럼 보여 따옴표 없이 쓰이고, TEXT 열이어도 앞자리 0이 사라집니다. 우편번호, 전화번호, 사번 같은 값은 직접 따옴표를 붙이세요:</li>
</ul>

<pre><code>{`INSERT INTO "customers" ("id", "name", "zip", "note") VALUES
  (1, 'O''Brien, Pat', '02134', NULL),
  (2, 'Lee', '10001', 'path C:\\new');`}</code></pre>

<h2>제한</h2>

<ul>
  <li>도구는 <code>{"INSERT"}</code> 문만 만들고 <code>{"CREATE TABLE"}</code>은 만들지 않습니다. 필요한 타입으로 테이블을 먼저 만드세요.</li>
  <li>MySQL은 <code>{"NO_BACKSLASH_ESCAPES"}</code>를 설정하지 않으면 문자열 리터럴의 백슬래시를 이스케이프 문자로 처리합니다(<a href="https://dev.mysql.com/doc/refman/8.4/en/string-literals.html" target="_blank" rel="noopener">MySQL string literals</a>). 도구는 작은따옴표만 두 번 쓰므로 위의 <code>{"C:\\new"}</code>는 MySQL에서 줄바꿈이 들어간 채 저장됩니다. PostgreSQL(표준 문자열)과 SQLite는 쓴 그대로 저장합니다.</li>
  <li>타입은 패턴으로만 판단합니다. <code>{"-?숫자(.숫자)?"}</code>는 숫자, 나머지는 따옴표 붙은 문자열입니다. 날짜, 불리언, <code>{"1e5"}</code>는 문자열이 됩니다.</li>
  <li>첫 줄은 항상 헤더입니다. 헤더 열 수를 넘는 셀은 경고 없이 버려집니다.</li>
  <li>큰 파일도 브라우저 탭에서 한 번에 변환합니다. 수백만 행이면 데이터베이스의 대량 적재(<code>{"LOAD DATA"}</code>, <code>{"COPY"}</code>, <code>{".import"}</code>)를 쓰세요.</li>
</ul>
