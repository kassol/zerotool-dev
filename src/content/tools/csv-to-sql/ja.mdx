<h2>使い方</h2>
<ol>
  <li>CSVデータを<strong>CSV入力</strong>テキストエリアに貼り付けるか、<strong>CSVアップロード</strong>をクリックしてファイルを読み込みます。</li>
  <li><strong>SQLダイアレクト</strong>（MySQL、PostgreSQL、SQLite）を選択します。</li>
  <li><strong>テーブル名</strong>を入力します。デフォルトは <code>my_table</code> です。</li>
  <li><strong>バッチINSERT</strong>（1文に複数行）または<strong>個別INSERT</strong>（行ごとに1文）を選択します。</li>
  <li>SQL出力は即座に更新されます。<strong>コピー</strong>をクリックしてクリップボードにコピーします。</li>
</ol>

<h2>NULL値の処理</h2>
<ul>
  <li>CSVの空フィールドはSQL出力で引用符なしの <code>NULL</code> になります。</li>
  <li>空白のみのフィールドは文字列として扱われ、NULLにはなりません。</li>
  <li>純粋な数値（整数・小数）は引用符なしで出力され、数値型として保存されます。</li>
  <li>その他の値はシングルクォートで囲まれ、内部のシングルクォートは <code>''</code> にエスケープされます。</li>
</ul>

<h2>例：引用符・先頭のゼロ・空欄</h2>

<p>入力：</p>

<pre><code>{`id,name,zip,note
1,"O'Brien, Pat",02134,
2,Lee,10001,"path C:\\new"`}</code></pre>

<p>出力（SQLite 方言、バッチモード、テーブル名 <code>{"customers"}</code>）：</p>

<pre><code>{`INSERT INTO "customers" ("id", "name", "zip", "note") VALUES
  (1, 'O''Brien, Pat', 02134, NULL),
  (2, 'Lee', 10001, 'path C:\\new');`}</code></pre>

<p>先にテーブルを作ってから SQLite 3 に読み込んだ結果：</p>

<pre><code>{`CREATE TABLE customers (id INTEGER, name TEXT, zip TEXT, note TEXT);
-- run the INSERT above, then:
SELECT * FROM customers;
-- 1 | O'Brien, Pat | 2134  | NULL
-- 2 | Lee          | 10001 | path C:\\new`}</code></pre>

<ul>
  <li>引用符で囲んだ <code>{"\"O'Brien, Pat\""}</code> はカンマを保ち、アポストロフィは二重（<code>{"''"}</code>）になります。</li>
  <li>空の <code>{"note"}</code> は <code>{"NULL"}</code> になります。空文字列 <code>{"''"}</code> は出力できません。</li>
  <li><code>{"02134"}</code> は数値に見えるため引用符なしで書かれ、TEXT 列でも先頭の 0 が失われます。郵便番号や電話番号、社員番号のような値は手で引用符を付けてください：</li>
</ul>

<pre><code>{`INSERT INTO "customers" ("id", "name", "zip", "note") VALUES
  (1, 'O''Brien, Pat', '02134', NULL),
  (2, 'Lee', '10001', 'path C:\\new');`}</code></pre>

<h2>制限</h2>

<ul>
  <li>出力は <code>{"INSERT"}</code> 文だけで、<code>{"CREATE TABLE"}</code> は生成しません。必要な型でテーブルを先に作ってください。</li>
  <li>MySQL は <code>{"NO_BACKSLASH_ESCAPES"}</code> を設定しない限り、文字列リテラル中のバックスラッシュをエスケープ文字として扱います（<a href="https://dev.mysql.com/doc/refman/8.4/en/string-literals.html" target="_blank" rel="noopener">MySQL string literals</a>）。ツールはシングルクォートを二重にするだけなので、上の <code>{"C:\\new"}</code> は MySQL では改行入りで保存されます。PostgreSQL（標準文字列）と SQLite は書いたとおりに保存します。</li>
  <li>型はパターンだけで判定します。<code>{"-?数字(.数字)?"}</code> は数値、それ以外は引用符付きの文字列です。日付、真偽値、<code>{"1e5"}</code> は文字列になります。</li>
  <li>1 行目は常にヘッダーです。ヘッダーの列数を超えるセルは警告なしで捨てられます。</li>
  <li>大きなファイルもブラウザのタブで一度に変換します。数百万行ならデータベースの一括ロード（<code>{"LOAD DATA"}</code>、<code>{"COPY"}</code>、<code>{".import"}</code>）を使います。</li>
</ul>
