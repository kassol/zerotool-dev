## 변환 예시

**한글이 섞인 인스타 소개 문구.** 한글에는 꾸민 글자가 없어서 영문만 바뀌고, 상태 줄에 「서 울에는 꾸민 글자가 없어」라는 안내가 나옵니다.

```text
입력:         서울 Seoul Night
필기체:       서울 𝒮ℯℴ𝓊𝓁 𝒩𝒾ℊ𝒽𝓉
굵은 필기체:  서울 𝓢𝓮𝓸𝓾𝓵 𝓝𝓲𝓰𝓱𝓽
검은 네모:    서울 🆂🅴🅾🆄🅻 🅽🅸🅶🅷🆃
```

필기체의 e, g, o는 수학 기호 블록보다 먼저 등록된 문자형 기호(ℯ U+212F, ℊ U+210A, ℴ U+2134)를 써서 모양이 조금 다를 수 있습니다.

**전각으로 입력된 영문.** 한글 입력기의 전각 모드에서 친 ｈｅｌｌｏ는 U+FF48 같은 전각 문자입니다. 많은 글씨체 변환기는 반각 영문만 바꾸고 전각은 그대로 돌려줍니다. 이 도구는 전각 영문과 숫자를 반각으로 되돌린 뒤 변환합니다(전각 공백은 유지).

```text
입력:            ｈｅｌｌｏ
일반 글자:       hello
굵게(산세리프):  𝗵𝗲𝗹𝗹𝗼
```

**받은 꾸민 글씨 고치기.** 𝓗𝓪𝓹𝓹𝔂 𝓓𝓪𝔂를 붙여넣으면 「일반 글자」는 `Happy Day`, 굵게(세리프)는 𝐇𝐚𝐩𝐩𝐲 𝐃𝐚𝐲, 동그라미는 Ⓗⓐⓟⓟⓨ Ⓓⓐⓨ가 됩니다.

## EUC-KR(CP949)로 저장할 때

꾸민 영문 대부분은 유니코드의 수학용 영숫자 기호 블록(U+1D400–U+1D7FF)에 있어 KS X 1001에 들어 있지 않습니다. Python 3.12 코덱으로 인코딩해 본 결과입니다.

| 문자 | EUC-KR / CP949 |
|---|---|
| 𝐁 (굵게) | 인코딩 불가 |
| Ⓐ (동그라미 대문자) | 인코딩 불가 |
| ⓐ (동그라미 소문자) | A8 CD |
| ① (동그라미 숫자) | A8 E7 |
| ² (위첨자 2) | A9 F7 |

KS X 1001에는 동그라미 소문자는 있지만 대문자는 없습니다. 그래서 Ⓢⓔⓞⓤⓛ을 CP949 텍스트 파일이나 CSV로 저장하면 첫 글자만 「?」가 되거나 오류가 납니다. UTF-8로 저장하세요.

## 스크린 리더와 검색

유니코드 컨소시엄은 [UTR #25 2.1절](https://www.unicode.org/reports/tr25/)에서 수학용 영숫자 기호는 수학·기술 표기용이며 일반 문장용이 아니라고 밝힙니다.

- **스크린 리더**: 정규화를 하지 않는 스크린 리더는 꾸민 글자를 한 자씩 문자 이름으로 읽거나 건너뛸 수 있습니다. NVDA는 2024.3에서 음성 출력에 유니코드 정규화를 추가하면서 「소셜 미디어에서 흔히 쓰는 굵은 글자와 기울인 글자」를 이유로 들었고, 2025.1부터 기본으로 켰습니다([NVDA 변경 내역](https://download.nvaccess.org/releases/2026.1/documentation/changes.html)). 작은 대문자와 검은 네모 글자는 유니코드 호환 분해가 없어 정규화로도 일반 글자가 되지 않습니다. 이름·링크·중요한 정보는 일반 글자로 쓰세요.
- **검색**: 𝐁𝐨𝐥𝐝와 Bold는 다른 문자열입니다. NFKC 정규화(JavaScript의 [`normalize('NFKC')`](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/String/normalize))를 거치면 대부분 일반 영문으로 돌아옵니다. 「일반 글자」 카드도 같은 대응을 쓰고, NFKC가 처리하지 않는 작은 대문자와 검은 동그라미·네모 글자는 별도 표로 보완합니다.

## 다른 글씨체 변환기와의 차이

2026-10-01 데스크톱 Chromium에서, Bing에서 「글씨체 변환」 2위였던 copyasymbol.com 한국어판에 같은 입력을 넣었습니다.

- `Café Müller`는 𝐂𝐚𝐟é 𝐌ü𝐥𝐥𝐞𝐫로 나와 é와 ü가 일반 글자로 남았습니다. 이 도구는 악센트를 유지하면서 글자를 바꿉니다.
- 전각 ｈｅｌｌｏ는 모든 스타일에서 그대로 나왔습니다.
- 꾸민 글씨 𝐁𝐨𝐥𝐝를 붙여넣으면 모든 스타일에서 그대로 돌아왔습니다.

이 페이지의 이전 버전은 취소선과 밑줄이 이모지를 서로게이트 사이에서 잘라 「�」로 깨뜨렸습니다. 지금은 문자소 클러스터([UAX #29](https://www.unicode.org/reports/tr29/)) 단위로 선을 붙여 `Hi 👋🏽`의 피부색 이모지도 그대로 남습니다.

## 제한 사항

- 꾸민 글자가 있는 것은 영문, 숫자, 일부 기호뿐입니다. 한글, 한자, 가나, 키릴 문자, 그리스 문자는 그대로 남습니다.
- 악센트가 있는 글자(é 등)는 세리프, 산세리프, 필기체, 프락투어, 겹선체, 고정폭에서만 바뀝니다. 동그라미, 네모, 전각, 작은 대문자, 위첨자, 아래첨자에서는 그대로 두고 카드에 표시합니다.
- 위첨자 C F Q S q와 아래첨자 w y z는 유니코드 14.0과 18.0에서야 추가되어 일반 폰트에 글리프가 없으므로 바꾸지 않습니다.
- 「일반 글자」 카드는 입력의 U+0332, U+0333, U+0335–U+0338 결합 기호를 모두 지웁니다.
- 표시 여부는 읽는 사람 기기의 폰트에 달려 있으며, 글리프가 없으면 빈 네모로 보입니다.

붙여넣은 글에 보이지 않는 문자가 섞였는지 확인하려면 [보이지 않는 문자 감지기](/ko/tools/zero-width-character-detector/)를, 꾸민 글자를 코드용 `\ud835\udc01` 형식으로 바꾸려면 [문자열 이스케이프](/ko/tools/string-escape/)를 쓰세요.
