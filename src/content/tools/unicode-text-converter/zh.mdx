## 示例

**中英混排的昵称。** 汉字没有花体形式，只有英文和数字会变：

```text
输入：      小王 Wang Lei 2026
粗体（无衬线）：小王 𝗪𝗮𝗻𝗴 𝗟𝗲𝗶 𝟮𝟬𝟮𝟲
空心体：    小王 𝕎𝕒𝕟𝕘 𝕃𝕖𝕚 𝟚𝟘𝟚𝟞
圆圈：      小王 Ⓦⓐⓝⓖ Ⓛⓔⓘ ②⓪②⑥
```

**输入法全角模式打出的字母。** 全角模式下打出的是 ｚｅｒｏ 这样的全角字母（U+FF41 起），多数花体字生成器原样输出。本工具先把全角字母和数字折回半角再转换，全角空格保留：

```text
输入：          ｚｅｒｏ　ｔｏｏｌ
普通文字：      zero tool
粗体（无衬线）：𝘇𝗲𝗿𝗼　𝘁𝗼𝗼𝗹
```

## 花体字存进数据库或旧系统时

花体字母大多来自 Unicode 的数学字母数字符号区（U+1D400–U+1D7FF），在基本多文种平面之外，UTF-8 下占 4 个字节。用 Python 3.12 的编解码器实测：

| 字符 | GBK | GB18030 | 说明 |
|---|---|---|---|
| 𝐁（粗体） | 无法编码 | 94 33 8A 33 | 数学字母区 |
| ⓐ（圆圈小写） | 无法编码 | 81 37 92 38 | 带圈字母 |
| ①（带圈数字） | A2 D9 | A2 D9 | GBK 里就有 |
| Ｂ（全角） | A3 C2 | A3 C2 | GBK 里就有 |

把花体昵称导出成 GBK 编码的 CSV 时，这些字符会变成问号或报错；GB18030 能编码全部 Unicode 字符。MySQL 的 `utf8mb3`（旧版的 `utf8`）只支持基本多文种平面字符（[MySQL 8.4 手册](https://dev.mysql.com/doc/refman/8.4/en/charset-unicode-utf8mb3.html)），写入 𝐁 这类字符会失败，表和连接都要用 `utf8mb4`。

## 读屏软件与搜索

[UTR #25 第 2.1 节](https://www.unicode.org/reports/tr25/)写明，数学字母数字符号只用于数学或技术记号，不用于普通文本。

- **读屏软件**：不做规范化的读屏软件可能逐个念出字符名称，或者直接跳过。NVDA 在 2024.3 版加入语音输出的 Unicode 规范化，说明里点名「社交媒体上常用的粗体和斜体字符」，2025.1 版起默认开启（[NVDA 更新日志](https://download.nvaccess.org/releases/2026.1/documentation/changes.html)）。小型大写和实心方框字母在 Unicode 里没有兼容映射，规范化也帮不上。名字、链接和关键信息请保留普通文字。
- **搜索和匹配**：𝐁𝐨𝐥𝐝 和 Bold 是不同的字符串。NFKC 规范化（JavaScript 的 [`normalize('NFKC')`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/String/normalize)）能把大部分样式折回普通字母。粘贴花体字时，「普通文字」卡片按同一套映射还原，并补上 NFKC 不处理的小型大写和实心字母。

## 和其他花体字生成器的区别

2026-10-01 在桌面版 Chromium 里，把同样的输入交给 SymbolDb 的花体文字生成器（cn.bing.com 搜「花体字」排第一）：

- `Café Müller` 输出 𝒞𝒶𝒻é ℳü𝓁𝓁ℯ𝓇，é 和 ü 没有变成花体；本工具保留重音并转换字母。
- 全角输入 ｈｅｌｌｏ 在所有样式里原样输出；本工具先折回半角再转换。
- 粘贴 𝐁𝐨𝐥𝐝 时各样式原样返回，删除线样式还把它拆成孤立代理项（`\ud835̶\udc01̶…`），复制后显示为 �，`Hi 👋🏽` 也一样。本页旧版本有同样的问题，现在组合符号按字素簇添加（[UAX #29](https://www.unicode.org/reports/tr29/)）。

## 限制

- 只有拉丁字母、数字和少数符号有花体形式，汉字、假名、谚文等原样保留。
- 重音只在衬线、无衬线、手写、哥特、空心、等宽这些样式里保留；圆圈、方框、全角、小型大写、上标、下标里的 é 原样保留并在卡片里列出。
- 上标 C F Q S q、下标 w y z 直到 Unicode 14.0 和 18.0 才编码，常见字体还没有字形，工具让它们保持原样。
- 「普通文字」卡片会删除输入里所有 U+0332、U+0333、U+0335–U+0338 组合符号。
- 阅读者设备缺字体时显示为空方框。

想检查粘贴文本里的隐藏字符，用[零宽字符检测器](/zh/tools/zero-width-character-detector/)；要把花体字写成代码里的 `\ud835\udc01` 转义，用[字符串转义](/zh/tools/string-escape/)。
