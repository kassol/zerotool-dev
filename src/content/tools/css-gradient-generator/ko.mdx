<h2>0deg는 위쪽입니다</h2>
<p>
  선형 그라디언트의 각도는 위쪽을 0으로 하여 시계 방향으로 커집니다. 명세 원문은 「0deg points upward, and positive angles represent clockwise rotation」입니다(<a href="https://www.w3.org/TR/css-images-3/#linear-gradients">CSS Images Level 3 §3.1</a>). 각도는 그라디언트 선이 향하는 방향이므로 <code>0deg</code>에서는 첫 번째 색이 아래쪽 가장자리, 마지막 색이 위쪽 가장자리에 놓입니다. 방향 버튼 위·오른쪽·아래·왼쪽은 각도를 0·90·180·270으로 바꾸는 바로 가기입니다.
</p>
<p>
  출력은 <code>.gradient</code> 클래스에 <code>background</code>를 설정합니다. 복사한 뒤 클래스 이름을 자신의 선택자로 바꾸거나 선언 한 줄만 기존 규칙에 붙여 넣으세요. 방사형은 색상 목록 앞에 모양과 중심 위치를, 원뿔형은 <code>from</code>에 시작 각도를, <code>at</code>에 회전 중심을 씁니다.
</p>

<h2>예시: KRDS 기본 색으로 만든 버튼 배경</h2>
<p>
  KRDS(<a href="https://www.npmjs.com/package/krds-uiux">krds-uiux</a> 1.1.0)의 <code>krds_tokens.css</code>에서 <code>--krds-light-color-button-primary-fill</code>의 값은 primary-50(<code>#256ef4</code>)이고, <code>--krds-light-color-button-primary-fill-hover</code>의 값은 primary-60(<code>#0b50d0</code>)입니다. 선형에서 각도를 180으로 두고 첫 정지점에 <code>#256ef4</code>(0%), 두 번째 정지점에 <code>#0b50d0</code>(100%)를 넣으면 위에서 아래로 짙어지는 버튼 배경이 됩니다.
</p>

{/* cgg-check: {"type":"linear","angle":180,"stops":[["#256ef4",0],["#0b50d0",100]]} */}
```css
.gradient {
  background: linear-gradient(180deg, #256ef4 0%, #0b50d0 100%);
}
```

<p>
  흰 글자를 올린다면 그라디언트 양 끝의 색을 각각 글자색과 비교해야 합니다. <a href="/ko/tools/color-contrast-checker/">색상 대비 검사기</a>로 두 번 확인하세요.
</p>

<h2>예시: 위쪽에서 퍼지는 은은한 배경</h2>
<p>
  방사형으로 바꾸고 모양은 타원, 위치는 top으로 고릅니다. 첫 정지점을 KRDS primary-5(<code>#ecf2fe</code>) 0%, 두 번째를 <code>#ffffff</code> 70%로 두면 위쪽 가운데에서 흰색으로 옅어지는 배경이 나옵니다. 70%보다 바깥은 마지막 색인 흰색이 그대로 이어집니다.
</p>

{/* cgg-check: {"type":"radial","shape":"ellipse","position":"top","stops":[["#ecf2fe",0],["#ffffff",70]]} */}
```css
.gradient {
  background: radial-gradient(ellipse at top, #ecf2fe 0%, #ffffff 70%);
}
```

<h2>전각 문자와 한글 입력 상태</h2>
<p>
  전각으로 입력한 색상값도 쓸 수 있습니다. 정지점 입력란은 Unicode NFKC로 전각 문자를 반각으로 바꾼 뒤 <code>#</code>과 16진수 6자리인지 판단하며, 대문자와 소문자를 모두 받고 CSS에는 소문자로 씁니다. 예를 들어 첫 정지점에 <code>＃２５６ＥＦ４</code>를 입력하고 두 번째 정지점은 기본값 <code>#8b5cf6</code>으로 두면 다음과 같습니다.
</p>

{/* cgg-check: {"type":"linear","angle":90,"typed":true,"stops":[["＃２５６ＥＦ４",0],["#8b5cf6",100]]} */}
```css
.gradient {
  background: linear-gradient(90deg, #256ef4 0%, #8b5cf6 100%);
}
```

<p>
  한/영 전환이 한글 상태이면 영문자 키가 자모로 입력되는데, 자모는 NFKC로 바꿔도 16진수가 되지 않으므로 반영되지 않습니다. 이때와 6자리를 다 채우지 않았을 때는 오류 표시 없이 미리보기와 CSS가 직전 색 그대로 남습니다. 색이 바뀌지 않으면 영문 상태로 바꿔 다시 입력하거나 왼쪽 색 견본을 눌러 색상 선택기로 고르세요.
</p>

<h2>제한 사항</h2>
<ul>
  <li>정지점은 2~6개, 위치는 0~100 사이의 정수(%)입니다. <code>20px</code> 같은 길이, 한 정지점에 위치 두 개를 쓰는 형식, 정지점 사이의 중간 지점을 정하는 힌트(transition hint)는 복사한 뒤 직접 고쳐야 합니다.</li>
  <li>CSS에는 위치가 작은 순서대로 정지점을 씁니다. 위치가 같은 정지점은 목록 순서를 유지하며, 이것이 경계를 선명하게 만드는 방법입니다. 0~100 밖의 값은 0%나 100%로 씁니다.</li>
  <li>색은 투명도가 없는 6자리 16진수만 받습니다. 투명하게 사라지는 그라디언트가 필요하면 복사한 뒤 마지막 정지점을 <code>transparent</code>나 <code>rgba()</code>로 바꾸세요.</li>
  <li>16진수 색은 감마 인코딩된 sRGB에서 보간되므로 보색 사이에서는 탁한 회색을 거칩니다. <code>linear-gradient(in oklch 90deg, ...)</code>처럼 직접 쓰면 피할 수 있으며 Chrome 111, Firefox 127, Safari 16.2부터 지원합니다(MDN 브라우저 호환성 데이터).</li>
  <li>방사형과 원뿔형의 중심은 키워드 9개 중에서만 고릅니다. 방사형 크기는 기본값인 <code>farthest-corner</code>로 고정이며 반복 그라디언트와 여러 겹의 배경은 만들지 않습니다.</li>
  <li>설정은 저장되지 않아 새로 고치면 기본 파란색–보라색 그라디언트로 돌아갑니다.</li>
</ul>

<h2>주요 사용 사례</h2>
<p>
  CSS 그라디언트는 히어로 섹션 배경, 카드 헤더, 버튼 채우기, 진행 표시줄, 장식 오버레이, <code>background-clip: text</code>를 이용한 글자 채우기 등에 쓰입니다. 원뿔형 그라디언트는 CSS만으로 그리는 파이 차트와 색상환에 알맞습니다.
</p>
