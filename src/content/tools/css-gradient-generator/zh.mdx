<h2>角度：0deg 朝上</h2>
<p>
  线性渐变的角度以「朝上」为 0，顺时针增加：<code>0deg</code> 朝上，<code>90deg</code> 朝右，<code>180deg</code> 朝下，<code>270deg</code> 朝左（<a href="https://www.w3.org/TR/css-images-3/#linear-gradients">CSS Images Level 3 §3.1</a>：「0deg points upward, and positive angles represent clockwise rotation」）。角度表示渐变线指向的方向，所以 <code>0deg</code> 时第一个颜色在底边、最后一个颜色在顶边。工具里的「上、右、下、左」四个按钮就是把角度设为 0、90、180、270。
</p>
<p>
  生成的 CSS 为 <code>.gradient</code> 类设置 <code>background</code>。复制后把类名换成自己的选择器，或者只把这一行声明粘进已有的规则。径向渐变在颜色列表前写形状和中心位置，锥形渐变用 <code>from</code> 写起始角度、用 <code>at</code> 写旋转中心。
</p>

<h2>示例：Ant Design 色板的蓝色按钮</h2>
<p>
  Ant Design 默认色板（<a href="https://github.com/ant-design/ant-design-colors">@ant-design/colors</a> 8.0.1 的 presets）中，blue-6 是 <code>#1677ff</code>，blue-7 是 <code>#0958d9</code>。在「线性」下把角度设为 135，第一个节点填 <code>#1677ff</code>、位置 0%，第二个节点填 <code>#0958d9</code>、位置 100%，得到从左上到右下逐渐变深的按钮底色：
</p>

{/* cgg-check: {"type":"linear","angle":135,"stops":[["#1677ff",0],["#0958d9",100]]} */}
```css
.gradient {
  background: linear-gradient(135deg, #1677ff 0%, #0958d9 100%);
}
```

<p>
  按钮文字放在渐变上时，要分别检查渐变两端颜色与文字颜色的对比度，可以用<a href="/zh/tools/color-contrast-checker/">颜色对比度检查器</a>。
</p>

<h2>示例：用锥形渐变画完成率</h2>
<p>
  切到「锥形」，起始角度保持 0，中心位置保持 center。先点两次「+ 添加」凑够四个节点，再把它们设成 <code>#1677ff</code> 0% 与 65%、<code>#f0f0f0</code> 65% 与 100%，就是一个从正上方开始顺时针占 65% 的蓝色扇形。两个节点位置相同时，上面一行的颜色写在前面，而离开位置框时各行会重新排序，所以改完后核对一下行的顺序：
</p>

{/* cgg-check: {"type":"conic","from":0,"position":"center","stops":[["#1677ff",0],["#1677ff",65],["#f0f0f0",65],["#f0f0f0",100]]} */}
```css
.gradient {
  background: conic-gradient(from 0deg at center, #1677ff 0%, #1677ff 65%, #f0f0f0 65%, #f0f0f0 100%);
}
```

<p>
  锥形渐变的 0deg 同样指向页面上方，角度增大时顺时针前进（<a href="https://www.w3.org/TR/css-images-4/#conic-color-stops">CSS Images Level 4 §3.3.2</a>）。两个节点落在同一位置时，颜色在该处直接切换，所以扇形边缘是硬边。给元素相同的宽和高，再加 <code>border-radius: 50%</code>，就成了圆形。完成率的数字要另外用文字写出来，屏幕阅读器读不到背景里的扇形。
</p>

<h2>用中文输入法输入色值</h2>
<p>
  输入法处于全角状态时打出的色值也能用：节点的文本框先按 Unicode NFKC 把全角字符换成半角，再判断是不是 <code>#</code> 加 6 位十六进制数字，大小写都可以，CSS 里统一写成小写。例如在第一个节点输入 <code>＃０９５８Ｄ９</code>，第二个节点保持默认的 <code>#8b5cf6</code>：
</p>

{/* cgg-check: {"type":"linear","angle":90,"typed":true,"stops":[["＃０９５８Ｄ９",0],["#8b5cf6",100]]} */}
```css
.gradient {
  background: linear-gradient(90deg, #0958d9 0%, #8b5cf6 100%);
}
```

<p>
  文本框里仍显示你打的原文。还没打满 6 位、或混入了十六进制以外的字符时，工具不提示错误，预览和代码保持上一个颜色；这时检查位数，或者点左侧的色块用取色器选择。
</p>

<h2>限制</h2>
<ul>
  <li>节点数为 2–6 个，位置是 0–100 的整数百分比。长度单位（如 <code>20px</code>）、一个节点写两个位置、过渡提示（transition hint）需要复制后手动修改。</li>
  <li>CSS 按位置从小到大写出节点；位置相同的节点保持列表中的顺序，硬边就是这样做出来的。超出 0–100 的位置写成 0% 或 100%。</li>
  <li>只能使用不带透明度的 6 位十六进制颜色。要渐变到透明，复制后把最后一个节点改成 <code>transparent</code> 或 <code>rgba()</code>。</li>
  <li>十六进制颜色在 gamma 编码的 sRGB 中插值，互补色之间会经过发灰的中间色。手写 <code>linear-gradient(in oklch 90deg, ...)</code> 可以避免，Chrome 111、Firefox 127、Safari 16.2 起支持（MDN 浏览器兼容数据）。</li>
  <li>径向和锥形的中心只能从 9 个关键字中选；径向渐变的尺寸固定为默认的 <code>farthest-corner</code>；不生成重复渐变和多层背景。</li>
  <li>设置不保存，刷新页面后回到默认的蓝紫渐变。</li>
</ul>

<h2>常见用途</h2>
<p>
  CSS 渐变常用于 Hero 区域背景、卡片头部、按钮填充、进度条、装饰性遮罩以及文字填充效果（配合 <code>background-clip: text</code>）。锥形渐变适合用纯 CSS 实现饼图和色轮。
</p>
