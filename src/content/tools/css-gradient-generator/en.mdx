<h2>Angles and Directions</h2>
<p>
  Build linear, radial, and conic CSS gradients visually, then copy the generated <code>background</code> rule.
  For linear gradients, adjust the angle in degrees: <code>0deg</code> points upward, <code>90deg</code> points right,
  <code>180deg</code> points downward, and <code>270deg</code> points left.
</p>

<h2>How to Use</h2>
<ol>
  <li>Select a gradient type — <strong>Linear</strong>, <strong>Radial</strong>, or <strong>Conic</strong> — using the tabs at the top.</li>
  <li>For <strong>Linear</strong>: drag the angle slider or type a value between 0 and 360 degrees. Use the direction buttons (Top / Right / Bottom / Left) as quick-set shortcuts.</li>
  <li>For <strong>Radial</strong>: choose a shape (circle or ellipse) and a center position from the dropdowns.</li>
  <li>For <strong>Conic</strong>: set the starting angle with the slider and pick the center position.</li>
  <li>In the <strong>Color Stops</strong> section, click the color swatch or type a hex value to change each stop's color. Adjust the percentage to control its position along the gradient.</li>
  <li>Click <strong>+ Add Stop</strong> to insert more stops (up to six), or click <strong>×</strong> to remove one (minimum two remain).</li>
  <li>The <strong>preview rectangle</strong> updates in real time as you make changes.</li>
  <li>Click <strong>Copy</strong> to copy the CSS rule to your clipboard.</li>
</ol>

<h2>Understanding the Generated CSS</h2>
<p>
  The output sets <code>background</code> on a <code>.gradient</code> class. For linear gradients, the angle
  controls the direction — 0deg points upward (bottom-to-top), 90deg points right (left-to-right),
  and 180deg points downward (top-to-bottom). For radial gradients, the syntax specifies the shape
  and its position before the color list. For conic gradients, <code>from</code> sets
  the starting angle and <code>at</code> sets the sweep center.
</p>

<h2>Example: the Default Linear Gradient</h2>
<p>The tool opens on Linear at 90deg with a blue and a violet stop:</p>

```css
.gradient {
  background: linear-gradient(90deg, #3b82f6 0%, #8b5cf6 100%);
}
```

<p>Click <strong>Top</strong> and the angle becomes <code>0deg</code>, so the blue stop sits at the bottom edge and violet at the top. An angle is measured clockwise from "to top" (<a href="https://www.w3.org/TR/css-images-3/#linear-gradients">CSS Images Level 3 §3.1</a>), and the gradient line is long enough for the corners to receive the first and last colors exactly, so 45deg on a wide box is not the same as <code>to top right</code>.</p>

<h2>Example: a Two-Slice Pie With Conic Stops</h2>
<p>Switch to <strong>Conic</strong>, keep <em>from 0deg</em> and <em>center</em>, set the stops to <code>#3b82f6</code> at 0% and 40%, add a stop, and set two <code>#f59e0b</code> stops at 40% and 100%. The output is:</p>

```css
.gradient {
  background: conic-gradient(from 0deg at center, #3b82f6 0%, #3b82f6 40%, #f59e0b 40%, #f59e0b 100%);
}
```

<p>Two stops at the same percentage make a hard edge, so the box shows a 40% blue slice starting at 12 o'clock and the rest in amber. Add <code>border-radius: 50%</code> and an equal width and height to turn it into a pie. Add a text label next to it: screen readers get nothing from a background.</p>

<h2>Limits</h2>
<ul>
  <li><strong>Two to six stops</strong>, each with a whole-number position from 0 to 100%. Lengths (<code>20px</code>), double positions (<code>#3b82f6 0% 40%</code>) and transition hints need a manual edit.</li>
  <li><strong>Stops are written in list order.</strong> The list is sorted when you add a stop, but not when you edit a position. If a stop's position is smaller than the one before it, CSS moves it up to that earlier position, which produces a hard edge instead of a blend.</li>
  <li><strong>sRGB blending.</strong> Hex stops interpolate in gamma-encoded sRGB, the compatibility rule for legacy colors in CSS Color 4, so complementary colors pass through a dull, grayish middle. Writing <code>linear-gradient(in oklch 90deg, ...)</code> by hand avoids that in Chrome 111, Firefox 127 and Safari 16.2 and later (MDN browser compat data).</li>
  <li><strong>Fixed positions and shapes.</strong> Radial and conic centers come from nine keywords; radial size is always the default <code>farthest-corner</code>. Repeating gradients and multiple layered backgrounds are not generated.</li>
  <li><strong>Hex colors only.</strong> The text field accepts a 6-digit code with <code>#</code>; there is no alpha, so for a fade to transparent replace the last stop with <code>transparent</code> or an <code>rgba()</code> value after copying.</li>
</ul>

<h2>Common Use Cases</h2>
<p>
  CSS gradients are used for hero section backgrounds, card headers, button fills, progress bars, decorative
  overlays, and text fill effects (via <code>background-clip: text</code>). Conic gradients are especially
  useful for pie charts and color-wheel pickers rendered purely in CSS.
</p>
