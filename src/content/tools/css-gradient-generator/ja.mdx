<h2>角度と方向ボタン</h2>
<p>
  線形グラデーションの角度は「上向き」を 0 として時計回りに増えます。仕様の原文は「0deg points upward, and positive angles represent clockwise rotation」です（<a href="https://www.w3.org/TR/css-images-3/#linear-gradients">CSS Images Level 3 §3.1</a>）。角度はグラデーションラインが向かう方向を表すので、<code>0deg</code> では最初の色が下端、最後の色が上端に来ます。方向ボタンの「上・右・下・左」は、角度をそれぞれ 0・90・180・270 にするショートカットです。
</p>
<p>
  出力は <code>.gradient</code> クラスに <code>background</code> を設定します。コピーしたらクラス名を自分のセレクターに変えるか、宣言の行だけを既存のルールに貼り付けてください。ラジアルでは色リストの前に形状と中心位置が、コニックでは <code>from</code> に開始角度、<code>at</code> に回転の中心が入ります。
</p>

<h2>例：デジタル庁デザインシステムの青でヘッダー帯</h2>
<p>
  デジタル庁デザインシステムのデザイントークン（<a href="https://github.com/digital-go-jp/design-tokens">@digital-go-jp/design-tokens</a> 2.0.1 の <code>tokens.css</code>）では、プリミティブカラーの <code>--color-primitive-blue-900</code> が <code>#0017c1</code>、<code>--color-primitive-blue-600</code> が <code>#3460fb</code> です。リニアのまま角度を 90 にし、1つ目のストップに <code>#0017c1</code>（0%）、2つ目に <code>#3460fb</code>（100%）を入れると、左から右へ明るくなる帯ができます。
</p>

{/* cgg-check: {"type":"linear","angle":90,"stops":[["#0017c1",0],["#3460fb",100]]} */}
```css
.gradient {
  background: linear-gradient(90deg, #0017c1 0%, #3460fb 100%);
}
```

<p>
  帯の上に白い文字を載せるなら、文字色と比べる相手はグラデーションの中で最も明るい側（ここでは右端の <code>#3460fb</code>）です。両端の色を<a href="/ja/tools/color-contrast-checker/">カラーコントラストチェッカー</a>で1つずつ確認してください。
</p>

<h2>例：アンケート結果の円グラフ</h2>
<p>
  「賛成 45%・反対 30%・未回答 25%」を3色の円グラフにします。コニックに切り替え、開始角度 0・中心位置 center のまま「+ 追加」を4回押してストップを6個にし、<code>#0017c1</code> を 0% と 45%、<code>#39abff</code> を 45% と 75%、<code>#99f2ff</code> を 75% と 100% に設定します。3色は同じ <code>tokens.css</code> の blue-900、light-blue-500、cyan-200 です。
</p>

{/* cgg-check: {"type":"conic","from":0,"position":"center","stops":[["#0017c1",0],["#0017c1",45],["#39abff",45],["#39abff",75],["#99f2ff",75],["#99f2ff",100]]} */}
```css
.gradient {
  background: conic-gradient(from 0deg at center, #0017c1 0%, #0017c1 45%, #39abff 45%, #39abff 75%, #99f2ff 75%, #99f2ff 100%);
}
```

<p>
  コニックでも 0deg はページの上を指し、角度が増えると時計回りに進みます（<a href="https://www.w3.org/TR/css-images-4/#conic-color-stops">CSS Images Level 4 §3.3.2</a>）。同じ位置に2つのストップを置くと、その位置で色が切り替わるので境目がぼけません。位置が同じときは上の行の色が先に書き出され、位置欄から離れると行が並べ替わるので、入力後に行の順序を確かめてください。色だけでは項目を区別できない人もいるため、凡例と数値は文字で併記します。
</p>

<p>
  6個のストップで作れる扇は最大4つです。<a href="https://www.w3.org/TR/css-images-3/#coloring-gradient-line">CSS Images Level 3 §3.4.2</a> は「Before the first color stop, the gradient line is the color of the first color stop, and after the last color stop, the gradient line is the color of the last color stop」と定めているので、最初と最後のストップを 0% と 100% に置かなくても、端まで同じ色が続きます。たとえば「賛成 40%・どちらでもない 25%・反対 20%・未回答 15%」なら、境目の 40%、65%、85% に2つずつストップを置き、4色目に同じ tokens.css の blue-50 <code>#e8f1fe</code> を使います。
</p>

{/* cgg-check: {"type":"conic","from":0,"position":"center","stops":[["#0017c1",40],["#39abff",40],["#39abff",65],["#99f2ff",65],["#99f2ff",85],["#e8f1fe",85]]} */}
```css
.gradient {
  background: conic-gradient(from 0deg at center, #0017c1 40%, #39abff 40%, #39abff 65%, #99f2ff 65%, #99f2ff 85%, #e8f1fe 85%);
}
```

<p>
  5項目以上の円グラフは、コピーした後にストップを手で書き足してください。
</p>

<h2>全角で入力したとき</h2>
<p>
  全角英数で確定した色も使えます。ストップの入力欄は Unicode の NFKC で全角文字を半角に直してから、<code>#</code> と16進数6桁かどうかを判定します。大文字・小文字はどちらでもよく、CSS には小文字で書き出します。入力欄に入るのは7文字までで、<code>#</code> と6桁でちょうど埋まります。たとえば1つ目のストップに <code>＃００１７Ｃ１</code> と入力し、2つ目は既定の <code>#8b5cf6</code> のままにすると、次のようになります。
</p>

{/* cgg-check: {"type":"linear","angle":90,"typed":true,"stops":[["＃００１７Ｃ１",0],["#8b5cf6",100]]} */}
```css
.gradient {
  background: linear-gradient(90deg, #0017c1 0%, #8b5cf6 100%);
}
```

<p>
  入力欄の表示は打ったままです。ひらがな入力のままローマ字で打つと、<code>a</code> と <code>e</code> は仮名になります（<code>#1a73e8</code> が <code>＃１あ７３え８</code> になる）。仮名は NFKC でも16進数にならないため、この色は反映されません。6桁に足りないときや16進数以外の文字が混じったときも同じで、エラー表示はなく、プレビューと CSS は直前の色のままです。色が変わらないときは英数入力に切り替えて打ち直すか、左の色見本をクリックしてカラーピッカーで選んでください。
</p>

<h2>制限</h2>
<ul>
  <li>ストップは2〜6個、位置は 0〜100 の整数（%）です。<code>20px</code> のような長さ、1つのストップに2つの位置を書く形、ストップ間の中間点を示すヒント（transition hint）は、コピー後に手で直します。</li>
  <li>CSS は位置の小さい順にストップを書き出します。同じ位置のストップはリストの順を保ち、これが境目をくっきりさせる方法になります。0〜100 の外の値は 0% か 100% として書き出されます。</li>
  <li>色は透明度のない6桁の16進数だけです。透明へ消えるグラデーションにするには、コピー後に最後のストップを <code>transparent</code> か <code>rgba()</code> に置き換えます。</li>
  <li>16進数の色は線形化していない（ガンマ符号化された）sRGB の値のまま補間されるため、補色どうしの間はくすんだ灰色を通ります。<code>linear-gradient(in oklch 90deg, ...)</code> と手で書けば避けられ、Chrome 111・Firefox 127・Safari 16.2 以降が対応しています（MDN のブラウザー互換性データ）。</li>
  <li>ラジアルとコニックの中心は9つのキーワードから選びます。ラジアルの大きさは既定の <code>farthest-corner</code> 固定で、繰り返しグラデーションや複数レイヤーの背景は生成しません。</li>
  <li>設定は保存されず、再読み込みすると既定の青紫のグラデーションに戻ります。</li>
</ul>

<h2>主な用途</h2>
<p>
  CSS グラデーションは、ヒーローセクションの背景、カードのヘッダー、ボタンの塗り、プログレスバー、装飾用のオーバーレイ、<code>background-clip: text</code> による文字の塗りなどに使われます。コニックグラデーションは CSS だけで描く円グラフやカラーホイールに向いています。
</p>
