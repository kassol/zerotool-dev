<h2>사용 방법</h2>
<ol>
  <li>JSON을 왼쪽 패널에 붙여넣거나 입력합니다. 실시간으로 유효성이 검사됩니다.</li>
  <li>선택적으로 <strong>루트 구조체 이름</strong>을 설정합니다 (기본값: <code>RootObject</code>).</li>
  <li><strong>Go Struct 생성</strong>을 클릭하거나 실시간 변환을 기다립니다.</li>
  <li><strong>복사</strong>를 클릭하여 출력을 클립보드에 복사합니다.</li>
</ol>

<h2>타입 매핑</h2>
<ul>
  <li><code>null</code> → <code>interface{"{}"}</code></li>
  <li>문자열 → <code>string</code></li>
  <li>정수 → <code>int</code></li>
  <li>부동소수점 → <code>float64</code></li>
  <li>불리언 → <code>bool</code></li>
  <li>배열 → <code>[]T</code></li>
  <li>nullable/선택적 → 포인터 (<code>*T</code>)</li>
  <li>중첩 객체 → 독립적으로 명명된 <code>struct</code></li>
</ul>

## 예시: API 응답

```json
{
  "user": {
    "id": 42,
    "name": "Alice",
    "email": "alice@example.com",
    "is_active": true,
    "roles": ["admin", "editor"],
    "address": { "city": "New York", "country": "US", "zip_code": "10001" },
    "last_login": null
  }
}
```

에서 다음이 생성됩니다:

```go
type RootObject struct {
	User User `json:"user"`
}

type User struct {
	Id int `json:"id"`
	Name string `json:"name"`
	Email string `json:"email"`
	IsActive bool `json:"is_active"`
	Roles []string `json:"roles"`
	Address Address `json:"address"`
	LastLogin interface{} `json:"last_login"`
}

type Address struct {
	City string `json:"city"`
	Country string `json:"country"`
	ZipCode string `json:"zip_code"`
}
```

`snake_case` 키는 `CamelCase` 필드 이름이 되고 `json` 태그에 원래 키가 남아 `encoding/json`이 양방향으로 매핑합니다. 필드가 정렬되어 있지 않으므로 `gofmt`(또는 저장할 때 포맷하는 편집기)로 태그를 맞추세요. 표준 라이브러리로 디코딩합니다:

```go
var root RootObject
if err := json.Unmarshal(data, &root); err != nil {
	log.Fatal(err)
}
fmt.Println(root.User.Name) // Alice
```

## 예시: 최상위가 배열인 경우

```json
[{"sku": "A1", "qty": 2}, {"sku": "B2", "note": "gift"}]
```

에서 다음이 생성됩니다:

```go
type RootObject struct {
	Sku string `json:"sku"`
	Qty *int `json:"qty,omitempty"`
	Note *string `json:"note,omitempty"`
}
```

최상위가 배열이면 구조체는 요소 하나를 나타내므로 `[]RootObject`로 디코딩합니다. 일부 요소에 없는 키는 `omitempty`가 붙은 포인터가 됩니다.

## 예시: 같은 키 이름, 소수, 숫자로 시작하는 키

```json
{
  "order": { "id": "A-1001", "total": 19.0, "meta": { "createdBy": "alice", "source": "web" } },
  "payment": { "status": "paid", "meta": { "provider": "stripe", "fee": 0.3 } },
  "2fa": true
}
```

생성 결과

```go
type RootObject struct {
	Order Order `json:"order"`
	Payment Payment `json:"payment"`
	X2fa bool `json:"2fa"`
}

type Order struct {
	Id string `json:"id"`
	Total float64 `json:"total"`
	Meta Meta `json:"meta"`
}

type Meta struct {
	CreatedBy string `json:"createdBy"`
	Source string `json:"source"`
}

type Payment struct {
	Status string `json:"status"`
	Meta PaymentMeta `json:"meta"`
}

type PaymentMeta struct {
	Provider string `json:"provider"`
	Fee float64 `json:"fee"`
}
```

`payment.meta`는 `order.meta`와 필드가 달라 별도 구조체가 되며, 부모 이름을 앞에 붙인 `PaymentMeta`가 됩니다(필드가 같으면 둘이 `Meta`를 함께 씀). `19.0`은 소수점으로 쓰였으므로 `total`은 `float64`입니다. `encoding/json`은 `19.0`을 `int` 필드로 디코딩하지 않습니다. 도구는 브라우저의 JSON 원본 텍스트 접근(Chrome 114+, Firefox 135+, Safari 18.4+)으로 숫자가 쓰인 모양을 읽습니다. 지원하지 않는 브라우저에서는 `19`로 보여 `int`가 됩니다. 키 `2fa`는 내보내는 이름의 첫 글자로 쓸 수 없어 필드 이름은 `X2fa`, 태그는 `2fa` 그대로입니다.

## 생성 후 고칠 부분

- `null`은 `interface{}`가 됩니다. API 문서를 확인한 뒤 `*string`, `*time.Time` 같은 실제 타입의 포인터로 바꾸세요.
- `.`이나 지수가 없는 숫자는 `int`, `19.0`이나 `1e3`은 `float64`가 됩니다. 같은 배열이나 키에 정수와 소수가 섞이면 `float64`입니다. 샘플이 우연히 정수뿐인 필드(가격 등)는 `int`로 남으니 확인하세요. 64비트 플랫폼에서 `int`는 64비트입니다.
- `[]`과 그 밖에 요소 타입이 섞인 배열은 `[]interface{}`가 됩니다.
- 필드 이름은 Go의 약어 관례에 맞게 조정되지 않습니다. `id`는 `Id`, `url`은 `Url`이 되지만 [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments#initialisms)는 `ID`, `URL`을 권장합니다. 어느 쪽이든 `json` 태그 덕분에 디코딩은 올바르게 동작합니다.
- 필드 이름이 대문자로 시작하지 않는 키(`2fa`, `名前`)는 앞에 `X`를 붙입니다(`X2fa`). 같은 필드 이름이 되는 두 키(`user_id`, `userId`)에는 번호를 붙입니다(`UserId2`). 빈 키와 구조체 태그에 쓸 수 없는 문자(`"`, `,` 등)가 있는 키는 `encoding/json`이 태그로 연결할 수 없으므로 필드 대신 주석에 적습니다.
- `PaymentMeta`, `Meta2` 같은 이름은 JSON 키에서 만들어집니다. 용도에 맞게 이름을 바꾸세요.
- `json` 태그만 생성됩니다. `gorm`, `bson`, `validate` 태그는 직접 추가하세요.

## 제한 사항

- 입력은 유효한 JSON이어야 합니다. 오류 메시지에 위치가 표시됩니다(끝 쉼표라면 `Expected double-quoted property name in JSON at position 8`).
- 타입은 붙여넣은 샘플에서만 결정됩니다.
