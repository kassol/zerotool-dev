<h2>公众号与网站：哪个方向</h2>
<p>先看图片要放到哪里，再决定方向。</p>
<ul>
  <li><strong>微信公众号正文：</strong>微信开放文档的<a href="https://developers.weixin.qq.com/doc/service/api/material/permanent/api_uploadimage.html">「上传图文消息内的图片」接口</a>写明“图片仅支持jpg/png格式，大小必须在1MB以下”；<a href="https://developers.weixin.qq.com/doc/subscription/api/material/permanent/api_addmaterial.html">永久素材接口</a>的图片类型列的是 bmp/png/jpeg/jpg/gif。拿到 .webp 素材时，用「WebP → PNG」转成 PNG 再上传。</li>
  <li><strong>自己的网站：</strong>主流浏览器都能显示 WebP，这时才适合把 JPG / PNG 转成 WebP 来减小体积。</li>
</ul>
<p>「WebP → PNG」模式只接收 WebP。设计同事发来的 <code>活动封面.jpg</code> 本来就是 JPG，可以直接上传；在这个模式下拖进去，工具会拒收并说明原因：</p>

{/* wc-check: {"mode":"from-webp","files":[{"name":"活动封面.jpg","type":"image/jpeg","size":245760}]} */}
```text

已转换 0 个文件，1 个失败
```

<p>转成 PNG 后要看一下大小。PNG 是无损格式，照片的 PNG 往往很大：上面的 <code>kodim23.png</code> 是 557,596 字节，同一张图的 WebP 只有 37,438 字节。超过公众号接口的 1MB 时需要先缩小尺寸，本工具不提供缩放。</p>

<h2>WebP 与 JPEG、PNG 的区别</h2>
<p>WebP 同时支持有损和无损压缩，也支持透明（类似 PNG）和动画（类似 GIF）。Google 公布的结果是：有损 WebP 在同等 SSIM 下比 JPEG 小 25–34%，无损 WebP 比 PNG 小 26%。这是平均值，具体能省多少取决于图片内容，上面的照片和下面提到的文字图表就是两个相反的例子。</p>

<h2>限制</h2>
<ul>
  <li><strong>动画会丢失。</strong>图片只画到 canvas 上一次，GIF 动图转出的是第一帧的静态 WebP，动态 WebP 转出的是单帧 PNG。要压缩 GIF 动图，请用 <a href="/zh/tools/gif-compressor/">GIF 压缩工具</a>。</li>
  <li><strong>元数据不保留。</strong>EXIF（相机、GPS、拍摄时间）和 XMP 不会复制到输出文件里。</li>
  <li><strong>按浏览器报告的类型判断格式。</strong>浏览器给出的类型是按扩展名推断的（见 <a href="https://developer.mozilla.org/zh-CN/docs/Web/API/Blob/type">MDN</a>）。HEIC、AVIF、BMP 会显示「不支持的格式」；改了扩展名的 PNG（比如改成 .jpg）照样能转；内容不是图片却用了图片扩展名的文件会显示「无法载入图片」。</li>
  <li><strong>用的是浏览器自带的编码器。</strong>同样的质量，Chrome 和 Firefox 得到的大小不同。Safari 的 canvas 不能编码 WebP，这时工具会报告无法编码，不会把 PNG 存成 .webp。</li>
  <li><strong>文字图表可能变大。</strong>按 <a href="/blog/webp-converter-guide/">WebP 指南</a>（英文版）的实测，66,664 字节的调色板 PNG 图表在质量 85 时变成 102,454 字节。这类图片请比较后再换。</li>
  <li><strong>只有质量一个参数。</strong>没有缩放、裁剪、编码耗时或近无损选项。需要这些时可以用 libwebp 的 <code>cwebp</code>，例如 <code>cwebp -q 80 in.png -o out.webp</code> 或 <code>cwebp -lossless in.png -o out.webp</code>。</li>
  <li><strong>改了质量要重新导入。</strong>质量在导入文件时读取，已有的结果不会自动重算；重新选择同一个文件即可。</li>
</ul>
