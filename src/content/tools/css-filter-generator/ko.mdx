<h2>출력 형식과 함수 순서</h2>
<p>
  출력은 <code>.element</code> 클래스에 <code>filter</code> 속성을 설정합니다. <code>.element</code>를 원하는 선택자로 바꾸면 이미지, div, canvas, video, 가상 요소 등에 쓸 수 있습니다. 함수는 항상 슬라이더 순서(blur, brightness, contrast, grayscale, hue-rotate, invert, opacity, saturate, sepia)로 적히고 미리보기도 같은 문자열을 씁니다. 브라우저는 적힌 순서대로 하나씩 적용하며 앞 함수의 결과가 다음 함수의 입력이 됩니다(<a href="https://www.w3.org/TR/filter-effects-1/#FilterProperty">Filter Effects Level 1 §5</a>). 다른 순서가 필요하면 복사한 뒤 직접 바꾸세요.
</p>

<h2>예시: 고대비 화면을 filter로 흉내 내지 않기</h2>
<p>
  저시력 사용자를 위한 고대비 화면을 만들려고 페이지 전체에 대비를 올리는 경우가 있습니다. 「대비」를 150으로 올리면 도구는 다음을 출력합니다.
</p>

{/* cfg-check: {"values":{"contrast":150}} */}
```css
.element {
  filter: contrast(150%);
}
```

<p>
  이 선언을 <code>body</code>에 붙이면 두 가지 문제가 생깁니다. 첫째, filter가 none이 아닌 요소는 절대 위치와 고정 위치 자손의 컨테이닝 블록이 되고, 예외는 문서의 루트 요소뿐입니다(Filter Effects Level 1 §5: 「unless the element it applies to is a document root element in the current browsing context」). <code>body</code>는 루트가 아니므로 상단 고정 메뉴 같은 <code>position: fixed</code> 요소가 뷰포트가 아니라 body를 기준으로 배치됩니다. 둘째, filter는 그려진 화면만 바꾸고 CSS의 색 값은 그대로 두므로, 색 값으로 대비를 계산하는 검사 결과는 달라지지 않습니다.
</p>
<p>
  KRDS(<a href="https://www.npmjs.com/package/krds-uiux">krds-uiux</a> 1.1.0)는 고대비 화면을 filter로 만들지 않습니다. <code>common.css</code>와 <code>component.css</code>에는 filter 선언이 없고, <code>[data-krds-mode=high-contrast]</code> 선택자 아래에서 <code>--krds-high-contrast-color-…</code> 토큰으로 색을 바꿉니다. 이처럼 색 토큰을 따로 두면 위의 두 문제가 생기지 않습니다.
</p>

<h2>예시: 품절 상품 썸네일</h2>
<p>
  쇼핑몰 목록에서 품절 상품을 흑백으로 조금 밝게 보이게 하려면 「회색조」를 100, 「밝기」를 110으로 둡니다.
</p>

{/* cfg-check: {"values":{"grayscale":100,"brightness":110}} */}
```css
.element {
  filter: brightness(110%) grayscale(100%);
}
```

<p>
  슬라이더를 어떤 순서로 움직였든 brightness가 grayscale보다 앞에 적힙니다. 이 규칙은 썸네일 <code>img</code>에만 붙이고 상품 카드 전체에는 붙이지 마세요. 필터는 자손까지 함께 그리므로 카드에 붙이면 ‘품절’ 표시와 가격도 흑백이 됩니다. 품절 여부는 색만이 아니라 글자로도 알려야 합니다.
</p>

<h2>제한 사항</h2>
<ul>
  <li>조정 범위: 흐림 0~20px(0.1px 간격), 밝기·대비·채도 0~200%, 색조 회전 0~360deg, 나머지 0~100%. 명세는 더 큰 값도 허용합니다. 밝기·대비·채도에는 상한이 없고, 회색조·반전·불투명도·세피아는 100%를 넘으면 100%로 처리됩니다. 필요하면 복사한 CSS를 직접 고치세요.</li>
  <li><code>drop-shadow()</code>와 SVG 필터를 참조하는 <code>url()</code>은 만들지 않습니다. 유리 패널 뒤쪽을 흐리게 하려면 <code>backdrop-filter</code>를 쓰고, <code>filter: blur()</code>는 글자를 포함한 요소 자체를 흐리게 합니다.</li>
  <li>미리보기 이미지는 5 MB까지이며, 넘으면 영어 안내 「Max file size is 5 MB」가 뜨고 이미지는 불러오지 않습니다.</li>
  <li>9개 값은 이 브라우저에 저장되고 이미지는 저장되지 않습니다.</li>
</ul>

<h2>주요 활용 사례</h2>
<p>
  CSS 필터는 이미지 호버 효과(평소에는 회색조, 호버 시 컬러), 다크 모드에서 스크린숏 조정(반전 + 색조 회전), 로딩 중 자리 표시 이미지(회색조 + 밝기), 세피아·고대비 같은 사진 스타일에 널리 쓰입니다. 요소 뒤쪽을 흐리게 하는 표현에는 <code>backdrop-filter</code>를 씁니다.
</p>
