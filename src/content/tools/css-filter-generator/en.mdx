<h2>Understanding the Generated CSS</h2>
<p>
  The output sets the <code>filter</code> property on an <code>.element</code> class. Replace
  <code>.element</code> with your own selector and apply the declaration to any HTML element —
  images, divs, canvases, videos, or pseudo-elements. Filter values are evaluated in order, so
  <code>blur(2px) brightness(120%)</code> first blurs and then brightens, which may produce
  a slightly different result than applying the functions in reverse.
</p>

<h2>Example: Grayscale Logos That Color on Hover</h2>
<p>Set <strong>Grayscale</strong> to 100 and <strong>Contrast</strong> to 110. The tool writes:</p>

{/* cfg-check: {"values":{"grayscale":100,"contrast":110}} */}
```css
.element {
  filter: contrast(110%) grayscale(100%);
}
```

<p>Use it as the resting state of a logo strip and add <code>.element:hover {'{'} filter: none; {'}'}</code> with <code>transition: filter 0.3s</code>. The transition is smooth because one side is <code>none</code>.</p>

<h2>Example: Reusing Light Screenshots in Dark Mode</h2>
<p>Set <strong>Invert</strong> to 100 and <strong>Hue Rotate</strong> to 180:</p>

{/* cfg-check: {"values":{"invert":100,"hue-rotate":180}} */}
```css
.element {
  filter: hue-rotate(180deg) invert(100%);
}
```

<p>White backgrounds turn black and the 180° rotation brings hues back near their original color: drawn in Chrome with this filter, <code>#1a73e8</code> became <code>rgb(72, 161, 255)</code>, a lighter blue, instead of the orange that invert alone gives. Apply it inside <code>@media (prefers-color-scheme: dark)</code> to diagrams and screenshots only; photos look wrong inverted.</p>

<h2>Function Order and Limits</h2>
<ul>
  <li><strong>Fixed order.</strong> The output always lists functions in the slider order (blur, brightness, contrast, grayscale, hue-rotate, invert, opacity, saturate, sepia), and the preview uses the same string. Order matters once a channel clips: on a <code>#999999</code> fill, <code>brightness(200%) contrast(50%)</code> gives <code>rgb(191, 191, 191)</code>, while <code>contrast(50%) brightness(200%)</code> gives white. Reorder the functions by hand if you need a different sequence.</li>
  <li><strong>Ranges:</strong> blur 0–20px in 0.1px steps, brightness, contrast and saturate 0–200%, hue-rotate 0–360deg, the rest 0–100%. The spec accepts larger values (brightness, contrast and saturate have no upper limit); type them into the CSS yourself.</li>
  <li><strong>Not included:</strong> <code>drop-shadow()</code> and <code>url()</code> references to SVG filters. For blurring what is behind a glass panel, the property is <code>backdrop-filter</code>, not <code>filter</code>: <code>filter: blur()</code> blurs the element itself, text included.</li>
  <li><strong>Containing block.</strong> Any value other than <code>none</code> makes the element the containing block for absolutely and fixed-positioned descendants, unless the element is the document root (<code>html</code>) (<a href="https://www.w3.org/TR/filter-effects-1/#FilterProperty">Filter Effects Level 1</a>).</li>
  <li>Preview images are limited to 5 MB and stay in the page. A larger file or a file that is not an image is not loaded: the status line gives the reason and the preview keeps the current image. The slider values are saved in this browser so the tool reopens with your last settings.</li>
</ul>
<p>The <code>filter</code> property works without a prefix in Chrome 53, Firefox 35 and Safari 9.1 and later (MDN browser compat data). For shadows around the element's box, use the <a href="/tools/box-shadow-generator/">box shadow generator</a>.</p>

<h2>Example: Zero Brightness and Opacity</h2>
<p>Set Brightness and Opacity to zero while leaving the other seven controls at their defaults. The generator preserves both zero values and writes brightness before opacity. Reset Opacity alone to 100 to remove opacity() from the rule; brightness(0%) stays.</p>

{/* cfg-check: {"values":{"brightness":0,"opacity":0},"out":"brightness(0%) opacity(0%)"} */}
```css
.element {
  filter: brightness(0%) opacity(0%);
}
```
