<h2>使用方法</h2>
<ol>
  <li>在输入框中输入或粘贴文本。</li>
  <li>选择分隔符（连字符、下划线或点）。</li>
  <li>根据需要开启或关闭小写和修剪选项。</li>
  <li>Slug 实时更新，点击 <strong>Copy</strong> 复制到剪贴板。</li>
</ol>

<h2>限制</h2>
<ul>
  <li>只转写表中列出的字母，其他带重音的字母会被删除：<code>{"Łódź"}</code> → <code>{"od"}</code>，<code>{"Škoda"}</code> → <code>{"koda"}</code>。</li>
  <li>非拉丁文字会被删除，只输入中文、日文或韩文时结果为空。</li>
  <li>撇号会被当作分隔符：<code>{"John's Guide"}</code> → <code>{"john-s-guide"}</code>。</li>
  <li>关闭「修剪」时，开头和结尾的分隔符会保留：<code>{"Hello World!"}</code> → <code>{"hello-world-"}</code>。</li>
</ul>

  <li><strong>数据库键：</strong> 无空格的可读唯一标识符。</li>
</ul>
