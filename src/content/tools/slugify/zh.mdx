<h2>字符映射</h2>
<p>符号换成独立的单词，Rock &amp; Roll 得到 <code>{"rock-and-roll"}</code>，Tom&amp;Jerry 得到 <code>{"tom-and-jerry"}</code>。带附加符号的字母去掉符号（先做 Unicode NFD 分解，再删去组合附加符号）：é → e、ñ → n、<code>{"Łódź"}</code> → <code>{"lodz"}</code>、<code>{"Tiếng Việt"}</code> → <code>{"tieng-viet"}</code>。不能分解的字母按第二张表替换，取值参考 <a href="https://github.com/sindresorhus/transliterate" rel="noopener">sindresorhus/transliterate</a>。大写字母保持大写（Ø → O、Œ → OE），开启「小写」时再转为小写。</p>

<h2>限制</h2>
<ul>
  <li>去掉附加符号时不按语言区分：德语 <code>{"ä ö ü"}</code> 变成 <code>{"a o u"}</code>（不是 <code>{"ae oe ue"}</code>），土耳其语 <code>{"İ"}</code> 变成 <code>{"I"}</code>。</li>
  <li>非拉丁文字会被删除，只输入中文、日文或韩文时结果为空。</li>
  <li>撇号会被当作分隔符：<code>{"John's Guide"}</code> → <code>{"john-s-guide"}</code>。</li>
  <li>关闭「修剪」时，开头和结尾的分隔符会保留：<code>{"Hello World!"}</code> → <code>{"hello-world-"}</code>。</li>
</ul>

<h2>Slug 的使用场景</h2>
<ul>
  <li><strong>博客文章 URL：</strong> <code>/blog/how-to-use-slugs</code></li>
  <li><strong>商品页面：</strong> <code>/products/red-running-shoes</code></li>
  <li><strong>文件名：</strong> <code>my-important-document.pdf</code></li>
  <li><strong>数据库键：</strong> 无空格的可读唯一标识符。</li>
</ul>
<p>
  一致的 Slug 生成策略可确保 URL 保持稳定且对 SEO 友好，即使原始标题在格式或标点上发生变化也不受影响。
</p>
