## 한글 제목을 넣으면

이 도구는 한글을 로마자로 바꾸지 않고 지웁니다. 남는 것은 제목 속 영문, 숫자, 그리고 아래 변환표에 있는 기호뿐입니다. 기본 옵션(하이픈, 소문자, 다듬기)으로 실제로 변환한 결과입니다.

- {/* slug-check: {"in":"2026년 서울 맛집 TOP 10"} */}`2026년 서울 맛집 TOP 10` → `2026-top-10`
- {/* slug-check: {"in":"React 19 업데이트 정리"} */}`React 19 업데이트 정리` → `react-19`
- {/* slug-check: {"in":"Spring Boot 3.3 + JPA 설정 방법"} */}`Spring Boot 3.3 + JPA 설정 방법` → `spring-boot-3-3-plus-jpa`
- {/* slug-check: {"in":"Spring Boot 3.3 + JPA 설정 방법","sep":"_","lower":false} */}같은 제목에서 구분자를 밑줄로 바꾸고 소문자를 끄면: `Spring Boot 3.3 + JPA 설정 방법` → `Spring_Boot_3_3_plus_JPA`

한글이 빠지면 글의 내용을 알기 어려운 슬러그가 됩니다. 이럴 때는 영문 제목이나 로마자 표기를 직접 써서 넣으세요.

- {/* slug-check: {"in":"Seoul Matjip Top 10"} */}`Seoul Matjip Top 10` → `seoul-matjip-top-10`

## 조사, 자모, 원화 기호

영문 단어 뒤에 붙은 조사는 한글이므로 지워지고, 지워진 자리는 공백으로 처리됩니다. 그래서 조사를 사이에 두고 영문이 이어져도 두 단어가 구분자로 나뉩니다.

- {/* slug-check: {"in":"Next.js로 블로그 만들기"} */}`Next.js로 블로그 만들기` → `next-js`
- {/* slug-check: {"in":"Vue3와Vite로 시작하기"} */}`Vue3와Vite로 시작하기` → `vue3-vite`

`ㅋㅋ` 같은 한글 자모도 지워지므로, 한글과 자모만 있는 입력은 결과가 비고 경고가 표시되며 복사 버튼이 비활성화됩니다.

- {/* slug-check: {"in":"맛집 후기 ㅋㅋ","empty":true} */}`맛집 후기 ㅋㅋ` → 빈 결과

원화 기호 `₩`(U+20A9)는 변환표에서 `won`이 됩니다. 유니코드 문자 이름이 WON SIGN이므로, YEN SIGN인 `¥`를 `yen`, EURO SIGN인 `€`를 `euro`로 쓰는 것과 같은 방식입니다([Unicode 통화 기호 코드 차트](https://www.unicode.org/charts/PDF/U20A0.pdf)). 전각 `￦`(U+FFE6)는 먼저 `₩`로 바뀌므로 결과가 같습니다.

- {/* slug-check: {"in":"₩10,000 할인 쿠폰"} */}`₩10,000 할인 쿠폰` → `won-10-000`
- {/* slug-check: {"in":"￦10,000 할인 쿠폰"} */}`￦10,000 할인 쿠폰` → `won-10-000`


<h2>문자 변환표</h2>
<p>기호는 별도 단어가 되어 Rock &amp; Roll은 <code>{"rock-and-roll"}</code>, Tom&amp;Jerry는 <code>{"tom-and-jerry"}</code>가 됩니다. 악센트가 있는 문자는 기호를 뗍니다(Unicode NFD 분해 후 결합 기호 삭제): é → e, ñ → n, <code>{"Łódź"}</code> → <code>{"lodz"}</code>, <code>{"Tiếng Việt"}</code> → <code>{"tieng-viet"}</code>. 분해되지 않는 문자는 두 번째 표로 바꿉니다(값은 <a href="https://github.com/sindresorhus/transliterate" rel="noopener">sindresorhus/transliterate</a> 기준). 대문자는 대문자로 바뀌고(Ø → O, Œ → OE) '소문자'가 켜져 있으면 소문자가 됩니다.</p>

<h2>제한 사항</h2>
<ul>
  <li>기호는 언어별 규칙 없이 뗍니다: 독일어 <code>{"ä ö ü"}</code>는 <code>{"a o u"}</code>(<code>{"ae oe ue"}</code>가 아님), 터키어 <code>{"İ"}</code>는 <code>{"I"}</code>가 됩니다.</li>
  <li>라틴 문자가 아닌 문자는 제거되므로 한국어만 입력하면 빈 결과가 나옵니다.</li>
  <li>두 글자 사이의 아포스트로피(<code>{"'"}</code>, <code>{"’"}</code>, <code>{"ʼ"}</code>)는 지웁니다: {/* slug-check: {"in":"John's Guide"} */}<code>{"John's Guide"}</code> → <code>{"johns-guide"}</code>. 옆이 공백, 숫자, 문자열 끝이면 구분자로 처리합니다: {/* slug-check: {"in":"rock 'n' roll"} */}<code>{"rock 'n' roll"}</code> → <code>{"rock-n-roll"}</code>.</li>
  <li>'다듬기'를 끄면 앞뒤의 구분자가 남습니다: <code>{"Hello World!"}</code> → <code>{"hello-world-"}</code>.</li>
  <li>한글을 로마자로 바꾸지 않습니다.</li>
  <li>a, the, of 같은 단어를 빼지 않고 길이 제한도 없어서, 긴 제목은 긴 슬러그가 됩니다. CMS에 슬러그 길이 제한이 있으면 직접 줄이세요.</li>
  <li>한 번에 문자열 하나만 변환합니다. 줄바꿈은 공백으로 처리되므로 여러 줄을 붙여 넣으면 긴 슬러그 하나가 됩니다.</li>
</ul>
