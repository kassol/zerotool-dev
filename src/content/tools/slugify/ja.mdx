<h2>使い方</h2>
<ol>
  <li>入力欄にテキストを貼り付けるか入力します。</li>
  <li>区切り文字（ハイフン・アンダースコア・ドット）を選択します。</li>
  <li>小文字化とトリムオプションを必要に応じて切り替えます。</li>
  <li>スラグはリアルタイムで更新されます。<strong>Copy</strong> をクリックしてコピーします。</li>
</ol>

<h2>文字の変換表</h2>
<p>記号は独立した単語になり、Rock &amp; Roll は <code>{"rock-and-roll"}</code>、Tom&amp;Jerry は <code>{"tom-and-jerry"}</code> になります。アクセント付きの文字は記号を外します（Unicode の NFD 分解のあと結合記号を削除）：é → e、ñ → n、<code>{"Łódź"}</code> → <code>{"lodz"}</code>、<code>{"Tiếng Việt"}</code> → <code>{"tieng-viet"}</code>。分解できない文字は 2 つ目の表で置き換えます（値は <a href="https://github.com/sindresorhus/transliterate" rel="noopener">sindresorhus/transliterate</a> に準拠）。大文字は大文字のまま変換し（Ø → O、Œ → OE）、「小文字」がオンなら小文字にします。</p>

<h2>制限事項</h2>
<ul>
  <li>記号は言語ごとの規則なしで外します：ドイツ語の <code>{"ä ö ü"}</code> は <code>{"a o u"}</code>（<code>{"ae oe ue"}</code> ではない）、トルコ語の <code>{"İ"}</code> は <code>{"I"}</code> になります。</li>
  <li>ラテン文字以外の文字は削除されるため、日本語だけの入力は空になります。</li>
  <li>アポストロフィは区切りになります：<code>{"John's Guide"}</code> → <code>{"john-s-guide"}</code>。</li>
  <li>「トリム」をオフにすると、先頭と末尾の区切り文字が残ります：<code>{"Hello World!"}</code> → <code>{"hello-world-"}</code>。</li>
</ul>
