## 日本語タイトルを入れたときの結果

ひらがな・カタカナ・漢字はローマ字にせず削除します。残るのはタイトル中の英数字と、後述の変換表にある記号だけです。初期設定（ハイフン、小文字、トリム）での実際の出力です。

- {/* slug-check: {"in":"GitHub Actions 実践ガイド 2026"} */}`GitHub Actions 実践ガイド 2026` → `github-actions-2026`
- {/* slug-check: {"in":"Next.js 15 入門","sep":"_"} */}区切り文字をアンダースコアにした場合：`Next.js 15 入門` → `next_js_15`
- {/* slug-check: {"in":"カフェ・ド・パリ Café de Paris"} */}`カフェ・ド・パリ Café de Paris` → `cafe-de-paris`（中黒も削除）
- {/* slug-check: {"in":"【2026年版】Next.js 15 入門"} */}`【2026年版】Next.js 15 入門` → `2026-next-js-15`

最後の例のように、削除した漢字や【】の位置は空白として扱うので、半角スペースがなくても `2026` と `next` は区切られます。

日本語の内容をスラッグに残したいときは、自分でローマ字や英語に書き換えてから入力します。長音記号（マクロン）付きのローマ字はそのまま貼り付けて構いません。NFD 分解のあとで記号が外れます。

- {/* slug-check: {"in":"Tōkyō Sukaitsurī Gaido"} */}`Tōkyō Sukaitsurī Gaido` → `tokyo-sukaitsuri-gaido`

## 全角文字と円記号

全角の英数字・記号と全角スペース（U+3000）は、最初に NFKC 正規化で半角にしてから変換します。半角で入力した場合と同じ結果になります。

- {/* slug-check: {"in":"ＷｏｒｄＰｒｅｓｓ入門"} */}`ＷｏｒｄＰｒｅｓｓ入門` → `wordpress`
- {/* slug-check: {"in":"WordPress入門"} */}半角で `WordPress入門` → `wordpress`
- {/* slug-check: {"in":"Hello　World"} */}全角スペースをはさんだ `Hello　World` → `hello-world`

全角の `％`（U+FF05）と `￥`（U+FFE5）も半角の `%` と `¥`（U+00A5）になり、変換表で単語に置き換わります。

- {/* slug-check: {"in":"50% OFF セール"} */}`50% OFF セール` → `50-percent-off`
- {/* slug-check: {"in":"100％ 純正"} */}`100％ 純正` → `100-percent`
- {/* slug-check: {"in":"価格 ¥1,980（税込）"} */}`価格 ¥1,980（税込）` → `yen-1-980`
- {/* slug-check: {"in":"価格 ￥1,980（税込）"} */}`価格 ￥1,980（税込）` → `yen-1-980`

NFKC をかけるのは全角英数字・記号と全角スペースだけです。`™` のような記号は NFKC では `TM` になりますが、このツールでは変換表どおり `tm` という単語になります。

## WordPress のスラッグとの違い

WordPress 7.1.2 は日本語を削除せず、`sanitize_title_with_dashes()` でパーセントエンコードして残します（[formatting.php](https://github.com/WordPress/wordpress-develop/blob/7.1.2/src/wp-includes/formatting.php)）。[解説記事](/ja/blog/slugify-guide/)で実行した結果では、`WordPress入門` は WordPress では `wordpress%e5%85%a5%e9%96%80`、このツールでは上の例のとおり `wordpress` です。

スラッグを作るタイミングも違います。WordPress の `wp_insert_post()` は、スラッグが空のまま公開などで保存されたときだけタイトルから作ります（[post.php](https://github.com/WordPress/wordpress-develop/blob/7.1.2/src/wp-includes/post.php)）。公開後にタイトルを直してもスラッグは変わりません。スラッグを手で変えると古い値が `_wp_old_slug` に残り、古い URL が 404 になる場面では `wp_old_slug_redirect()` が 301 で新しい URL へ転送します（[query.php](https://github.com/WordPress/wordpress-develop/blob/7.1.2/src/wp-includes/query.php)）。このツールは入力欄の文字から毎回作り直すので、公開済みの記事のタイトルを直したあとに出てきたスラッグで上書きしないようにしてください。

<h2>制限事項</h2>
<ul>
  <li>アクセント記号は言語ごとの規則なしで外します：ドイツ語の <code>{"ä ö ü"}</code> は <code>{"a o u"}</code>（<code>{"ae oe ue"}</code> ではない）、トルコ語の <code>{"İ"}</code> は <code>{"I"}</code> になります。</li>
  <li>ラテン文字以外の文字は削除されるため、トリムが有効なら日本語だけの入力は空になります。トリムを無効にすると区切り文字が 1 つだけ残ります：{/* slug-check: {"in":"東京","trim":false} */}<code>{"東京"}</code> → <code>{"-"}</code>。</li>
  <li>英字か数字のあと、英字の前にあるアポストロフィ（<code>{"'"}</code>、<code>{"’"}</code>、<code>{"‘"}</code>、<code>{"ʼ"}</code>、<code>{"ʻ"}</code>、<code>{"´"}</code>、<code>{"′"}</code>）は削除します：{/* slug-check: {"in":"John's Guide"} */}<code>{"John's Guide"}</code> → <code>{"johns-guide"}</code>、{/* slug-check: {"in":"1990's Music"} */}<code>{"1990's Music"}</code> → <code>{"1990s-music"}</code>。隣が空白のときや、文字列の先頭・末尾にあるときは区切りになります：{/* slug-check: {"in":"rock 'n' roll"} */}<code>{"rock 'n' roll"}</code> → <code>{"rock-n-roll"}</code>。</li>
  <li>「トリム」をオフにすると、先頭と末尾の区切り文字が残ります：<code>{"Hello World!"}</code> → <code>{"hello-world-"}</code>。</li>
  <li>ローマ字への変換は行いません。</li>
  <li>a、the、of などの語は残し、長さの上限もありません。CMS にスラッグの文字数制限がある場合は手で短くしてください。</li>
  <li>1 回に変換できるのは 1 つの文字列です。改行は空白として扱うため、複数行を貼り付けると 1 つの長いスラッグになります。</li>
</ul>
