<h2>使い方</h2>
<ol>
  <li>エンコードまたはデコードしたいテキストを入力欄に貼り付けます。</li>
  <li><strong>エンコード</strong>または<strong>デコード</strong>をクリックします。フォームデータを扱うときは<strong>スペースを + に（フォームデータ）</strong>をオンにします。エンコードは <code>URLSearchParams</code> と同じになり（<code>a b+c</code> → <code>a+b%2Bc</code>、<code>! ' ( ) ~</code> もエンコード）、デコードでは <code>+</code> をスペースとして読みます。既定は RFC 3986 どおりで、スペースは <code>%20</code>、<code>+</code> はそのままです。</li>
  <li>デコードに失敗すると位置と原因を表示します。<code>%</code> の後が 16 進数 2 桁でない（<code>100%</code> など）か、UTF-8 でないバイト（Shift_JIS の「あ」<code>%82%A0</code> など）です。対応する文字コードは UTF-8 だけです。</li>
  <li><strong>コピー</strong>で結果をクリップボードにコピーします。</li>
</ol>

<h2>URLエンコードについて</h2>
<p>URLで使用できる文字はASCII文字の一部に限られています。スペース、日本語、特殊記号などはパーセントエンコーディングで%XXという形式に変換する必要があります。</p>
<p>フォームの送信、APIリクエストの構築、URLの手動作成などで頻繁に必要になります。</p>
