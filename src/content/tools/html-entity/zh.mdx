<h2>示例演示</h2>

<h3>编码代码片段以供展示</h3>
<p>
  你希望在网页上将 <code>&lt;div class="box"&gt;</code> 作为可见文本显示。
  将其粘贴到输入框并选择<strong>编码</strong>，输出为：
</p>
<pre><code>&amp;lt;div class=&amp;quot;box&amp;quot;&amp;gt;</code></pre>
<p>这样可以在任何浏览器中安全地渲染为字面量 HTML 标签文本。</p>

<h3>解码接收到的 HTML 内容</h3>
<p>
  你从 API 收到字符串：<code>Tom &amp;amp; Jerry &amp;mdash; Season 1</code>。
  将其粘贴并选择<strong>解码</strong>，输出为：
</p>
<pre><code>Tom &amp; Jerry — Season 1</code></pre>

<h3>编码非 ASCII 字符</h3>
<p>
  粘贴 <code>Caf&eacute; &copy; 2024</code> 并选择<strong>编码</strong>，
  非 ASCII 字符将被转换为数值实体：
</p>
<pre><code>Caf&amp;#233; &amp;#169; 2024</code></pre>
