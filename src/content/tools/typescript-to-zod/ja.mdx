<h2>使い方</h2>
<ol>
  <li>TypeScriptの<code>interface</code>または<code>type</code>宣言を左のパネルに貼り付けます。</li>
  <li>入力停止から300ms後に自動でバリデーションと変換が行われます。</li>
  <li><strong>Zodスキーマを生成</strong>ボタンで強制変換できます。</li>
  <li><strong>コピー</strong>ボタンでZod出力をクリップボードにコピーします。</li>
  <li>結果をプロジェクトに貼り付けます。出力には<code>import</code>文と<code>export type</code>の型推論行がすでに含まれています。</li>
</ol>

<h2>対応TypeScript機能</h2>
<ul>
  <li><strong>基本型</strong>：<code>string</code>、<code>number</code>、<code>boolean</code>、<code>null</code>、<code>undefined</code>、<code>any</code>、<code>unknown</code>、<code>void</code>、<code>never</code>、<code>bigint</code>、<code>symbol</code></li>
  <li><strong>省略可能プロパティ</strong>：<code>prop?: type</code> → <code>.optional()</code></li>
  <li><strong>Union型</strong>：<code>A | B</code> → <code>z.union([A, B])</code></li>
  <li><strong>文字列enum</strong>：<code>"a" | "b" | "c"</code> → <code>z.enum(["a", "b", "c"])</code></li>
  <li><strong>配列</strong>：<code>T[]</code> / <code>Array&lt;T&gt;</code> → <code>z.array(T)</code></li>
  <li><strong>ネストオブジェクト</strong>：インラインオブジェクト型 → <code>z.object(&#123;&#125;)</code></li>
  <li><strong>相互参照</strong>：宣言済み型間の参照 → Schemaの定数</li>
  <li><strong>readonly</strong>：<code>readonly</code>修飾子を受け入れ、変換時に取り除きます（読み取り専用の型が必要なら <code>.readonly()</code> を追加）</li>
  <li><strong>ユーティリティ型</strong>：<code>Partial&lt;T&gt;</code>、<code>Record&lt;K, V&gt;</code>、<code>Promise&lt;T&gt;</code></li>
  <li><strong>交差型</strong>：<code>A &amp; B</code> → <code>z.intersection(A, B)</code></li>
  <li><strong>タプル</strong>：<code>[A, B]</code> → <code>z.tuple([A, B])</code></li>
  <li><strong>リテラル型</strong>：<code>"value"</code>、<code>42</code>、<code>true</code> → <code>z.literal()</code></li>
</ul>

<h2>サンプル</h2>
<p>以下のTypeScriptを入力すると：</p>
<pre><code>{`interface Address {
  street: string;
  city: string;
  zipCode?: string;
}

export interface User {
  id: number;
  name: string;
  role: "admin" | "user" | "guest";
  age?: number;
  isActive: boolean;
  tags: string[];
  address: Address;
}

export type Status = "active" | "inactive" | "pending";`}</code></pre>
<p>このように生成されます：</p>
<pre><code>{`import { z } from "zod";

export const AddressSchema = z.object({
  street: z.string(),
  city: z.string(),
  zipCode: z.string().optional(),
});
export type Address = z.infer<typeof AddressSchema>;

export const UserSchema = z.object({
  id: z.number(),
  name: z.string(),
  role: z.enum(["admin", "user", "guest"]),
  age: z.number().optional(),
  isActive: z.boolean(),
  tags: z.array(z.string()),
  address: AddressSchema,
});
export type User = z.infer<typeof UserSchema>;

export const StatusSchema = z.enum(["active", "inactive", "pending"]);
export type Status = z.infer<typeof StatusSchema>;`}</code></pre>

<h2>例：会員登録フォーム</h2>

<p>入力：</p>

<pre><code>{`interface SignupForm {
  email: string;
  password: string;
  nickname?: string;
  referrer: string | null;
  age?: number | undefined;
  plan: "free" | "pro";
}`}</code></pre>

<p>出力：</p>

<pre><code>{`import { z } from "zod";

export const SignupFormSchema = z.object({
  email: z.string(),
  password: z.string(),
  nickname: z.string().optional(),
  referrer: z.union([z.string(), z.null()]),
  age: z.union([z.number(), z.undefined()]).optional(),
  plan: z.enum(["free", "pro"]),
});
export type SignupForm = z.infer<typeof SignupFormSchema>;`}</code></pre>

<p>生成したスキーマで zod 3.25 を使い 3 つのデータを検証した結果：</p>

<pre><code>{`SignupFormSchema.safeParse({ email: "not-an-email", password: "1", referrer: null, plan: "pro" })
// success: true  (types match; no format rules yet)

SignupFormSchema.safeParse({ email: "a@example.com", password: "x", plan: "free" })
// referrer: Invalid input  (string | null is required, it cannot be missing)

SignupFormSchema.safeParse({ email: "a@example.com", password: "x", referrer: "ad", plan: "team" })
// plan: Invalid enum value. Expected 'free' | 'pro', received 'team'`}</code></pre>

<h2>null・undefined・省略可能の違い</h2>

<ul>
  <li><code>{"prop?: T"}</code> は <code>{".optional()"}</code> になります。キーがなくてもかまいません。</li>
  <li><code>{"T | null"}</code> は <code>{"z.union([T, z.null()])"}</code>、つまり <code>{"T.nullable()"}</code> と同じです。キーは必須で、値に <code>{"null"}</code> を許します。<code>{"referrer"}</code> のないデータは失敗します。</li>
  <li>省略可能かつ null 可（<code>{"prop?: T | null"}</code>）なら両方が必要です。API がそう返すなら <code>{".nullish()"}</code> と手で書きます。</li>
</ul>

<h2>TypeScript では書けないルールを足す</h2>

<p>TypeScript の型には形式や範囲がないため、上の 1 件目は不正なメールアドレスと 1 文字のパスワードでも通ります。生成後に制約を足します：</p>

<pre><code>{`export const SignupFormSchema = z.object({
  email: z.string().email(),
  password: z.string().min(8),
  nickname: z.string().max(20).optional(),
  referrer: z.string().nullable(),
  age: z.number().int().min(13).optional(),
  plan: z.enum(["free", "pro"]),
});`}</code></pre>

<p>生成した <code>{"z.infer"}</code> の型を唯一の定義にして元の interface は消すと、両者がずれていくことを防げます。</p>
