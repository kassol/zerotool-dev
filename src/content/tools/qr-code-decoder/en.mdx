## What You See for Each Content Type

The decoder reads the text in the code and picks a card from its first characters. Nothing is opened automatically: a URL is shown as a link you can inspect before clicking.

| Text in the code starts with | Badge | Shown as |
|---|---|---|
| `http://` or `https://` | URL | Clickable link (opens in a new tab only when you click) and Copy |
| `WIFI:` | Wi-Fi | Table with SSID, password, encryption and hidden flag |
| `BEGIN:VCARD` | vCard | Raw text |
| `mailto:` | Email | Raw text |
| `tel:` | Phone | Raw text |
| `sms:` or `smsto:` | SMS | Raw text |
| Anything else (`geo:`, `MECARD:`, `www.example.com` without a scheme, plain text in any language) | Text | Raw text |

Examples checked by generating the codes with the qrcode library and decoding them with the jsQR build this page loads:

- `WIFI:T:WPA;S:CafeGuest;P:latte2026;;` shows SSID `CafeGuest`, password `latte2026`, encryption `WPA`.
- `https://zerotool.dev/tools/qr-code-decoder/` shows the URL card with the full address.
- `smsto:+819012345678:Hello` gets the SMS badge; `geo:35.6812,139.7671` and `MECARD:N:Sato,Taro;TEL:0312345678;;` show as text.

## Tips for Images That Do Not Decode

- **Crop to the code.** Leave a small white margin (the quiet zone) around it; a wide photo where the code is a small part of the frame fails more often.
- **Use a screenshot when you can.** A screenshot of a code on screen is sharper than a phone photo of a printed code.
- **Avoid glare and steep angles.** jsQR corrects some perspective, but reflections over the finder patterns (the three big squares) can stop it.
- **Light-on-dark codes work.** If the normal pass finds nothing, the decoder tries again with the colors inverted.
- **Damage is tolerated up to the code's error-correction level**: about 7%, 15%, 25% or 30% of the codewords for levels L, M, Q and H ([DENSO WAVE: Error correction](https://www.qrcode.com/en/about/error_correction.html)).

## Limits

- **One code per image.** If an image has several codes, only one result is shown; crop to the one you want.
- **Wi-Fi fields are read with a simple pattern.** The Wi-Fi format escapes `;`, `:`, `,`, `"` and `\` with a backslash ([ZXing: Barcode Contents](https://github.com/zxing/zxing/wiki/Barcode-Contents)). The decoder does not remove the escapes, and a value that contains `\;` is cut at that point: `S:Home\;Net` shows the SSID as `Home\`. An unescaped `P:` inside the SSID is also taken as the password (`S:SHOP:2F;P:secret` shows the password `2F`). When the table looks wrong, read the raw string with Copy.
- **Only image files.** PDFs must be screenshotted first. Formats your browser cannot display (for example HEIC outside Safari) cannot be read.
- **URL mode downloads the image from that address.** It works only if the server allows cross-origin requests (CORS); otherwise download the image and drop it in.
- The image is decoded at full resolution; very large photos take longer.
