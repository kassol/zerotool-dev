## What the Reader Shows

| Text in the code starts with | Badge | Shown as |
|---|---|---|
| `http://` or `https://` | URL | Link (opens only when you click it), the real host, warnings |
| `WIFI:` | Wi-Fi | SSID, password, encryption, hidden flag; backslash escapes removed ([ZXing: Barcode Contents](https://github.com/zxing/zxing/wiki/Barcode-Contents)) |
| `BEGIN:VCARD` or `MECARD:` | Contact | Name, organization, phone, email, address, URL, note |
| `mailto:` or `MATMSG:` | Email | To, Cc, subject, body ([RFC 6068](https://www.rfc-editor.org/rfc/rfc6068)) |
| `tel:` | Phone | Number ([RFC 3966](https://www.rfc-editor.org/rfc/rfc3966)) |
| `sms:` or `SMSTO:` | SMS | Number and message ([RFC 5724](https://www.rfc-editor.org/rfc/rfc5724)) |
| `geo:` | Location | Latitude, longitude, altitude and an OpenStreetMap link ([RFC 5870](https://www.rfc-editor.org/rfc/rfc5870)) |
| any other `scheme:` | App link | Text only, with a note that only an app opens it |
| anything else | Text | Text as stored |

Structured cards keep the raw text one click away, and every card has a **Bytes** section with the stored bytes in hex.

These are the results the tool gave for codes generated with the page's own QR library:

- A business card code (`BEGIN:VCARD … FN:Ana Rivera … TEL;TYPE=CELL:+1-415-555-0134`) shows **Contact** with Name `Ana Rivera`, Organization `Example Labs`, Phone `+1-415-555-0134` and Email `ana@example.com`.
- A screenshot with three codes side by side gives three numbered cards in reading order: **Wi-Fi** (`CafeGuest` / `latte2026` / `WPA`), **URL** (`https://example.com/menu`), **Phone** (`+81312345678`). The preview numbers the codes on the image.
- `geo:37.5665,126.9780` shows **Location** with a link to that point on OpenStreetMap.

## Check a Link Before You Open It

The FTC [warns](https://consumer.ftc.gov/consumer-alerts/2023/12/scammers-hide-harmful-links-qr-codes-steal-your-information) that scammers paste their own QR codes over the ones on parking meters and send codes by email and text, and advises you to inspect the URL before you open it. Two tricks are hard to see on a phone screen, and the reader flags both:

- `https://citypark.example.gov@pay-meter.example.net/zone/4471` looks like a city domain. The host line says **pay-meter.example.net**, and a warning explains that everything before `@` is a user name.
- `https://exаmple.com/login` uses a Cyrillic `а`. The host line shows the punycode form **xn--exmple-4nf.com** with a look-alike warning.

Only `http` and `https` text becomes a link. `javascript:alert(document.domain)` is shown as an **App link** with the warning that it is not opened, and so are `data:`, `vbscript:` and `file:` addresses. To take a long address apart (query parameters, fragments, encoded characters), paste it into the [URL Parser](/tools/url-parser/).

## Photos, Screenshots and Hard Images

- **Several codes in one image** are all decoded, up to 16, and numbered from the top left.
- **Light-on-dark codes**, rotated codes and codes without a white margin are read as well.
- **Large photos** are decoded at full resolution up to 16,777,216 pixels (the canvas limit of iOS Safari); bigger images are scaled down first, and the status line says so. A 4000×3000 phone-style photo with a small code took about 1.2 s in desktop Chromium on the test machine.
- **Tiny codes** need roughly 1.5 image pixels per module: a 33-module code at 45×45 pixels failed, at 60×60 it read.

## Text Encoding: UTF-8, Shift_JIS, GBK and ECI

A QR code stores bytes. It can declare their character set with an ECI header (ISO/IEC 18004), but most generators just write UTF-8. With an ECI, the card says so (for example `UTF-8 (ECI 26)`). Without one, the reader follows [ZXing's guessing rule](https://github.com/zxing/zxing/blob/master/core/src/main/java/com/google/zxing/common/StringUtils.java): valid UTF-8 is UTF-8, then Shift_JIS or ISO-8859-1. The card labels the result `(guessed)`, and the **Text encoding** menu re-decodes the same bytes as UTF-8, Shift_JIS, GB18030/GBK, Big5, EUC-KR, ISO-8859-1 or UTF-16.

In tests, a code holding the Shift_JIS bytes of `東京都千代田区丸の内 カフェ` decoded correctly on this page. GBK bytes for `你好，世界。二维码测试` were guessed as ISO-8859-1 on the English page, as ZXing does, and read correctly after choosing GB18030 in the menu. Bytes that are not text in any encoding get the **Binary** badge and open in hex.

## How It Compares

Tested on 2026-09-30 with the same seven images in desktop Chromium:

| Image | ZeroTool | [ScanQR](https://scanqr.org/) | [DNS Checker](https://dnschecker.org/qr-code-scanner.php) |
|---|---|---|---|
| Three codes in one image | 3 cards | 3 found | Still "Scanning…" after 10 s |
| Shift_JIS text, no ECI | Correct text | "QR code detected!", empty text | "Empty QR Code" |
| GBK text, no ECI | Correct after picking GB18030 | Empty text | Still "Scanning…" after 11 s |
| Light-on-dark code | Read | Read | Read |
| Gray on gray (110/170) | Read | Read with its fallback engine | Read |
| `javascript:` payload | Text with warning | Plain text | Plain text |
| 4000×3000 photo, small code | Read (about 1.2 s) | "No QR code found" | Read |

Given `https://paypal.com@evil.example/login`, ScanQR shows the address as an Open Link button with no warning; ZeroTool shows the host `evil.example` and the `@` warning.

## Limits

- One image at a time. PDFs need a screenshot first; HEIC works only where the browser displays it (Safari).
- The first decode waits for the 420 KB decoder; after that, decoding is local and works offline until you reload.
- Only the QR family is read. For EAN, UPC or Code 128 barcodes this page shows nothing; the [Barcode Generator](/tools/barcode-generator/) makes them but does not read them.
- Chrome's built-in `BarcodeDetector` is not used: [MDN's compatibility data](https://developer.mozilla.org/docs/Web/API/BarcodeDetector) lists it only on macOS, ChromeOS and Android, not in Firefox, and behind a flag in Safari.
- URL mode works only when the image's server allows cross-origin requests (CORS). Otherwise save the image and drop it in.
- Wi-Fi cards show SSID, password, encryption and the hidden flag; WPA2-Enterprise fields such as `E:` and `I:` stay in the raw text.

To make a code rather than read one, use the [QR Code Generator](/tools/qr-code-generator/) or, for network logins, the [Wi-Fi QR Code Generator](/tools/wifi-qr-code-generator/).
