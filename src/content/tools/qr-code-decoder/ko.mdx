## 내용 종류별 표시 방식

디코더는 코드 안의 텍스트를 읽고, 앞부분 문자로 표시할 카드를 고릅니다. 자동으로 열리는 것은 없습니다. URL은 링크로 보여 주므로 확인한 뒤 클릭하면 됩니다.

| 코드 텍스트의 시작 | 배지 | 표시 |
|---|---|---|
| `http://` 또는 `https://` | URL | 클릭할 수 있는 링크(클릭할 때만 새 탭에서 열림)와 복사 |
| `WIFI:` | Wi-Fi | SSID, 비밀번호, 암호화 방식, 숨김 여부 표. 복사하면 같은 항목이 한 줄에 하나씩 `항목: 값`으로 들어감 |
| `BEGIN:VCARD` | vCard | 원문 텍스트 |
| `mailto:` | 이메일 | 원문 텍스트 |
| `tel:` | 전화 | 원문 텍스트 |
| `sms:` 또는 `smsto:` | SMS | 원문 텍스트 |
| 그 밖의 모든 것(`geo:`, `MECARD:`, 스킴 없는 `www.example.com`, 모든 언어의 일반 텍스트) | 텍스트 | 원문 텍스트 |

아래는 qrcode 라이브러리로 코드를 만들고 이 페이지가 불러오는 jsQR로 디코딩해 확인한 예시입니다:

- `WIFI:T:WPA;S:CafeGuest;P:latte2026;;`는 SSID `CafeGuest`, 비밀번호 `latte2026`, 암호화 `WPA`로 표시됩니다.
- `WIFI:T:WPA;S:SHOP:2F;P:ab\;cd;;`는 SSID `SHOP:2F`, 비밀번호 `ab;cd`로 표시됩니다. 백슬래시 이스케이프는 풀립니다.
- `https://zerotool.dev/tools/qr-code-decoder/`는 URL 카드에 전체 주소가 표시됩니다.
- `tel:+82-2-1234-5678`처럼 전화번호 코드는 전화 배지와 원문으로 표시되며, 전화를 걸지는 않습니다.

## 디코딩되지 않을 때

- **코드 부분만 잘라내세요.** 주변에 흰 여백(콰이어트 존)을 조금 남깁니다. 코드가 화면 일부만 차지하는 넓은 사진은 실패하기 쉽습니다.
- **가능하면 스크린샷을 쓰세요.** 화면에 뜬 코드의 스크린샷이 인쇄물을 휴대폰으로 찍은 사진보다 선명합니다.
- **반사와 심한 각도를 피하세요.** jsQR은 어느 정도의 원근 왜곡을 보정하지만, 큰 사각형 세 개(위치 검출 패턴)에 반사가 있으면 실패할 수 있습니다.
- **어두운 배경의 밝은 코드도 읽습니다.** 일반 판독에 실패하면 색을 반전해 한 번 더 시도합니다.
- **오류 정정 레벨 안의 손상은 괜찮습니다**: 레벨 L, M, Q, H에서 각각 약 7%, 15%, 25%, 30%의 코드워드를 복원합니다([DENSO WAVE: Error correction](https://www.qrcode.com/en/about/error_correction.html)).

## 제한 사항

- **이미지 하나에서 코드 하나만 읽습니다.** 여러 코드가 있어도 결과는 하나입니다. 읽을 코드만 잘라내세요.
- **Wi-Fi 항목은 ZXing 형식으로 읽습니다.** 백슬래시가 `;`, `:`, `,`, `"`, `\`를 이스케이프합니다([ZXing: Barcode Contents](https://github.com/zxing/zxing/wiki/Barcode-Contents)). 디코더는 항목을 하나씩 읽고 이스케이프를 푼 값을 표시하고 복사합니다(`S:Home\;Net`은 `Home;Net`). 값 안의 `;`를 이스케이프하지 않는 생성기로 만든 코드는 거기서 값이 끝납니다(`P:ab;cd`는 `ab`). SSID, 비밀번호, 암호화 방식, 숨김 여부만 표시하며 `E:`, `I:` 같은 WPA2 엔터프라이즈 항목은 표시하지 않습니다.
- **이미지 파일만 받습니다.** PDF는 먼저 스크린샷을 찍으세요. 브라우저가 표시하지 못하는 형식(Safari 외 브라우저의 HEIC 등)은 읽을 수 없습니다.
- **URL 모드는 입력한 주소에서 이미지를 내려받습니다.** 서버가 교차 출처 요청(CORS)을 허용할 때만 성공하며, 안 되면 이미지를 저장한 뒤 끌어다 놓으세요.
- 이미지를 원래 해상도로 디코딩하므로 아주 큰 사진은 시간이 더 걸립니다.
