## 各类内容的显示方式

解码器读出二维码里的文本，按开头的字符选择显示卡片。不会自动打开任何东西：网址显示为链接，确认后再点。

| 二维码文本开头 | 标签 | 显示方式 |
|---|---|---|
| `http://` 或 `https://` | URL | 可点击的链接（只有点击时才在新标签页打开）和复制按钮 |
| `WIFI:` | Wi-Fi | 表格：SSID、密码、加密方式、是否隐藏；复制按钮复制同样的字段，每行一个「名称: 值」 |
| `BEGIN:VCARD` | vCard | 原始文本 |
| `mailto:` | 邮箱 | 原始文本 |
| `tel:` | 电话 | 原始文本 |
| `sms:` 或 `smsto:` | 短信 | 原始文本 |
| 其他（`geo:`、`MECARD:`、不带协议的 `www.example.com`、任何语言的纯文本） | 文本 | 原始文本 |

以下示例用 qrcode 库生成二维码，再用本页加载的 jsQR 解码核对：

- `WIFI:T:WPA;S:CafeGuest;P:latte2026;;` 显示 SSID `CafeGuest`、密码 `latte2026`、加密 `WPA`。
- `WIFI:T:WPA;S:SHOP:2F;P:ab\;cd;;` 显示 SSID `SHOP:2F`、密码 `ab;cd`：反斜杠转义已去掉。
- `https://zerotool.dev/tools/qr-code-decoder/` 显示 URL 卡片和完整地址。
- `你好，世界` 按文本显示，中文不会乱码。

## 解不出来时

- **裁到只剩二维码。** 四周保留一圈白边（静区）；二维码只占画面一小块的大图更容易失败。
- **能截图就截图。** 屏幕上二维码的截图比手机拍的打印件清晰。
- **避开反光和大角度。** jsQR 能校正一定的透视变形，但三个大方块（定位图形）上有反光时可能失败。
- **深色底浅色码也能解。** 正常识别不到时，解码器会反色再试一次。
- **损坏程度在纠错等级之内都能解**：L、M、Q、H 四级分别约可恢复 7%、15%、25%、30% 的码字（[DENSO WAVE：纠错功能](https://www.qrcode.com/en/about/error_correction.html)）。

## 限制

- **一张图只解一个码。** 图里有多个二维码时只显示一个结果，先裁出要解的那个。
- **Wi-Fi 字段按 ZXing 格式读取。** 反斜杠转义 `;`、`:`、`,`、`"` 和 `\`（[ZXing：Barcode Contents](https://github.com/zxing/zxing/wiki/Barcode-Contents)）；解码器逐个字段读取，显示和复制的都是去掉转义后的值（`S:Home\;Net` 为 `Home;Net`）。生成器如果在值里写了没转义的 `;`，值会在那里结束：`P:ab;cd` 读成 `ab`。只显示 SSID、密码、加密方式和是否隐藏，`E:`、`I:` 等 WPA2 企业版字段不显示。
- **只接受图片文件。** PDF 要先截图。浏览器不能显示的格式（例如 Safari 以外的 HEIC）读不了。
- **URL 模式会从该地址下载图片。** 只有服务器允许跨域（CORS）时才能成功，否则先下载图片再拖进来。
- 图片按原始分辨率解码，很大的照片会慢一些。
