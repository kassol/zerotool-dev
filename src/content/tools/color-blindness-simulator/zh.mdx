<h2>使用方法</h2>
<ol>
  <li>在<strong>颜色模式</strong>下，输入 HEX 颜色值或使用取色器。工具会即时展示该颜色在 8 种色觉障碍下的外观。</li>
  <li>在<strong>图片模式</strong>下，拖放图片或点击选择文件。工具在本地处理后显示 9 张并排预览——原图加 8 种模拟效果。</li>
  <li>拖动<strong>严重程度</strong>滑块（0.1–0.9）可改变红色弱、绿色弱、蓝色弱的程度；红色盲、绿色盲、蓝色盲固定为 1.0。</li>
  <li>颜色模式下，点击任意 HEX 值即可复制到剪贴板。</li>
</ol>

<h2>色觉障碍简介</h2>
<p>色觉障碍（CVD）影响眼睛锥细胞对光的反应。人类色觉依赖三种锥细胞：L 型（红色）、M 型（绿色）和 S 型（蓝色）。当某一类型缺失或功能异常时，特定颜色会变得难以区分。</p>
<ul>
  <li><strong>红色盲 / 红色弱</strong>——影响 L 锥细胞（红色感知）。红色变暗，偏向棕色或绿色。约 2% 的男性受影响。</li>
  <li><strong>绿色盲 / 绿色弱</strong>——影响 M 锥细胞（绿色感知）。最常见类型，约 6% 的男性受影响。绿色和红色看起来相似。</li>
  <li><strong>蓝色盲 / 蓝色弱</strong>——影响 S 锥细胞（蓝色感知）。罕见，影响不到 0.01% 的人群。蓝色和绿色容易混淆。</li>
  <li><strong>全色盲 / 全色弱</strong>——影响所有锥细胞类型。完全性全色盲呈灰度视觉；全色弱显著降低色彩饱和度。</li>
</ul>

<h2>无障碍设计建议</h2>
<p>将此工具与<a href="/zh/tools/color-contrast-checker/">颜色对比度检测器</a>配合使用，进行完整的无障碍审查。传达信息时不要仅依赖颜色，应同时使用形状、图案或文字标签。至少通过红色盲和绿色盲模拟测试关键 UI 元素（错误状态、图表、状态指示器），因为这两种类型覆盖了大多数受影响用户。</p>

<h2>隐私</h2>
<p>所有模拟均在浏览器端运行。颜色数据和图片不会发送到任何服务器。</p>

<h2>检查一张截图</h2>
<p>在<strong>图片模式</strong>里拖入仪表盘、带校验错误的表单或图表的截图，工具会并排显示原图和 8 种模拟结果。找出变成同一颜色的状态标签、图表系列和链接，改过的颜色再用<a href="/zh/tools/color-contrast-checker/">颜色对比度检测器</a>核对。</p>

<h2>限制</h2>
<ul>
  <li>红、绿、蓝三类使用 <a href="https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html" target="_blank" rel="noopener">Machado 等（2009）</a>的矩阵，在线性 RGB 中计算，与 R 包 <a href="https://colorspace.r-forge.r-project.org/reference/simulate_cvd.html" target="_blank" rel="noopener">colorspace</a> 在 <code>linear = TRUE</code> 时的流程相同。使用 Brettel（1997）或 Viénot（1999）模型的工具，结果会有差异。</li>
  <li>严重程度按论文的 0.1 一档调整。全色盲取线性光下的 sRGB（Rec. 709）亮度。全色弱没有公开的矩阵，工具在线性光下把原色与全色盲结果各取 50% 混合。</li>
  <li>任一边超过 600 像素的图片会先缩小到 600 × 600 以内再模拟，整页截图里的小字可能变糊。先裁出要检查的区域。</li>
  <li>颜色模式只接受 3 位或 6 位十六进制色值。</li>
</ul>
