<h2>操作步骤</h2>
<ol>
  <li>点“打开图片”，或把图片拖到工具里任意位置，也可以直接 Ctrl+V / ⌘V 粘贴截图。电脑浏览器还有“截取屏幕”：选一个窗口或屏幕，工具取一帧后立即停止共享。打开页面时显示的是示例图表。</li>
  <li>九张卡片依次是原图和 8 种模拟。切到“并排对比”可以放大看原图与某一种类型。</li>
  <li>拖动“严重程度”调整三种色弱。</li>
  <li>点卡片上的 PNG，按原尺寸保存该类型的模拟图。</li>
  <li>检查配色时切到“颜色”，每行写一个颜色，冒号前可以加名称，如 <code>涨: #F5222D</code>。支持 HEX、<code>rgb()</code>、<code>hsl()</code>、<code>oklch()</code> 和颜色名，全角输入也能识别。表格列出每个颜色在各类型下的样子，以及最接近的一对。</li>
</ol>

<h2>案例：行情页的红涨绿跌</h2>
<p>A 股行情用红色表示上涨、绿色表示下跌。以 <a href="https://ant.design/docs/spec/colors-cn" target="_blank" rel="noopener">Ant Design</a> 色板为例，红色 6 号 <code>#F5222D</code> 与绿色 6 号 <code>#52C41A</code> 在正常色觉下对比度 1.80:1，主要靠色相区分。输入这两个颜色：</p>
<ul>
  <li>绿色盲下，红变成 <code>#9E8D21</code>，绿变成 <code>#BCA933</code>，都是黄褐色，ΔEOK 0.091，对比度 1.40:1。工具判为“可区分”，但只剩明暗差。</li>
  <li>换成更深的 7 号 <code>#CF1322</code> 和 <code>#389E0D</code>，绿色盲下变成 <code>#847617</code> 与 <code>#978725</code>，ΔEOK 降到 0.058、对比度 1.26:1，被标为“难以区分”。</li>
  <li>红色盲下，6 号红变暗为 <code>#6C612A</code>，绿变成 <code>#CAB200</code>，ΔEOK 0.282、对比度 2.92:1，反而容易分开。</li>
</ul>

<p>涨跌幅数字前加“+”“−”号、配上箭头，就不再只靠颜色。中国证监会发布的<a href="https://www.csrc.gov.cn/csrc/c101954/c2334725/2334725/files/%E9%99%84%E4%BB%B63%EF%BC%9A%E9%9D%A2%E5%90%91%E8%80%81%E5%B9%B4%E4%BA%BA%E7%9A%84%E8%AF%81%E5%88%B8%E6%9C%9F%E8%B4%A7%E4%B8%9A%E7%A7%BB%E5%8A%A8%E4%BA%92%E8%81%94%E7%BD%91%E5%BA%94%E7%94%A8%E7%A8%8B%E5%BA%8F%E8%AE%BE%E8%AE%A1%E8%A7%84%E8%8C%83.pdf" target="_blank" rel="noopener">《面向老年人的证券期货业移动互联网应用程序设计规范》</a> 7.3 条也写明：颜色不应作为传达信息、表明动作、提示响应等区分视觉元素的唯一手段。</p>

<h2>检查一张截图</h2>
<p>把带状态标签的后台页面或图表截图粘贴进来，先看红色盲和绿色盲两张卡片：哪些标签、折线、图例变成了同一种黄褐色。再把可疑的颜色值（可用<a href="/zh/tools/eyedropper-color-picker/">取色器</a>从截图上取）填进“颜色”模式，确认它们的 ΔEOK。修改后的文字配色用<a href="/zh/tools/color-contrast-checker/">颜色对比度检查器</a>复核。</p>

<h2>判定标准与计算方法</h2>
<p>每个像素先从 sRGB 换算到线性光，乘以 3×3 矩阵，截到 0–1 后再编码回 sRGB。红、绿、蓝三类的矩阵来自 <a href="https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html" target="_blank" rel="noopener">Machado 等（2009）</a>。配色检查计算两个模拟色在 OKLab 中的距离 ΔEOK 和 WCAG 对比度：</p>
<ul>
  <li>小于 0.02 判为“看起来相同”。0.02 是 <a href="https://drafts.csswg.org/css-color-4/#binsearch" target="_blank" rel="noopener">CSS Color 4</a> 色域映射采用的最小可觉差。</li>
  <li>小于 0.06 判为“难以区分”。<a href="https://doi.org/10.1109/TVCG.2017.2744359" target="_blank" rel="noopener">Szafir（2018）</a>测得散点图上的点要比实验室模型大约 3 倍的色差才能被察觉，工具据此取 3 倍最小可觉差；折线、散点这类小图形至少要拉开到这个距离。</li>
  <li>0.06 及以上判为“可区分”。</li>
</ul>

<h2>与同类工具的差异</h2>
<p>2026 年 10 月 2 日实测必应中文搜索“色盲模拟器”排在前两位的 <a href="https://tool.xuecan.net/color-blindness" target="_blank" rel="noopener">tool.xuecan.net 在线色盲模拟器</a>：图片在本地处理，但一次只显示一种类型，没有下载按钮。它用 SVG 滤镜套一组矩阵，红色盲为 0.567、0.433、0 / 0.558、0.442、0 / 0、0.242、0.758，这组数值不是 Machado（2009）或 Viénot（1999）发表的矩阵。按这组矩阵在线性光下计算，<code>#F5222D</code> 得到 rgb(192, 190, 43)，<code>#52C41A</code> 得到 rgb(146, 147, 105)；Machado 模型的结果是上文的 <code>#6C612A</code> 与 <code>#CAB200</code>，红色明显更暗。</p>

<p>Chrome 开发者工具 Rendering 面板中的 Emulate vision deficiencies 用的是 Machado 矩阵，但色觉类型只有红、绿、蓝色盲和全色盲，没有色弱档位，也不能导出。它在屏幕的颜色空间里计算：在 Display P3 屏幕的 Mac 上（Chrome 152），<code>#2CA02C</code> 的蓝色盲结果是 rgb(32, 155, 136)，本工具按 sRGB 计算为 rgb(0, 155, 137)。本工具的结果与屏幕无关，下载的 PNG 在任何设备上都相同。</p>

<h2>限制</h2>
<ul>
  <li>模拟是平均观察者模型，不能代替色觉异常者本人的测试。</li>
  <li>超出 sRGB 的颜色（如 Display P3 照片）在模拟前截到 sRGB；浏览器能按 Display P3 读取图片时，工具会提示这类像素的占比。</li>
  <li>超过 16,777,216 像素的图片会缩小处理。HEIC、TIFF 只有能解码它们的浏览器（Safari）才能打开。</li>
  <li>“颜色”模式最多检查 12 个颜色，透明度会被忽略。</li>
</ul>
