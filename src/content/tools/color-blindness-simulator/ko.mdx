<h2>사용 방법</h2>
<ol>
  <li><strong>색상 모드</strong>에서 HEX 색상을 입력하거나 색상 선택기를 사용하세요. 8가지 색각 이상 유형에서 해당 색상이 어떻게 보이는지 즉시 그리드로 표시됩니다.</li>
  <li><strong>이미지 모드</strong>에서 이미지를 드래그 앤 드롭하거나 클릭하여 선택하세요. 로컬에서 처리 후 원본과 8가지 시뮬레이션 결과가 나란히 표시됩니다.</li>
  <li><strong>정도</strong> 슬라이더(0.1–0.9)로 적색약·녹색약·청색약의 강도를 바꿉니다. 적색맹·녹색맹·청색맹은 항상 1.0입니다.</li>
  <li>색상 모드에서 HEX 값을 클릭하면 클립보드에 복사됩니다.</li>
</ol>

<h2>색각 이상이란</h2>
<p>색각 이상(CVD)은 눈의 원추세포가 빛에 반응하는 방식에 영향을 미칩니다. 인간의 색각은 L-원추(적색), M-원추(녹색), S-원추(청색) 세 가지 유형에 의존합니다. 한 유형이 없거나 기능이 비정상이면 특정 색상을 구별하기 어려워집니다.</p>
<ul>
  <li><strong>적색맹 / 적색약</strong> — L-원추(적색 인식)에 영향. 빨간색이 어두워지고 갈색이나 녹색에 가까워집니다. 남성의 약 2%.</li>
  <li><strong>녹색맹 / 녹색약</strong> — M-원추(녹색 인식)에 영향. 가장 흔한 유형으로 남성의 약 6%. 녹색과 빨간색이 비슷하게 보입니다.</li>
  <li><strong>청색맹 / 청색약</strong> — S-원추(청색 인식)에 영향. 드물며 인구의 0.01% 미만. 파란색과 녹색 구별이 어렵습니다.</li>
  <li><strong>전색맹 / 부분색약</strong> — 모든 원추 유형에 영향. 완전 전색맹은 회색조 시각이 되며, 부분색약은 색상 채도가 크게 감소합니다.</li>
</ul>

<h2>접근성 디자인 팁</h2>
<p>이 도구를 <a href="/ko/tools/color-contrast-checker/">색상 명도 대비 검사기</a>와 함께 사용하여 포괄적인 접근성 감사를 수행하세요. 정보 전달에 색상만 의존하지 말고 모양, 패턴, 텍스트 레이블도 활용하세요. 적색맹과 녹색맹 시뮬레이션으로 오류 상태, 차트, 상태 표시기 등 핵심 UI 요소를 테스트하세요.</p>

<h2>개인정보</h2>
<p>모든 시뮬레이션은 브라우저에서 실행됩니다. 색상 데이터나 이미지가 서버로 전송되지 않습니다.</p>

<p>적색맹과 녹색맹에서는 이 빨간색이 칙칙한 올리브색이 되고, 적색맹에서는 훨씬 어두워집니다. L 원뿔세포가 없으면 긴 파장의 빛이 어둡게 보이기 때문입니다. 청색맹에서는 빨간색 그대로입니다. 실제 점검은 색 쌍으로 합니다. 오류 색과 성공 색을 차례로 입력하고 적색맹·녹색맹 견본을 비교하세요. 두 색이 색상으로만 구분된다면 아이콘, 텍스트, 패턴 같은 두 번째 단서를 더합니다. <a href="https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html" target="_blank" rel="noopener">WCAG 2.2 성공 기준 1.4.1</a>은 색을 정보 전달의 유일한 시각적 수단으로 쓰지 않도록 요구합니다.</p>

<h2>스크린샷 점검</h2>
<p><strong>이미지 모드</strong>에 대시보드, 검증 오류가 있는 폼, 차트의 스크린샷을 끌어다 놓으면 원본과 8가지 시뮬레이션이 나란히 표시됩니다. 같은 색으로 보이는 상태 배지, 차트 계열, 링크를 찾고, 바꾼 색은 <a href="/ko/tools/color-contrast-checker/">색상 명도 대비 검사기</a>로 확인하세요.</p>

<h2>제한</h2>
<ul>
  <li>적색·녹색·청색 유형은 <a href="https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html" target="_blank" rel="noopener">Machado 외(2009)</a>의 행렬을 선형 RGB에서 씁니다. R 패키지 <a href="https://colorspace.r-forge.r-project.org/reference/simulate_cvd.html" target="_blank" rel="noopener">colorspace</a>의 <code>linear = TRUE</code>와 같은 절차입니다. Brettel(1997)이나 Viénot(1999) 모델을 쓰는 도구와는 결과가 다를 수 있습니다.</li>
  <li>정도는 논문과 같이 0.1 단위로 바뀝니다. 전색맹은 선형광에서의 sRGB(Rec. 709) 휘도입니다. 부분색약에는 공개된 행렬이 없어, 선형광에서 원래 색과 전색맹 결과를 50%씩 섞습니다.</li>
  <li>가로나 세로가 600픽셀을 넘는 이미지는 600 × 600 안으로 줄인 뒤 처리하므로, 전체 페이지 스크린샷에서는 작은 글자가 흐려질 수 있습니다. 점검할 부분을 먼저 잘라 내세요.</li>
  <li>색상 모드는 3자리 또는 6자리 16진수 값만 받습니다.</li>
</ul>
