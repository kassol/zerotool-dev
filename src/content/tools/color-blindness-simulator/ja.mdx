<h2>使い方</h2>
<ol>
  <li><strong>カラーモード</strong>：HEXカラーを入力するかカラーピッカーを使用します。8種類の色覚特性でその色がどう見えるか、即座にグリッド表示されます。</li>
  <li><strong>画像モード</strong>：画像をドラッグ＆ドロップするか、クリックして選択します。ローカルで処理され、元画像と8種類のシミュレーション結果が並べて表示されます。</li>
  <li><strong>程度</strong>のスライダー（0.1〜0.9）で 1型・2型・3型色弱の強さを変えられます。1型・2型・3型色覚は常に 1.0 です。</li>
  <li>カラーモードでは、HEX値をクリックするとクリップボードにコピーできます。</li>
</ol>

<h2>色覚特性について</h2>
<p>色覚特性（CVD）は、目の錐体細胞の光への反応に影響します。人間の色覚はL錐体（赤）、M錐体（緑）、S錐体（青）の3種類に依存しています。いずれかが欠如または機能不全の場合、特定の色の区別が困難になります。</p>
<ul>
  <li><strong>1型色覚 / 1型色弱</strong> — L錐体（赤の知覚）に影響。赤が暗く見え、茶色や緑に近づきます。男性の約2%。</li>
  <li><strong>2型色覚 / 2型色弱</strong> — M錐体（緑の知覚）に影響。最も一般的で、男性の約6%。緑と赤が似て見えます。</li>
  <li><strong>3型色覚 / 3型色弱</strong> — S錐体（青の知覚）に影響。まれで、人口の0.01%未満。青と緑の区別が困難。</li>
  <li><strong>全色盲 / 色弱</strong> — すべての錐体タイプに影響。完全な全色盲はグレースケール視覚になり、色弱は色の彩度が大幅に低下します。</li>
</ul>

<h2>アクセシブルなデザインのヒント</h2>
<p>このツールを<a href="/ja/tools/color-contrast-checker/">カラーコントラストチェッカー</a>と併用して、包括的なアクセシビリティ監査を行いましょう。情報伝達に色だけに頼らず、形状・パターン・テキストラベルも活用してください。少なくとも1型色覚と2型色覚のシミュレーションで、エラー状態・チャート・ステータスインジケーターなど重要なUI要素をテストしましょう。</p>

<h2>プライバシー</h2>
<p>すべてのシミュレーションはブラウザ内で実行されます。カラーデータや画像がサーバーに送信されることはありません。</p>

<h2>例：初期値の赤が各タイプでどう見えるか</h2>
<p>ツールを開いたときの色は <code>#E74C3C</code> です。既定の程度 0.6 で表示される色見本は次のとおりです。</p>
<table>
  <thead><tr><th>タイプ</th><th>シミュレーション色</th><th>タイプ</th><th>シミュレーション色</th></tr></thead>
  <tbody>
    <tr><td>1型色覚</td><td><code>#786D39</code></td><td>1型色弱</td><td><code>#A16A38</code></td></tr>
    <tr><td>2型色覚</td><td><code>#9F8F36</code></td><td>2型色弱</td><td><code>#B18137</code></td></tr>
    <tr><td>3型色覚</td><td><code>#FE1B49</code></td><td>3型色弱</td><td><code>#F13D42</code></td></tr>
    <tr><td>全色盲</td><td><code>#828282</code></td><td>色弱</td><td><code>#BE6C67</code></td></tr>
  </tbody>
</table>
<p>1型・2型ではこの赤がくすんだオリーブ色になり、1型ではさらに大きく暗くなります。L 錐体がないと長い波長の光が暗く見えるためです。3型では赤のままです。実際の確認は色の組で行います。エラー色と成功色を順に入力し、1型・2型の色見本を見比べてください。色相だけで区別している組なら、アイコン、文字、模様などもう 1 つの手がかりを足します。<a href="https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html" target="_blank" rel="noopener">WCAG 2.2 達成基準 1.4.1</a> は、色を情報を伝える唯一の視覚的手段にしないことを求めています。</p>

<h2>スクリーンショットを確認する</h2>
<p><strong>画像モード</strong>にダッシュボード、入力エラーのあるフォーム、グラフのスクリーンショットをドロップすると、元画像と 8 種類のシミュレーションが並びます。同じ色に見えてしまうステータス表示、グラフの系列、リンクを探し、変更した色は<a href="/ja/tools/color-contrast-checker/">カラーコントラストチェッカー</a>で確認してください。</p>

<h2>制限</h2>
<ul>
  <li>1型・2型・3型は <a href="https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html" target="_blank" rel="noopener">Machado ほか（2009）</a>の行列を線形 RGB で使います。R パッケージ <a href="https://colorspace.r-forge.r-project.org/reference/simulate_cvd.html" target="_blank" rel="noopener">colorspace</a> の <code>linear = TRUE</code> と同じ手順です。Brettel（1997）や Viénot（1999）のモデルを使うツールとは結果が異なることがあります。</li>
  <li>程度は論文と同じ 0.1 刻みです。全色盲は線形光での sRGB（Rec. 709）輝度です。「色弱」（achromatomaly）には公開された行列がないため、線形光で元の色と全色盲の結果を 50% ずつ混ぜています。</li>
  <li>縦横どちらかが 600 ピクセルを超える画像は 600 × 600 に収まるよう縮小してから処理するため、ページ全体のスクリーンショットでは小さな文字がぼやけることがあります。確認したい部分を切り出してから使ってください。</li>
  <li>カラーモードは 3 桁または 6 桁の 16 進数だけを受け付けます。</li>
</ul>
