  - question: "UPDATE や DELETE を実行すると元のファイルは変わりますか？"
    answer: "変わりません。ブラウザは選択されたファイルへの書き込み権限を持っていません。SQL はメモリ上のコピーに対して実行されるため、INSERT・UPDATE・DELETE・CREATE は動作し、テーブル一覧も更新されますが、再読み込みや別ファイルを開いた時点で変更は消えます。編集後のコピーをダウンロードする機能はありません。ディスク上のファイルを変更するには sqlite3 コマンドラインか DB Browser for SQLite を使ってください。"

  - question: "「SQLite データベースではありません」と表示されるのはなぜ？"
    answer: "SQLite 3 のファイルは必ず 16 バイトのヘッダー SQLite format 3 で始まります。これがなければ別形式のファイルか、暗号化されたファイルです。SQLCipher や SQLite Encryption Extension はヘッダーごと暗号化するため、暗号化 DB はここでは開けません。sqlcipher で復号するか、SQLCipher に対応した DB Browser for SQLite で開いてください。"
  - question: "最近書き込んだ行が見えないのはなぜ？"

<h2>使い方</h2>

<ol>
  <li><code>.db</code>・<code>.sqlite</code>・<code>.sqlite3</code> ファイルをドロップエリアに置くか、クリックして選択します。</li>
  <li>左の一覧からテーブルかビューを選びます。データの上に列名・型・主キー・インデックス・元の <code>CREATE</code> 文が表示されます。</li>
  <li><strong>前へ</strong> / <strong>次へ</strong> で 100 行ずつページ送りします。</li>
  <li>エディタに任意の SQL を書き、<strong>SQL 実行</strong>か Ctrl/Cmd + Enter で実行します。</li>
  <li><strong>CSV エクスポート</strong>でテーブル全体、または直前のクエリ結果全体を保存します。</li>
</ol>

<h2>ブラウザで SQLite を開くのが向いている場面</h2>

<ul>
  <li><strong>エージェントやスクリプトが書き込んだ内容の確認。</strong>コーディングエージェントがマイグレーションやテストデータ投入を行ったら、信用する前にファイルを開いて行を目で確かめます。</li>
  <li><strong>アプリのローカルデータの閲覧。</strong>ブラウザ、モバイルアプリ、Electron アプリ、多くの CLI は状態を SQLite に保存しています。ファイルを取り出せば、デスクトップクライアントを入れずに中身を読めます。</li>
  <li><strong>データの受け渡し。</strong>クエリを実行して CSV にし、それを渡します。データベース本体は手元に残ります。</li>
</ul>

<h2>仕組み</h2>

<p>ページはまずファイル先頭の 100 バイトだけを読み、SQLite ヘッダーを確認します。SQLite エンジン（sql.js、圧縮後約 340 KB）はこの確認を通過してから取得するため、ページを開くだけでは追加の読み込みは発生せず、別形式のファイルでダウンロードが走ることもありません。その後ファイル全体をインメモリデータベースとして SQLite に渡します。テーブル構造は <code>pragma_table_info</code> と <code>pragma_index_list</code> から取得し、テーブル名・列名はすべて引用符で囲むため、空白や引用符、日本語を含む名前も扱えます。</p>

<h2>対応範囲</h2>

<p>このツールは 100 MB までの SQLite 3 ファイル 1 つを開いて読むものです。変更をファイルに書き戻すことはなく、<code>-wal</code> / <code>-journal</code> ファイルは読まず、暗号化 DB も開きません。SpatiaLite のジオメトリテーブル、FTS5 全文検索インデックス、R-Tree インデックスなど拡張依存の仮想テーブルは、行の代わりに SQLite のエラーを表示します。これらのケースは、手元の sqlite3 コマンドラインか DB Browser for SQLite を使ってください。</p>
